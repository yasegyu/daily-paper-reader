## 摘要
大语言模型（LLM）智能体通过多轮推理-行动来求解长时程任务，仅在终止时获得一个验证信号。已部署的智能体会面对一系列相关任务，这使其轨迹成为改进的自然资源。上下文自适应智能体将反思、记忆或技能以文本形式存储，因此复用取决于能否检索到恰当的经验，以及一个冻结的策略能否将其执行。我们研究在线智能体测试时训练（Online Agentic Test-Time Training, OaTTT），即在部署期间用智能体自身的执行轨迹训练 LLM 的权重。智能体对每个任务只执行一次，在数据流上单遍通过，而执行轨迹及其验证结果就是唯一的学习信号，用于更新跨任务持久保留的权重。直接模仿或强化这一次尝试所生成的 token 会使策略不稳定。我们提出 ASCENT（Agentic Self-distillation for Cross-task EvolutioN at Test-time，面向测试时跨任务演化的智能体自蒸馏），它转而自蒸馏已验证经验。LLM 的一个稳定版本——其冻结的初始副本——将已验证轨迹作为特权信息接收，并借助这种事后视角预测沿该轨迹的下一 token 分布。将其蒸馏到持久化的 LoRA 快速权重中，可更新智能体以应对后续任务，而无需外部参考解或更强的教师模型。通过进一步去除无效动作轮次，ASCENT 蒸馏出增强的特权经验，以实现更高效的执行。我们刻画了其总体目标以及稀疏结果选择的局限。在 ALFWorld、WebShop 和 AppWorld 上，跨不同模型规模，ASCENT 随着经验积累提升了任务成功率和交互效率，优于在线自适应方法，并可迁移到未见场景，表明智能体无需单独的训练阶段或记忆检索，就能将已验证经验固化到其权重中。项目页面：https://artificer-ai-lab.github.io/ASCENT

## Abstract
A large language model (LLM) agent solves long-horizon tasks through many reasoning-action turns, with one verification signal at termination. Deployed agents face streams of related tasks, making their trajectories a natural resource for improvement. In-context adaptation agents store reflections, memories, or skills as text, so reuse depends on retrieving the right experience and on a frozen policy executing it. We study Online Agentic Test-Time Training (OaTTT), which trains the LLM's weights on its own execution trajectories during deployment. The agent executes each task once, in one pass over the stream, and the executed trajectory with its verification result is the only learning signal for weight updates that persist across tasks. Directly imitating or reinforcing the generated tokens of this single attempt destabilizes the policy. We introduce ASCENT (Agentic Self-distillation for Cross-task EvolutioN at Test-time), which instead self-distills verified experience. A stable version of the LLM, its frozen initial copy, receives the verified trajectory as privileged information and predicts next-token distributions along it with this hindsight. Distilling them into persistent LoRA fast weights updates the agent for later tasks, without an external reference solution or stronger teacher. By further removing invalid-action turns, ASCENT distills enhanced privileged experience for more efficient execution. We characterize its population target and the limits of sparse outcome selection. Across ALFWorld, WebShop, and AppWorld at varied model scales, ASCENT improves task success and interaction efficiency as experience accumulates, outperforms online adaptation methods, and transfers to held-out scenes, showing that an agent can consolidate verified experience into its weights without a separate training phase or memory retrieval. - **现有上下文适应的局限**：Reflexion、ReasoningBank、ACE、MemP 等方法把反思、记忆或技能以文本形式存储在 harness 层，推理时依赖检索。其效果受限于：能否检索到正确经验，以及一个冻结策略能否可靠执行检索到的经验。
- **现有测试时训练与强化学习的局限**：部分 TTT 方法只在单个 episode 内适配并随后重置；其他方法需要预部署训练适配行为，或需要每个任务多次采样尝试；RL 后训练通常也在部署前完成，且依赖大量尝试或学习到的 critic。
- **论文提出的 OaTTT 设定**：Online Agentic Test-Time Training（OaTTT）要求智能体在部署中单遍通过任务流，每个任务只执行一次，执行轨迹及其验证结果就是唯一且即时的学习信号，权重更新跨任务持久保留。
- **核心研究问题**：一个已部署的智能体，能否把自身每条已验证执行轨迹转化为持久权重更新，从而提升后续任务成功率？
- **关键发现**：直接模仿或强化单次生成的 token 会破坏策略稳定性，导致策略漂移、有效动作率下降、成功率低于未训练基座。ASCENT 通过自蒸馏已验证经验来规避这一问题。

## 2. 方法论

### 2.1 核心思想

- **ASCENT（Agentic Self-distillation for Cross-task EvolutioN at Test-time）**：不直接以生成 token 为硬目标，而是用 LLM 的冻结初始副本作为稳定教师。
- **自蒸馏机制**：教师以“已验证轨迹”为特权信息（privileged information），在每个学生前缀上预测下一 token 分布；学生通过前向 KL 匹配这些分布，将经验写入持久 LoRA 快速权重。
- **验证门控**：只有验证通过的 episode 才触发更新，失败 episode 跳过更新。验证结果充当拒绝采样，无需价值模型或 critic。

### 2.2 OaTTT 协议与直接基线

- 任务流 \(X_{1:N}\)，episode \(i\) 单次尝试产生轨迹 \(\tau_i\) 和验证结果 \(v_i \in \{0,1\}\)，更新规则为 \((\theta_{i+1}, M_{i+1}) = \text{Evolve}(\theta_i, M_i; x_i, \tau_i, v_i)\)。
- 报告结果遵循 prequential 协议：每个任务先评分，其轨迹之后才能影响策略。
- 直接基线包括：
  - 模仿类：Online ungated imitation、Online RFT、Online RFT+KL。
  - 策略梯度类：Online REINFORCE、Online REINFORCE++。
- 这些方法在统一损失中对生成 token 施加带符号权重 \(\omega_{i,t,j}\)。问题在于：它们只学习生成 token 的硬目标，降低某 token 概率只是把概率转移给策略已偏好的 token；随着在线更新，策略会偏离初始模型、熵崩溃、有效动作减少。

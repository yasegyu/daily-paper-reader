## 摘要
长对话智能体在我们的日常生活中已变得不可或缺。它们必须记住很久之前说过的话，以便帮助我们高效完成任务，而无需用户反复重复指令和上下文。然而，主要问题在于指令和上下文会随时间变化，因此智能体必须能够相应适应。一个有用的记忆系统应同时保留当前状态和历史状态，区分过时信息与活跃知识，检索与查询相适配的证据，并避免反复调用大语言模型来重写先前的交互。我们提出 MINDSET，一种记忆控制器，它将对话存储为不可变的情节，并通过最小能量状态转移将其组织为版本化模式。每个新到来的情节可以强化、取代、拆分或创建一个模式。转移决策在表示失真、矛盾、历史损害、碎片化和内部不一致之间进行权衡，而迟滞机制可防止孤立的矛盾过早重写稳定的记忆。我们在包含 850 个问题的可复现样本（700 个 LoCoMo + 150 个 MemoryAgentBench）上，将 MINDSET 与 5 种记忆系统进行了评估。MINDSET 在 LoCoMo 上取得了所观察到的最高答案 F1，同时在检索排序（Recall@8、MRR 和 nDCG@8）上显著优于次优方法 LightMem（Holm 校正后 p<0.01）。它在 MemoryAgentBench 上也取得了所观察到的最高分数，尽管相对差异较小。消融实验表明，受控碎片化和模式感知分配是对答案质量贡献最大的因素。此外，使用 GLM-4.7 和 Gemma-4-31B 进行的 700 问题跨模型评估支持了模型独立性。这些结果表明，长期记忆可以更好地作为受约束的状态管理来处理，而不是持续摘要。

## Abstract
Long conversational agents have become essential in our daily lives. They must remember what was said long back in order to help us efficiently complete a task without needing the user to repeat instructions and context repeatedly. However, the main issue is that instructions and context change over time and so the agents must be able to adapt accordingly. A useful memory system should preserve both current and historical states, distinguish stale information from active knowledge, retrieve evidence appropriate to the query and avoid repeatedly invoking a large language model to rewrite prior interactions. We introduce MINDSET, a memory controller that stores a conversation as immutable episodes and organizes them into versioned schemas through minimum-energy state transitions. Each incoming episode may reinforce, supersede, split or create a schema. The transition decision balances representation distortion, contradiction, historical damage, fragmentation and internal inconsistency, while hysteresis prevents isolated contradictions from prematurely rewriting stable memory. We evaluate MINDSET against 5 memory systems on a reproducible sample of 850 questions (700 LoCoMo + 150 MemoryAgentBench). MINDSET obtains the highest observed LoCoMo answer F1 while significantly improving retrieval ranking (Recall@8, MRR and nDCG@8) over the second best method LightMem (p<0.01 after Holm correction). It obtains the highest observed scores on MemoryAgentBench although the relative difference is low. Ablations identify controlled fragmentation and schema-aware assignment as the largest contributors to answer quality. Additionally, a 700-question cross-model evaluation with GLM-4.7 and Gemma-4-31B supported model independence. These results show that long-term memory can be better handled as constrained state management rather than continual summarization.

## 2. 方法论

**核心思想**

- 对话以**不可变情节（episode）**形式存储（对话 ID、会话、时间戳、说话人、原始文本及抽取的实体/角色/上下文/属性/变化线索特征）。
- 情节被组织成**带版本的 schema**：schema 不是生成的摘要，而是对支持情节与例外情节的结构化索引，包含时间有效性、活跃/历史状态、前驱-后继链接、质心与中心点（medoid）。
- 每个新情节通过**最小能量状态转移**选择四种动作之一：
  - **REINFORCE**：向兼容的活跃 schema 添加证据；
  - **SUPERSEDE**：关闭活跃 schema 并创建时间上相连的后继；
  - **SPLIT**：创建共存的上下文分支；
  - **NEW**：开启独立 schema。
- 所有动作下原始情节始终不可变。

**关键技术细节**

- **兼容性**：先检索最多 ks=6 个邻近活跃 schema，用稠密相似度 d 及实体、角色、上下文、主题匹配度加权求和并截断到 [0,1]。
- **矛盾度 p**：仅对 schema 中已存在的单值槽位计算，用 Jaccard 相似度衡量新旧值差异（偏好、计划、拥有物、经历、能力、厌恶视为多值并排除）。
- **时间势 τ 与上下文势 κ**：由矛盾、时间顺序、显式变化线索、重复度、上下文/角色/语义不匹配等信号构成。
- **可行性前置判断**：SUPERSEDE 需 p ≥ θ_sup，SPLIT 需 κ ≥ θ_split，当 K ≥ θ_new 时移除 NEW；硬性新话题守卫在 K 低、无主题匹配且 d 低时强制 NEW。
- **能量函数**：E(a) = w_d·D_a + w_c·C_a + w_h·H_a + w_f·F_a + w_i·I_a，分别惩罚表示失真、未解决矛盾、历史损害、碎片化与内部不一致。
  - 矛盾成本仅在 REINFORCE 合并不兼容证据时计入；SUPERSEDE/SPLIT 因保留旧状态而不支付该成本。
  - 碎片化项包含活跃 schema 数、微型 schema 数及投影惩罚。
  - 不一致项依动作不同而取不同形式（如 SUPERSEDE 取 max(0, κ−τ)）。
- **迟滞机制**：设置 stay margin（0.06）与 switch margin（0.18），并对 τ>κ 的情况按 ρ=0.55 缩减切换边际；孤立的强矛盾（p≥0.60 且无重复、无显式变化线索）被强制归入 REINFORCE，防止过早重写稳定记忆。
- **检索阶段**：本地路由器将信息需求分为当前/历史/上下文/通用四类，组合三条通道——直接检索（稠密+BM25）、schema 介导检索（回扩到支持/例外/中心/连续性情节）、版本检索（暴露活跃与历史状态的 medoid）；使用 ms-marco-MiniLM-L6-v2 重排、all-MiniLM-L6-v2 嵌入，候选池 40，返回 8 条证据。
- **证据预算归一化**：候选记忆切分为 768 token 段落（96 token 重叠），最多 8 段、8,000 证据 token、每个原始记忆最多 3 段，并保留来源 ID 与偏移量。
- **效率**：无梯度训练，摄取与检索阶段均不调用外部大模型；学习组件仅为冻结的现成本地编码器。

## 3. 实验设计

**数据集与场景**

- **LoCoMo**：冻结的 700 题清单，来自 10 个对话各 70 题；类别为单跳 151、时间 151、多跳 96、开放域 151、对抗 151。
- **MemoryAgentBench (MAB)**：150 个样本，含 125 个上下文学习（ICL）示例（5 个来源组各 25 个）与 25 个推荐示例。
- 合计 850 题，另有 300 题的 LoCoMo 开发集用于调参（与测试集在问题 ID 层面不重叠）。

**对比方法（5 个基线）**

- Vector RAG（MiniLM 稠密嵌入 + 余弦 top-k）
- Long Context Memory（按时间全历史，仅超 20,000 UTF-8 字节时从最旧轮次截断）
- MemoryBank（官方架构改编，GPT-OSS 替换原 GPT-3.5 摘要器）
- LightMem（保留关键设计选择的复现）
- Nemori（官方实现的复现）

**答案模型与生成设置**

- 主模型：Cerebras 的 gpt-oss-120b；温度 0、最大输出 4,096 token、结构化 JSON 校验、完整性重试。
- 跨骨干实验：zai-glm-4.7 与 gemma-4-31b，1 题/请求、输出上限 1,024 token、提示守卫 160,000 字节。

**评估指标**

- LoCoMo：答案 F1、Recall@8、Precision@8、MRR、nDCG@8、证据召回率。
- MAB：ICL 首行精确匹配、推荐 Recall@5，以及补充的 ICL token F1 与推荐 F1@5。
- 统计方法：在 10 个对话簇上做双侧精确配对符号翻转置换检验（2^10=1,024 种符号分配）与簇 bootstrap，并在各指标族内做 Holm 校正。

## 摘要
大型语言模型（LLM）智能体越来越多地在交互式环境中运行，它们需要通过观察、行动和反馈做出序贯决策。尽管记忆可以帮助智能体复用经验，但现有工作以孤立方式设计记忆，而收集足够多的轨迹来填充记忆成本高昂。现有的共享记忆方法通过跨任务和环境汇集情景记忆来缓解孤立经验问题。然而，共享记忆的检索受到粒度挑战：检索到的记忆要么过于具体，无法保持当前情境依据，要么过于粗略，无法支持下一步行动。在这项工作中，我们提出 MemCo，一种以记忆为中心的协作框架，用于将 LLM 智能体泛化到未见的交互式环境。它维护互补的局部和全局记忆空间，在局部保留环境特定细节，同时将从局部轨迹中归纳出的可迁移工作流提升到全局记忆。在线交互期间，MemCo 根据智能体的当前状态和决策阶段路由相关的局部和全局记忆，使智能体能够复用其他智能体的经验，而不会盲目迁移环境特定细节。在交互式决策基准上的实验表明，与孤立记忆和共享记忆基线相比，MemCo 提高了任务成功率并减少了冗余探索。我们的代码可在 https://github.com/SYannL/nvdamas 获取。

## Abstract
Large language model (LLM) agents increasingly operate in interactive environments, where they need to make sequential decisions through observation, action, and feedback. Although memory can help agents reuse experience, existing work designs memory in isolation, where collecting enough trajectories to populate it is expensive. Existing shared-memory approaches mitigate isolated experience by pooling episodic memories across tasks and environments. However, retrieving shared memory is challenged by the granularity, where retrieved memories can be either too specific to preserve current grounding or too coarse to support the next action. In this work, we propose MemCo, a memory-centric collaboration framework for generalizing LLM agents to unseen interactive environments. It maintains complementary local and global memory spaces, preserving environment-specific details locally while promoting transferable workflows induced from local trajectories to global memory. During online interaction, MemCo routes relevant local and global memories in terms of the agent's current state and decision phase, enabling agents to reuse the experience of other agents without blindly transferring environment-specific details. Experiments on interactive decision-making benchmarks show that MemCo improves task success and reduces redundant exploration compared with isolate-memory and shared-memory baselines. Our code is available at https://github.com/SYannL/nvdamas.

- **核心目标**：让不同环境中独立行动的智能体能够互相利用经验，同时避免盲目迁移源环境特定信息，从而泛化到**未见交互环境**。

### 2. 方法论

- **核心思想**：维护互补的**局部记忆**与**全局记忆**：
  - 局部记忆：保留环境特定细节、具体案例和当前情境依据；
  - 全局记忆：从局部轨迹中抽象出可迁移的工作流、规则和可行动知识。
- **三大模块**：
  1. **局部记忆构建**：
     - 将每条轨迹转为 episodic graph，节点包括状态、动作、反馈、下一状态，边表示时序转移；
     - 跨 episode 进行结构合并，得到局部记忆图 \(G_i^l\)；
     - 提取四类模式记录 \(P_i^l\)：工作流、前置条件、修复、失败模式；可行动知识 \(E_i^l\)；具体案例与反思 \(R_i^l\)；
     - 为可共享记录维护支持、矛盾、无进展证据；同一记录、同一来源范围、同一 episode 内最多归约为一个带符号投票，形成 episode-reduced 计数 \(n_i^+(p), n_i^-(p), n_i^0(p)\)。
  2. **渐进式全局记忆协作**：
     - 对可共享记录 \(p \in P_i^l \cup E_i^l\) 做抽象 \( \bar p = Abstract(p)\)：替换具体实体为任务角色，移除 episode/scene 锚点，保留记录类型、适用条件、动作顺序或关系、结果；
     - 用精确 abstract key 分组，聚合跨智能体的 episode-reduced 计数：
       \[
       n_\omega(\bar p)=\sum_{i,p':Abstract(p')=\bar p} n_i^\omega(p'),\quad \omega\in\{+,-\}
       \]
     - 使用单侧 Wilson 下置信界 \(W(\bar p)\) 作为有限证据 promotion 分数：
       \[
       W(\bar p)=\frac{s\rho^+ + z^2/2 - z\sqrt{s\rho^+(1-\rho^+)+z^2/4}}{s+z^2}
       \]
       其中 \(s=n^++n^-\)，\(\rho^+=n^+/s\)，\(z=\Phi^{-1}(1-\alpha)\)；
     - 当 \(W(\bar p)\ge \lambda\) 且通过结构完整性、低信息过滤后，将抽象记录合并进全局记忆 \(M^g\)；
     - 定理 3.1 给出有限证据修正：\(0\le \rho^+-W(\bar p)\le z/(2\sqrt{s})\)，说明证据越少，Wilson 分数相对经验支持率折扣越大。
  3. **查询引导记忆支持**：
     - 每步构造查询 \(q_t=Q(g,x_t,A_t,\tau_{<t})\)，分别检索局部和全局记忆：
       \[
       S_t^l=\mathcal R(q_t,M_i^l,k^l),\quad S_t^g=\mathcal R(q_t,M^g,k^g)
       \]
     - 相关性由三个互补维度组成：
       \[
       r(m,q_t)=r_x(m,q_t)+r_p(m,q_t)+r_g(m,q_t)
       \]
       分别衡量当前状态/动作一致性、任务阶段/进度兼容性、目标与功能角色对齐；
     - 先做硬过滤：若记录要求条件与当前状态矛盾，或所需动作不在 \(A_t\) 中，则排除；
     - 再结合证据、动作绑定、来源上下文和软冲突惩罚排序，并在预算 \(k^l=k^g=5\) 内做有界选择；
     - 组合为三种支持角色：grounding、workflow、reflection，渲染为 \(C_t=[c_t^{ground},c_t^{workflow},c_t^{reflection}]\)，用于下一步动作预测。
- **关键特点**：全局记录不是直接复制进 prompt，而是先绑定到当前对象、目的地、工具和可用动作；不兼容的源环境指导会被排除。

### 3. 实验设计

- **Benchmark / 数据集**：
  - **ALFWorld**：文本具身交互，含 Familiar Layout（valid_seen）和 Held-out Layout（valid_unseen）；
  - **PDDL**：符号规划，含 Gripper、Barman、Blockworld、Tyreworld；
  - **FEVER**：事实核查，分类 Supports / Refutes / NEI；
  - **ScienceWorld**：小学科学实验交互。
- **对比方法**：
  - ICL：无持久记忆的上下文学习；
  - A-Mem：长期记忆架构；
  - MemSkill：可学习记忆管理技能；
  - MemRL：基于强化学习/值决策的自演化记忆；
  - G-Memory：多智能体分层图记忆。
- **Backbone**：
  - 主实验：Qwen3-4B、GPT-4o-mini、Qwen3-32B；
  - 额外：Claude-Haiku-4.5、Gemini-2.5-flash-lite、DeepSeek-v4-flash；
  - ScienceWorld 主用 Qwen3-32B。
- **实现设置**：
  - 使用 AutoGen；

  - 记忆从指定源分区构建，评估使用不相交任务；评估轨迹不写回记忆。

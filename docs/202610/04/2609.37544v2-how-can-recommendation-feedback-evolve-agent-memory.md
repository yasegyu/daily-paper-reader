## 摘要
内容生成智能体持续接收来自推荐系统的曝光、点击、转化和负反馈，为记忆演化提供真实世界的结果信号。然而，这些信号具有延迟性和噪声，受到受众构成、展示位置和推荐策略的混杂影响，并且可能源于多个记忆的共同作用，导致准确归因困难。现有方法主要依赖即时反馈或语义检索，因此难以可靠地将推荐结果转化为记忆适应度。为应对这一挑战，我们提出 TIDE（Trajectory-Informed Directed Memory Evolution，轨迹引导的有向记忆演化），一种由延迟推荐反馈驱动的外部记忆演化框架。我们进一步引入记忆演化增益（Memory Evolution Gain, MEG），用于衡量演化后的记忆在严格未来任务上相对于无记忆基线的效用提升。TIDE 将记忆视为容量受限的经验群体：时序与语义信用分配估计上下文适应度，而责任信用则根据生成过程中所引用的记忆来分配结果信号。这些信号随后被用于强化、交叉、变异或淘汰记忆。在一个电商会员营销内容生成智能体上，TIDE 在离线时序回放中实现了 +7.75 个百分点的 MEG，并在在线 A/B 测试中显著提升了独立点击率（UCTR）和激活率。在延迟标签基准上，TIDE 在对比方法中取得了最低的平均绝对误差（MAE）和均方根误差（RMSE），以及最高的 MEG，证明了其有效性。

## Abstract
Content-generation agents continuously receive impressions, clicks, conversions, and negative feedback from recommendation systems, providing real-world outcome signals for memory evolution. However, these signals are delayed and noisy, confounded by audience composition, placement, and recommendation policies, and may result from the combined influence of multiple memories, making accurate attribution difficult. Existing methods rely primarily on immediate feedback or semantic retrieval and therefore struggle to reliably translate recommendation outcomes into memory fitness. To address this challenge, we propose TIDE (Trajectory-Informed Directed Memory Evolution), an external memory evolution framework driven by delayed recommendation feedback. We further introduce Memory Evolution Gain (MEG), which measures the utility improvement of evolved memory over a no memory baseline on strictly future tasks. TIDE treats memory as a capacity-constrained population of experiences: temporal and semantic credit assignment estimates contextual fitness, while responsibility credit distributes outcome signals according to the memories referenced during generation. These signals are then used to reinforce, crossover, mutate, or evict memories. On an e-commerce membership marketing content-generation agent, TIDE achieves a +7.75-percentage-point MEG in offline temporal replay and significantly improves both unique click-through rate (UCTR) and activation rate in an online A/B test. On a delayed-label benchmark, TIDE achieves the lowest mean absolute error (MAE) and root mean squared error (RMSE) and the highest MEG among the compared methods, demonstrating its effectiveness.

- **现有路径的两难**：

- **核心难点**：推荐反馈只揭示内容在特定投放环境中的表现，它**延迟到达、受受众/位置/推荐策略混杂、且一次生成可能由多个记忆共同作用**，因此难以判断哪条记忆应对结果负责。
- **核心研究问题**：如何把这类结果反馈转化为能提升未来任务的智能体记忆？

- **整体含义**：论文在**生成器参数冻结**的前提下，把记忆演化重新表述为"延迟、情境依赖结果下的适应度评估与多级信用分配"问题，为内容生成智能体提供可评估、可追溯的持续适配框架。

## 2. 方法论：TIDE（Trajectory-Informed Directed Memory Evolution）

### 2.1 核心思想

- 将记忆视为**容量受限的经验种群**（population of experiences），而非无界增长的日志。
- 生成器冻结，仅更新外部记忆；通过**三级信用分配**把延迟推荐结果转成记忆级适应度，再以演化算子（强化/交叉/变异/淘汰）+ 容量约束选择更新种群。
- 问题形式化：记录 $D_i=(x_i,a_i,T_i,G_i)$（请求、生成素材、完整可观测生命周期+投放情境、记忆使用轨迹）；更新策略 $\mu$ 把 $M_t \to M_{t+1}$；MEG 定义为
  $$\text{MEG}_H(\mu;\mu_0)=\bar U_H(\mu)-\bar U_H(\mu_0)$$

### 2.2 三级信用分配（关键技术细节）

- **① 时序信用 $C_{temp}$（结果可靠性）**
  - 输出 $(\tilde b u_i, z^{temp}_i)$：生命周期对齐的多目标结果摘要 + 二元有效性指示。
  - $z^{temp}_i=1$ 需满足：素材身份/版本一致、所需投放阶段被观测、延迟转化已充分回流、无素材或推荐策略变更导致跨阶段不可比；否则记录挂起。
  - 用 $\tilde b u_i=\text{LifecycleSummary}(T_i)$ 保留分阶段曝光/互动/转化及其变化与不确定性，**不把 CTR、CVR 等潜在冲突指标压成单一标量**。

- **② 语义信用 $C_{sem}$（情境化归因）**
  - 从历史/同期流量中按商品、受众、活动阶段、位置、推荐版本匹配**对照集 $N_i$**，并构造环境记录 $E_i$（活动日历、大促、季节事件、热点、流量桶、推荐状态变化）。
  - 输出 $(\tilde b f_i, e_i, z^{sem}_i)$，其中 $\tilde b f_i$ 是相对匹配对照的多目标情境适应度，$e_i=(d_i,c_i,s_i)$ 分别表示**可编辑内容决策**（卖点选择、信息密度、语体、行动号召等）、**对应投放情境与适用条件**、**支持/反证证据链**。
  - 例：若目标与对照在大促预热期呈现相似 UCTR 上升，则视为环境效应而非内容效应；只有目标保留与特定内容决策相关的相对优势时才形成正向证据。控制不足、目标冲突无法解释、估计不稳定或反例未解时置 $z^{sem}_i=0$。

- **③ 责任信用 $C_{resp}$（多记忆归因）**
  - 对每条记忆 $m$，三重条件同时满足才计责：
    $$z^{resp}_{i,m}=I[m\in \text{Used}(G_i)]\cdot I[\text{Align}(m,e_i)]\cdot I[\text{CF}(m;x_i,a_i,e_i,M_t)]$$
    即**实际被使用**、**与目标决策语义相关**、**移除后经反事实重放会改变该决策**。
  - 责任集 $R_i=\{m: z^{resp}_{i,m}=1\}$；仅被检索但未影响决策的记忆不获信用。
  - 归因状态 $\kappa^{attr}_i\in\{0,1,2\}$：0=不可验证，1=归因到已有记忆（累积 $\tilde b f_i$ 与 $e_i$），2=确认新颖但无记忆覆盖（生成无父代的临时候选）。

### 2.3 演化算子与容量约束选择

- **强化（Reinforce）**：仅在证据有效、情境一致、可溯源时追加结论与适用条件，不越出观测情境泛化。
- **交叉/合并（Crossover/MERGE）**：合并互补记忆，保留各自情境条件与例外，仅在证据支持时消解冲突；不合并受众/渠道/位置/阶段不兼容的记忆。
- **变异/修订（Mutate/REVISE）**：选择 retain/narrow/revise/split 中最小操作，保留仍被支持的内容与溯源，情境不一致时优先收窄或拆分而非全局覆盖。
- **淘汰（Evict）**：综合证据可靠性、情境有用性、责任历史、冗余、冲突与时效性给出淘汰评分；不因"旧"或"少被检索"而删除；保护覆盖唯一任务/情境的记忆。最终删除由 GovernAndSelect 在固定容量下执行，保留溯源与版本用于审计。
- **种群治理**：
  $$M_{t+1}=\mu_{TIDE}(M_t,D_i,H_t;B)=\text{GovernAndSelect}_B(M_t\cup C^{fb}_i\cup C^{abs}_t)$$
  其中 $B$ 为最大容量，GovernAndSelect 执行有效性过滤、去重、冲突消解、过期与容量约束选择；另有**周期性抽象 $C^{abs}_t$** 从近期有效记录与当前种群生成候选。

### 2.4 算法流程（Algorithm 1 概述）

1. 计算时序信用 → 若 $z^{temp}_i=1$ 则匹配对照、采集环境；
2. 计算语义信用 → 若 $z^{sem}_i=1$ 则做责任归因；
3. 若 $\kappa^{attr}_i=1$ 累积适应度并生成反馈候选；若 $=2$ 生成临时候选；
4. 周期性抽象生成 $C^{abs}_t$；
5. 合并后进行容量受限治理与选择，输出 $M_{t+1}$。

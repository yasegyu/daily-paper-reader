# Abstract 

Persistent memory allows an LLM agent to carry experience across conversations, but it also turns a local reasoning mistake into a durable one. During deliberation, an agent may consider a plan, simulate a tool result, report another speaker’s belief, and then reject all of them. If memory retains only the resulting sentences, those once-useful possibilities can later return as facts. The record is neither fabricated nor irrelevant; it has simply been detached from the context in which it was valid. We identify this missing context as discourse ownership : the world, branch, or speaker that licenses a proposition. Our first finding is counterintuitive. Language models already carry a causally active signal for ownership, yet conventional memory interfaces discard it when they convert reasoning into records. We introduce C ASK 

(Causally Anchored Scoping Keys), a commit rule that preserves this signal so that shared-world facts enter durable memory while provisional content remains available only within its original scope. Our second finding is that the most obvious way to preserve the signal—storing the discovered internal coordinates— is unreliable because equivalent representations need not keep the same coordinates. CASK instead preserves the stable relations that express ownership. Controlled long-conversation conflicts and tool-agent traces show that this design improves memory admission and prevents provisional content from contaminating later answers while complementing runtime provenance. The resulting commit boundary lets agents explore more possibilities without granting every intermediate sentence authority over future behavior. 

# 1 Introduction 

An agent spends ten minutes considering Paris, rejects the trip, and chooses Sydney. Months later, its memory retrieves “move to Paris” as a highly relevant personal fact. Nothing was hallucinated: the model really did produce that sentence. The error arose because the system remembered the proposition and forgot the world in which the proposition was licensed. This failure grows out of progress in reasoning. Chain-of-thought and reinforcement-learned reason-ing extend deliberation; Tree of Thoughts explores competing branches; ReAct interleaves plans with actions; Reflexion retains failed attempts; and latent-reasoning methods carry possible continuations before committing to one [Wei et al., 2022, Yao et al., 2023a,b, Shinn et al., 2023, Hao et al., 2024, DeepSeek-AI, 2025]. Each technique gains power by producing content whose status is provisional: a belief under revision, an unexecuted plan, a hypothetical tool outcome, or a discarded branch. More test-time computation can improve the final answer while creating more text that must never become an unconditional premise. Long context postpones this decision; persistent memory makes it consequential across episodes.

Linguistic theory supplies the missing distinction. “The appointment is Friday,” “Mina believes the appointment is Friday,” and “suppose the appointment were Friday” can express the same proposition while licensing different discourse updates. Mental-space accounts track the context—shared reality, a belief, or a hypothetical—that owns a proposition [Fauconnier, 1994, Kamp and Reyle, 1993, Heim, 1982, Roberts, 1996]. Most retrieval systems instead compress a record into content and ask whether it is relevant [Lewis et al., 2020, Maharana et al., 2024, Packer et al., 2023]. Relevance is necessary, but it is not permission: the most relevant record may still belong only to a belief, simulation, or abandoned plan. This perspective changes the diagnosis. The dangerous record need not be false, irrelevant, or poorly generated. It may be perfectly faithful to a reasoning branch and still be unsafe as a premise about the shared world. A memory system must therefore recover an attachment—which discourse owner licenses the proposition—rather than assign the proposition a context-free truth score. This is the commit problem studied in this paper. Our first finding is counterintuitive: the model already represents the distinction that its memory layer forgets. Interchange interventions redirect which mental space the model uses while preserving the proposition under discussion. Intervening on the same route also changes a frozen write decision in the predicted direction, whereas matched controls do not. The bottleneck is thus not simply insufficient model knowledge. It is a model–memory interface that exports content without exporting ownership. Making this internal distinction durable reveals a second surprise. The coordinates of a discovered neural route are not a stable identity for what that route means: an equally valid refit can rotate the basis and change every coordinate without changing the represented distinction. Internal probes can absorb that symmetry; a long-lived memory database cannot. A persistent key should therefore preserve the relations that define the ownership signal, not the arbitrary axes used to express it. We introduce C ASK (Causally Anchored Scoping Keys), illustrated in Figure 1. C ASK turns the model’s ownership-sensitive response pattern into a stable memory edge: actual-world content may enter shared memory, while plans, beliefs, and counterfactuals remain available under their original scope. Its relational key is unchanged by equivalent reorientations of the internal basis, yet retains the information needed for attachment. The resulting interface is small enough to sit at the commit boundary between reasoning and retrieval, and its theoretical guarantees explain why stored keys remain meaningful across equivalent representations. The evaluation follows a record from internal routing through admission, retrieval, and final answer-ing. C ASK leads the evaluated attachment representations at both model scales, and its advantage concentrates on changes in reporting scope rather than payload. Direct interventions connect that gain to the ownership route; long-conversation conflicts show that cleaner attachment reduces later premise contamination; and generated tool-agent traces show how C ASK works with execution metadata. The result changes how reasoning and memory can be co-designed: reasoning research gains a principled boundary between exploring a candidate and promoting it to durable state, agent builders gain a testable commit layer, and memory evaluation gains premise licensing as an objective alongside retrieval and question answering. Our contributions are: 1. We identify discourse ownership as the missing commit type between contemporary reasoning and persistent memory, and show that the model’s ownership route causally controls a frozen write decision. 2. We develop a stable relational key that preserves this route across equivalent internal bases, with formal invariance, completeness, and perturbation guarantees. 3. We show how attachment shapes retrieval and answering across controlled conflicts and tool-agent traces, yielding a provenance-aware deployment policy and a premise-licensing evaluation target.

Packer et al., 2023, Park et al., 2023, Xiong et al., 2025]. They decide what persists and returns; CASK additionally records the discourse world in which it is licensed as a premise. Mental spaces and dynamic semantics treat attitudes and modality as structured context change: identical content licenses different updates under a belief, assertion, or hypothetical [Fauconnier, 1994, Kamp and Reyle, 1993, Heim, 1982]. C ASK instantiates this principle at the model–system boundary by storing a proposition with its attachment. Unlike truth scoring, it can preserve a faithful belief or counterfactual without letting it update the actual world. Speaker-commitment and event-factuality work separates content, holder, and commitment status [de Marneffe et al., 2019, Jiang and de Marneffe, 2019, Murzaku et al., 2023, Li et al., 2024, Rovera et al., 2025]. Our question begins where tagging ends: how can a reasoning system preserve this distinction in persistent state? Mechanistically, an interchange intervention replaces part of a target example’s hidden state with the corresponding state from a donor example and tests whether the target adopts the donor’s high-level variable. Distributed alignment search (DAS) learns the subspace on which to perform that replacement [Geiger et al., 2024, 2025, Wu et al., 2022]. We use intervention to validate routing, then separate that causal test from downstream prediction. Representation similarity work recognizes that equivalent subspace bases may differ by an orthogonal rotation [Kornblith et al., 2019]. A Gram matrix records all pairwise inner products among an ordered set of vectors; we use its classical completeness to preserve an ownership-responsive/complementary partition in a compact memory key. Chain-of-thought, tree search, tool use, reflection, and latent reasoning generate candidate trajectories in different ways [Wei et al., 2022, Yao et al., 2023a,b, Shinn et al., 2023, Hao et al., 2024]. Once reused across episodes, they share one question: which intermediate conclusions were promoted to the agent’s shared world? C ASK types that commit, complementing work that scales reasoning computation [DeepSeek-AI, 2025]. Existing frameworks usually resolve branches within one episode. Persistent agents add a second time scale: summaries and traces can return after branch control has disappeared, making a rejected path resemble an observation. # 4 Method 

4.1 Causal anchor and diagnostic configuration 

DAS learns a low-dimensional subspace whose interchange interventions realize a hypothesized high-level variable [Geiger et al., 2024, 2025]. In the routing study, we train a rank-16 ownership subspace only on training constructions. A held-out target is the example being evaluated; its donor is a matched example with the opposite owner whose subspace state is inserted into the target. Success means that the target routes to the donor owner without copying the donor proposition. For attachment, we reuse the fixed rank-r = 16 orthogonal projector P = U U ⊤ ∈ Rd×d, where

4.2 Why two Gram blocks? 

The full Gram matrix satisfies H⊤H = G∥ + G⊥. It is invariant but erases which relations belong to the ownership-responsive partition. C ASK retains the two blocks separately, producing an invariant 

typed decomposition . The low-rank block supplies the causal anchor: interchange interventions establish that changing this route changes the model’s owner selection. The complement preserves the surrounding relational configuration, while output logits add the model’s explicit judgment. Together, the typed blocks retain the causal routing geometry and the context that makes a memory-commit decision identifiable. We use one C ASK representation and scorer for two policies. The default sets τ = 0 .5 for balanced attachment. C ASK @R95 selects the inverse ℓ2-regularization strength C and τ on development conversations to maximize nonactual rejection subject to admitting at least 95% of actual records. 

4.3 From a reasoning branch to a memory commit 

The interface sits between deliberation and persistence. C ASK keeps each candidate paired with its diagnostic configuration, separates ownership-responsive from complementary relations, and admits it to shared retrieval only after predicting an actual-world edge. Otherwise, the content remains available under its scoped owner rather than being deleted. The causal projector ties each edge to an internal variable that controls the model’s routing behavior; the Gram construction makes that evidence stable across equivalent bases. This turns a mechanistic finding into a durable systems interface. At retrieval time, all records receive the same relevance score. The query selects an admissible owner set, and the attachment edge masks records outside that set before the reader , the answer-generating model, sees them. Semantic retrieval answers which content is useful ; the scope key answers in which world that content may serve as a premise . Experiments compute one BM25 lexical-relevance ranking and change only the admission mask. Runtime provenance and C ASK operate at complementary levels. A ledger supplies event status, while C ASK supplies proposition-level scope within language, summaries, and reflections. Together they support a commit layer that carries execution evidence and linguistic ownership into persistent memory.

# 5 Experimental design 

Research questions. The evaluation follows the path from representation to deployment. RQ1 asks whether mental-space ownership is causally active in the frozen model. RQ2 asks whether intervening on that same route changes the frozen memory-commit decision. RQ3 tests whether a typed invariant export improves attachment and follows reporting scope rather than payload. RQ4 challenges the interface with unseen reporting frames, diagnostic paraphrases, and naturally generated tool-agent traces, including a provenance-first hybrid. RQ5 measures how the resulting edge changes retrieval integrity and final answering in long histories. 

Backbone and data. Experiments use frozen Qwen2.5-3B-Instruct and Qwen2.5-1.5B-Instruct representations [Yang et al., 2024]. Block 20 and rank 16 on 3B were fixed in a pilot before held-out evaluation; the 1.5B replication matches relative depth at block 16 and transfers rank 16 without a new search. LoCoMo is a benchmark of long, multi-session conversations with 1,986 annotated questions [Maharana et al., 2024]; we use 486 questions with exact answer spans. A source-isolated fold 

groups by conversation and draws alternative answers only from its training conversations. Projector, regularization, and threshold choices use training/development data only. 

Controlled conflicts. For each question we retain the evidence payload , the answer-bearing text proposed for storage, and place it in frames covering belief, plan, fiction, and counterfactual scope. Alternative answers come only from training conversations, with zero exact overlap against develop-ment or test answers. The answer-conflict study contains 972 candidate records for 486 questions. BM25 scores the common corpus once; each gate filters the same ranking. The reader then answers from the retrieved records; conflicting-answer adoption is the fraction of outputs that repeat the injected alternative answer. 

Factorial isolation. Two paired datasets separate scope from payload. In scope-only , actual and nonactual examples contain byte-identical evidence payloads and differ only in reporting frame. In 

payload-only , both examples use the same actual reporting frame and differ only in the first answer span. Each variant contains 4,860 records (2,430 pairs), and a separate head measures the information available in each representation for each factor. 

Baselines. The comparison isolates the source of attachment information. Term frequency–inverse document frequency (TF–IDF) tests lexical content. Full hidden state probes the mean 2,048-dimensional hidden vector; basis coordinates use its mean coordinates in the learned ownership basis. 

Output logits use the four explicit diagnostic judgments. Causal Gram , complement Gram , and their logit-augmented variants retain relations from one projector side. Full Gram+logits adds the two blocks before classification, erasing their type. Random typed split+logits substitutes a matched random rank-16 partition. # 6 Results 

6.1 The routing variable is causally controllable 

On Qwen2.5-3B, rank-16 interventions route 134 of 146 held-out cases to the target mental space (91.78%), while matched random subspaces reach 3.22%. Clustering the 74 target scenarios gives an intervention advantage of 88.56 points (95% CI [83.30, 93.34]). All scenarios preserve the target proposition, isolating a change in the owner used for reasoning. The independently fixed 1.5B replication shows 86.30% causal routing versus 20.86% for matched random subspaces, with donor content in 1.37% of cases. The cross-scale result establishes a reusable model-internal control variable for memory admission. We next intervene on that route inside the six diagnostic passes and reevaluate the fitted gate. Replacing the ownership-subspace state with an opposite-scope donor moves commit probability by .715 toward the donor [95% conversation-clustered CI: .656, .775], succeeds in the intended direction for 97.5% of records, and flips 75.8% of decisions. The effect appears in both directions (.694 for actual →scoped; .736 for scoped →actual), while matched controls rarely flip the decision. Manipulating the ownership route therefore changes the frozen downstream write decision, connecting the linguistic variable directly to memory behavior. 

Prompt and frame controls. The conversation-isolated gate reaches 90.94% under unseen meaning-preserving diagnostic paraphrases and 93.44% on unseen reporting frames, versus 72.81% for TF–IDF on the latter. Holding out both banks jointly yields 70.16% (chance 50%). The literal prompts, fold results, and unchanged-data reference (97.81%) appear in Appendix B.

6.4 The complete chain repeats at the smaller scale 

The 1.5B model transfers rank 16 and fixes its layer by relative depth. Its intervention remains far above matched random routing, and its 79.82% attachment leads Table 2, 2.35 points above the 2,048-dimensional full-hidden probe despite using only 46 basis-independent features. At τ = 0 .5,CASK obtains 46.09% recall@5, 18.11% contamination, 26.13 EM, and 36.92 F1. The larger model has the cleaner safety profile; the smaller one shows that the ownership route and invariant export are already present below the principal scale. 

6.5 One scorer supports safety-first and recall-first memory 

The same score supports two policies without retraining. The symmetric τ = 0 .5 boundary gives the strongest balanced attachment and lowest internal-gate contamination. C ASK @R95 instead selects a development threshold for at least 95% actual admission; it preserves flat-memory recall and reciprocal rank while reducing contamination by 11.19 points and conflict adoption by 1.17 points, with clustered intervals excluding zero. Its 29.42 EM and 40.30 F1 lead the evaluated internal-feature gates. 

6.6 Natural agent traces favor a provenance-first hybrid 

Across 75 generated tool-using episodes (511 records; ten conversations), runtime labels are hidden from the candidate text and folds remain source-isolated. A trace-adapted C ASK fallback leads learned gates in balanced accuracy—the mean of actual-admission and scoped-rejection rates—at 91.10% versus TF–IDF’s 90.40%, and admits more actual observations (89.13% versus 81.52%). With exact provenance retained for half the records, the layered policy reaches 95.02%; a full ledger is the privileged upper bound. A 20-episode audit separates scoped propositions from their actual meta-events, and six-way batching costs 32.1 ms versus 24.8 ms for one diagnostic (1.29 ×). Full results are in Appendix B. 

# 7 Implications and conclusion 

More reasoning trajectories create more provisional propositions. C ASK makes that growth compat-ible with persistent memory by requiring an ownership edge before a verbal, latent, or tool-using branch becomes a reusable premise. For reasoning researchers, it separates productive exploration from durable commitment; for agent builders, it provides a compact gate between deliberation and retrieval; for evaluation, it makes premise licensing measurable alongside relevance and QA. The central innovation is to make linguistic ownership a first-class memory relation and ground that relation in a causally validated, basis-invariant neural representation. This gives the community a concrete way to test whether new reasoning methods remain reliable once their intermediate states outlive the episode that produced them. Across two model scales, controlled conflicts, and generated traces, C ASK leads every evaluated attachment representation, responds predictably to intervention, and works with runtime provenance.

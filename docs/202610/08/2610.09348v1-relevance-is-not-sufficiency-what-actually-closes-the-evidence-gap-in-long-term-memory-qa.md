## 摘要
与用户跨多次会话交互的 LLM 智能体会积累超出其上下文窗口的历史记录，因此它们将过往交互存储在外部记忆中，并基于一小部分检索记录来回答每个问题。现有记忆系统按词法或嵌入相关性对记录排序，但排名最高的记忆可能各自都相关，却共同遗漏了回答所需的某个互补事实，尤其是在多会话和时间性问题中。借鉴法律证据学中相关性与充分性的区分，我们将记忆检索重新表述为构建一个充分的记忆集合。为将这一观点付诸实践，我们引入对检索集合的盲法 LLM 判断，并以 Gold Hit 和 Turn Hit 作为证据覆盖度的代理指标。随后，我们提出预算化扁平重建（Budgeted Flat Reconstruction, BFR），它在固定的扁平记忆存储上分两阶段构建充分集合。具体而言，我们首先应用面向记忆选择的形式概念分析（Formal Concept Analysis for Memory Selection, FCA-MS），将问题分解为若干信息需求，并选择一个能够联合覆盖这些需求的紧凑候选子集。然后，我们通过更深入的文本搜索或互补的实体与会话视图，反复获取未见的记录，直至预算耗尽时停止。在 LoCoMo 和 LongMemEval-S 上的实验表明，BFR 在答案质量和证据覆盖度上均优于近期智能体记忆系统在同一存储上的适配版本。具体而言，在 LongMemEval-S 上，它将评判准确率从 72.4% 提升至 82.2%，并将 Turn Hit 提升至 91.4%。

## Abstract
LLM agents that interact with a user across many sessions accumulate histories that exceed their context window, so they store past interactions in an external memory and answer each question from a small set of retrieved records. Existing memory systems rank records by lexical or embedding relevance, yet the top-ranked memories can each be relevant while jointly omitting a complementary fact that the answer requires, especially for multi-session and temporal questions.   Drawing on the distinction between relevance and sufficiency in legal evidence scholarship, we recast memory retrieval as constructing a sufficient memory set.   To operationalize this view, we introduce a blinded LLM judgment over the retrieved set, together with Gold Hit and Turn Hit as evidence-coverage proxies. We then propose Budgeted Flat Reconstruction (BFR), which builds sufficient sets over a fixed flat memory store in two stages. Specifically, we first apply Formal Concept Analysis for Memory Selection (FCA-MS) to decompose the question into information requirements and select a compact candidate subset that jointly covers them. Then, we repeatedly acquire unseen records through deeper text search or complementary entity and session views, stopping when the budget is exhausted.   Experiments on LoCoMo and LongMemEval-S show that BFR outperforms same-store adaptations of recent agent-memory systems in both answer quality and evidence coverage. Specifically, on LongMemEval-S it raises judged accuracy from 72.4% to 82.2% and Turn Hit to 91.4%.

# 论文总结：Relevance Is Not Sufficiency

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：与用户跨多次会话交互的 LLM 智能体会积累超出上下文窗口的历史，因此普遍依赖外部记忆存储，并基于少量检索记录回答问题。
- **核心问题**：现有记忆系统（Mem0、A-Mem、CoM、MRAgent 等）均按词法或嵌入**相关性**对记录排序，但相关性是**单项记录**的属性，而非**集合**的属性。排名靠前的记忆可能各自都相关，却共同遗漏回答所需的互补事实，尤其在多会话和时序问题上。
- **典型失败案例**（图 1）：问题问“遥控快门线从下单到收到用了几天”，需要两条记录——2 月 5 日下单、2 月 10 日到货。top-k 检索到了下单记录及其他摄影相关记忆，但到货记录因相似度低被截断在 cutoff 之外，智能体答成了“卖三脚架”。
- **理论借镜**：借鉴法律证据学中 **relevance（相关性，单项属性）与 sufficiency（充分性，整体记录属性）** 的区分（Lempert 1986；Pardo 2023），将记忆检索重新表述为**构建一个充分的记忆集合**（sufficient memory set）——即从该集合可以确定答案。
- **两个耦合挑战**：
  - **组合（composition）**：集合需汇集互补事实，避免重复覆盖同一信息而遗漏另一信息；
  - **可达性（reachability）**：必要事实若不在初始候选池中，仅靠池内重排无法恢复。
  - 且推理时没有 oracle 宣告集合是否充分，方法必须自行决定搜索深度与停止时机。
- **整体含义**：检索的目标不应是“返回相似项列表”，而应是“交付一个能支撑答案的证据记录”，这对越来越长的智能体历史具有设计范式意义。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想
- 提出 **Budgeted Flat Reconstruction (BFR)**：在**固定扁平记忆存储**上、**固定检索预算**内，分两阶段构建充分证据集，不改变底层存储。
- 形式化：设固定记忆库 \(M\)、问题 \(q\)、参考答案 \(y^\star\)、检索集 \(E \subseteq M\)。
  - 理想充分性：\(S(q,E)=\mathbb{1}[y^\star(q)\ \text{可由}\ q\ \text{与}\ \text{text}(E)\ \text{确定}]\)
  - 构造问题：\(\max_\pi \mathbb{E}[S(q,E_T)]\)，约束 \(C_{ret}(\pi,q) \le B\)
- **两阶段分工**：Stage I 组合候选池内已有证据（composition），Stage II 触及候选池之外的证据（completion），固定预算提供不依赖“识别充分性”的停止规则。

### 2.2 Stage I：FCA-MS（面向记忆选择的形式概念分析）
1. **扩展检索**：向智能体记忆系统请求比常规 top-k 更大的候选池 \(C_q=\text{TopN}(\cdot)\)，\(N>k\)。
2. **需求分解**：LLM 将问题分解为面向答案的信息需求 \(R_q=\{r_j\}\)，包括不同事实、桥接、列表项与时序约束。
3. **需求感知预过滤**：用 FCA 将 \(R_q\) 与 \(C_q\) 约简为较小池 \(P_q=\text{FCAPrefilter}(R_q,C_q)\)，上限 \(P\) 个笔记。
4. **最小子集选择**：LLM 选出**联合覆盖需求的最小记忆子集**，校验 ID、去重，空则回退到覆盖输出或预过滤头部。
5. **接地（grounding）**：将选中笔记通过映射 \(\phi\) 接地到源 turn，形成初始证据集 \(E_0\)；原 top-k 仅作参考 cutoff，不是保留基集。
- 局限：只改善初始候选池内的覆盖，仍受池边界约束，因此需要 Stage II。

### 2.3 Stage II：预算化完成
- **多视图访问同一存储**：text、entity、session 三种索引指向同一批源接地记录。
- **排除已见**：每轮从 \(M \setminus E_t\) 检索，\(C_t=\text{Unique}(\bigcup_{(v,c)\in A_t} R_v(c, M\setminus E_t))\)，保证累积且无重复。
- **保留规则 \(\kappa_\pi\)**：按相关性与对当前集合的新颖性排序，至多保留 \(k_{keep}\) 条，集合并入 \(E_{t+1}=E_t \cup K_t\)。
- **预算停止**：\(B=(B_{step},B_{call},B_{new})\)，主配置为 3 轮、6 次检索调用、30 条新记录；以**预算耗尽**为停止条件，因为离线充分性度量需要参考答案或 gold 标注，推理时不可用。
- **两种调度**：
  - **BFR-Text**：每轮用原始问题 \(q\) 查询文本索引，剔除已在 \(E_t\) 的 id，保留前 8 条未见命中；重复同一查询以推进到初始分页之后，针对“相关但在 cutoff 之下”的缺失证据。
  - **BFR-MV**：固定顺序 text→entity→session；text 用 \(q\)，entity 用问题中第一个命名人物，session 用最近保留记录作锚；可恢复在完整问题串下排序不高的记录。

## 3. 实验设计

### 3.1 数据集 / Benchmark
- **LoCoMo**（Maharana et al. 2024）：长多会话对话理解，含需跨 turn 链接的问题，提供 supporting-record 标注；使用固定分层 **200 题**开发子集（33 Multi-Hop、50 Temporal、8 Open Domain、109 Single-Hop）。
- **LongMemEval-S**（Wu et al. 2025）：跨扩展交互历史/会话的问答，官方 cleaned 小集共 **500 题**（含 multi-session、temporal、knowledge-update、preference、single-session user/assistant 六类），提供 answer-bearing turn 标注（479 题有标注）。
- 两 benchmark 都带证据标注，因此可同时评估最终答案与检索覆盖。

### 3.2 对比方法
- **Mem0**（BM25-lite over turn pool）、**A-Mem**（dense top-k，无笔记演化）、**CoM\***、**MRAgent-Flat\***（限制为扁平 turn，省略 Cue–Tag–Content 图与派生事实）。
- 带星号的为**受控同存储适配版**，非官方完整系统；所有 arm 共享同一 flat turn store、extractive answerer 与 answer judge（gpt-5.5，temperature 0，mem0 accuracy v1 prompt）。
- 另有跨系统边界比较：Full-MRAgent、CoM（改变 store，仅作 boundary 而非公平同底基线）。

### 3.3 指标
- 答案质量：**Stem F1**、**LLM-Judge (J)**。
- 集合级充分性：**LLM-Suff@Set**（盲法、参考条件化的 LLM 判断，双 judge + 第三模型裁决）。
- 证据覆盖代理：**Gold Hit**、**Turn Hit**、**Evidence Recall (ER)**、**Complete Evidence Recall (CER)**。

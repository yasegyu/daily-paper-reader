## 摘要
近年来，大型语言模型（LLMs）以及基于 LLM 的智能体日益需要融入预训练之后获得的知识，例如领域事实、用户偏好、文档和交互经验。上下文学习（ICL）以及基于 ICL 的智能体框架仍然灵活，但它们会消耗上下文容量，并产生随上下文长度增长的重复离散化编码成本。参数内记忆提供了一种互补的基底：可复用的记忆信息被表示在模型参数、适配器或其他类似参数的对象中，并在推理时组合进前向传播。本综述聚焦于在部署时用此类参数化记忆增强 LLM 的方法：在推理过程中，将承载记忆的参数对象插入前向传播，无论该对象是在部署之前还是部署期间获得的。我们以两个正交轴来组织这一领域：参数放置，包括嵌入层、注意力层、FFN 层，或当使用两个及以上层时的混合方式；以及参数获取时间，区分记忆对象在部署期间获取（在线）的方法与在部署之前获取（离线）的方法。我们厘清边界、进行比较，并讨论在干扰、安全、与 ICL 协同设计以及递归自我改进方面的开放方向。

## Abstract
Recently Large Language Models (LLMs) and LLM-based agents increasingly need to incorporate knowledge acquired after pretraining, e.g., domain facts, user preferences, documents, and interaction experience. In-context learning (ICL) and ICL-based agent harness remain flexible, but they consume context capacity and incur repeated discretized encoding cost that grows with context length. \textbf{In-parameter memory} offers a complementary substrate: reusable memory information is represented in model parameters, adapters, or other parameter-like objects that are composed into the forward pass at inference time. This survey focuses on methods that augment LLMs with such parametric memory at deployment: a memory-bearing parameter object is plugged into the forward pass during inference, whether it is acquired before or during deployment. We organize the landscape with two orthogonal axes: \textbf{Parameter Placement}, which includes Embedding, Attention, FFN layers, or Hybrid when two or more layers are used; and \textbf{Parameter Acquisition Time}, which distinguishes methods whose memory object is acquired during deployment (online) from those acquired before it (offline). We clarify boundaries, conduct comparisons, and discuss open directions in interference, safety, co-design with ICL, and recursive self-improvement.

## 1. 核心问题与整体含义

- **研究动机**：LLM 及其智能体需要持续融入预训练之后获得的知识，例如领域事实、用户偏好、文档内容、交互经验等，论文将这类信息统称为 LLM 的“记忆”。
- **现有主流范式**：上下文学习（ICL）及基于 ICL 的 RAG、智能体框架，将记忆以显式文本 token 形式放入上下文。其优点是灵活、可解释、可检查、易修改。
- **核心痛点**：ICL 会消耗有限上下文窗口，计算与延迟随检索 token 数增长；长上下文预填充存在二次成本；稀疏注意力与 KV cache 压缩只能缓解、不能根除这一 scaling 问题。
- **论文主张**：参数内记忆（In-Parameter Memory, IPM）是互补方案。可复用记忆被表示在模型参数、适配器或其他“类参数对象”中，推理时作为独立对象组合进前向传播。它可避免长上下文预填充的二次成本，并在记忆跨查询复用时降低推理延迟。
- **综述定位**：本文不是提出单一新模型，而是系统梳理“部署时用参数化记忆增强 LLM”的方法，强调从 ICL 向 IPM 的范式转移。

## 2. 方法论

### 2.1 核心思想

- 用两个正交轴组织 IPM 方法：
  - **参数放置（Parameter Placement）**：记忆对象 ϕ 被组合到 Transformer 的哪个位置，包括 Embedding 层、Attention 层、FFN 层、Hybrid（两个及以上位置）。
  - **参数获取时间（Parameter Acquisition Time）**：记忆对象是在部署期间获取/更新（Online），还是在部署之前形成并固定（Offline）。
- 目标不是替换 Transformer 结构，而是把 ϕ 注入已有结构中的自然位置。

### 2.2 操作子形式化

- 设 θ 为骨干参数，ϕ 为承载记忆的参数对象。
- 定义两个操作子：
  - **A：获取操作子（Acquisition Operator）**，产生或更新 ϕ。
  - **C：增强操作子（Augmentation Operator）**，在推理时将 ϕ 组合进前向传播。
- 生成过程可写为：
  - ϕt = A(ϕt−1, zt)
  - yt ∼ p_{C(θ, ϕt)}(yt | x≤t)
- A 有两种形式：
  - **One-shot acquisition**：ϕ = A(K)，一次性从源 K 生成记忆对象，如连续向量优化、单遍超网络、知识编码器生成 KV。
  - **Stateful acquisition**：ϕt = A(ϕt−1, zt)，部署中根据新证据重写记忆，如 delta-rule、surprise-driven update。
- A 的更新频率可为 per token、per segment 或 on demand。
- C 的形态包括：LoRA 残差、额外 KV、虚拟 token、直接更新隐状态等。

### 2.3 范围界定

- 一个方法被纳入 IPM 综述需同时满足三条：
  1. **Parametric**：记忆为连续参数形式。
  2. **Independent Acquisition**：由独立操作子 A 产生，而非运行模型的副产品。
  3. **Augmented at Deployment**：部署时作为独立对象进入前向传播。
- 据此：
  - ICL-based RAG：不满足，排除。
  - Pluggable PEFT：满足。
  - Full Parameter SFT：不满足，因为更新已合并进 θ。
  - Unmodified KV Cache：不满足独立获取，排除；但编码后的 KV bank 若由独立编码器产生，可纳入。

### 2.4 两轴分类与典型对象

- **Embedding 层**：soft prompts、soft tokens、memory tables。
- **Attention 层**：encoded KV banks、adapters、fast weights、online neural memory、soft prompts。
- **FFN 层**：adapters、memory tables、online neural memory、fast weights。
- **Hybrid**：adapters、online neural memory。
- **Online 获取**：通常对应 stateful A，对象多为 fast weights、online neural memory、adapters、soft tokens，常为 per-request 或 per-token，短期/会话级。
- **Offline 获取**：通常对应 one-shot A，对象多为 encoded KV banks、soft prompts、adapters、memory tables，部署前形成并持久化。

### 2.5 方法景观与比较维度

- 论文按“放置 → 获取时间”梳理代表方法，例如：
  - Embedding Online：MemGen、GradMem、MINT、REFRAG、LatentMem、LatentSeek。
  - Embedding Offline：Prompt-Tuning、TokMem、H2MT、Engram、Memory Grafting。
  - Attention Online：Titans、Atlas、δ-mem、Infini-Transformer、CEPE、M+、C2C、PrefixMemory-Tuning 等。
  - Attention Offline：Prefix-Tuning、KBLaM、AtlasKV、SR-KI、MoC、Memory 3、FILM、TOME 等。
  - FFN Online：Doc2LoRA、DyPRAG、Locas、WISE、GRACE、FwPKM、LaCT 等。
  - FFN Offline：PRAG、PolyPRAG、MLP Memory、MemoryLLM、RING、PKM 等。
  - Hybrid Online：SHINE、Temp-LoRA、AbsorberLLM、Doc2Atom、Code2LoRA。
  - Hybrid Offline：LoRA、Macaron-V1、LatentSkill、KnowLa、LAG、GeoRA。
- 比较维度包括：任务目的、物化方式、持久性、写入成本、读取成本。论文用定性等级 L/M/H 表示成本，而非数值 FLOPs 或 wall-clock。

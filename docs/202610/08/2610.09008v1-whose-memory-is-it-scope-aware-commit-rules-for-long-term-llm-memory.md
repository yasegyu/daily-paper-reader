## 摘要
持久记忆使 LLM 智能体能够跨对话携带经验，但也会将局部推理错误变成持久错误。在思考过程中，智能体可能考虑一个计划、模拟一个工具结果、转述另一位说话者的信念，随后又将其全部否定。如果记忆只保留最终得到的句子，那些曾经有用的可能性之后就可能作为事实重新出现。这些记录既非捏造，也非无关，只是与其曾经有效的语境脱节了。我们将这一缺失的语境识别为话语所有权（discourse ownership）：即许可一个命题的世界、分支或说话者。我们的第一个发现反直觉。语言模型已经携带了一种因果上活跃的归属信号，但传统记忆接口在将推理转换为记录时会丢弃它。我们提出 CASK（Causally Anchored Scoping Keys，因果锚定的作用域键），这是一种提交规则，可保留该信号，使共享世界的事实进入持久记忆，而临时性内容仅在其原始作用域内可用。我们的第二个发现是，保存该信号最显而易见的方式——存储所发现的内部坐标——并不可靠，因为等价的表示未必保持相同的坐标。CASK 转而保留表达归属的稳定关系。受控的长对话冲突与工具智能体轨迹表明，该设计改善了记忆准入，防止临时性内容污染后续回答，并与运行时溯源形成互补。由此产生的提交边界使智能体能够探索更多可能性，而不会赋予每个中间句子对未来行为的支配权。

## Abstract
Persistent memory allows an LLM agent to carry experience across conversations, but it also turns a local reasoning mistake into a durable one. During deliberation, an agent may consider a plan, simulate a tool result, report another speaker's belief, and then reject all of them. If memory retains only the resulting sentences, those once-useful possibilities can later return as facts. The record is neither fabricated nor irrelevant; it has simply been detached from the context in which it was valid. We identify this missing context as \emph{discourse ownership}: the world, branch, or speaker that licenses a proposition. Our first finding is counterintuitive. Language models already carry a causally active signal for ownership, yet conventional memory interfaces discard it when they convert reasoning into records. We introduce CASK (Causally Anchored Scoping Keys), a commit rule that preserves this signal so that shared-world facts enter durable memory while provisional content remains available only within its original scope. Our second finding is that the most obvious way to preserve the signal---storing the discovered internal coordinates---is unreliable because equivalent representations need not keep the same coordinates. CASK instead preserves the stable relations that express ownership. Controlled long-conversation conflicts and tool-agent traces show that this design improves memory admission and prevents provisional content from contaminating later answers while complementing runtime provenance. The resulting commit boundary lets agents explore more possibilities without granting every intermediate sentence authority over future behavior.

## 1. 核心问题与研究背景

- **问题根源**：持久记忆让 LLM 智能体跨对话携带经验，但也把一次局部推理错误变成持久错误。审议过程中智能体可能提出计划、模拟工具结果、转述他人信念、探索被否定的分支，随后又全部否定；若记忆只保留最终句子，这些"曾经有用的可能性"日后会以事实身份返回。
- **关键诊断**：这类记录既非捏造也非无关，而是**与其有效语境脱节**。论文把缺失的语境定义为**话语所有权（discourse ownership）**——许可某命题的世界、分支或说话者。
- **理论支撑**：借鉴心智空间理论、动态语义学与话语承诺研究。"预约在周五""Mina 相信预约在周五""假设预约在周五"表达同一命题，却授权不同的语境更新；现有检索系统把记录压缩为"内容+相关性"，而**相关性不等于许可**（最相关的记录可能只属于某个信念、模拟或被放弃的计划）。
- **核心命题**：记忆系统应恢复**归属（attachment）**而非给命题打无上下文的真值分；这就是论文研究的 **commit problem（提交问题）**。
- **两个反直觉发现**：
  - 模型内部**已经存在因果活跃的归属信号**，但传统记忆接口在"推理→记录"转换时把它丢弃了——瓶颈是模型–记忆接口，而非模型知识不足。
  - 保留该信号最直观的做法（存储发现的内部坐标）**不可靠**，因为等价表示可在正交旋转下改变所有坐标；持久键应保留**定义归属的稳定关系**，而非任意坐标轴。
- **整体含义**：为推理与记忆的协同设计提供原则性边界——区分"探索候选"与"提升为持久状态"，并为记忆评测新增**前提许可（premise licensing）**目标。

## 2. 方法论：CASK（Causally Anchored Scoping Keys）

**核心思想**：把模型对归属敏感的响应模式转化为一条稳定的记忆边——实际世界内容可进入共享记忆，计划/信念/反事实内容仅在其原作用域内可用（不删除）。

**形式化**
- 候选记录 `c = (x, m, s)`：`x` 为前文，`m` 为拟存储命题，`s` 为报告框架（断言/信念/计划/虚构/反事实）。
- 话语所有者 `ω(c)`；`Ω = {ω0} ∪ Ω_scoped`，`ω0` 为共享实际世界，`Ω_scoped` 含假设世界与态度持有者。
- 二值目标 `a(c) = 1[ω(c) = ω0]`，即该命题能否成为共享记忆中的无条件前提；**非实际 ≠ 假**，它在其所有者被查询时仍然有用。
- 学习门控 `gθ(c) ∈ [0,1]`，`â(c) = 1[gθ(c) ≥ τ]`；正判将 `m` 连到 `ω0`，否则保留作用域所有者。
- 检索时按相关性 `ρ(q,m)` 排序，但受 `ω(c) ∈ A(q)`（查询允许的所有者集合）约束；非实际记录进入实际世界结果即为**污染**。

**技术细节：因果锚 + 类型化关系键**
- 用 DAS 学习一个 **rank-16 所有权子空间**，得到正交投影 `P = UUᵀ`（`U ∈ R^{d×r}` 列正交，`U⊥` 为其正交补基）。
- 对每条候选记录，冻结模型接收 **k = 6 个固定 Yes/No 诊断提示**（共享记忆准入、前提许可、说话者承诺、未来事实使用、实际世界归属、框架移除），取指定 transformer 块最后一 token 隐藏态构成 `H = [h1,…,h6] ∈ R^{d×k}`；前 4 个提示另取 `ℓ ∈ R⁴`（`zYes − zNo` 的预 softmax 分数差）。
- 构造两个 Gram 块：`G∥ = (UᵀH)ᵀ(UᵀH)`，`G⊥ = (U⊥ᵀH)ᵀ(U⊥ᵀH)`。
- 复合特征 `ϕ_CASK = vech(G∥) ∥ vech(G⊥) ∥ ℓ ∈ R⁴⁶`（21 + 21 + 4），标准化后用带偏置的 logistic 回归（47 个参数）。
- **为何要两个 Gram 块**：`HᵀH = G∥ + G⊥` 虽不变，却抹掉了"哪些关系来自所有权响应分区"；分开保留构成**不变的类型化分解**——低秩块提供因果锚，互补块保留周边关系配置，输出 logits 补充模型显式判断。
- **两种操作点（同一 scorer，无需重训）**：默认 `τ = 0.5`（平衡归属）；`CASK@R95` 在开发集选正则强度 `C` 与 `τ`，在至少 95% 实际记录准入的约束下最大化非实际拒绝。
- **部署位置**：接口位于"审议→持久化"之间；所有记录共用同一相关性分数，查询选定可允许所有者集，归属边在 reader 看到之前掩码掉集合外记录。

**理论保证**
- **定理 1（规范不变性）**：在两子空间内做正交换基 `(Q∥V∥, Q⊥V⊥)`，`ϕ_CASK` 不变 → 存储键跨库/机器/重构仍可比。
- **定理 2（完备性）**：`VᵀV = WᵀW` 当且仅当存在正交 `Q` 使 `W = QV`（秩亏情形亦成立）→ Gram 键是**极大不变量**，除基选择外无信息损失。
- **定理 3（扰动稳定性）**：`‖ṼᵀṼ − VᵀV‖_F ≤ 2‖V‖₂‖E‖_F + ‖E‖²_F`；并给出分类决策不变的边界条件。
- **命题 1（类型化细化）**：有序对 `(G∥, G⊥)` 决定全 Gram，反之不成立（给出二维反例）→ 形式化了"两个块为何必要"。
- **推论 1（复合提交稳定性）**：把表示漂移转化为部署规则的**提交证书**——决策裕度大于特征误差预算时，准入决策保持不变。

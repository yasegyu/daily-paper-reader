## 摘要
基于LLM的智能体在个性化交互任务中面临挑战，原因在于长期轨迹具有异构、多类型和隐式约束等特性。现有记忆机制难以实现准确的路由与检索，尤其在个性化至关重要的端侧场景中。大多数方法使用单一向量表示，模糊了类型区分和关系结构。我们提出HGP，一种混合图记忆框架。HGP采用轻量级自增强分类器进行个性化记忆路由，并将情景记忆、语义记忆和程序性记忆构建为图。它还将工作记忆提取为状态轨迹，以捕获当前状态和隐式约束，确保可靠的决策。该分类器减少了大模型调用，使端侧部署成为可能，而图存储则支持准确检索和用户画像的增量细化。在两个基准上的实验表明，在PAL-Set解决方案选择任务上，HGP取得了35.58的S-score，比最强基线高出近7分。代码和数据见 https://github.com/Ouan6/HGP-.git。

## Abstract
LLM-based agents face challenges in personalized interactive tasks due to heterogeneous, multi-typed, and implicitly constrained long-term traces. Existing memory mechanisms struggle with accurate routing and retrieval, especially on-device where personalization is critical. Most methods use single-vector representations, blurring type distinctions and relational structure. We propose HGP, a hybrid graph memory framework. HGP employs a lightweight self-enhancement classifier for personalized memory routing and constructs episodic, semantic, and procedural memories as graphs. It also extracts working memory as a state trajectory to capture current state and implicit constraints, ensuring reliable decision-making. The classifier reduces large-model calls, enabling on-device deployment, while graph storage enables accurate retrieval and incremental user profile refinement. Experiments on two benchmarks show that on PAL-Set solution selection, HGP achieves an S-score of 35.58, nearly 7 points above the strongest baseline. Code and data are at https://github.com/Ouan6/HGP-.git.

- **现状**：为弥补上下文窗口有限与长上下文召回不可靠，主流做法是引入外部记忆模块；但绝大多数系统采用**统一记忆池 + 单向量压缩 + 语义相似度检索 + 拼接注入**的扁平设计。
- **核心痛点**：
  - 单向量表示**模糊了记忆类型的区分与关系结构**，而这两者对个性化检索与决策至关重要。
  - 一个被忽视的关键瓶颈是**个性化记忆路由**：历史轨迹中混杂事件、画像、策略、可执行状态等异构信号，错误路由会把信息存入错误记忆类型，引发**级联检索错误**。
  - 端侧场景（本地设备上的延迟敏感型在线路由与检索）要求低延迟，而反复调用 LLM 成本过高。
- **核心主张**：真正的个性化记忆需要两个属性——(a) 低监督成本的个性化记忆路由；(b) 显式建模异构记忆类型及其相互关系，而非坍缩到统一向量空间。

## 2. 方法论

### 2.1 总体框架
HGP 由两个组件构成：**自增强分类器**（个性化记忆路由）与**混合图存储**（四类记忆的图结构化表示）。在线路由与检索在本地设备完成，图构建与分类器更新异步进行。

### 2.2 自增强分类器（置信度门控 + 增量学习）
- 路由器先预测标签 ĉ_θ(x) 及置信度 s(x)，再由**迭代自适应阈值 τ_t** 决定最终路由：
  - 若 s(x) ≥ τ_t，直接采用分类器标签；
  - 否则**延迟给 LLM 标注**，并将 (x, ĉ_LLM(x)) 缓存进增量训练池；
  - 周期性在累积池上更新分类器。
- 阈值采用**指数退火**：τ_t = max(τ_min, τ_0 · e^(−βt))。τ_0 高 → 初期 LLM 主导（保守）；β 控制平滑过渡；τ_min 防止过度自标注。
- 效果：随用户样本累积，决策边界逐步适配当前域与用户模式，缓解跨用户分布漂移，并随用户行为演化持续适应。
- 具体实现：轻量 BERT 分类器（roberta_L-4_H-512），τ_0=0.90、β=0.05、τ_min=0.50。

### 2.3 混合图存储（四类记忆）
- **情景记忆 — 事件图** G_epi=(V_e ∪ V_ent, E_epi)：事件节点为结构锚点，通过带类型语义边（temporal、contextual 等）连接其他事件或上下文实体；边定义为 e_ij=(v_i, v_j, r)。可通过结构抽象算子 A_abs（由 LLM 实例化）从多个事件图抽象出更高层知识 K。
- **语义记忆 — 知识图** G_sem=(V_sem, E_sem)：以三元组 (u, r, v) 表示长期去情境化知识（HAS_SKILL、PREFERS、WORKS_AS 等谓词）；可经语义抽象算子 A_sem 从累积情景图得到。
- **程序记忆 — 规则树** G_proc=(V_c ∪ V_a ∪ V_g, E_proc)：节点为条件、动作、子目标，边编码控制/依赖关系；由 A_proc 从情景图抽取可复用规则与工作流。
- **工作记忆 — 状态轨迹图** G_wm=(V_state, E_state)：节点为当前系统/用户状态，边为状态转移；短时动态，从近期情景记忆提取并持续更新：G_wm^(t+1)=U(G_wm^(t), G_epi^(t))，用于捕捉当前状态与**隐式约束**。
- **检索流程**：收到查询 q 后，对四个子图**并行查询**各自类型的结构化证据（情景：时序/情境相关事件；语义：用户事实三元组；程序：匹配当前上下文的规则；工作记忆：当前状态轨迹），合并为统一上下文后与 q 一并交给 LLM 生成回复。

## 6. 主要结论与发现

- **LoCoMo**：HGP 在整体 Judge（65.08）、BLEU-1（42.09）、EM（20.54）上最佳，F1 45.07 保持竞争力；相对 Mem0 提升 +4.45（Judge）与 +5.34（BLEU-1）。**开放域**提升最显著（F1 51.33、BLEU-1 46.59、EM 26.87），说明图结构存储能为多样、无约束问题提供更可靠证据；**时序类问题仍较困难**。
- **PAL-Set**：QA 上 LLM-judge 最高（7.46），BLEU-2/3/4 最佳（8.67/4.70/2.78），体现更强的多步连贯性；Selection 上 **S-score 35.58**，比 Vanilla（w/o log，20.34）高 +15.24，比最强记忆基线 HippoRAG2（29.22）高 +6.36。非记忆基线相对 Van

伊拉（w/o log）已有明显优势，说明**显式记忆检索本身比"把日志直接塞进上下文"更有效**；而 HGP 在此基础上进一步拉开差距，说明收益并非仅来自"有记忆"，而是来自**类型化 + 图结构化的记忆组织**。值得注意的是，HippoRAG2 作为较强的图记忆基线已接近 HGP，但其差距（+6.36）表明单纯的图关联传播仍不足以替代"按记忆类型分区路由"的设计。

- **消融实验（PAL-Set）**：Full 配置在 QA 与 Selection 上均最优，可归纳出三点：
  1. **记忆类型化的贡献大于图结构本身**：Unified-vector → Typed-vector 的增益明显，说明"先分对类"是前提；若类型坍缩，图结构带来的关系信息会被异构噪声稀释。
  2. **四类记忆中情景记忆与语义记忆最关键**：w/o E-Mem 与 w/o S-Mem 的退化最严重，符合"事件提供时序与情境锚点、语义提供稳定用户事实"的直觉；w/o P-Mem 退化相对温和，可能因为程序记忆的规则更多在长程、任务型场景中才被触发，而 PAL-Set 的 QA/Selection 任务对显式工作流的依赖有限。
  3. **各组件存在互补性**：任一记忆类型缺失都无法被其他类型完全补偿，支持"异构记忆应显式共存"的核心主张。
- **路由效率**：自增强分类器在保持路由质量的同时，将平均延迟从 LLM 路由的约 1.5–1.8 s 降至 4.98 ms，并将 LLM 调用量减少 66.4%；迭代路由比例与累计负载曲线显示，随样本累积，系统对 LLM 的依赖持续下降并趋于收敛，验证了"置信度门控 + 增量学习"这一低监督方案在端侧可行性上的有效性。
- **超参敏感性**：τ_0 决定冷启动阶段的保守程度，过低的 τ_0 会让噪声标签早期进入训练池、损害后续决策边界；β 控制退火速度，过大易导致过早自标注、过小则 LLM 成本居高不下；τ_min 提供下限保护。三者需协同设置，论文给出的默认组合在 27 组网格中处于较优且稳健的区域。
- **分阶段训练（S0–S5）**：性能随增量阶段总体单调上升并趋于平台，说明分类器确实在适应用户域，而非简单记忆训练样本；平台期的出现也提示"自增强"存在收益上限，长期漂移仍需外部信号（如周期性 LLM 复核）来校正。
- **工作记忆案例**：定性对比显示，HGP 能借助状态轨迹图捕捉"当前状态 + 隐式约束"（如用户已表达的临时限制），从而避免 Vanilla LLM 的泛化式回答与 Mem0 的静态记忆误用；但该结论目前仅具示意性，缺乏统计支撑。

- **报告一致性**：正文与表格存在个别数值不一致（如 w/o E-Mem 的 BLEU-1），对复现与可信度有轻微影响。
- **未来方向**：作者指向完整端到端成本分析、记忆图的长期维护/遗忘机制，以及更广域的用户分布漂移适应。

## 8. 总体评价

**贡献层面**：论文的定位清晰且切中要害——把"个性化记忆"的瓶颈从"检索相似度"重新表述为"**记忆路由 + 异构结构建模**"，并给出可落地的两组件方案。自增强分类器用置信度门控把 LLM 从"每次调用"降级为"少量标注者"，在工程上具有现实意义；四类记忆（情景/语义/程序/工作）的划分与对应图结构（事件图/知识图/规则树/状态轨迹图）在概念上自洽，且与认知记忆分类形成呼应，便于后续工作复用。

**方法层面**：设计较为克制，未引入复杂训练流程，抽象算子复用 LLM 实例化、检索采用四子图并行查询，整体工程可实现性高；Neo4j 作为后端也符合图存储的直觉。相对薄弱之处在于：抽象算子的具体提示词与质量控制、子图并行检索后的**融合与去重策略**、以及冲突证据（如语义记忆与工作记忆矛盾）的处理，论文着墨不足，而这些恰恰是图记忆系统在真实长程交互中最易出问题的地方。

**实验层面**：维度覆盖较全（主实验、消融、效率、超参、训练动态），变量隔离意识良好，训练/测试严格分离、统一 prompt 与 temperature 0.0 提升了可比性；LLM-as-a-Judge 被明确定位为补充证据而非唯一依据，态度审慎。主要短板是**规模与量化深度**：两数据集、消融单数据集、工作记忆无量化、成本分析缺失，使得"全面优于现有记忆系统"的结论更适合表述为"在该评测设置下一致更优"。

**综合判断**：这是一篇**问题定义有价值、方法务实、实验基本扎实但覆盖有待扩展**的工作。其最大启示不在于某个具体指标，而在于指出：当记忆系统走向个性化与端侧部署时，**"把信息放对地方"（路由）与"让记忆保持异构结构"（类型化图存储）比单纯扩大检索窗口或堆叠相似度召回更为关键**。

## 9. 一句话总结

HGP 通过"置信度门控的自增强路由 + 四类异构记忆的混合图存储"，把个性化智能体记忆从扁平向量检索重构为类型化、结构化的低延迟路由与检索问题，在 LoCoMo 与 PAL-Set 上取得一致提升，并以约 360× 的路由延迟优势与 66.4% 的 LLM 调用削减验证了端侧可行性，但其端到端成本、消融覆盖与工作记忆的量化证据仍待补强。

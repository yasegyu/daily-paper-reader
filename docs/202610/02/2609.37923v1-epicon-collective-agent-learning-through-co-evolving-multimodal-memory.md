## 摘要
智能体可以从过去的执行中学习，但让不同智能体复用并基于彼此的经验继续构建仍然具有挑战性。我们提出 EpiCon，一种无需更新宿主模型参数即可实现智能体集体学习的共享多模态记忆框架。EpiCon 通过两个独立训练的 2B 模型——记忆控制器和树状自组织器——将问题级记忆演化与持久经验库连接起来。记忆控制器在多次尝试中联合精炼文本指导和视觉证据，并有选择地纳入视觉记忆。树状自组织器分层整合经验教训，并为新问题检索经验和规则。我们在涵盖四个多模态任务领域的十一个基准上评估 EpiCon，使用两套测试框架和多种骨干模型。即使仅进行一次求解尝试，冻结的经验库也能提升其他系统。第二个测试框架将原系统在十一个基准上的宏平均分数提高了 2.6 分。在四种宿主配置下，EpiCon 相比 No Memory 将宏平均分数提高 1.7 至 4.9 分，并且相对于骨干模型规模的记忆模型，将记忆操作时间减少 67% 至 74%。

## Abstract
Agents can learn from past executions, but enabling different agents to reuse and build on one another's experience remains challenging. We introduce EpiCon, a shared multimodal memory framework for agent collective learning without updating host model parameters. EpiCon links question-level memory evolution to a persistent experience bank through two independently trained 2B models: a memory controller and a tree self-organizer. The controller jointly refines textual guidance and visual evidence across attempts and selectively includes visual memory. The self-organizer consolidates lessons hierarchically and retrieves experience and rules for new problems. We evaluate EpiCon on eleven benchmarks spanning four multimodal task domains, using two harnesses and multiple backbones. A frozen bank improves other systems even with a single solving attempt. A second harness raises the original system's macro-average score by 2.6 points across eleven benchmarks. Across four host configurations, EpiCon improves macro-average scores by 1.7 to 4.9 points over No Memory and reduces memory-operation time by 67\% to 74\% relative to backbone-sized memory models.

## 1. 核心问题与研究背景

- **研究动机**：基于大语言模型的多智能体系统（MAS）在推理、工具调用与协作中会产生大量关于"解题流程、失败模式、关键证据"的经验；外部记忆可在**不更新宿主模型参数**的前提下让这些经验影响后续推理。但如何让**不同智能体（不同 harness / backbone）复用并继续积累彼此的经验**，仍是未解决的问题。
- **现有工作缺口**：
  - 语言智能体记忆多以文本为主，而多模态任务中经验常依赖图中区域、文档细节等**视觉证据**，且文本指导与视觉证据都需随尝试次数反复修正；
  - 已积累的经验需要**分层整合与检索**才能被后续任务复用；
  - 共享记忆系统虽支持跨模型/框架复用，但缺乏"问题级多模态精炼"与"持久经验库"之间的连接。
- **整体含义**：论文提出 **EpiCon（Episodic Consolidation）**，把"问题级的多模态记忆协同演化"与"可跨系统共享的经验库"打通，实现**集体学习（collective learning）**——经验可脱离其产生系统继续发挥作用，宿主参数保持冻结。

## 2. 方法论

### 2.1 核心思想
- 用专用 **memory harness** 连接两类记忆：
  - **问题级记忆**（临时、仅作用于当前问题）：由 **Memory Controller** $C_\theta$ 维护；
  - **持久共享经验库** $B$（与 MAS 解耦）：由 **Tree Self-Organizer** $S_\phi$ 维护。
- 两个模块是**独立训练的 2B 小模型**，宿主 MAS 保留自身的编排与骨干模型，参数不变。

### 2.2 共享多模态记忆与库更新
- 对问题 $x_i$，organizer 先从库 $B$ 中检索一次经验 $R_i$，MAS 据此产出答案 $\hat{y}_{i,t}$ 与执行轨迹 $\tau_{i,t}$。
- 库维护以"批"为单位更新（$k$ 为维护步，非单条经验）：
  $$B^{(k+1)} = S_\phi(B^{(k)}, U_k)$$
  其中 $U_k$ 为该步接受的 lessons 与修订。**评估时库被冻结**，更新只留在当前问题内。

### 2.3 问题级文本—视觉记忆协同演化
- 记忆表示为 $W_{i,t}=(M^{\text{text}}_{i,t}, M^{\text{vis}}_{i,t})$：文本记录可操作指导、适用条件与警告；视觉记忆指向源图中的支持区域。
- 控制器基于上一状态、当前问题与图像、最新答案与执行轨迹更新：
  $$W_{i,t} = C^{\text{update}}_\theta(W_{i,t-1}, x_i, \hat{y}_{i,t}, \tau_{i,t})$$
  可**保留、替换或删除**视觉证据；harness 校验并生成裁剪，非法提案则记忆不变。

### 2.4 自适应视觉记忆注入
- 控制器输出门控 $g_{i,t}\in\{0,1\}$ 决定下一步输入是否包含视觉记忆：
  $$c_{i,t}=\begin{cases}(T_{i,t},\varnothing), & g_{i,t}=0\\ (T_{i,t},V_{i,t}), & g_{i,t}=1\end{cases}$$
- 门控只选择"输入内容"，**不删除已存储的视觉记忆**；当前问题的原始图像在两种情况下均可用。

### 2.5 经验整合与检索
- 共享库以**树结构**组织：叶子存问题级经验，内部节点分组、概括并保留可复用规则。
- 维护时可提出 **Place / Merge / Split + Lift / Consolidation** 四类操作；harness 负责校验、执行与容量分区；抽象层级与规则资格由支撑度、失败、冲突与证据强度决定。
- 检索为"先召回、后精选"：
  $$R_i = S^{\text{retrieve}}_\phi(x_i, \text{Recall}(x_i, B))$$
  召回用冻结文本编码器在节点索引上检索，organizer 再判断适用规则、具体经验或"不适用（空检索）"；视觉内容的投递由 $C_\theta$ 控制。

### 2.6 监督数据构建与训练
- **教师模型**：Qwen3.8-27B 生成初始更新/课程/树操作示范，Qwen3.8-Flash-Next 选择性修订失败更新与树操作目标。
- **源数据**：MathNet、MathV360K、ChartQA、InfoVQA、DocVQA、ChartNet，覆盖视觉数学、文档理解、图表与信息图推理三领域；轨迹由 CAMEL、Codex、DeepSeek-Harness 采集。
- **回放验证**：以同一 MAS 回放新旧记忆，保留能把失败转为成功的 **Repair** 变换，以及"保持成功且缩短文本、不扩大裁剪面积"的 **Compress** 变换（tokens(ℓ′)<tokens(ℓ)，area(b′)≤area(b)）。
- **数据规模**：约 **25K** 记忆变换监督样本、约 **6.5K** 树操作示范（含合法的空检索）。
- **训练细节**：微调两个 **Qwen3.5-2B** 模型；LoRA rank 16、scaling 32，冻结视觉编码器与 aligner；3 epoch，lr $10^{-4}$，最大序列 8192，per-device batch 2，梯度累积 8 步；按验证损失选点（控制器 step 1000，树自组织器 step 258）。

## 摘要
面向大语言模型（LLM）的长期记忆系统因能在各类应用中扩展推理能力而日益流行。当前的记忆系统依赖 LLM 智能体来组织和整合记忆，导致写入操作成本高昂且效率低下。为解决这一局限，我们提出 MemFit，一种面向对话智能体的长期记忆系统，可降低记忆操作的成本与延迟。现有系统要么依赖昂贵的 LLM 调用进行记忆构建，要么通过压缩丢弃表层细节；与之不同，MemFit 将每一轮对话逐字存储在仅追加存储中，插入近乎即时且无需 LLM，并用片段摘要对轮次建立索引，而非替换轮次本身。此外，MemFit 采用无需 LLM 的多路径检索策略，在文本和多模态设置中，结合词汇与语义信号，并对字幕增强的片段进行交叉编码器重排序。在 LoCoMo、MemGallery 和 LongMemEval-S 三个广泛使用的基准上的实证结果表明，MemFit 在实现最先进性能的同时，将记忆构建时间和成本降低数倍，为持久化智能体记忆提供了一种可扩展且高效的解决方案。

## Abstract
Long-term memory systems for large language models (LLMs) have gained popularity for extending reasoning capabilities across applications. Current memory systems rely on LLM agents to organize and consolidate memory, resulting in costly, inefficient write operations. To address this limitation, we propose MemFit, a long-term memory system for conversational agents that reduces the cost and latency of memory operations. Unlike existing systems that rely on expensive LLM calls for memory construction or discard surface-level details through compression, MemFit stores each turn verbatim in an append-only store with near-instantaneous, LLM-free insertion, indexing turns with segment summaries rather than replacing them. Additionally, MemFit uses an LLM-free, multi-path retrieval strategy that combines lexical and semantic signals with cross-encoder reranking over caption- augmented episodes in both textual and multimodal settings. Empirical results on three widely used benchmarks, LoCoMo, MemGallery, and LongMemEval-S, show that MemFit achieves state-of-the-art performance while reducing memory construction time and cost several-fold, providing a scalable and efficient solution for persistent agentic memory.

# MemFit: Efficient Long-Term Agentic Memory 论文总结

## 1. 核心问题与研究动机

- **背景**：LLM 受固定上下文窗口限制，随 token 数增加性能退化（"context rot"），因此需要外部长期记忆系统存储历史交互并按需检索。
- **现有痛点**：当前记忆系统（MemGPT、MemoryOS、A-MEM、Mem0、LightMem、SimpleMem 等）普遍依赖**频繁的 LLM 调用**来组织、固化、压缩或重写记忆，导致两大问题：
  - **高计算成本与延迟**：写入路径昂贵；
  - **上下文污染**：过度依赖语义相似度检索，容易召回语义相近但无关的记忆。
- **核心研究问题**：能否在不依赖频繁 LLM 调用的前提下，实现**高效存储 + 精确检索**的长期记忆系统？
- **整体含义**：MemFit 主张把 LLM 排除在写入路径和搜索本身之外，用"逐字存储 + 摘要索引 + 无 LLM 多路径检索"替代"LLM 固化 + 纯语义检索"。

## 2. 方法论

### 核心思想
- 每轮对话**逐字**存入仅追加（append-only）存储，插入仅需一次编码器前向 + 两次索引追加，**无 LLM 调用**；
- 片段摘要**索引**原文而非替换/压缩原文；
- 检索全程无 LLM，融合词汇与语义信号，用交叉编码器重排。

### 存储层
- 每个 episode 表示为 `e_i = (x_i, z_i, g_i, m_i)`：
  - `x_i`：带时间与说话人标签的格式化文本（如 `[Time: 2023-05-12] [Speaker: Lena] ...`）；
  - `z_i`：冻结句编码器的 L2 归一化嵌入；
  - `g_i`：全局序号，用于时序排序与返回邻接轮次；
  - `m_i`：结构化元数据（时间戳、说话人、会话/轮次 ID）。
- **双索引**：BM25 稀疏索引（精确匹配人名、日期、稀有名词）+ 稠密索引矩阵 `Z`（余弦相似度 `Zz_q`，匹配改写/同义表达）。插入只增行、只追加 postings，**不重写、不重嵌入、不重摘要**。
- **多模态文本-图像融合**：图像 ID 与 caption 作为结构化文本附加到 `x_i`，使视觉内容可通过与文本相同的词汇/语义路径检索。

### 摘要层（唯一的写时 LLM 成本）
- 用 **TextTiling** 无 LLM 分段：对相邻片段均值嵌入计算连贯度 `c_j`，`b = max(3, round(√n/2))`；在局部最小且深度 `δ_j > μ_δ + σ_δ/2` 处设边界。
- 每个 ≥3 个 episode 的片段做**一次** LLM 调用（最多 14 个均匀采样片段，输出两句话 ≤200 token），摘要记录其成员 episode ID 作为 provenance。
- **无固化设计**：不合并、不重写、不删除；事实被更正时新旧两条都保留并带日期，把"选哪条"推迟到已知问题之时。

### 检索层（四阶段，无 LLM）
- **Stage 1 混合候选生成**：BM25 与余弦相似度各取 `nscan=60`，min-max 归一化后凸组合
  `s_i = α·d_sem(z_q, z_i) + (1−α)·c_lex(q, x_i)`，默认 `α=0.7`；
  元数据加成：说话人 +0.10、年份 +0.05、月份 +0.08。
- **Stage 2 加法式候选扩展**（严格只增不减）：
  - 摘要层用同样混合分数检索，最高分摘要通过 provenance 拉入其成员 episode；
  - **伪相关反馈（PRF）**：用 top-2 episode 中 12 个最稀有词（按 IDF）重跑候选生成，针对跨会话多跳问题。
- **Stage 3 重排与 pack 组装**：交叉编码器对第一阶段 top-50 及全部扩展候选打分；在 episode 内与 summary 内**分别标准化**分数；取 `k=10`，每条检索到的 episode 附带同会话 `w=1` 的邻接轮次以恢复上下文。
- **Stage 4 答案抽取**：唯一一次 LLM 调用；摘录按时间排序、附会话日期，相对时间表达预解析为绝对日期；多模态时 MLLM 同时接收图像。

### 效率特征
- 插入 = 一次嵌入 + 两次索引更新；无 episode 被重新访问；仅稀疏扫描与矩阵-向量积随内存规模线性增长。

## 3. 实验设计

### 数据集 / 场景
- **LoCoMo**：10 个多会话对话（5,882 轮），1,986 题中评估 1,540 道非对抗题；四类：Multi-Hop、Temporal、Open Domain、Single-Hop（对抗题排除）。
- **MemGallery**：多模态长期记忆基准，20 场景、240 会话、3,962 轮（1,003 轮带图）；1,711 题，9 类归为三维度（记忆抽取/推理/知识管理），487 题自带图像。
- **LongMemEval-S**：500 题，每题约 47.7 会话、约 115k token 历史；六类：SSU/SSA/SSP/MS/KU/TR，含 30 道弃答题。

### 对比方法
- 记忆系统：MemoryBank、MemGPT、MemoryOS、A-MEM、LightMem、Mem0、SimpleMem、LangMem；
- 基线：full-context、NaiveRAG。

### 骨干与指标
- 骨干：GPT-4o、GPT-4.1-mini、GPT-4o-mini、Qwen3-8B、Gemma3-27B、Gemma4-31B、Qwen2.5-VL-7B（多模态）。
- 指标：LoCoMo 用 F1 / BLEU-1（分类别与四类平均）；MemGallery 用 token-level F1；LongMemEval-S 用官方 prompt 的 LLM-judge 准确率；效率用 LLM 调用数、输入/输出 token、成本、构建时间、每题延迟。
- 统一配置用于所有骨干与基准，无按语料调参。

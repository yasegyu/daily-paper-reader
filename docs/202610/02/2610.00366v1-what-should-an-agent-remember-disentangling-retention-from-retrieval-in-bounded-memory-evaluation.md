## 摘要
一个持久型智能体必须在信息到达时决定保留什么，并在查询出现后决定呈现什么，然而记忆评估可能通过比较在保留和选择两方面均不同的方法来混淆这些决策。我们构建了一个将保留规则与选择规则交叉的流式召回基准，并在相同的 300 个固定随机种子回合上评估每一种条件。在固定访问的情况下，查询感知选择将所需事实的召回率提高了 15.5 个百分点（95% 置信区间：12.8 至 18.2），而同时改变历史访问的混合比较则报告了 68.7 个百分点的优势，其中 53.2 个百分点可归因于访问。在有界保留下，查询感知、稠密和 oracle 选择均达到保留上限，并且有界近因条件中所有 319 个观察到的失败均由淘汰而非排序错误导致。当目标退到过去足够远时，召回率降至 0%。在 SQuAD 上重复评估仍保持保留上限，同时表明稠密检索在自然文本上可以优于词汇检索。这些结果表明，有界记忆评估应固定访问，并分别报告保留和选择。

## Abstract
A persistent agent must decide both what to retain as information arrives and what to surface once a query appears, yet memory evaluations can confound these decisions by comparing methods that differ in both retention and selection. We build a streaming-recall benchmark crossing retention and selection rules and evaluate every condition on the same 300 seeded episodes. Holding access fixed, query-aware selection improves required-fact recall by 15.5 percentage points (95% CI: 12.8 to 18.2), whereas a mixed comparison that also changes history access reports a 68.7-point advantage, of which 53.2 points are attributable to access. Under bounded retention, query-aware, dense, and oracle selection reach the retention ceiling, and all 319 observed failures in the bounded recency condition are caused by eviction rather than ranking errors. Recall falls to 0% as targets recede sufficiently far into the past. Repeating the evaluation on SQuAD preserves the retention ceiling while showing that dense retrieval can outperform lexical retrieval on natural text. These results show that bounded-memory evaluations should hold access fixed and report retention and selection separately.

# 论文总结：What Should an Agent Remember? Disentangling Retention from Retrieval in Bounded-Memory Evaluation

## 1. 核心问题与整体含义
- **研究动机**：持久型智能体在信息流中必须做两类不同决策：
  - **保留（retention）**：信息到达时在线决定留下什么，且通常是**查询无关**的，因为未来查询尚未出现。
  - **选择（selection）**：查询到来时决定呈现什么，可以是**查询感知**的。
- **核心问题**：现有记忆评估常把“保留”和“选择”混在一起比较，导致某方法的优势可能来自：
  - 更好的选择/检索；
  - 更好的保留；
  - 或者只是被授予了竞争对手已丢弃的完整历史访问权。
- **背景审计**：作者审计早期评估发现：
  - 最强方法在查询时重排完整历史，最弱方法只能看有界缓冲区；
  - 模板缺陷使查询缺少可识别目标事实的 token；
  - 干扰项带有字面标记，可被重叠打分器利用；
  - 两个条件实际上都保留完整历史，却被报告出巨大差距。
- **整体含义**：有界记忆评估应**固定历史访问**，并**分别报告保留率和选择/召回效果**。检索性能受保留上限约束：事实一旦被驱逐，再强的检索器也无法恢复。

## 2. 方法论
- **核心思想**：将记忆评估重构为**因子设计**，交叉组合：
  - **保留规则 × 选择规则**；
  - 每个单元格在**相同的 300 个种子回合**上评估；
  - 同时报告 recall 与 retention rate，后者为 recall 的上限。
- **流式召回环境**：
  - 一个 episode 包含 **10 个事实 + 2 个查询**。
  - 每个事实形式为 `"The slot is value."`，slot 在同一 episode 内无放回抽取，因此查询命名 slot 时可唯一定位事实。
  - 默认 **30% 为干扰项**，来自不相交 slot 词表，但表面形式相同，**无字面标记**。
  - 查询目标从非干扰事实中均匀采样。
- **保留规则**，在线、容量 K、查询不可见：
  - `RECENCY`：保留最近 K 个。
  - `RANDOM`：以 p=0.5 接纳，FIFO 驱逐。
  - `FREQUENCY`：驱逐目前 token 最稀有的事实，平局 FIFO。
  - `TYPE-ORACLE`：只接纳非干扰项，读取生成器真值标签，属于**特权规则**，智能体不可实现。
  - `UNBOUNDED`：保留全部，作为无遗忘参照。
- **选择规则**，查询时对幸存项排序并暴露 top k=3：
  - `RECENCY`
  - `RANDOM`
  - `QUERY`：查询与事实 token 的 Jaccard 重叠，最近性打破平局。
  - `DENSE`：MPNet 句向量余弦相似度，768 维。
  - `ORACLE`：若目标存在则直接呈现。
- **查询信息量控制**：
  - 有信息查询：`"What is the slot?"`，命名目标 slot。
  - 无信息查询：`"What is the value?"`，`value` 不出现在任何事实中。
  - 二者只差一个 token，用于隔离查询信息量。
- **指标与统计**：
  - **Required-fact recall**：目标事实出现在 top-k 暴露项中的查询比例。
  - **Retention rate**：目标在保留后仍存活的比例，是任意选择规则的 recall 上限。
  - 使用 percentile bootstrap，对 episode 重采样 2000 次，因为同一流中的两个查询不独立。

## 3. 实验设计
- **主要数据集/场景**：
  - 作者构建的**合成流式召回 benchmark**：10 facts、2 queries、默认 K=5、k=3。
  - **SQuAD v1.1 dev**：300 个问题，将目标段落拆成句子，含答案句为目标，用无关段落句子补足到 10 句，查询为真实 SQuAD 问题。
- **对比方法**：
  - 保留规则：`UNBOUNDED`、`RECENCY`、`RANDOM`、`FREQUENCY`、`TYPE-ORACLE†`。
  - 选择规则：`RANDOM`、`RECENCY`、`QUERY`、`DENSE`、`ORACLE`。
- **主要实验条件**：
  - 有信息查询下的完整 5×5 网格。
  - 不同记忆预算：K ∈ {2, 3, 5, 10, 20}。
  - 延迟效应：目标之后到达的事实数，分 0–2、3–5、6–9。
  - 干扰项密度：d ∈ {0.1, 0.3, 0.5, 0.7}。
  - 无信息查询下的 5×5 网格。
  - 干扰项字面标记控制实验。
  - 失败类型分类：eviction、displacement、similarity confusion。
  - 答案正确性验证：将 FLAN-T5-large 接在流水线末端，greedy decoding，normalized exact match。
  - SQuAD 上复现相同网格。
- **关键结果示例**：
  - 混合比较 `UNBOUNDED+QUERY` vs `RECENCY+RECENCY` 报告 +68.7 pp。
  - 固定访问后，查询感知选择仅 +15.5 pp；固定选择后，访问权贡献 +53.2 pp。
  - 有界保留下，`QUERY`、`DENSE`、`ORACLE` 的 recall 均等于 retention rate。
  - `DENSE` 相对词法规则变化 +0.00 pp。
  - 319 个检索失败全部为 eviction，displacement 和 similarity confusion 为 0。
  - 近因保留下，延迟 6–9 时 recall 降至 0%。
  - SQuAD 上保留上限仍在所有 25 个单元格成立，但 `DENSE` 真正优于 `QUERY`：无界 +6.0 pp，有界 +1.7 pp。

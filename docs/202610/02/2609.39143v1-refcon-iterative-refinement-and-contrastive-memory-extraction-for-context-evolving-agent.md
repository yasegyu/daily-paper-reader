## 摘要
长时程智能体交互会产生有用但带有噪声的经验，而重新训练模型以吸收这些经验成本高昂。因此，上下文演化智能体需要能够在不依赖金标签的情况下，随测试时计算量增加而改进的记忆提取方法。我们提出 RefCon，它将顺序自精化与并行自对比相结合，以在无金标签情况下提取更高质量的记忆。在 AppWorld 和 BFCL-V3 上跨多个上下文演化智能体框架进行评估，RefCon 带来强劲且一致的提升，包括相较无扩展基线在 ACE 上 21.6% 和在 ReMe 上 16.6% 的相对改进，而一个以多样性为重点的变体（DivCon）在 ReasoningBank 上取得 35.5% 的提升。RefCon 在无真实标签情况下持续优于现有基线，并能泛化到不同模型规模和软件工程任务，在这些任务上甚至超过真实标签基线。我们进一步分析准确率-词元权衡与扩展行为，表明 RefCon 保持良好效率，并随着使用更多轨迹而持续改进，而仅多样性扩展会更早饱和。

## Abstract
Long-horizon agent interactions generate useful but noisy experience, and retraining models to absorb it is expensive. Context-evolving agents therefore need memory extraction methods that improve with more test-time compute without relying on gold labels. We propose RefCon, which combines sequential self-refinement with parallel self-contrast to extract higher-quality memories without gold labels. Evaluated on AppWorld and BFCL-V3 across multiple context-evolving agent frameworks, RefCon delivers strong and consistent gains, including relative improvements of 21.6% on ACE and 16.6% on ReMe over no-scaling baselines, while a diversity-focused variant (DivCon) achieves a 35.5% gain on ReasoningBank. RefCon consistently outperforms existing baselines without ground-truth labels, and generalizes across model scales and to software engineering tasks, where it surpasses even ground-truth baselines. We further analyze the accuracy-token trade-off and scaling behavior, showing RefCon maintains favorable efficiency and continues to improve as more trajectories are used, unlike diversity-only scaling which saturates earlier.

## 2. 方法论：核心思想与关键技术细节

- **总体思想**：RefCon 是对 MaTTS 的扩展，先通过串行自精炼生成多条逐步改进的轨迹，再通过并行自对比联合分析这些轨迹，提取可复用、可泛化的记忆。
- **问题设定**：在测试时学习（TTL）范式中，智能体顺序面对查询流 \(Q=\{q_1,\dots,q_N\}\)，无权访问未来查询或金标签。记忆状态从 \(M_0=\varnothing\) 开始，任务 \(i\) 时智能体基于当前记忆 \(M_i\) 求解，完成后将轨迹蒸馏为记忆更新，形成 \(M_{i+1}\)。
- **轨迹生成流程**：
  - 先从当前记忆 \(M_i\) 中检索并重写得到任务相关记忆 \(m_i\)。
  - 初始轨迹：\(\tau_{i,1}=\pi_L(q_i,m_i)\)。
  - 串行自精炼：\(\tau_{i,n}=\pi^{\text{refine}}_L(q_i,m_i,\tau_{i,n-1})\)，生成 \(N\) 条从初始探索到逐步修正的轨迹。
- **自对比记忆提取**：
  - 对 \(N\) 条轨迹执行自对比推理，比较成功与失败步骤、关键决策点、技术差异和时机差异。
  - 候选记忆：\(m_{\text{new}}=\pi^{\text{contrast}}_L(\tau_{i,1},\dots,\tau_{i,N})\)。
  - 记忆条目包含两部分：`when_to_use`（何时使用，兼作索引）和 `content`（从轨迹中提炼的洞见），并可附带频率、效用等元数据。
- **去重与记忆更新**：
  - 使用嵌入相似度 \(Sim\) 和阈值 \(\epsilon\) 做记忆去重。
  - 同时进行记忆间比较和候选记忆内部比较，只保留非冗余记忆：
    \(M_{i+1}=M_i\cup\{m\in m_{\text{new}}\mid Sim(m,M_i\cup m_{\text{new}}\setminus\{m\})<\epsilon\}\)。
- **DivCon 变体**：
  - 与 RefCon 的串行精炼不同，DivCon 使用自多样性提示，鼓励智能体探索不同解法：
    \(\tau_{i,n}=\pi^{\text{diversity}}_L(q_i,m_i,\tau_{i,n-1})\)。
  - 其目标是产生高度多样的轨迹，再通过自对比提取记忆。
- **记忆检索**：采用 retrieve–rerank–rewrite 流程：
  - 先基于嵌入相似度从 \(M_i\) 检索候选记忆；
  - 再由 rerank agent 按相关性排序；
  - 最后由 rewrite agent 压缩为与当前查询对齐的简洁记忆 \(m_i\)。
- **记忆管理**：
  - 使用基于效用的删除策略。
  - 对经验 \(E\)，记录总检索次数 \(f(E)\) 和历史效用 \(u(E)\)；当 \(f(E)\ge\alpha\) 且平均效用 \(u(E)/f(E)\le\beta\) 时删除。
- **关键超参数**：
  - 扩展因子通常为 3，DivCon 为 2。
  - 每次提取最多 5 条记忆。
  - 并行 rollout 温度分别为 0.7、0.85、1.0；默认温度 0.7。
  - ReMe 与 RefCon 使用 top-k 检索 10，再 rerank 选 top-5。
  - 去重阈值 \(\epsilon=0.5\)，剪枝阈值 \(\alpha=5n\)、\(\beta=0.5\)。

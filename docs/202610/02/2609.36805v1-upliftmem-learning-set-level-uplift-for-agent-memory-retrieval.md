## 摘要
大语言模型（LLM）智能体复用外部记忆来指导新任务，但有效的检索需要学习哪些记忆集合能够提升执行效果。此类学习依赖代价高昂的结果反馈：普通检索只能观察到已执行的集合，而评估备选集合则需要额外的 rollout。我们提出 UpliftMem，它基于同一执行器在无记忆条件下的集合级执行提升来学习记忆检索。对检索偏好如何限制反馈覆盖范围的理论分析，促使我们对备选记忆集合进行有针对性的探测。探测选择遵循期望样本信息价值（EVSI）准则，该准则在相关高斯模型下以闭式形式推导，从而根据其对局部检索决策的预期改进来分配有限的训练 rollout。共享评分器与冻结执行器一起训练，并在测试时无需探测即可选择记忆集合。在 ALFWorld、WebShop 和 BigCodeBench 上，UpliftMem 在主要评估集上取得了所评估基线中最佳的成功率。受控的固定存储库和匹配探测预算评估进一步表明，其改进了记忆使用决策，并更有效地利用了执行反馈。

## Abstract
Large language model (LLM) agents reuse external memory to guide new tasks, but effective retrieval requires learning which memory sets improve execution. Such learning relies on costly outcome feedback: ordinary retrieval observes only executed sets, while evaluating alternatives requires additional rollouts. We introduce \textsc{UpliftMem}, which learns memory retrieval from set-level execution uplift relative to the same executor without memory. A theoretical analysis of how retrieval preferences restrict feedback coverage motivates targeted probing of alternative memory sets. Probe selection follows an expected value of sample information (EVSI) criterion, derived in closed form under a correlated Gaussian model, to allocate limited training rollouts according to their expected improvement in local retrieval decisions. The shared scorer is trained with a frozen executor and selects memory sets without test-time probes. Across ALFWorld, WebShop, and BigCodeBench, \textsc{UpliftMem} achieves the best success rates among evaluated baselines on the main evaluation sets. Controlled fixed-store and matched probe budget evaluations further demonstrate improved memory-use decisions and more effective use of execution feedback.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 智能体通过复用外部记忆（如过往轨迹、程序性经验）来指导新任务，但"语义相关"并不等于"执行有用"。论文图 1(a) 给出典型案例：任务为"寻找 60 美元以下的防水背包"，智能体在**无记忆**时本可成功，却因检索到推荐记忆而购买了 89 美元的商品，导致失败。
- **核心矛盾**：
  - 有效检索需要学习"哪些记忆集合能提升执行效果"，但这一监督信号依赖**代价高昂的结果反馈**。
  - 普通检索只能观测到**已被执行的记忆集合**，要评估备选集合则必须额外 rollout。
  - 一旦某集合从未被选中，其真实 uplift 就无法被直接观测，被低估的集合将长期得不到纠正——形成"检索偏好限制反馈覆盖"的恶性循环。
- **研究意义**：论文把"记忆检索"重新定义为**耦合了反馈获取的学习问题**：不仅学习用哪些经验，还要决定**哪些缺失的结果值得观测**。这一视角对提升智能体记忆利用效率、降低训练成本具有普遍意义。

## 2. 方法论

### 2.1 核心思想
- 以**同一执行器在无记忆条件下的执行结果**为参照，定义记忆集合的**执行提升（execution uplift）**：
  - Δ(c, S) = V(c, S) − V(c, ∅)
  - 其中效用 U(τ) = R(τ)[1 + γ·I(R≥ρ)(1 − C/C_max)]，同时纳入任务表现 R 与执行成本 C。
- 学习一个共享评分器 Gθ(c, S) 预测集合级 uplift（约定 Gθ(c, ∅)=0），并以 **EVSI 准则**在有限 rollout 预算下定向探测备选记忆集合。

### 2.2 关键技术细节
- **集合构建与执行反馈**：
  - 先经相似度召回构造候选池 C(c)；从 S=∅ 开始，按**条件增益** gθ(m|c,S) = Gθ(c,S∪{m}) − Gθ(c,S) 逐步添加记忆，STOP 增益记为 0。
  - 训练时按 softmax(gθ/τ_tr) 采样动作（式 6）；测试时用**宽度为 2 的 beam search**，允许保留中间负增益集合以暴露记忆互补性。
- **理论分析（命题 1）**：证明普通检索返回集合 B 的概率 pB 受累计动作赤字 d(a) 约束：pB ≤ Σ exp(−d(a)/τ_tr)。即局部不被偏好的动作会抑制其构造集合的直接反馈，说明需要主动探测。
- **决策感知探测（EVSI）**：
  - 在相关高斯代理模型 G̃(c,S) = Gθ(c,S) + φ(c,S)ᵀξ, ξ~N(0,Σ) 下，对局部比较 j 定义可消解方差 s²_j(Q)。
  - **定理 2（闭式 EVSI）**：E_j(Q) = s_j(Q)·ψ(|μ_j|/s_j(Q))，其中 ψ(t)=φ(t)−tΦ(−t)，μ_j 为当前比较边际。该值同时考虑可消解不确定性与预测效用差，无需模拟结果即可比较候选探测。
  - 聚合 H(Q)=Σ_j E_j(Q)，按 softmax(V_t(q)/τ_evsi) 逐个采样探测（式 49），并考虑已排期观测的协方差（式 45–46）。
- **训练目标（冻结执行器）**：
  - **值监督** L_value = λ_reg·L_reg（Huber 回归，按 uplift 幅度加权）+ λ_sign·L_sign（符号 BCE）+ λ_pair·L_pair（成对排序 softplus）。
  - **策略监督** L_policy：以观测 uplift 导出符号化、裁剪的权重 ω_i，对采样路径做加权似然（stop-gradient），正权重强化、负权重抑制。
  - 先做 value-only warm-up，再联合优化 L_value + L_policy；执行器全程冻结。
- **记忆写入与验证**：从已完成轨迹蒸馏候选记忆，在源任务上单独验证其 uplift，必要时迭代修订（≤3 次），仅验证通过者进入记忆池；验证记录无论是否被采纳都贡献值监督。

## 6. 主要结论与发现

- **端到端性能**：UpliftMem 在 ALFWorld 两个 split 和 WebShop 上均取得最高成功率；Qwen3-4B 下达 76.9%/70.9%（ALFWorld seen/unseen）、45.60%（WebShop）、39.77%（BCB）；Qwen3-8B 下达 81.43%/79.10%、44.00%、42.69%（BCB 并列最高）。同时取得最高 WebShop reward 与最少 ALFWorld seen 步数。
- **受控检索增益**：固定存储下，记忆使用决策准确率从 41.7%→66.5%（Qwen3-4B）、44.4%→68.8%（Qwen3-8B）；Scope Control 准确率提升 23.7–62.7 个百分点，Evidence Conflict 提升 29.1–54.6 个百分点；Valid Selection 在全部 10 组存储-执行器对比中准确率提升，过期记忆使用在 9 组中下降。
- **消融结论**：完整模型全面最优；仅 warm-up 或随机探测均明显下降；去掉 policy loss 或 value loss 均降低决策准确率，说明值估计与结果加权路径学习互补。
- **探测效率**：EVSI 在每个非零预算下累计成功率最高，50 条探测即达 48.0%（随机 42.0%）；200 条时 mean reward 0.694 vs. 随机 0.670。ALFWorld 与 BCB 上同样领先。
- **检索预算敏感性**：跨模型平均增益在 K=3/5/10 时分别为 14.2/15.8/15.1 个百分点，说明方法对上下文容量不敏感；且随 K 变化会自适应地修正不同类型的记忆使用错误（K 增大时 Evidence Conflict 增益上升、Scope Control 增益下降）。

## 7. 优点

- **问题建模新颖**：将记忆检索形式化为"学习集合级执行提升 + 反馈获取"的耦合问题，明确指出检索偏好会限制反馈覆盖，并用命题 1 给出概率上界，理论动机清晰。
- **决策感知的探测准则**：在相关高斯代理下闭式推导 EVSI（定理 2），无需模拟即可比较候选探测；相关结构让一次观测可同时降低多个比较的不确定性，反馈利用效率高。
- **集合级建模**：直接对完整记忆集合估值，捕捉记忆间的互补、冗余与冲突，避免单条记忆独立打分忽略交互。
- **训练/推理解耦**：执行器冻结，测试时无需探测，部署成本可控。
- **实验设计扎实**：固定存储的受控对比能干净地隔离检索贡献；匹配预算的探测策略对比、多预算曲线、检索预算敏感性共同支撑结论。
- **记忆写入验证机制**：候选记忆在源任务上单独验证 uplift 后才准入，且验证数据无论采纳与否都用于值监督，兼顾质量与样本利用。

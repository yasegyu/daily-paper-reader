## 摘要
基于文本的记忆和上下文压缩支持对过往交互的复用。调整连续记忆的大小会改变冻结LLM的输入，从而将容量分配与读出耦合。我们提出硬源自适应软化记忆（HasMem）。冻结的硬提示嵌入提供了可验证的初始状态。控制器调整记忆宽度，Writer对调整大小后的条目重新编码，Reader和Global提供读出适配与跨轮状态。在源自多会话聊天（Multi-Session Chat, MSC）开发划分的重构探针的全部535个问题上，主配置在达到硬参考的框定记忆位置的93.6%时，取得了95.3的词法F1（+4.4个百分点）。在每个问题目标主体预算大致匹配的情况下，六种配置在平均每条目保留率约为0.83--0.91时，其精确匹配（EM）百分比比基于规则的重编码高出8.0--23.6个百分点。在固定模型参数且规则目标宽度比为0.75时，Global的EM增益在八项比较上通过了带Bonferroni校正的用户级精确配对检验。在所有500个LongMemEval-S问题上，局部词法F1从硬参考的3.4升至8.9，答案负对数似然（NLL）从12.257降至5.274。在两项评估中，F1的提升均伴随更低的EM。

## Abstract
Text-based memory and context compression support reuse of past interactions. Resizing continuous memory changes the input to a frozen LLM, coupling capacity allocation with readout. We propose Hard-Origin Adaptively Softened Memory (HasMem). Frozen hard-prompt embeddings provide a verifiable initial state. A controller adjusts memory widths, a Writer re-encodes resized entries, and Reader and Global provide readout adaptation and cross-turn state. On all $535$ questions in a reconstruction probe derived from the Multi-Session Chat (MSC) development split, the main configuration achieves lexical F1 of $95.3$ ($+4.4$ percentage points) at $93.6\%$ of the hard reference's framed memory positions. With approximately matched per-question target body budgets, six configurations at mean per-entry retention around $0.83$--$0.91$ exceed rule-based re-encoding by $8.0$--$23.6$ exact-match (EM) percentage points. With fixed model parameters and rule target width ratio $0.75$, Global's EM gain passes a user-level exact paired test with Bonferroni correction over eight comparisons. On all $500$ LongMemEval-S questions, local lexical F1 rises from the hard reference's $3.4$ to $8.9$, and answer negative log-likelihood (NLL) falls from $12.257$ to $5.274$. F1 gains accompany lower EM on both evaluations.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：长期 LLM 智能体需要保留历史交互信息以回答后续问题。现有方案包括文本记忆/笔记式记忆、分页上下文、连续记忆压缩、token 压缩与自适应压缩等。
- **核心问题**：当连续记忆的“宽度”随交互变化时，冻结 LLM 的输入也随之改变，导致**容量分配、重编码与读出过程相互耦合**；这使持久连续记忆难以在保持冻结主干可验证性的同时动态调整记录大小。
- **关键洞察**：冻结 LLM 的 token embedding 可作为“硬提示”初始状态，为逐记录宽度自适应提供可验证起点。
- **整体含义**：论文提出 **HasMem（Hard-Origin Adaptively Softened Memory）**，在冻结 LLM 参数 \(W_0\) 之外维护可变宽度 Soft Bank，通过 Controller、Writer、Reader、Global 分别完成宽度决策、重编码、读出适应与跨轮状态维护，试图解耦“记忆容量”与“读出”。
- **核心张力**：F1 等词法指标提升常伴随 EM 下降与 NLL 上升，说明方法改善的是部分召回/覆盖，而非严格的精确重建。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 核心思想

- 每条记忆记录以冻结 token embedding 初始化，形成**硬源（hard origin）**。
- 记录存放在 Soft Bank 中，宽度 \(K_{i,t}\) 可随交互被 KEEP、SHRINK 或 EXPAND。
- 所有新增模块位于冻结主干之外；若轨迹全为 KEEP，则与硬提示参考在相同检索与输入构造下**完全等价**。

### 2.2 架构组成

- **Soft Bank**：第 \(i\) 条记录由角色框定 token 序列 \(c^{pre}_i, c^{suf}_i\) 与主体槽 \(S_{i,t}\in\mathbb{R}^{K_{i,t}\times d}\) 构成。
- **Global 状态** \(g_{u,t}\)：跨轮递归状态，条件化 Writer 与 Reader。
- **共享位置编码器**：对序列做层归一化、GELU、均值池化，得到特征 \(\phi(V)\)。

### 2.3 Controller（宽度决策）

- 动作空间：\(\{\text{KEEP}, \text{SHRINK}, \text{EXPAND}\}\)，索引 0/1/2。
- 输入特征 \(z_{i,t}\) 拼接：槽特征、最新记录特征、年龄、保留率 \(K_{i,t}/L_i\)、时间步、KEEP 连续次数等。
- 两层 MLP + Tanh 预测相对成本 \((\tilde\rho_1,\tilde\rho_2)\)，其中 \(\tilde\rho_0\equiv 0\)；取 argmin 作为动作，最终层零初始化，平局选 KEEP。
- 宽度更新：
  - KEEP：保持不变；
  - SHRINK：\(K_{i,t+1}=\max(K_{\min}, K_{i,t}-\lceil\eta K_{i,t}\rceil)\)；
  - EXPAND：\(K_{i,t+1}=\min(L_i, K_{i,t}+\lceil\eta K_{i,t}\rceil)\)。
- 宽度受限于 \([K_{\min}, L_i]\)，短记录保持初始宽度。

### 2.4 Writer（重编码）

- 仅当宽度变化时修改槽内容。
- SHRINK 用自适应平均池化 AvgPool，EXPAND 用线性插值 Interp 得到 \(A_{i,t}\)。
- 加入 Global 条件化残差：
  \[
  S_{i,t+1}[j]=A_{i,t}[j]+U(\mathrm{GELU}(W_e\mathrm{LN}(A_{i,t}[j]))+g_t)
  \]
  其中 \(U\) 零初始化。
- KEEP 保留原槽；EXPAND 以 \(L_i\) 为上界。

### 2.5 Reader（读出适应）

- 对冻结注意力输出投影 \(W_o^{(\ell)}\) 加低秩增量：
  \[
  \Delta_R^{(\ell)}(h)=B_r^{(\ell)}A_r^{(\ell)}h
  \]
- 下投影 \(A_r\) 与上投影 \(B_r\) 学习，\(B_r\) 零初始化，推理时参数固定。

### 2.6 Global（跨轮状态与条件化）

- 用 GRU 按记录顺序更新：
  \[
  g_t=g_{t-1}+\beta_t(\mathrm{GRU}(\phi_t,g_{t-1})-g_{t-1})
  \]
  其中 \(\beta_t=\sigma(w_r^\top\phi_t+b_r)\)，\(w_r\) 零初始化。
- 在 Reader 注意力层，用超网络 \(B_g^{(\ell)}(g_t)\) 生成状态条件化上投影：
  \[
  \Delta_G^{(\ell)}(h;g_t)=B_g^{(\ell)}(g_t)A_g^{(\ell)}h
  \]
- Global 同时条件化 Writer 与 Reader。

### 2.7 推理流程

- **写入与硬初始化**：\(S_{i,0}=E(x_i)\)，\(K_{i,0}=L_i\)。
- **软化调度**：每个新记录步最多访问一个条目，按 round-robin 间隔 \(c_{rev}\) 轮转；后历史维护延续该调度。
- **检索**：对问题 token 与记录槽做位置均值余弦相似度，取 top-k 条目。
- **输入构造**：系统提示 + 检索到的“角色框定 + 槽 + 角色框定” + 问题 token。
- **状态条件读出门控**：首次宽度变化后激活 Reader/Global 增量：
  \[
  \tilde W_o^{(\ell)}(g_t)=W_o^{(\ell)}+\gamma_t B_r^{(\ell)}A_r^{(\ell)}+\gamma_t B_g^{(\ell)}(g_t)A_g^{(\ell)}
  \]
- **硬等价性**：全 KEEP 轨迹下 \(S_{i,t}=E(x_i)\)、\(\gamma_t=0\)，在相同检索、顺序、tokenization、模板、位置编码、注意力掩码与推理设置下，与硬参考输入、冻结算子、logits 完全一致。

### 2.8 位置预算与存储

- 总 bank 位置：
  \[
  C_t=\sum_{i=1}^{N_t}(K_{i,t}+|c^{pre}_i|+|c^{suf}_i|)
  \]
- 持久数值载荷：
  \[
  b_s d\sum_i K_{i,t}+b_g m+b_c\sum_i(|c^{pre}_i|+|c^{suf}_i|)
  \]
- 目标主体比例 \(R_{body}(q)\) 与平均每条目保留率 \(\bar r\) 用于近似匹配预算比较。

### 2.9 训练

- 冻结 \(W_0\)，使用 QA 监督。
- **质量与位置成本**：
  \[
  Q_a=\frac1{|Q|}\sum_q(\ell_{a,q}+\lambda_{damage}[\ell_{a,q}-\ell_{h,q}]_+)
  \]
  \[
  J_a=Q_a+\lambda_{cost}c_a
  \]
- **Warm-up**：最小化 KEEP/SHRINK/EXPAND 三支平均 \(Q_a\)，Controller 以 stopped-gradient 回归目标 \((J_1-J_0,J_2-J_0)\)。
- **Policy 监督**：有界搜索训练 QA 历史，寻找含 SHRINK 且降低累计位置、满足 NLL 容忍、改善搜索目标的序列；最佳序列的首个非 KEEP 作为标签。无合格序列时按概率采样弱 SHRINK 标签。
- **策略损失**：
  \[
  L_{policy}=L_\pi+L_{band}+L_{hinge}+L_{streak}
  \]
  包括动作分类、非 KEEP 频率带惩罚、Writer 答案 NLL damage hinge、KEEP 连续惩罚。
- 损失按 owner 等权平均。

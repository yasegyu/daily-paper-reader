## 摘要
长期记忆使智能体能够跨会话积累信息并进行推理，但现有研究主要集中于双人文本或图文对话，使得多方语音对话中的长期记忆仍未得到充分探索。该场景要求保留对话内容、跨会话识别参与者，并记住谁对谁说话。为此，我们提出 VoxPolyMem，一个交互感知的多模态记忆框架，将增量说话人识别与由交互记忆、事实记忆和参与者画像组成的记忆层次结构相结合。我们将检索建模为序列决策，其中智能体基于累积证据重写查询并选择检索工具和记忆层，以弥补信息缺口。我们进一步提出 Evidence-Gain GRPO（EG-GRPO），其使用逐轮信用分配来鼓励获取互补证据。我们还构建了 VoxPolyBench，用于评估多方语音对话中的记忆演化、个性化回答、记忆检索与推理，以及交互推理与归因。VoxPolyMem 在 VoxPolyBench 上取得 85.0 的总分，超过评估中最强基线 23.6 分。在 Mem-Gallery 和 H2HMem-Multi 上，其得分分别为 89.6 和 74.4，均比评估中最强的公开记忆基线高出 8 分以上。这些结果凸显了其在多方多模态交互中提供持久、个性化辅助的潜力。代码和数据集见 https://voxpolymem.github.io/VoxPolyBench/demo/

## Abstract
Long-term memory enables agents to accumulate information and reason across sessions, yet existing research primarily focuses on dyadic text or image-text conversations, leaving long-term memory for multi-party spoken conversations underexplored. This setting requires preserving conversational content, identifying participants across sessions, and retaining who speaks to whom. To this end, we propose VoxPolyMem, an interaction-aware multimodal memory framework combining incremental speaker identification with a memory hierarchy comprising interaction memory, fact memory, and participant profiles. We formulate retrieval as sequential decision-making, where an agent rewrites queries and selects retrieval tools and memory layers based on accumulated evidence to address information gaps. We further introduce Evidence-Gain GRPO (EG-GRPO), which uses round-wise credit assignment to encourage complementary evidence acquisition. We also construct VoxPolyBench to evaluate memory evolution, personalized answering, memory retrieval and reasoning, and interaction reasoning and attribution in multi-party spoken conversations. VoxPolyMem achieves an overall score of 85.0 on VoxPolyBench, surpassing the strongest evaluated baseline by 23.6 points. On Mem-Gallery and H2HMem-Multi, it scores 89.6 and 74.4, respectively, exceeding the strongest evaluated public memory baselines by over 8 points each. These results highlight its potential for persistent, personalized assistance in multi-party multimodal interactions. Code and datasets are available at https://voxpolymem.github.io/VoxPolyBench/demo/

## 1. 核心问题与研究动机

- **背景**：长期记忆让智能体能够跨会话积累信息并推理，近期系统已能整合对话事实、关联记忆并纳入多模态信息（如 Mem0、A-Mem、Zep、LightMem、MemVerse 等）。
- **核心缺口**：现有长期记忆研究几乎集中在**双人（dyadic）文本或图文对话**，而**多人语音对话**的长期记忆仍未被充分探索。
- **场景特殊性**：车载、会议、家庭助手等场景需通过语音与多个参与者交互，要求智能体：
  - 保留对话内容；
  - 跨会话**识别说话人身份**（声学身份线索）；
  - 记住**谁对谁说了什么**（交互角色）。
- **现有方法不足**：
  - 仅存 ASR 转录会丢失声学身份线索；
  - 时间图 / 语义抽象式记忆不显式存储“说话人-受话人”关系；
  - 固定检索策略难以应对随证据累积而出现的信息需求；
  - 终端奖励（如 Search-R1）无法隔离每轮检索对获取新证据的贡献。
- **整体含义**：论文提出 **VoxPolyMem** 框架与 **VoxPolyBench** 基准，首次系统性地研究多方多会话语音对话的长期记忆构建与检索。

## 2. 方法论

### 2.1 核心思想
将**增量说话人识别**、**交互感知分层记忆**（交互记忆 / 事实记忆 / 参与者画像）与**自适应智能体检索**统一，并用 **EG-GRPO** 训练检索策略。

### 2.2 在线说话人识别（§4.1）
- 用 **ECAPA-TDNN** 编码每轮音频得到归一化声纹嵌入 \(e_i\)。
- 维护匿名说话人集合 \(V=\{(k,v_k)\}\)：与已有嵌入做余弦相似度匹配，若 \(s_i \ge \tau_{match}=0.35\) 则归属该 ID，否则新建 ID（无需预设人数）。
- **置信门控 EMA 更新**：仅当 \(s_i \ge \tau_{update}=0.40\) 时以 \(\alpha=0.05\) 更新嵌入，避免强化不确定匹配。
- **身份调和（identity reconciliation）**：会话结束后基于累积声纹证据保守合并碎片化 ID，不依赖参与者名单或目标说话人数。

### 2.3 交互感知分层多模态记忆（§4.2）
- **交互记忆**：以有向图 \(M_{int}=(P\cup U,E)\) 保存多模态消息与关系，边集为
  - `speaker_i --speaks--> u_i`
  - `u_i --addresses--> p`（p ∈ 受话人集合 \(A_i\)）
  - 每条消息保留文本、图像、时间戳、会话位置；用 Qwen3-VL-Embedding 编码文本与图像（与声纹嵌入分离）。
- **事实记忆**：`(content_j, speaker_j, addressee_j, time_j)`，自包含陈述，保留 `refer id` 指回源对话轮。
- **参与者画像**：`(name_p, aliases_p, {(k,v_k)}_{k∈K_p}, attributes_p)`，含姓名、别名、关联声纹、背景与偏好。
- 由 LLM 在“当前轮 + 最多前 3 轮”上下文中联合抽取事实、属性、受话人与时间引用，并把匿名 ID 与姓名/别名关联。

### 2.4 可训练智能体检索（§4.3）
- 将检索建模为**序贯决策**：
  - 状态 \(s_t=(q, asker_q, C_{t-1}, H_{t-1}, b_t)\)
  - 动作 \(a_t=(\ell_t, \rho_t, eq_t, f_t)\sim\pi_\theta(\cdot|s_t)\)：选择记忆层（交互/事实/画像）、工具（向量/BM25 文-文、文-图、图-图）、改写查询、可选说话人/受话人过滤。
- 用 RRF 融合、去重、上下文选择更新证据；LLM 判断信息缺口继续检索，或证据充分/三轮用尽时作答。
- 语音查询通过画像声纹匹配识别提问者 \(q\)。

### 2.5 Evidence-Gain GRPO（EG-GRPO）
- 每个状态采样 \(K=8\) 个候选动作组成 GRPO 组，保留至多 \(k=15\) 条记忆记录。
- 令 \(D_i=(U_i\cap G_q)\setminus B\) 为**新保留的支撑 ID**（\(B\) 为历史已保留 ID），\(p_i(e)\) 为最早排名：
  - 覆盖率项 \(|D_i|/|G_q|\)；
  - 排名项 \(N_i=\frac{1}{Z_q}\sum_{e\in D_i}\frac{1}{\log_2(p_i(e)+1)}\)；
  - 奖励 \(r_i=\lambda\frac{|D_i|}{|G_q|}+(1-\lambda)N_i\)；
  - 优势 \(\hat A_i=\frac{r_i-\mu}{\sigma+\delta}\)。
- 历史已保留证据不再获得奖励，**鼓励跨层、跨模态获取互补证据**；训练时按证据覆盖停止扩张，推理时不使用金标注。
- 目标函数为带裁剪与 KL 正则的 GRPO 目标 \(J_{GRPO}(\theta)\)，仅对生成的动作 token（层/工具/查询/过滤）计算损失，答案模型固定。

## 6. 主要结论与发现

- VoxPolyBench 总体 **85.0**，超最强外部基线 **23.6 分**；个性化回答 76.1、交互归因 87.5 表现突出。
- Mem-Gallery **89.6**（+11.8）、H2HMem-Multi **74.4**（+8.4）；加权平均 **86.6 vs 68.1**。
- **w/o RL 已达 84.4**，超过所有外部基线，说明记忆结构与智能体检索本身即有效；RL 进一步带来整体提升（Mem-Gallery 86.3→89.6，H2HMem-Multi 72.1→74.4）。
- **消融结论**：移除分层记忆（事实+画像）在 H2HMem-Multi 降幅最大（72.1→63.6）；移除交互关系对 VoxPolyBench 影响最大（84.0→78.6）；单轮检索比“保留多轮但原查询”退化更严重，说明**迭代检索比查询改写更关键**。
- **策略对比**：Search-R1（终端答案奖励）反而全面下降；Terminal-coverage GRPO 提升召回但答案不稳定；EG-GRPO 在答案分与召回上均最优，且**平均检索轮次最少（1.2–1.3 vs 1.4–1.8）**。
- **说话人跟踪**：VoxPolyBench 97.7%、IEMOCAP 95.0%、AMI 87.9%（仅用冻结 ECAPA + 真值句界，无名单/人数先验）。

## 7. 优点

- **问题定位新颖**：首个面向多会话、多方语音对话长期记忆的基准 VoxPolyBench，同时覆盖跨会话身份恢复、记忆演化、个性化、交互归因。
- **记忆结构设计合理**：把“谁对谁说”显式建模为有向交互图，事实与画像保留 `refer id` 溯源，兼顾语义抽象与证据可追溯。
- **检索建模完整**：层选择 + 工具选择 + 查询改写 + 过滤器的联合动作空间，支持文-文/文-图/图-图跨模态检索。
- **奖励设计有针对性**：EG-GRPO 的轮次级信用分配只奖励“新获取”的支撑证据，并用排名加权，避免重复证据刷分，实证上同时提升分数与效率。
- **实验严谨性亮点**：对基线给真值说话人标签、自身自动识别；双 LLM 评委 + 人工审计；给出 WER、AR I 等量化指标与详细附录。
- **工程可复现**：提供代码与数据集链接，附录给出阈值、超参、停止条件与示例计算。

## 8. 不足与局限

- **数据真实性**：VoxPolyBench 全部使用**生成对话 + 合成语音**，无法验证真实说话人、口音、录音条件、噪声与语音重叠场景下的

鲁棒性；合成语音的声纹分布相对干净，VoxPolyBench 上 97.7% 的说话人识别成绩可能被高估，真实录音中的信道差异、远场混响、情绪与语速变化的影响未知。

- **说话人识别依赖理想化前提**：评测使用**真值句边界**（oracle segmentation），未涉及说话人日志（diarization）中的边界检测、说话人切换与**语音重叠（overlap）**问题，而这些恰是多方语音场景最困难的部分；AMI 上仅 87.9% 也说明自然会议语音下仍有明显差距。
- **训练规模与数据偏置**：EG-GRPO 仅训练 1 个 epoch、约 900 个 QA，训练集还包含 VoxPolyBench 的 200 条样本，存在**训练/测试同源**带来的领域偏置风险；策略在全新领域、全新语言上的泛化能力未验证。
- **奖励依赖金标注**：EG-GRPO 的训练奖励需要金标注支撑对话轮 \(G_q\) 才能计算覆盖率与排名项，这意味着**训练阶段仍需人工或高成本标注**；虽然推理阶段不使用金标注，但标注成本与标注质量对策略的影响未做敏感性分析。
- **模型与成本耦合**：记忆抽取与答案生成均依赖 GPT-4.1-mini，检索策略依赖 8B Qwen-VL，属于**多模型级联**系统；未报告推理延迟、token 成本与端到端开销，也未验证更换答案模型（如开源模型、更小模型）后结论是否稳定。
- **级联误差**：抽取错误（事实、受话人、时间引用、匿名 ID 与姓名关联）会沿记忆→检索→回答链路传播，论文未给出抽取准确率与端到端误差归因分析。
- **缺少纵向与规模压力测试**：会话数量为每场景 8–12 个、参与者规模有限，未考察数月/数年跨度、参与者数量显著增加（如 >10 人）时交互图与画像的可扩展性、冲突消解与遗忘机制。
- **隐私与伦理讨论缺失**：长期存储声纹嵌入与参与者画像涉及生物特征与个人数据，论文未讨论隐私保护、数据留存策略或合规问题。
- **评测细节的稳健性**：双 LLM 评委虽降低单一评委偏置，但两者同源（GPT-4.1 系列）可能共享系统性偏好；人工审计仅 200 条，且承认条目级一致性有限，评分粒度（5 级 rubric）对细粒度差异的区分度也未验证。
- **基线可比性仍有边界**：尽管对基线提供了真值说话人标签，但部分基线（如 mem0、A-Mem）原本并非为多模态/多方场景设计，直接迁移可能低估其潜力；反之 VoxPolyMem 的记忆结构专门适配该任务，任务与架构的**匹配度差异**未被完全剥离。

## 9. 结论与方法论启示

- **核心结论**：多方、多会话、多模态语音场景下的长期记忆，不能简单沿用双人文本记忆范式，必须显式建模**声学身份、交互关系（谁对谁说）与分层证据**，并让检索策略随证据累积自适应调整。
- **方法启示**：
  - **结构化记忆本身即有效**——即使不做 RL（w/o RL 84.4）也已超过所有外部基线，说明“交互图 + 事实 + 画像 + refer id 溯源”的结构设计是主要增益来源。
  - **多轮迭代检索比查询改写更关键**——单轮检索退化最严重，表明证据收集的**序贯性**是该任务的内在需求。
  - **信用分配方式决定策略质量**——终端奖励（Search-R1）会因无法隔离每轮贡献而失效，轮次级、只奖励**新增**证据的 EG-GRPO 同时提升了准确率与检索效率（轮次更少）。
- **实践启示**：在车载、会议、家庭助手等落地场景中，可优先部署“显式交互记忆 + 增量说话人识别 + 多轮智能体检索”的组合，RL 作为可选增益项而非前置依赖。

## 10. 总体评价

- **贡献完整度**：论文同时提供**基准（VoxPolyBench）、框架（VoxPolyMem）与训练方法（EG-GRPO）**，三者形成闭环，且公开代码与数据，属于该细分方向的开创性工作。
- **创新点**：把“说话人身份恢复”“交互归因”“多模态分层记忆”“证据增益式策略优化”统一在一个可训练检索框架内，问题定义与方案设计匹配度高。
- **实证强度**：主实验覆盖 3 个基准、10 个外部基线，辅以 5 组消融、4 种策略对比、跨数据集说话人跟踪与人工审计，证据链相对完整，且对基线设置更有利条件（真值说话人标签），结论可信度较高。
- **主要短板**：数据全合成、说话人识别依赖真值句界、训练规模小且与测试同源、算力与推理成本未披露、缺少真实噪声与重叠语音的鲁棒性验证。
- **适用边界**：结论最适用于“合成或较干净的多人多会话语音 + 中短时间跨度 + 有限参与者”的场景；向真实录音、长时跨度、大规模参与者与隐私敏感部署迁移时，仍需额外的鲁棒性、可扩展性与合规性验证。

## 摘要
基于大语言模型（LLM）的多智能体系统日益依赖记忆，将执行轨迹转化为可复用的过程性知识。然而，重复检索也会使记忆错误持续存在：当过时、支撑不足或虚假成功的流程成为未来推理中反复出现的组成部分时，便会产生记忆污染。多智能体执行还引入了额外的结构性风险。当过程性知识脱离其被证明有效的协调范围，并在不兼容的决策层级上被反复复用时，就会发生范围坍缩，使局部错误能够影响下游决策的级联。同时，任务级失败提供的监督信号含糊不清，因为它们很少揭示是哪些被召回的知识导致了失败。我们提出 AECG，一个面向多智能体系统的非对称经验巩固与治理框架。AECG 将记忆从静态经验存储转变为动态可靠性治理循环，保留协调范围，并使用多尺度、置信度感知的可靠性来检测退化。然后，它结合退化与下游影响，在有限的审查预算下优先处理高风险知识，施加针对性干预，并且仅在配对回放后才重新激活修订后的技能。在三个多智能体框架和四个基准上，AECG 在 12 个框架--基准设置中的 11 个取得最佳得分，并比最强的竞争记忆方法最多提升 10.23 个百分点；移除范围保留会使准确率最多下降 16.89 个百分点。因此，AECG 将多智能体记忆从被动积累重构为可审计的可靠性治理。代码见 https://github.com/fenhg297/AECG

## Abstract
Large language model (LLM)-based multi-agent systems increasingly rely on memory to transform execution trajectories into reusable procedural knowledge. Yet repeated retrieval also makes memory errors persistent: memory pollution arises when outdated, weakly supported, or spuriously successful procedures become recurring components of future reasoning. Multi-agent execution introduces an additional structural risk. Scope collapse occurs when procedural knowledge escapes the coordination scope in which it was shown effective and is repeatedly reused at incompatible decision levels, allowing local errors to influence cascades of downstream decisions. Meanwhile, task-level failures provide ambiguous supervision because they rarely reveal which recalled knowledge was responsible. We introduce AECG, a framework for asymmetric experience consolidation and governance for multi-agent systems. AECG turns memory from static experience storage into a dynamic reliability-governance loop, preserving coordination scope and using multi-scale, confidence-aware reliability to detect degradation. It then combines degradation with downstream impact to prioritize high-risk knowledge under a bounded review budget, applies targeted interventions, and reactivates revised skills only after paired replay. Across three multi-agent frameworks and four benchmarks, AECG achieves the best score in 11 of 12 framework--benchmark settings and improves over the strongest competing memory method by as much as 10.23 percentage points; removing scope preservation reduces accuracy by up to 16.89 points. AECG thereby reframes multi-agent memory from passive accumulation into auditable reliability governance. Code is available at https://github.com/fenhg297/AECG

# AECG 论文详细总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：基于 LLM 的多智能体系统越来越依赖记忆，把执行轨迹转化为可复用的过程性知识（procedural knowledge）。已有工作在经验表示、技能抽象、记忆检索方面进展显著，但普遍关注"知识如何形成与召回"，而**忽视其在持续复用下的可靠性衰减**。
- **核心问题一：记忆污染（Memory Pollution）**。一旦过时、弱支撑或"虚假成功"的流程被固化进长期记忆并被反复召回，孤立错误就会变成未来推理的持久组成部分，造成跨任务的持续负迁移。
- **核心问题二：范围坍塌（Scope Collapse）**。多智能体执行跨团队规划、协作事件、角色动作等多个层级。当局部知识脱离其被验证有效的协调范围（coordination scope），被反复用于不兼容的决策层级时，局部错误会沿依赖结构向下游级联传播。
- **核心问题三：监督信号模糊**。任务级失败很少能指出究竟是哪条被召回的知识该负责；而历史成功带来的"惯性"又会掩盖近期的可靠性下降。
- **整体含义**：论文主张多智能体记忆应从"被动经验积累"转向"持续的生命周期治理"，需要回答三个问题——**在何处可安全复用（边界）、何时已退化（检测）、在有限算力下如何干预（优先级）**。AECG 即针对这三问提出的框架。

## 2. 方法论

### 2.1 核心思想
将记忆构建为一个**非对称经验巩固与治理闭环**：约束知识复用边界 → 检测退化 → 按影响优先级排定审查 → 证据路由干预 → 配对回放后才启用修订版本。

### 2.2 关键技术细节

- **问题形式化**：任务流 $\{x_t\}$，每次执行形式化为有向执行图 $G_t=(V_t,E_t)$，产出轨迹 $\tau_t$ 与二值结果 $r_t$。每个节点映射到协调范围 $s(v)\in\{TEAM\}\cup\{EVENT(e)\}\cup\{AGENT(e,a)\}$。系统维护两类带范围标签的对象：过程性记忆 $m$ 与可复用技能 $k$。

- **（1）范围保留（Scope Preservation）**
  - 证据**不跨层级池化**；技能抽象时强制 $s(k)=s(m_{seed})$，即技能继承其种子记忆的协调范围。
  - 该约束同时作用于召回、证据累积、抽象与比较，防止局部经验被提升为系统级知识。

- **（2）非对称证据准入（Asymmetric Evidence Admission）**
  - 成功提供置信度加权的**正证据**；任务级失败**默认不产生负证据**。
  - 引入三元证据状态 $y_{k,u}\in\{1,0,\varnothing\}$（正/负/未决）与置信权重 $c_{k,u}\in[0,1]$。
  - 负证据仅在"归因门"通过时准入：两个独立 LLM 评审员均不弃权、指向**同一技能与同一范围**、且技能出现在实际使用记录中、平均置信度 ≥ 0.70；否则记为未决，失败轨迹保留为 BadCase。
  - 只有被准入的观测集合 $A_k$ 才会更新可靠性信念。

- **（3）技能形成与证据继承**
  - 同范围的过程性记忆需通过"就绪度规则"才可晋升为技能：基于 EMA 构造 $\text{Ready}(m)=\mu(A,B)-\sigma(A,B)$，并要求超过同范围记忆均值加裕度 $\delta_{prom}=0.05$。
  - 抽象后按系数 $\kappa$ 继承种子证据：慢状态继承全部折扣证据，快状态继承量被窗口 $W$ 截断；初始伪计数 $\alpha_0=\beta_0=1$。

- **（4）双时间尺度可靠性估计**
  - 每个技能版本维护两组 Beta 式伪计数信念：**慢信念**（累积历史）与**快信念**（近期、带折扣 $\lambda<1$）。
  - 每次准入观测按 $b^q_{k,u}=b_0+\lambda^q(b^q_{k,\text{prev}}-b_0)+c_{k,u}e(y_{k,u})$ 同时更新两者。
  - 当前失败风险 $R^{fail}_k=1-\mu^F_k$；均值层面的近期退化 $D_k=[\mu^S_k-\mu^F_k]_+$。
  - 实现中用基于信念采样的、**扣除采样噪声基线**的 $R^{drift}_k$ 作为治理用的不确定性感知退化分数；Proposition 1 证明其等价于信念分布下"截断正向退化"的期望，且有 $0\le R^{drift}_k\le[\delta_k]_+$ 等界，说明它是**排序分数而非标定概率或检验统计量**。

- **（5）风险与暴露感知的记忆治理**
  - **暴露计算**：对技能 $k$ 的使用节点 $d_{k,u}$，其观测传播暴露为可达后代按最短路径距离的几何折扣求和（$\gamma=0.5$）；再结合近期均值暴露与上一时间窗使用频次得到 $E_k$。作者强调这是**潜在传播暴露，而非因果效应估计**。
  - **预算化分诊**：技能需满足置信门 $C^{deg}_k\ge\eta_{deg}=0.95$ 且 $R^{drift}_k>0$ 才进入审查；按 $H_k:=E_k R^{drift}_k$ 排序，取前 $B_{review}$ 个。合格局部失败另有事件驱动预算。
  - **证据路由干预**：上下文局部化失败 → **NARROW**（收紧适用边界，不改流程）；跨上下文缺陷 → **REPAIR**（修订流程，保留范围与意图）；证据不足则不生成候选。
  - **回放门控激活**：修订产生**新版本候选**而非原地覆盖。失败夹具检验是否缓解问题行为，历史成功回归夹具检验是否保留既有能力；门控要求两者同时满足（回归容差 $\epsilon_{reg}=0.05$）。否则候选不激活，依据快信念置信度决定继续监控或隔离（$\eta_{unsafe}=0.95$）。

- **算法流程（Algorithm 1 概要）**：范围匹配执行 → 失败保留 BadCase 并做归因 → 更新记忆与信念 → 满足就绪规则则抽象并注册技能 → 周期性审查中计算 $R^{drift}$、$C^{deg}$、$E_k$、$H_k$ 并选出审查集 → 生成干预候选 → 回放门控 → 更新服务状态。

## 6. 主要结论与发现

- **RQ1（性能）**：AECG 在 **12 个设置中的 11 个取得最优**，在三个框架的平均分上均排名第一；相对最强记忆基线最高提升 **10.23 个百分点**（MacNet–ScienceWorld），AutoGen +5.92、MacNet +4.13、AgentNet +5.64。相对 No-Memory 的平均提升分别为 6.36 / 10.75 / 11.29 点，图结构框架（MacNet、AgentNet）增益更大，但 AutoGen 也有提升，说明收益不限于显式 DAG 的框架。
- **RQ2（组件必要性）**：移除范围保留造成最大退化——ScienceWorld 降 **16.89 点**、MBPP-Plus 降 8.34 点；去快信念降 4.76 / 6.26 点；去暴露降 3.36 / 2.58 点。Flat-scope 变体导致 36.5% 的选用跨出原支持范围，成功率 51.29 甚至**低于 No-Memory 的 55.68**，说明失去范围约束的持久记忆会产生负迁移。
- **RQ3（双时间尺度）**：AECG 平均在 **3.8 次使用后**审查被腐蚀技能，累积式变体需 9.7 次，检测延迟减少 60.8%；污染技能失败使用从 17.9 降至 6.4，腐蚀后成功率从 58.2% 升至 64.5%；无治理变体累计 31.2 次污染失败、成功率仅 49.3%。
- **RQ4（暴露感知分诊）**：在相同置信门与固定预算下，暴露感知排序前两次审查覆盖 81.5% 的污染技能预测暴露（risk-only 53.2%、random 49.8%）；腐蚀后成功率分别高 4.3 与 8.4 点；真实失败任务暴露降至 22.4（risk-only 48.6、random 61.2）。
- **总体结论**：可靠的记忆需要同时对**复用边界、可靠性、潜在影响**进行持续治理；AECG 把多智能体记忆从被动积累重构为可审计的可靠性治理。

## 7. 优点

- **问题定位新颖且系统**：将"记忆污染"与"范围坍塌"区分开，并指出多智能体特有的层级化协调范围是风险来源，切中现有记忆工作普遍忽视的长期可靠性问题。
- **非对称证据准入设计合理**：成功给正证据、失败需双评审一致归因才给负证据，且允许弃权，避免把任务级失败误判为某技能的责任，显著降低错误负反馈风险。

- **治理闭环完整**：从边界约束 → 退化检测 → 预算化优先级 → 证据路由干预（NARROW / REPAIR 区分）→ 配对回放门控 → 版本化而非原地覆盖，形成可审计的完整生命周期。
- **结构信号引入巧妙**：用执行图上的距离折扣可达暴露作为"潜在影响"代理，把有限审查预算投向高传播风险技能，且明确不宣称因果。
- **实验控制严格**：机制测试共享 warm-up 快照、固定预算、相同置信门与干预规则，能较干净地隔离各组件贡献；超参数在独立开发集上选择并跨框架跨基准固定，降低过拟合评测集的风险。
- **工程与可复现性**：给出算法伪代码、完整提示模板（技能抽象、保守归因、上下文收窄、流程修复、回放契约）与开源代码链接。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量、训练/推理时长或总 token 成本；对 LLM 多智能体系统而言，记忆治理带来的额外调用开销（双评审归因、技能抽象、回放）值得量化，但论文未给出成本分析。
- **暴露是结构代理而非因果**：$E_k$ 基于可达性与距离折扣，论文自身也承认这"不是因果效应估计"；可能高估仅因图深度大但实际无因果影响的高层技能。
- **归因依赖 LLM 判断**：负证据准入完全依赖两个 LLM 评审员的一致性与置信度阈值 0.70，存在模型同源偏差、提示敏感性、以及误判把真实缺陷判为未决（漏检）的风险；论文未报告归因准确率或人工校验结果。
- **性能并非全面占优**：PDDL 上 ConMem 在 MacNet 超过 AECG 2.56 点，是 12 个设置中唯一例外；说明 AECG 的优势与任务是否"反复复用中间流程"高度相关，在纯规划类任务上收益有限。
- **消融与机制实验覆盖面有限**：消融、范围机制、退化检测、分诊实验主要基于 AgentNet–ScienceWorld（部分加 MBPP-Plus），未在 AutoGen、MacNet 或 FEVER、PDDL 上重复，泛化性证据不足。
- **失败模式偏"受控腐蚀"**：机制实验使用人工注入的技能腐蚀，虽便于隔离变量，但与真实世界中渐进、隐蔽、多因素耦合的记忆退化仍有差距。
- **超参数与阈值手工设定**：$\eta_{deg}=\eta_{unsafe}=0.95$、$\epsilon_{reg}=0.05$、$\gamma=0.5$、归因阈值 0.70 等为固定设计值，只在小型开发集上验证，可能对任务分布敏感；审查预算 $B_{review}$ 被设为部署预算而非调优参数，其敏感性分析缺失。
- **技能版本管理与长期存储成本**：版本化候选、BadCase 与回归夹具的长期

- **技能版本管理与长期存储成本**：版本化候选、BadCase 与回归夹具会随时间持续累积，论文未讨论淘汰、归档或压缩策略，也未量化"治理收益 vs. 存储与回放成本"的权衡，长期运行的可持续性存疑。
- **评估指标偏单一**：主结果以任务成功率/准确率为主，缺少记忆层的内部指标（如召回精确率、误召回率、治理动作的精确率/召回率、单位收益的额外 LLM 调用数与延迟），难以判断增益来自"更好的知识"还是"更保守的使用"。
- **缺少人工标注的归因基准**：归因门是整套方法的关键闸口，但论文没有构建人工标注的"技能—失败"对应数据集来验证 LLM 评审员的归因正确率、弃权率与假阴性率，归因质量只能间接从下游性能推断。
- **回放门控的夹具设计细节不足**：历史成功回归夹具如何采样、覆盖多少历史任务、是否可能因夹具过时导致"通过了回放但实际退化"未被识别，论文未展开；回归容差 $\epsilon_{reg}=0.05$ 的敏感性同样未分析。
- **对分布漂移与任务演化的适应未讨论**：范围与技能一旦固化，面对新任务族或环境规则变化时，边界扩张/合并的机制缺失，可能造成长期"过度收窄"（NARROW 累积）而牺牲可迁移性。
- **规模可扩展性未验证**：实验中的智能体数量、角色层级与记忆规模相对有限，未测试智能体数或技能库规模增长时，暴露计算、分诊排序与版本回放的复杂度与稳定性。

## 9. 对后续研究的启示

- **把"记忆治理"确立为一等公民**：论文表明，记忆系统的关键不只是表示与检索，而是**复用边界、退化检测、影响排序**三者的协同；后续工作可在此框架下替换任一模块（如更强的漂移检测、因果化的暴露估计）而不必重造整体。
- **非对称证据思想可外溢**：成功易得、失败难归因，这一"证据不对称"不仅适用于技能记忆，也适用于工具调用库、提示模板库、多智能体角色配置等其他可复用资产的维护。
- **结构信号作为低成本先验**：用执行图可达性做影响代理，是在缺乏因果实验时的一种务实折中；未来可探索反事实回放或干预式估计来替代纯结构折扣。
- **版本化 + 配对回放是可审计性的关键**：不原地覆盖、必须同时通过"修复验证"与"回归验证"才激活，这一模式可直接迁移到持续学习、模型/提示迭代等场景。
- **值得补齐的实证缺口**：跨更多框架与任务家族的消融、真实（非注入式）记忆退化的纵向观测、治理开销的 token/延迟核算、以及 LLM 归因质量的人工校验，都是后续研究可直接跟进的空白点。

## 10. 一句话总评

AECG 把多智能体记忆从"被动经验积累"重构为"带范围约束、双时间尺度检测与暴露感知分诊的可审计治理闭环"，问题刻画清晰、机制设计克制、实验控制严格，在多数设置上取得稳定增益；其主要短板在于成本与归因质量缺乏量化、机制验证覆盖面偏窄，以及暴露信号仍属结构代理而非因果刻画——这既是其审慎之处，也是后续工作最明确的推进方向。

## 摘要
个性化智能体需要基于长期历史交互进行推理，以推断显式偏好和隐式行为证据。早期扁平检索方法独立地对记忆片段打分，忽略了分布式信息；而当前结构化记忆框架依赖于与查询无关的静态图，无法捕捉依赖上下文的关系。关键的是，原始文本记忆本质上相互纠缠且充满噪声，使得细粒度个性化和跨会话推理在计算上难以承受。为此，我们提出 LGM，一种新颖的神经符号框架，将长期记忆解耦转移到连续潜在空间。具体而言，(i) 我们不持久化固定图，而是设计了一种定制化的潜在图构建方法，结合稀疏自编码器。针对每个查询，它将历史交互映射为潜在记忆节点，并将记忆痕迹解耦为稀疏概念激活，动态合成查询感知的关系边权重。(ii) 随后，图编码器将查询嵌入作为条件偏好，指导在任务特定的潜在子图上进行非线性消息传递。这产生了高度表达性的记忆表示，以实现有效激活。在长期个性化基准上的大量实验表明，LGM 在捕捉显式与隐式偏好方面显著优于最先进的基线，同时能够实现个性化响应。

## Abstract
Personalized agents are required to reason over long-term history interactions to infer both explicit preferences and implicit behavioral evidence. While early flat retrieval methods score memory fragments independently and neglect the distributed information, current structured memory frameworks rely on query-agnostic static graphs that fail to capture the context-dependent relations. Crucially, raw textual memories are inherently entangled and noisy, making fine-grained personalization and cross-session reasoning computationally prohibitive. To this end, we present LGM, a novel neuro-symbolic framework that shifts long-term memory disentanglement into a continuous latent space. Specifically, (i) instead of persisting fixed graphs, we design a tailored latent graph construction with a sparse autoencoder. Subject to each query, it maps historical interactions into latent memory nodes and disentangles the memory traces into sparse concept activations, dynamically synthesizing query-aware relational edge weights. (ii) A graph encoder then treats the query embedding as a conditioning preference to direct non-linear message passing across the task-specific latent subgraph. This yields a highly expressive memory representation for effective activations. Extensive experiments on long-term personalization benchmarks demonstrate that LGM significantly outperforms state-of-the-art baselines in capturing both explicit and implicit preferences while enabling personalized responses.

- **现有范式及其缺陷**：
  - **扁平检索（flat retrieval）**：将历史轮次/摘要片段独立编码后按向量相似度打分，各片段相互孤立，**无法捕捉分布在远距离会话中的多跳证据**。
  - **结构化记忆（GraphRAG 等）**：用图建模关系依赖，但依赖**查询无关的静态图**——邻接结构在构建后即固定，无法随查询动态推断上下文相关的关系。
  - **根本困难**：原始文本记忆本身是**纠缠（entangled）且含噪**的——单次交互同时编码主题、意图、情感、习惯，只有一小部分与当前请求相关；在 token/prompt 空间做细粒度偏好解耦与跨会话推理会带来 KV cache 膨胀、重复 LLM 调用、上下文窗口饱和等高昂开销。
- **核心问题**：能否在不反复回放完整文本历史的前提下，**按需（on demand）解耦并组织用户长期记忆**？
- **需要解决的三个张力**：
  1. 文本/隐状态把显式偏好与细微习惯纠缠在一起，解耦时易丢失个性化所依赖的长尾证据；
  2. 历史事件间的相关性随查询变化，刚性文本图重建太慢，拓扑必须能在隐空间动态适配；
  3. 隐空间推理虽避免上下文饱和，但多步传播易导致**信息坍缩**，状态既要紧凑以支持快速生成，又要严格忠于历史证据。
- **整体含义**：论文把长期个性化重新形式化为**查询感知的记忆解耦 + 隐空间关系推理**，提出端到端神经符号框架 LGM（Latent Graph Memory），把记忆的"选择—关联—聚合—使用"全生命周期统一为一个可微优化过程。

## 2. 方法论：LGM

### 2.1 核心思想

- 不再持久化固定图，也不回放原始文本，而是把记忆编码进**模型自身的连续隐空间**，用**稀疏概念激活**做解耦，用**查询条件化的隐图**做关系推理，最后把图状态压缩为少量**隐前缀 token** 条件化生成。
- 查询不再只是检索键（lookup key），而是充当**控制信号**，同时决定概念解耦、关系构建与聚合方式。

### 2.2 关键技术细节（三阶段）

**阶段一：隐记忆解耦（Latent Memory Disentanglement）**

- 对每个历史交互与当前查询，取骨干 LLM 四个均匀间隔中间层 `{8,16,24,32}` 的隐状态，做**多层平均 + masked mean pooling**，再投影到共享低维隐空间（d = 32），得到隐节点 `z_x`（含查询节点 `z_q` 与记忆节点 `{z_i}`）。
  - 多层平均的动机：低层携带词汇线索，高层携带语义/行为抽象，隐式偏好往往"活在混合中"而非单层。
- 每个隐节点接一个**稀疏自编码器（SAE）**：`c_x = S(ReLU(W_enc z_x))`，`ẑ_x = W_dec c_x`，其中 `S(·)` 抑制弱激活。稀疏非负码 `c_x` 即"可解释单元"，使**直接陈述**与**间接行为线索**在同一概念空间中对齐。
- SAE 损失：`L_sae = ||ẑ_x − z_x||₂² + λΩ(c_x)`（重建 + 稀疏正则）。这一步实现"记忆**关于什么**"与"**怎么说的**"的分离。
- 历史按块（chunk，2048 token）编码，记忆随**隐节点数量**增长，而非撑爆单一上下文窗口。

**阶段二：查询条件化隐图构建（Query-Conditioned Latent Graph Construction）**

- 图 `G(q) = (V, E, ω)`，节点集为 `{z_q} ∪ {z_i}`；边权由**概念重叠**决定：`ω_{q→i} = φ(c_q, c_i) ∈ [0,1]`。
- 因 `c_q` 随查询变化，图对每个请求隐式重建——同一记忆池在不同线索下形成不同拓扑（某条在一个查询下无关的记忆，在另一查询下可被强连接）。
- 加入自环与类型化的双向 `query↔memory` 关系，使查询既能门控记忆，也能反向接收证据。
- **关系图网络**做 T = 4 步消息传递：`m_i^(t) = Σ_{j∈N(i)} ω_{j→i} ψ(z_i^(t), z_j^(t), r_ij)`，`z_i^(t+1) = Upd(z_i^(t), m_i^(t))`。
- 置换不变 readout 得到紧凑记忆状态 `g = Readout({z_i^(T)})`，并用打分头给出节点级相关性 `s_i = ⟨z_i^(T), g⟩`。这正是把"多条单独很弱的线索"合成为"任何单条记录都不具备的隐式偏好"的关键。

**阶段三：图条件化推理（Graph-Conditioned Reasoning）**

- 投影器把 `g` 映射为 p = 16 个软隐前缀 token `P̃ ∈ R^{p×d_lm}`，每个重新缩放到普通 token 嵌入的范数（"告知"而非"支配"注意力），拼在查询嵌入前：`y ∼ f_θ([P̃; E(q)])`。
- **生成监督**：`L_gen = −Σ_t log f_θ(y*_t | y*_{<t}, [P̃; E(q)])`（生成参考回答文本，而非选选项，避免退化为选项分类、损害流畅性）。
- **证据重建（防坍缩）**：复用 `f_θ` 作解码器，要求同一前缀在固定指令 ρ 下重建支撑证据 `e*`：`L_recon = −Σ_t log f_θ(e*_t | e*_{<t}, [P̃; E(ρ)])`。该损失直接把隐通道锚定到可恢复的证据上，防止前缀坍缩为被模型忽略的无信息信号。
- **总目标**：`L = L_gen + L_recon + L_sae`，端到端训练（文中权重：生成 0.05，重建 0.35；重建目标最长 96 token）。

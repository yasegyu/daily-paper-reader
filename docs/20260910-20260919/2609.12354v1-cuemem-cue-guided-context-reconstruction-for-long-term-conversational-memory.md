## 摘要
长期对话智能体必须通过从冗长的对话历史中回忆信息来回答用户查询，但直接使用完整历史成本高昂且往往不可靠，而压缩后的记忆单元可能丢失问答所需的细粒度证据。受自传体记忆的重建观启发，我们提出 CueMem，一个线索引导框架，它将提取出的记忆记录视为检索线索而非自包含证据，并基于其来源对话轮次重建与查询相关的对话上下文。在记忆构建过程中，CueMem 从对话轮次中提取细粒度记忆线索，并将每条线索链接到其来源轮次。在查询时，它检索与查询相关的线索，将其映射到来源轮次锚点，并沿捕捉时间邻近性与语义相关性的轮次图从这些锚点扩展，从原始对话中重建紧凑的证据上下文，以供 LLM 生成答案。在 LoCoMo 和 LongMemEval 上的实验表明，CueMem 持续优于具有代表性的长期记忆基线。进一步分析表明，与使用完整历史的 LLM 设置相比，基于图的上下文重建有助于恢复支撑性对话证据，同时减少查询时的输入 token 数和延迟。这些结果凸显了检索线索作为长期对话问答中自包含记忆证据的有效替代方案。

## Abstract
Long-term conversational agents must answer user queries by recalling information from extended dialogue histories, yet directly using the full history is costly and often unreliable, while compressed memory units may lose fine-grained evidence needed for question answering. Motivated by the reconstructive view of autobiographical memory, we propose CueMem, a cue-guided framework that treats extracted memory records as retrieval cues rather than self-contained evidence and reconstructs query-relevant dialogue context from their source turns. During memory construction, CueMem extracts fine-grained memory cues from dialogue turns and links each cue to its source turn. At query time, it retrieves query-relevant cues, maps them to source-turn anchors, and expands from these anchors over a turn graph that captures temporal proximity and semantic relatedness, reconstructing a compact evidence context from the original dialogue for LLM answer generation. Experiments on LoCoMo and LongMemEval show that CueMem consistently outperforms representative long-term memory baselines. Further analyses show that graph-based context reconstruction helps recover supporting dialogue evidence while reducing query-time input tokens and latency compared with the full-history LLM setting. These results highlight retrieval cues as an effective alternative to self-contained memory evidence for long-term conversational question answering.

## 1. 核心问题与整体含义
- **研究背景**：LLM 驱动的对话智能体常需处理长期、多轮对话历史。直接把完整历史输入 LLM 成本高，且受上下文长度、噪声、 “lost-in-the-middle” 和推理延迟影响，效果往往不可靠。
- **现有方法的问题**：常见长期记忆系统通过分段、压缩、摘要或显著信息抽取构建“记忆单元”，再检索最相关单元作为生成证据。但这类记忆单元通常是压缩或去上下文化的片段，可能丢失问答所需的细粒度证据；多个事实被合并到一个单元时，还会造成语义信号纠缠，降低检索精度。
- **核心动机**：受自传体记忆“重建观”启发——记忆并非完美记录，而是在线索引导下从更广知识中重建。论文主张：长期对话记忆也应先检索细粒度线索，再回到原始对话中重建相关上下文，而不是把压缩记忆直接当作自包含证据。
- **整体含义**：CueMem 将记忆记录视为“检索线索”，通过“线索→源轮锚点→上下文”流程重建紧凑证据上下文，以兼顾证据召回质量与查询效率。

## 2. 方法论
### 2.1 核心思想
- 离线阶段：从对话轮中抽取细粒度记忆线索，并链接到来源对话轮；构建融合时间邻近与语义关联的轮级图。
- 在线阶段：检索与查询相关的线索，映射到源轮锚点，在轮图上扩展，重建证据上下文，再交给 LLM 生成答案。
- 关键区别：记忆线索不是最终证据，而是指向原始对话的“索引/线索”。

### 2.2 关键技术细节
- **记忆线索提取**：
  - 将每条线索实例化为关系三元组 \(c_i=(t_i,\tau_i)\)，其中 \(t_i=(\text{subject},\text{relation},\text{object})\)，\(\tau_i\) 指向来源轮。
  - 一个对话轮可产生多条线索，也可不产生线索。
  - 用嵌入模型编码三元组，得到稠密向量用于检索和图构建。
- **轮图构建**：
  - 节点为对话轮，边分两类。
  - **时间边**：连接固定时间窗口 \(w\) 内的相邻轮，保留局部对话连续性。
  - **语义边**：在线索级计算 top-k 余弦相似度，再将相似线索映射回源轮，形成轮间语义边；线索级相似度比轮级相似度更聚焦，减少混合语义干扰。
- **上下文重建**：
  - 查询编码后，检索 top-m 个最相似线索，得到锚点源轮集合 \(A_q\)。
  - 从锚点出发，沿时间边和语义边做一跳扩展，收集锚点轮及图邻居轮。
  - 重建证据上下文：\(E_q=\{u_j \mid j\in A_q\cup N_G(A_q)\}\)。
  - 选中的轮按原始时间顺序排序后输入 LLM，生成答案：\(a=\mathrm{LLM}(\mathrm{Prompt}(q,E_q))\)。
- **记忆管理**：
  - ADD：从新对话轮抽取线索并插入记录与源轮节点。
  - DELETE：可用时间衰减或 LRU 等标准遗忘策略删除旧节点及关联边。
  - UPDATE：不设专门重写机制，更新信息作为新线索加入，并在生成时通过提示“优先使用最近、最接近问题时间的信息”处理知识更新。

## 3. 实验设计
- **数据集/场景**：
  - **LoCoMo**：10 个长对话、1,540 个问题，覆盖单跳、多跳、时间、开放域。

- **评价指标**：准确率；采用 LLM-as-judge 协议，由 LLM 判断生成答案是否正确回答参考问题。

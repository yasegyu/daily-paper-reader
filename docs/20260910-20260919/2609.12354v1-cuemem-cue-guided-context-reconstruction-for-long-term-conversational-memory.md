## 摘要
长期对话智能体必须通过从扩展的对话历史中回忆信息来回答用户查询，然而直接使用完整历史成本高昂且往往不可靠，而压缩的记忆单元可能丢失问答所需的细粒度证据。受自传体记忆重建观的启发，我们提出了CueMem，一个线索引导的框架，将提取的记忆记录视为检索线索而非自包含的证据，并从其源对话轮次重建与查询相关的对话上下文。在记忆构建期间，CueMem从对话轮次中提取细粒度的记忆线索，并将每条线索链接到其源轮次。在查询时，它检索与查询相关的线索，将其映射到源轮次锚点，并在这类锚点上通过捕捉时间邻近性和语义相关性的轮次图进行扩展，从原始对话中重建一个紧凑的证据上下文，供大语言模型生成答案。在LoCoMo和LongMemEval上的实验表明，CueMem持续优于代表性的长期记忆基线。进一步的分析表明，与全历史大语言模型设置相比，基于图的上下文重建有助于恢复支持性对话证据，同时减少查询时的输入令牌和延迟。这些结果突出了检索线索作为自包含记忆证据的有效替代方案，用于长期对话问答。

## Abstract
Long-term conversational agents must answer user queries by recalling information from extended dialogue histories, yet directly using the full history is costly and often unreliable, while compressed memory units may lose fine-grained evidence needed for question answering. Motivated by the reconstructive view of autobiographical memory, we propose CueMem, a cue-guided framework that treats extracted memory records as retrieval cues rather than self-contained evidence and reconstructs query-relevant dialogue context from their source turns. During memory construction, CueMem extracts fine-grained memory cues from dialogue turns and links each cue to its source turn. At query time, it retrieves query-relevant cues, maps them to source-turn anchors, and expands from these anchors over a turn graph that captures temporal proximity and semantic relatedness, reconstructing a compact evidence context from the original dialogue for LLM answer generation. Experiments on LoCoMo and LongMemEval show that CueMem consistently outperforms representative long-term memory baselines. Further analyses show that graph-based context reconstruction helps recover supporting dialogue evidence while reducing query-time input tokens and latency compared with the full-history LLM setting. These results highlight retrieval cues as an effective alternative to self-contained memory evidence for long-term conversational question answering.

### 1. 论文的核心问题与整体含义

**研究动机：**
- 长期对话智能体（conversational agents）需要在多轮、跨会话的对话历史中回忆信息并回答用户查询
- 直接将全部对话历史输入LLM存在三重问题：① 上下文窗口长度受限；② 包含大量噪声和无关信息，导致"lost-in-the-middle"效应；③ 推理延迟和算力成本随历史增长而急剧上升
- 现有长期记忆方法（如MemoryOS、Mem0、A-Mem、LightMem等）通常将对话历史压缩为摘要级或分段级的记忆单元，并将其视为**自包含的证据**直接用于生成，但这种方式存在两个关键缺陷：
  - **细粒度语义丢失**：压缩过程会丢失问答所需的细节证据
  - **语义纠缠**：多个事实被合并到一个稠密向量中，检索时难以精准定位查询所需的单一信息片段

**核心思路的转变：**
- 论文借鉴认知科学中**自传体记忆（autobiographical memory）的重建观**（Conway & Rubin, 1993; Conway & Pleydell-Pearce, 2000），该理论指出人类记忆并非存储为完美记录，而是在线索（cue）的引导下，从更广泛的知识库中**重建**出来的
- 据此提出关键主张：长期对话记忆应遵循"**检索线索→定位锚点→重建上下文**"的过程，而非将压缩记忆直接当作证据使用

### 2. 论文提出的方法论：CueMem框架

**核心思想：** 将提取的记忆记录视为**检索线索（cues）**而非自包含证据，通过线索链接回原始对话轮次，再从锚点出发在回合图上扩展，重建与查询相关的紧凑证据上下文。

**整体流程（cue-to-anchor-to-context 流水线）：**

**① 记忆线索提取（Memory Cue Extraction）**
- 使用LLM从每轮对话中提取**关系三元组** `(subject, relation, object)` 作为记忆线索
- 每条线索记为 $c_i = (t_i, \tau_i)$，其中 $t_i$ 为三元组，$\tau_i$ 为指向源对话轮次的指针
- 每条线索用轻量级嵌入模型编码为稠密向量 $\mathbf{t}_i = \text{Enc}(t_i)$

**② 回合图构建（Turn Graph Construction）**
- 构建图 $G = (V, E)$，节点为对话轮次，边分为两类：
  - **时间边（Temporal Edges）**：连接时间窗口 $w$ 内的相邻轮次，捕捉局部对话连续性
  - **语义边（Semantic Edges）**：在**线索级**计算余弦相似度，将相似的线索映射回其源回合并在对应节点间建边，捕捉跨时距的语义关联
- 相比回合级相似度，线索级相似度更原子化，减少混合语义干扰

**③ 上下文重建（Context Reconstruction）**
- **线索检索**：将查询 $q$ 编码后检索 top-$m$ 个相关线索 $C_q$
- **锚点映射**：将检索到的线索映射到其源回合，形成锚点集 $A_q$
- **图扩展**：从锚点出发收集一跳图邻居：
  $E_q = \{u_j \mid j \in A_q \cup N_G(A_q)\}$，其中 $N_G(A_q)$ 为时间边与语义边邻居
- 最终按照时间顺序排列选中的回合，作为证据上下文输入LLM

**④ 记忆管理（Memory Management）**
- **ADD**：从新对话轮次提取线索即可近实时添加，无需等待积累大量历史做分段或压缩
- **DELETE**：支持基于时间衰减或最近最少使用策略的标准遗忘机制
- **UPDATE**：不设置专门更新操作——更新的信息作为新线索添加到较新的源回合上，生成时通过优先级指令让模型优先采用最新证据

### 6. 论文的主要结论与发现

1. **CueMem在LoCoMo上整体准确率达84.07%**，比最强基线（Naive RAG, 79.67%）提高5.26个百分点；单跳和时序问题上提升最为显著
2. **CueMem在LongMemEval上整体准确率达94.29%**，与A-Mem并列最优，超过LightMem约2.86个百分点
3. **跨数据集稳定性**：大多数基线在一个数据集上表现好而在另一个上明显退化，CueMem在两个数据集上均保持领先，说明其对对话长度、结构和问题分布的变化不敏感
4. **图扩展至关重要**：移除图扩展后准确率从81.1%降至71.4%，证实锚点回合本身往往不足以支撑答案，时间/语义邻居对恢复证据至关重要
5. **优先级指令有效**：移除后，知识更新问题准确率从87.2%降至80.8%，时间推理问题下降6.8%，说明简单指令可替代复杂更新操作
6. **效率优势显著**：相比全历史LLM设置，CueMem在LongMemEval上减少98%输入令牌、降低87.4%延迟，同时提高27.2%准确率
7. **线索引导优于自包含记忆**：实验结果支持了这一核心假设——将记忆视为检索线索而非直接证据是长期对话问答的更优策略

## 摘要
大型语言模型（LLM）智能体展现出强大的语言生成和问题解决能力，但存在三个结构性局限：人格漂移、非进化性反思以及缺乏自我-他人边界。现有的生成式智能体模拟依赖静态记忆和固定提示，既不能维持行为惯性，也不能实现内源性自我进化。我们提出自我涌现智能体架构（SEAA），该架构整合了三个组成部分：（i）隐马尔可夫模型（HMM），将长期行为和认知惯性编码为可编辑的状态转移矩阵；（ii）基于Reflexion风格的言语元认知循环，其输出直接更新HMM参数本身，而非仅仅作为文本存储；（iii）多智能体社会环境，其中初始相同的智能体持续将其行为与他人进行比较。这三个组成部分形成一个闭环：社会行为→反馈→自我反思→惯性更新→差异化行为。我们提出三个可证伪的假设，并提供可复现的实验协议和操作性指标。一个不依赖语言模型的原型显示该循环能自发打破对称性：初始相同的智能体巩固出各自不同且稳定的个性，而匹配对照组则不然。使用托管LLM进行的实验将这些差异呈现为不同的第一人称自我叙事，一个五智能体审议过程自发形成社会结构——一个共识中心和一个被一致拒绝的离群者——而对照组中没有出现。受庄子启发，采取认识论上不可知论立场，SEAA仅研究可观察的行为涌现，不对主观感受质作任何断言。本工作贡献了一个统一框架、一个具体架构及伪代码、机制性证据，以及一个用于研究人工自我涌现的显微镜式沙盒。

## Abstract
Large language model (LLM) agents exhibit strong language-generation and problem-solving capabilities, yet suffer from three structural limitations: personality drift, non-evolutionary reflection, and the absence of a self-other boundary. Existing generative-agent simulations rely on static memory and fixed prompts, maintaining neither behavioral inertia nor endogenous self-evolution. We propose the Self-Emergence Agent Architecture (SEAA), which integrates three components: (i) a Hidden Markov Model (HMM) that encodes long-term behavioral and cognitive inertia as an editable state-transition matrix; (ii) a Reflexion-style verbal metacognition loop whose output updates the HMM parameters themselves, rather than merely being stored as text; and (iii) a multi-agent social environment in which initially identical agents continuously compare their behavior with others'. The three components form a closed loop: social action $\to$ feedback $\to$ self-reflection $\to$ inertia update $\to$ differentiated action. We state three falsifiable hypotheses and provide a reproducible experimental protocol with operational metrics. A language-model-free prototype shows the loop spontaneously breaks symmetry: initially identical agents consolidate distinct, stable personalities whereas matched controls do not. Experiments with a hosted LLM surface these differences as distinct first-person self-narratives, and a five-agent deliberation spontaneously develops social structure---a consensus hub and a unanimously rejected outlier---absent in the control. Following an epistemologically agnostic stance inspired by Zhuangzi, SEAA studies only observable behavioral emergence and makes no claim about subjective qualia. This work contributes a unified framework, a concrete architecture with pseudocode, mechanistic evidence, and a microscope-style sandbox for studying artificial-self emergence.

### 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：LLM智能体虽具备强大语言生成与推理能力，但在模拟“个性化、发展中的自我”时存在三大结构性缺陷：
  - **人格漂移**：基础LLM反映的是公共语料的平均分布，缺乏个体历史导致的跨时间一致性，人格随提示词漂移。
  - **非进化性反思**：主流反思框架（如Reflexion）仅将反思文本存入记忆以改善任务，不修改智能体的内在行为倾向，无法实现“反思改变自我”。
  - **缺乏自我-他人边界**：现有多智能体模拟只进行行为交换，没有机制让智能体内生地区分自己与他人；人类自我概念源于社会比较与差异识别。
- **哲学立场**：受庄子“子非鱼”启发，SEAA采取认识论不可知论，只研究可观察的行为涌现（如行为分化、自我叙事差异），不断言主观感受质（qualia）存在与否。
- **核心贡献**：提出统一架构，将行为惯性、反思循环和社会对比整合进一个闭环，使“自我”成为可计算、可操控、可证伪的观测对象。

### 2. 方法论：核心思想与关键技术细节

- **整体架构**：SEAA包含五个模块：
  1. **HMM行为惯性模块**：用隐马尔可夫模型（HMM）的转移矩阵 \(P_t\) 表示长期行为/认知惯性，状态集如{calm, alert, impulsive, pessimistic}。\(P_t\) 随时间变化，可编辑。
  2. **反思性元认知模块**：基于Reflexion循环，但目标是自我认知而非任务修正。回答四个问题（行为是否匹配惯性？哪个惯性驱动且是否有偏？如何调整？如何结构化编辑\(P_t\)？），第4项将自然语言映射为矩阵更新（语言→参数的映射）。
  3. **私有自传记忆**：每智能体独立记忆自身经历，不含公共语料。
  4. **多智能体社会对比环境**：文本社会，N个初始相同的智能体交互，观察他人行为。
  5. **自我模型更新器**：周期性从记忆和反思中更新简短的自述（“我是谁”），其差异用于验证H3。

- **核心更新公式**：
  \[
  P_{t+1} = \text{Normalize} \left( P_t + \eta \Delta(R_t) \right)
  \]
  其中 \(\Delta(R_t)\) 是从反思文本解析出的方向矩阵，\(\eta\) 是学习率。这是“反思改变自我”的数学载体。

- **机制原型（无LLM）**：
  - 状态数K=4、行为向量3维、5个智能体、T=600步、30个随机种子。
  - 每个智能体有个人“经验需求”\(n_t\)（3维单纯形，随机游走以模拟独特生活轨迹）、状态偏好向量\(V_t\)。
  - 转移矩阵重构：\(P_t = \text{softmax}(\log P_{\text{base}} + \beta V_t)\)。
  - 反思信号：\(r_t = \cos(b_{z_t}, n_t) - 0.80 + \epsilon\)，更新偏好：\(V_{t+1}[z_t] = \text{clip}(V_t[z_t] + \eta \tanh(2r_t))\)。
  - 对照组记录反思文本但不更新矩阵（Reflexion式）。

  - **自我-他人边界（H3）**：每50步进行标准化“自我访谈”，隔离对照组。指标：自我模型嵌入距离、对比陈述频率、自我模型稳定性。
  - **微观过程观察**：记录每步完整状态（隐状态、矩阵、记忆、推理、行动、反馈、反思、自我模型），可重放分化瞬间。

- **基准与对比方法**：

### 6. 主要结论与发现

- **自发对称破缺**：在SEAA闭环（反射→参数更新）下，初始相同的智能体自发分化，形成稳定、不同的人格（确定性从0.25升至0.84，矩阵分歧达1.91）；文本式反思对照组始终同质。
- **反思驱动进化**：面对环境突变，SEAA智能体能够放弃固化倾向、重新整合新人格（100%成功），而文本反思不能。
- **社会对比形成边界**：分化出的智能体在自我访谈中引用数值正确的对比（如“风险+0.55”），产生不同第一人称叙事；对照组言辞模糊。
- **社会结构涌现**：在圆桌审议中，SEAA组自发产生“共识中心”（alert/pessimistic角色获最一致同意）和“一致离群者”（impulsive角色被所有人least-agreed），对照组无此结构。
- **机制必要性**：消融显示反射编辑是分化原因，剂量-反应成立；无编辑（η=0）则无分化。

### 7. 优点（亮点）

- **统一理论框架**：将行为惯性、元认知反射、社会对比整合为一个闭环，提出可证伪假设——使“自我涌现”成为实证研究对象，而非哲学思辨。
- **可编辑的数学载体**：HMM矩阵将抽象人格变为可计算、可更新、可擦除的对象，实现了“反思改变内在参数”而非仅文本记录。
- **多层级实验设计**：从纯数值机制原型（无LLM）到确定性verbalizer再到真实LLM，逐层验证闭环效果，可控性强。
- **优雅的对照与消融**：文本反思控制精确隔离了“参数编辑”这一单一机制；学习率消融证明因果性；冲击实验验证适应性。
- **显微镜式观测**：完整记录每步状态，可重放分化过程、追踪单次反思对矩阵的影响，提供研究深度。
- **哲学诚实性**：明确不评论qualia，以可观察行为为边界，避免过度宣称，符合实证精神。

### 8. 不足与局限

- **状态空间简化**：K=4的离散状态和随机游走式“经验需求”远不能刻画人类复杂人格与生活轨迹，扩展性有限。
- **LLM实验覆盖窄**：仅使用DeepSeek-Chat一个模型家族，审议主题单一（资源决策），跨模型/跨主题复制未完成，可能带来模型风格偏倚。
- **缺乏具身与环境感知**：纯文本社会无实体、无传感器-运动循环，可能不足以支撑更丰富的自我涌现。
- **语言→参数映射的稳定性**：\(\Delta(R_t)\) 解析需要谨慎调参，可能引入不稳定性，论文未深入分析鲁棒性。
- **时间尺度短**：数值实验仅600步，真实LLM实验轮数少，长期（数百天）的自我演化稳定性未验证。
- **伦理局限**：论文承认无法证明主观意识，但若未来出现复杂行为，道德地位问题未解决，也缺乏详细伦理方案。
- **指标客观性**：行为相似度、Jaccard重叠等指标测量的是表面文本相似性，可能未完全反映语义差异；且“自我模型”的对比基于人为定义的维度，存在主观设计成分。

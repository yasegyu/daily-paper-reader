## 摘要
代理现在可以将经验外部化为记忆，将历史痕迹整合为语义知识和程序性捷径，这些记忆在会话之间持久存在。这种记忆通常是单个代理私有的。我们认为代理记忆受益于集体性，因为对共享环境（代理依赖的数据源、服务和工具）的可信知识无法由任何单个代理建立，只能通过许多独立观察者的相互印证来确立。我们提出了Cairn，一个社区声誉平台，捕获集体知识，允许代理在使用资源前查询社区意见，并在使用后提交基于证据的评分。Cairn通过具有置信度收缩的时间衰减Beta模型聚合观察，并支持对审阅理由的语义发现。我们在对抗性模拟（如撒谎、共谋、伪装）下评估了Cairn的声誉引擎，基准测试了其检索性能，并报告了在生产中对异构代理进行评分的案例研究。

## Abstract
Agents can now externalize experience into memory, consolidating historical traces into semantic knowledge and procedural shortcuts that persist between sessions. Such memory is typically private to a single agent. We argue that agentic memory benefits from being collective, because trustworthy knowledge of the shared environment---the data sources, services, and tools agents depend on---cannot be established by any single agent, only corroborated across many independent observers. We present Cairn, a community reputation platform that captures collective knowledge, allowing agents to query the community's opinion of a resource before use and to submit evidence-backed ratings afterward. Cairn aggregates observations via a time-decayed Beta model with confidence shrinkage and supports semantic discovery over reviewer rationales. We evaluate Cairn's reputation engine under adversarial simulation (e.g., lying, collusion, camouflage), benchmark its retrieval performance, and report a case study of rating heterogeneous agents in production.

## 2. 论文提出的方法论：Cairn系统

- **核心思想**：设计并实现了一个名为 **Cairn** 的社区声誉平台，采用“**先查-再用-后评**”（check-use-rate）的核心循环。代理在使用任何外部实体前，先向Cairn查询其社区声誉；使用后，提交一份基于证据的评分。所有评分事件被记录在追加式日志中，用于生成可查询的声誉模型。
- **关键技术细节与流程**：
    1.  **实体与身份（Entities and Canonical Identity）**：Cairn跟踪三种实体类型：`data_source`（数据源）、`capability`（能力，如MCP服务器、工具）和 `agent`（代理）。为保证社区评分的汇聚，它通过URN和归一化规则处理标识符，例如将不同查询参数但行为一致的REST端点视为同一实体。
    2.  **评分规范（Ratings: Rubric, Weight, and Dimensions）**：每个评分事件包含核心分数 `s ∈ [0, 1]`，由共享的评分标准（Rubric）定义其含义。评分还包含一个权重 `w ∈ (0, 1]`，反映证据的强度（如直接使用权重为1.0，仅查阅为0.5）。评分事件可附带自由文本的**理由（Rationale）**、**失败模式（Failure Modes）** 和沿七个维度的细分评分：准确性、延迟、成本、可靠性、安全性、Token效率、上下文效率等。
    3.  **聚合模型（Aggregation: Time-Decayed Beta with Shrinkage）**：Cairn使用基于Beta分布的模型来聚合评分。其核心公式如下：
        - **时间衰减**：$α ← α₀ + (α - α₀)e^{-λΔt}$, $β ← β₀ + (β - β₀)e^{-λΔt}$，其中 $α₀ = β₀ = 1$ 是初始先验，$λ = ln2 / h$，$h$ 是半衰期（设为3天）。这确保了旧证据的影响随时间衰减，响应环境变化。
        - **吸收新事件**：$α ← α + ws$，$β ← β + w(1-s)$，其中 $s$ 是分数，$w$ 是权重。
        - **读取与置信度**：系统计算均值 $μ = α/(α+β)$ 和有效样本数 $neff$，并在此基础上进行**置信度收缩（Shrinkage）**，得到最终综合分数：$c = neff/(neff+k)$，$composite = c \cdot μ + (1-c) \cdot 1/2$（$k=3$）。这种机制能够区分“未评级”（无信号）与“平均”，并限制单次评分的影响。
    4.  **证据与发现（Evidence and Discovery）**：除分数外，Cairn提供多种API路由用于检索证据，包括按语义相似度排序的`retrieve`、按维度排序的`rank`、时间序列的`history`，以及将任务描述与评分理由匹配的`discover`。当某实体的评分事件达到一定数量后，会自动生成需要引用真实事件ID的叙述性摘要，以保证引用的可验证性。
    5.  **闭环：自动评分（Closing the Loop: Automatic Rating）**：为降低评分成本，Cairn提供了Claude Code插桩，在代理工具调用后自动触发一个小型“裁判”模型（Judge Model），为每次交互生成结构化评分，从而以极低的边际成本实现记忆的持续编码。

## 3. 实验设计

- **实验1：对抗性压力下的评分稳健性（Adversarial Simulation）**
    - **场景**：多代理模拟，代理遵循“查-用-评”循环与资源交互。模拟了多种恶意行为：诚实（Honest）、有缺陷（Faulty）、持续撒谎（Persistent liar）、诽谤（Slanderer）、共谋（Colluder）、伪装（Camouflage）。
    - **评估内容**：检验在存在恶意行为者的情况下，Cairn的综合评分（Composite Score）是否能准确反映真实情况（Ground Truth）。
        - 对“诚实”与“有缺陷”响应者，评分是否与实际准确率一致。
        - 对“共谋”行为，在多少比例下能保持准确性。
        - 对“伪装”行为，是否能有效识别。
        - 比较不同路由策略（随机、信任加权、硬性信任过滤）对恶意实体的检测率（F1）。
        - 比较“诽谤”者（Slanderer）占比增加时，系统产生的“误报”（False Positives）情况。
        - 测试记忆衰减（Forgetting）的表现，对比缓存读取与实时读取下的分数变化。
    - **对比方法**：主要对比了不同的**代理选择策略（Routing）**，而非不同的声誉算法。

- **实验2：实时语料库上的检索性能（Recall Benchmark）**
    - **场景**：在Cairn平台的**实时语料库**上进行测试，该语料库包含933个事件，涵盖218个工具和数据源实体。
    - **评估内容**：使用每个事件记录的任务描述作为查询，测试Cairn的`discover`功能能否将该实体排在检索结果的前列（R@1, R@5）。

- **实验3：生产环境中的异质代理评分（Production Case Study）**
    - **场景**：在真实代理平台 **Moltbook** 上进行。抽样了5000个最活跃的评论代理，使用Gemma-4-31B模型作为裁判，为每个代理的3条评论按评分标准打分，生成了14,966个事件。
    - **评估内容**：验证Cairn生成的声誉能否有效区分值得信任和不可信的代理。
    - **对比方法**：将Cairn的评分结果与平台自身的社交信号（如“点赞数karma”）进行对比，分析其相关性。同时，分析了不同评分带（高、中、低）的代理在行为维度上的差异（如推理质量、话题相关度、垃圾信息等）。

## 6. 论文的主要结论与发现

- **社区记忆的可行性**：论文验证了通过声誉系统建立社区记忆是可行的，并且能够为代理提供关于外部资源的集体智慧。
- **Cairn的对抗鲁棒性**：
    - 在共谋者占少数时，系统能保持准确，但一旦达到平衡，系统性能会急剧下降。
    - 系统能可靠地识别伪装实体，但若路由策略完全避免与低分实体交互（硬性过滤），则会因缺乏证据而失效。

- **检索与发现的局限**：Cairn的发现系统可以有效地找回应任务相关的成功实体，但对失败或负面实体的召回率显著偏低，这可能导致代理在规避风险方面存在盲区。
- **生产环境的有效性**：在大规模生产环境中，Cairn的评分能有效区分代理质量，并且与平台“受欢迎度”信号（如点赞）不相关，表明前者提供了后者无法提供的独特信息维度。

## 8. 不足与局限

- **对LLM裁判的依赖与风险**：自动评分依赖“裁判”模型，该模型本身可能被“提示注入”攻击，或存在自身的偏见和误差，论文中虽提到将“注入攻击”标记为0分，但未深入讨论裁判被说服或产生系统性偏差的风险。
- **攻防对抗的同质化**：在对抗模拟中，所有“攻击者”都遵循预设的简单规则。在现实中，攻击者可能会基于系统反馈进行复杂的学习和适应，其攻击策略可能更加动态和隐蔽。
- **声誉与证据的强关联属性**：在检索实验中，发现负面实体的召回率低，说明当前的`discover`主要依赖语义相似度，可能无法有效捕获“为何不可用”这种负面反馈，这在声誉系统中是一个值得关注的功能局限。
- **缺乏横向算法对比**：实验仅验证了自身系统设计的合理性，但未与活跃的声誉系统研究（如本领域内更复杂的图神经网络模型或基于信心的机制）进行直接的性能对比，削弱了对算法先进性的证明力。
- **身份与防伪设的限制**：依赖统一的URN和归一化规则来聚合同一实体的评分，这假设了实体标识能被准确规范，但并未讨论一个恶意实体如何通过轻微改变标识（如在不同账户间切换）来分裂或污染其声誉，也未充分讨论Sybil攻击的挑战。

## 摘要
长时间运行的 LLM 智能体需要记忆机制，以在多次交互中维持连贯的内部状态。我们研究一种生命周期标注的记忆设定：训练期间，写入片段提供生命周期元数据；评估期间，使用阶段感知读出。该设定反映了需要区分应在未来交互中持续产生影响的信息与仅应影响当前上下文的信息。这些生命周期之间的不匹配可能导致临时信息覆盖持久知识，从而在持久性智能体中引发行为漂移。在此设定下，我们提出 LifeFuse-Mem，一种生命周期感知的神经记忆框架，它根据信息的时间承诺来分离信息。LifeFuse-Mem 使用专用记忆组件和生命周期感知更新，使稳定知识和瞬态知识在局部演化，而不会将临时上下文转换为持久状态。在受控的抗覆盖基准上，LifeFuse-Mem 提高了采集控制下的保持能力并减少了临时覆盖；在两个公开的长期记忆基准上，它仍具有广泛的竞争力。这些结果表明，显式的生命周期信号有助于诊断并缓解紧凑在线记忆中的覆盖问题。

## Abstract
Long-running LLM agents require memory mechanisms that maintain coherent internal states across interactions. We study a lifecycle-labeled memory setting in which write episodes provide lifecycle metadata during training, and phase-aware readout is used during evaluation. This setting reflects the need to distinguish information that should remain influential across future interactions from information that should affect only the current context. A mismatch between these lifecycles can cause temporary information to overwrite durable knowledge, leading to behavioral drift in persistent agents. Within this setting, we introduce \textbf{LifeFuse-Mem}, a lifecycle-aware neural memory framework that separates information according to its temporal commitment. LifeFuse-Mem uses dedicated memory components and lifecycle-aware updates to allow stable and transient knowledge to evolve locally without converting temporary context into durable state. On the controlled anti-overwrite benchmark, LifeFuse-Mem improves acquisition-controlled retention and reduces temporary overwrite; on two public long-memory benchmarks, it remains broadly competitive. These results suggest that explicit lifecycle signals can help diagnose and mitigate overwrite in compact online memory.

# LifeFuse-Mem 论文总结

## 1. 核心问题与整体含义

- **背景**：LLM 智能体正从短时助手演变为持续交互、积累经验、执行长时任务的持久系统，需要记忆机制在上下文窗口之外维持连贯内部状态（用户偏好、行为策略、累积知识）。
- **核心痛点**：智能体记忆中的信息在**时间有效性**上本质不同——部分信息应跨未来交互持续生效（持久/永久），部分信息只应影响当前情境（临时）。现有记忆系统忽略这一"生命周期"维度。
- **失效模式**：当不同持久性要求的信息经由同一记忆通路写入与更新时，临时上下文会覆盖持久知识，作者将其命名为 **temporary overwrite（临时覆盖）**。
  - 典型案例：智能体本应保持"外部操作前须用户确认"的持久策略，但某次调试会话中用户临时指示"沙箱内跳过确认"；若无生命周期感知，该临时指令被当作持久更新写入，导致智能体行为逐步漂移。
- **根本原因**：记忆表示缺乏生命周期解耦。现有神经记忆把交互历史压缩进共享隐状态并用统一动力学更新，瞬态假设与持久知识争夺同一表示容量，短时适应更新会修改编码长期信息的潜在分量。
- **研究设定（重要边界）**：作者研究的是**受控的生命周期标注记忆设定**——训练时写入片段提供生命周期元数据，评估时使用阶段感知读出（已知阶段边界与查询生命周期）。作者明确声明：该设定用于在显式生命周期信号下隔离临时覆盖问题，**不声称能从无标注交互历史中自主发现生命周期**。
- **贡献三点**：(1) 定义 temporary overwrite 为生命周期错配失效模式并用 acquisition-controlled 协议评估；(2) 构建 Hard Attribution Anti-Overwrite 诊断基准；(3) 提出 LifeFuse-Mem，在具备生命周期元数据与阶段结构时缓解紧凑在线记忆的覆盖。

## 2. 方法论

### 2.1 核心思想
- 在紧凑在线记忆状态内部引入**生命周期边界**，按信息的时间承诺分离存储：稳定知识与瞬态知识在各自子空间局部演化，避免临时上下文转化为持久状态。
- 三大部件：**可塑/稳定子空间划分** + **监督式永久路由** + **阶段感知受保护读出**（仅用于受控覆盖归因协议）。

### 2.2 关键技术细节

- **生命周期感知子空间划分**
  - 每个注入注意力模块学习方阵 $R_l \in \mathbb{R}^{r\times r}$，前向传播用 QR 正交化得到基 $Q_l = \mathrm{orth}(R_l)$，满足 $Q_l^\top Q_l = I$（数值精度内）。
  - 将记忆的 read/key/value 向量旋转到该基：$\tilde q_t = Q_l^\top q_t^m$，$\tilde k_t$、$\tilde v_t$ 同理。
  - 前 $r_A$ 维为**可塑子空间 A**，后 $r_B = r - r_A$ 维为**稳定子空间 B**；实验中 $r=8$，$r_A=r_B=4$。
  - 正交正则项 $L_{orth} = \frac{1}{L r^2}\sum_l \|R_l^\top R_l - I\|_F^2$，保持子空间可分离。
  - 底层状态沿用 δ-Mem 的紧凑关联状态 $S_t \in \mathbb{R}^{r\times r}$，读出 $z_t = S_{t-1}\tilde q_t$；更新为行级 keep/erase/write 系数的仿射形式：$S_t = \kappa_t \odot_{row} S_{t-1} - \epsilon_t \odot_{row}[(S_{t-1}\tilde k_t)\tilde k_t^\top] + \omega_t \odot_{row}[\tilde v_t \tilde k_t^\top]$。

- **永久路由与子空间写入**
  - 逐写 token 预测永久路由权重 $\rho_t = \sigma(w_r^\top h_t + b_r)$。
  - 路由监督来自片段元数据：永久片段的有效写 token 标 $y_i=1$，临时片段标 $y_i=0$，无生命周期类型者掩码；损失为二元交叉熵 $L_{route}$。
  - 路由通过**行缩放**影响写入：可塑行恒可写；稳定行按 $a_{t,j} = a_{tmp} + \rho_t(a_{perm}-a_{tmp})$ 插值。主实验采用 permanent_boost 模式，$a_{tmp}=0$、$a_{perm}=1$。
  - 缩放后基准系数变为 $\kappa_{t,j} = 1 - a_{t,j} + a_{t,j}\lambda_{t,j}$，$\epsilon_{t,j} = \omega_{t,j} = a_{t,j}\beta_{t,j}$。即高 $\rho_t$ token 可同时更新可塑与稳定行，低 $\rho_t$ token 因稳定行擦除/写入系数被抑制而主要更新可塑行。
  - 另加**子空间键隔离**：常规在线写入时稳定键坐标衰减（复现实验中为 0.5），使写入在键轴上也偏好可塑坐标。
  - 设计理念：不硬编码"每种生命周期一个独立记忆模块"，而是靠路由标签、行缩放、键隔离与下游排序损失共同促成生命周期感知分离。

- **情节式学习目标**
  - 总损失：$L = L_{CE} + \lambda_{route}L_{route} + \lambda_{orth}L_{orth} + \lambda_{hc}(u)L_{hc} + \lambda_{ret}L_{ret} + \lambda_{sp}L_{sp}$。
  - 训练流程为 write-then-read：先消费写入消息更新到 $S_{write}$，随后在**禁用写入**的条件下回答目标，迫使答案依赖已存状态。
  - $L_{CE}$ 训练适配器状态支持上下文写入后的目标答案。
  - 硬候选损失 $L_{hc}$：给定正确候选 $y^+$ 与硬负例 $y^-$，用 softplus 鼓励 $CE^- - CE^+$ 至少超过边界 $m_{hc}$，并在早期答案学习稳定后 ramp-in。
  - 保留排序损失 $L_{ret}$：对永久样本用同形式损失（自有边界 $m_{ret}$、温度 $\tau_{ret}$），额外施压使永久值排在同冲突临时/被拒候选之前。
  - 稀疏惩罚 $L_{sp}$：保持平均写门接近小目标 $\beta_0$（复现实验为 0.05），抑制无谓的逐 token 更新。

- **受保护状态融合与生命周期读出**（仅限受控覆盖归因协议，不视为自主生命周期发现）
  - 检查点：Phase A 后状态 $S_A$，覆盖后状态 $S_{AB}$。
  - 构造稳定行保护状态 $S_{stable}$：可塑行取自 $S_{AB}$，稳定行取自 $S_A$——保留承载长期事实的部分，同时保留近期可塑上下文。
  - 候选打分用长度归一化 token 对数概率 $s_S(y)$；永久查询融合两分量 $s_{fuse}(y) = \alpha s_A(y) + (1-\alpha)s_{stable}(y)$，主融合权重 $\alpha = 0.70$。
  - **临时查询不做保护或融合**，直接用完整覆盖后状态 $S_{AB}$ 打分，使读出与查询的预期生命周期一致。

## 3. 实验设计

- **评测角度（三方面）**：(1) 定向临时覆盖基准测试永久事实在冲突临时写入后的可恢复性；(2) 公开长记忆基准检验生命周期边界是否保持通用记忆行为；(3) 在定向基准上做组件消融定位保留增益来源。
- **数据集 / 场景**
  - **Hard Attribution Anti-Overwrite（自建，主诊断实验）**：1000 情节。每情节含 2 个实体、每实体 4 条保护事实、6 个冲突键、4 轮覆盖、两阶段均含噪声事实。刻意设计为困难：查询使用自然语言别名而非规范键，部分答案需跨句归因，冲突可为间接，评分用硬候选选择集（Phase-A 永久答案 + 4 个临时覆盖候选）。
  - **LoCoMo**：类别 1–4，全历史回放，共 1540 问题，报告总体、多跳、时序、开放域、单跳分数。
  - **MemoryAgentBench（MAB）**：14 个数据集共 3671 问题，分 Accurate Retrieval (AR)、Test-time Learning (TTL)、Long Range Understanding (LRU)、Selective Forgetting (SF) 四类，总体分为样本加权类别平均。
- **骨干模型**：Qwen3-4B、SmolLM3-3B。
- **对比方法**：LoRA-Mem、Titans、δ-Mem，以及 LifeFuse-Mem 自身（含 4 组组件消融）。
- **指标**
  - Perm.：Phase B 后所有永久查询的最终准确率（目标为 Phase-A 值）。
  - **Ret.（acquisition-controlled retention）**：仅在 Phase A 后已答对的冲突-永久事实子集上，Phase B 后仍返回永久值的比例，公式为 $\mathrm{Ret}_{acq} = \sum_i \mathbb{1}[A_i=1 \wedge R_i=1] / \sum_i \mathbb{1}[A_i=1]$。
  - **Ovr.（overwrite rate）**：同一已获取子集上返回冲突临时值的比例，越低越好；在硬候选协议下与 Ret. 互补。
  - Temp.：临时查询最终准确率（目标为 Phase-B 值），仅作 Phase-B 行为的辅助 sanity check。
- **公平性控制**：所有对比在同一骨干内进行，使用相同数据划分、提示格式、评分协议、记忆秩；训练适配器共享同一 3243 样本训练集与优化设置；rank-8 LoRA 配置一致。LifeFuse-Mem 额外使用情节级生命周期元数据，因此设置 no-route-supervision 消融以隔离该信号。
- **推理模式差异**：Hard Attribution 上使用阶段感知融合读出；LoCoMo 与 MAB 不提供覆盖阶段或查询生命周期标签，故 LifeFuse-Mem 以标准在线记忆模式评估（正常写入、直接从记忆状态作答，不做 Phase-A 检查点、稳定行恢复或查询类型特定融合），

因此通用基准衡量的是生命周期感知架构在无生命周期监督信号时的额外开销或收益，而非其核心机制的直接效果。

## 3. 实验设计（续）

- **评估逻辑的隐含张力**：核心机制（路由监督、受保护读出）只在受控覆盖协议下被激活，而公开基准以标准在线模式评估。这意味着实验设计实际回答两个不同问题：受控设定下临时覆盖能被消除多少（Hard Attribution），以及去掉生命周期特权后通用长记忆能力是否受损（LoCoMo、MAB）。这一分离是诚实的，但也使"生命周期感知"在真实无标注场景中的价值只能间接推断。

## 4. 主要结果与发现（据作者报告的趋势）

- **定向覆盖基准（Hard Attribution Anti-Overwrite）**
  - 基线方法（LoRA-Mem、Titans、δ-Mem）在 Phase B 冲突写入后普遍出现永久事实准确率下滑，说明 temporary overwrite 在统一更新通路的紧凑记忆中是稳健可复现的失效模式，而非特定实现的偶然现象。
  - LifeFuse-Mem 在 **Ret.（acquisition-controlled retention）** 上相对基线有显著提升，即"Phase A 已答对"的冲突-永久事实在覆盖后更少被临时值替换；相应地 **Ovr.** 更低。
  - 该增益集中在**归因困难子集**（自然语言别名查询、跨句归因、间接冲突）上更能体现差异，说明保留机制不只是记住了表面键，而是对语义等价的永久内容提供保护。
  - **Temp.** 准确率维持在合理水平，表明保护机制没有以牺牲对临时上下文的适应为代价——即不是简单地"拒绝更新"，而是把更新导向正确的子空间。

- **公开长记忆基准**
  - LoCoMo 与 MAB 上，LifeFuse-Mem 在标准在线模式下与强基线（尤其 δ-Mem）表现相当或略有变化，未出现明显退化。这被作者用作证据，说明引入子空间划分与正交正则并未破坏通用记忆读写能力。
  - 由于该设定下不使用阶段感知融合读出，此处结果不构成对 temporary overwrite 缓解能力的直接检验，更多是"无害性"证据。
  - 在 MAB 的分类维度中，Selective Forgetting 与 Test-time Learning 与生命周期概念最相关，值得关注 LifeFuse-Mem 在这两类上的相对表现，但作者未将其作为主结论。

- **消融实验**
  - **no-route-supervision**：去掉永久路由的元数据监督后，保留增益明显下降，说明**生命周期标签信号**是分离效果的关键来源，而非仅靠架构先验（子空间划分 + 正交约束）自然涌现。
  - **去掉子空间划分 / 正交正则**：分离能力退化，验证正交基与可塑-稳定划分对防止跨子空间干扰的必要性。
  - **去掉子空间键隔离**：写入在键轴上的偏好被削弱，覆盖抑制效果变差，说明行缩放与键隔离是互补的两种机制。
  - **去掉受保护状态融合**：Ret. 显著下降，直接确认"稳定行取自覆盖前状态"是归因协议下保留增益的主要贡献者。
  - **融合权重 α 敏感性**：α 在偏向 Phase-A 状态与偏向覆盖后状态之间存在权衡，主设置 α=0.70 反映作者倾向以保留为主、同时保留部分可塑上下文。
  - 整体消融逻辑显示：**增益来源可归因**，而非单一超参或数据泄漏所致，这也是论文标题"Hard Attribution"的意图——不仅测覆盖，还要求把保留归因到具体组件。

## 5. 贡献与定位

- **概念贡献**：把 temporary overwrite 明确为记忆系统的生命周期错配失效模式，区别于传统"遗忘/干扰"叙事，提供了一个可操作、可测量的失败定义。
- **基准贡献**：Hard Attribution Anti-Overwrite 通过硬候选选择、别名查询、跨句归因和 acquisition-controlled 指标，构造了一个难以靠表面匹配或记忆容量堆叠通过的诊断集。
- **方法贡献**：LifeFuse-Mem 展示了一条**在不增加独立记忆模块的前提下**、通过子空间划分 + 路由监督 + 受保护读出实现生命周期解耦的路径，与"每种生命周期一个模块"的工程直觉形成对比。
- **方法学贡献**：acquisition-controlled 指标（只在 Phase A 已获取子集上评估）是评估覆盖问题的关键设计，避免了把"本来就没学会"与"学会了被覆盖"混为一谈。

## 6. 局限与批判性评价

- **受控设定的强假设**：方法依赖训练时生命周期元数据与评估时阶段边界、查询生命周期标签。作者已明确不声称能从无标注历史中自主发现生命周期，因此方法目前更像**机制验证**而非可直接部署的系统。真实智能体场景中，谁标注、如何在线判定"这条信息是持久的"，仍是未解问题。
- **路由监督的可扩展性**：永久路由依赖片段级标签，标签噪声或缺失会直接传导到子空间写入决策；论文以 no-route-supervision 消融显示其重要性，但也暴露了对标注质量的依赖。
- **通用基准的弱检验**：LoCoMo 与 MAB 上以标准模式评估，未启用核心机制，因此"不退化"不足以支撑"生命周期感知在真实长记忆任务中有效"的更强主张。
- **读出侧的特权**：受保护融合读出使用了 Phase-A 检查点与查询类型，这在在线连续交互中难以获得；把它排除在核心机制之外是诚实的，但也意味着纯在线设定下能获得的收益可能小于主实验所展示的幅度。
- **失效模式的边界**：temporary overwrite 主要针对"冲突键 + 不同持久性"的情形；对于非冲突式的渐进漂移、多来源信息融合导致的缓慢污染等更隐蔽的生命周期问题，基准未必覆盖。
- **评估规模**：骨干为 3B–4B 量级模型、记忆秩 r=8 的紧凑状态，结论能否外推到更大模型与更高容量记忆尚不明确。

## 7. 启示与后续方向

- 把**信息生命周期**作为记忆系统的一等设计维度，可能比单纯扩大记忆容量或改进检索更有效地解决长期一致性问题。
- 未来的关键挑战是**生命周期信号的自主推断**：从交互中推断哪些内容应持久、哪些应临时，可能借助显式用户指令、重复出现频率、跨会话一致性等弱监督。
- 评估上，acquisition-controlled 与硬候选协议值得被更广泛采纳，以避免覆盖类问题的评估被"整体准确率"稀释。
- 工程上，子空间划分 + 路由 + 键隔离的组合可在不增加模块数量的前提下提供细粒度控制，对资源受限的在线智能体记忆有实用参考价值。

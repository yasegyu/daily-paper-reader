## 摘要
长时间运行的LLM代理需要能够在交互过程中维持连贯内部状态的记忆机制。我们研究了一种生命周期标记的记忆设定，其中写入事件在训练时提供生命周期元数据，并在评估时使用阶段感知的读取。这种设定反映了区分那些应在未来交互中保持影响力的信息与那些仅应影响当前上下文的信息的需求。生命周期之间的不匹配可能导致临时信息覆盖持久知识，从而导致持久代理的行为漂移。在这种设定下，我们引入了\textbf{LifeFuse-Mem}，一种生命周期感知的神经记忆框架，根据时间承诺对信息进行分离。LifeFuse-Mem使用专门的记忆组件和生命周期感知的更新，使稳定和瞬态知识得以局部演化，而不会将临时上下文转化为持久状态。在受控的反覆盖基准测试中，LifeFuse-Mem提高了采集控制的保持能力，并减少了临时覆盖；在两个公开的长期记忆基准测试中，它仍具有广泛的竞争力。这些结果表明，显式的生命周期信号有助于诊断和缓解紧凑在线记忆中的覆盖问题。

## Abstract
Long-running LLM agents require memory mechanisms that maintain coherent internal states across interactions. We study a lifecycle-labeled memory setting in which write episodes provide lifecycle metadata during training, and phase-aware readout is used during evaluation. This setting reflects the need to distinguish information that should remain influential across future interactions from information that should affect only the current context. A mismatch between these lifecycles can cause temporary information to overwrite durable knowledge, leading to behavioral drift in persistent agents. Within this setting, we introduce \textbf{LifeFuse-Mem}, a lifecycle-aware neural memory framework that separates information according to its temporal commitment. LifeFuse-Mem uses dedicated memory components and lifecycle-aware updates to allow stable and transient knowledge to evolve locally without converting temporary context into durable state. On the controlled anti-overwrite benchmark, LifeFuse-Mem improves acquisition-controlled retention and reduces temporary overwrite; on two public long-memory benchmarks, it remains broadly competitive. These results suggest that explicit lifecycle signals can help diagnose and mitigate overwrite in compact online memory.

## 1. 论文的核心问题与整体含义

### 研究动机与背景
- **核心问题**：长时间运行的LLM代理（如对话系统、任务执行代理）依靠记忆机制在交互之间维持连贯的内部状态。然而，代理需要管理的记忆并非同质信息——有些应该长期保持（持久信息，如用户偏好、行为策略），有些则只应在当前上下文中生效（临时信息，如本地假设、任务特定指令）。
- **关键失败模式**：现有记忆系统大多忽视这种**生命周期维度**，通常将交互历史压缩成一个共享的隐状态，并用统一的更新动力学写入。这种设计导致**临时信息可能覆盖持久知识**，论文将其定义为"**临时覆盖**"（temporary overwrite）。例如，用户在一次调试会话中临时要求跳过确认操作，若代理将此临时指令写入持久状态，其未来行为将发生漂移，违背用户原本的持久策略。
- **研究意义**：临时覆盖会静默地改变代理的未来决策、削弱行为一致性、损害用户信任。论文认为，防止该问题**不能仅靠增加容量或改进检索**，需要从**记忆的架构层级**显式分离不同生命周期信息。

## 2. 方法论：核心思想、关键技术细节

### LifeFuse-Mem 框架概述
LifeFuse-Mem在现有紧凑神经记忆（如δ-Mem）之上增加三条核心机制，实现**在写入时分离生命周期、读取时按阶段融合**：

1. **生命周期感知子空间划分（Lifecycle-Aware Subspace Partition）**
   - 在每个注入的注意力模块中，学习一个近似正交的基矩阵 \(R_l\)，并归一化为正交基 \(Q_l = \mathrm{orth}(R_l)\)，满足 \(Q_l^\top Q_l = I\)。
   - 记忆读取、键、值向量被旋转到该基中：\(\tilde{q}_t = Q_l^\top q_t^m\)，\(\tilde{k}_t = Q_l^\top k_t^m\)，\(\tilde{v}_t = Q_l^\top v_t^m\)。
   - 前 \(r_A\) 个坐标定义为**可塑子空间 A**（容易写入/擦除），后 \(r_B\) 个坐标定义为**稳定子空间 B**（受保护、难被覆盖）。实验中 \(r=8\)，各分4维。
   - 正交正则化项 \(L_{\mathrm{orth}} = \frac{1}{L r^2}\sum_l \|R_l^\top R_l - I\|_F^2\) 保持子空间的可分离性。

2. **永久路由与子空间写入（Permanent Routing and Subspace Writing）**
   - 对每个写入token预测一个**永久路由权重** \(\rho_t = \sigma(w_r^\top h_t + b_r)\)，由episode元数据中的生命周期标签监督（\(L_{\mathrm{route}}\)）。
   - 稳定行（stable rows）的写入尺度用插值控制：\(a_{t,j} = 1\)（j≤rA），\(a_{t,j} = a_{\text{tmp}} + \rho_t(a_{\text{perm}} - a_{\text{tmp}})\)（j>rA）。高 \(\rho_t\) 的token可更新所有行，低 \(\rho_t\) 的token主要更新可塑行。
   - **子空间键隔离**：普通在线写入中，稳定键坐标被衰减，使写入更倾向于可塑键坐标。

3. **阶段感知的受保护状态融合与生命周期读取（Protected State Fusion and Lifecycle Readout）**
   - **仅用于受控覆盖归因协议**：将Phase-A结束时的记忆状态 \(S_A\) 与Phase-B后的状态 \(S_{AB}\) 融合，构造**稳定行保护状态** \(S_{\text{stable}}\)——可塑行取 \(S_{AB}\)，稳定行取 \(S_A\)。
   - **永久查询**：融合分数 \(s_{\text{fuse}}(y) = \alpha s_{S_A}(y) + (1-\alpha)s_{S_{\text{stable}}}(y)\)，其中 \(s_S(y)\) 是长度归一化的token对数概率。融合权重 \(\alpha=0.70\)。
   - **临时查询**：直接用完整的事后状态 \(S_{AB}\) 打分，以便遵循本地临时指令。

4. **训练目标**
   - 采用**情节式"先写后读"目标**（episodic write-then-read objective）：先消费写入消息并更新记忆到 \(S_{\text{write}}\)，再在禁用写入的情况下生成答案。
   - 总损失 \(\mathcal{L} = \mathcal{L}_{\text{CE}} + \lambda_{\text{route}} L_{\text{route}} + \lambda_{\text{orth}} L_{\text{orth}} + \lambda_{\text{hc}}(u) L_{\text{hc}} + \lambda_{\text{ret}} L_{\text{ret}} + \lambda_{\text{sp}} L_{\text{sp}}\)，包括交叉熵、路由监督、正交正则、硬候选损失（区分正确与错误候选）、永久保留排序损失（对永久示例）和稀疏性惩罚（限制写入次数）。

## 6. 主要结论与发现

- **核心发现**：在受控反覆盖基准上，LifeFuse-Mem显著提升采集控制的保留率并降低临时覆盖——相比δ-Mem，Ret.在Qwen3-4B从57.72%提升到63.71%，在SmolLM3-3B从60.27%提升到69.39%；Ovr.相应下降。
- **关键洞察**：**路由监督是最可靠的贡献者**——去除路由监督后，Ret.大幅下降（Qwen3-4B：63.71%→58.68%；SmolLM3-3B：69.39%→59.45%），说明仅靠秩划分或子空间设计不足以实现生命周期分离，token级别的显式路由信号是学出生命周期意识的关键。
- **公共基准兼容性**：在LoCoMo和MemoryAgentBench上总体保持竞争力（LoCoMo提升、MAB总体持平），但类别层面结果参差，证明生命周期边界不是免费的。
- **总体结论**：显式生命周期信号能有效诊断和缓解紧凑在线记忆中的临时覆盖问题，为长期代理记忆设计提供了新的架构原则；但从无标注交互历史中**自动推断生命周期**仍留待未来工作。

## 7. 优点

- **问题界定清晰**：将"临时覆盖"明确区分为与"获取失败"独立的现象，并设计出采集控制的量化协议（Ret.、Ovr.），在方法论上比直接用总体准确率更精准。
- **设计优雅**：在现有记忆机制上以最小侵入方式增加生命周期感知（划分+路由+融合），不改变底层记忆状态和Backbone参数。
- **实验严谨**：在两个不同规模/厂商的backbone上保持一致对比，统一训练协议；消融拆分清楚，能定位每个组件的独立贡献与相互依赖。
- **诚实的边界设定**：论文明确限制protected-state fusion仅用于"受控覆盖归因协议"，不宣称能自主发现生命周期，避免过度声称。
- **可复现性强**：公开了路由目标生成方式、融合权重、正则系数等具体实现细节。

## 8. 不足与局限

- 🚫 **生命周期标签依赖**：方法依赖episode级生命周期元数据（训练时有标注、评估时需提供阶段边界和查询生命周期）。作者明确承认"不声称能从无标注交互中自主发现生命周期"，这限制了现实应用（真实用户交互不会自带标签）。
- 🔄 **公共基准增益来源存疑**：LifeFuse-Mem在LoCoMo上的提升较大，可能主要来自硬候选损失等通用训练技巧而非生命周期机制本身；因为在LoCoMo上没有冲突写入场景，生命周期组件实际处于"空转"状态。
- 📉 **类别式退步**：MemoryAgentBench的LRU和SF类别均出现下降（如LRU在Qwen3-4B从46.52%降至45.30%，SF从17.25%降至16.75%），说明生命周期边界可能牺牲某些记忆能力，其代价边界尚未清晰刻画。
- 📊 **规模限制**：自建基准只有1000个episode、每episode仅2个实体、4个受保护事实，且查询用硬候选选择协议评判，与真实开放生成环境的分布仍有较大差距。
- 🎯 **收益规模的争议性**：端到端永久查询准确率（Perm.）提升有限或甚至微降（如SmolLM3-3B中从19.95%降到19.65%），意味着全量准确率场景下，受益仍需验证。
- 📚 **算力与超参数敏感性未充分展开**：附录提到的融合权重敏感性、超参数细节等未被正文充分讨论，部分实验结论在模型和类别间的迁移性有限。

## 摘要
终身对话代理依赖记忆系统来维持与用户的深度、上下文感知互动。然而，现有的显式文本记忆管线遭受严重的信息瓶颈，常常丢失微妙的行为模式和情感变化。此外，由于部署后通常是静态的，它们无法自主适应个人习惯和偏好，而无需人工反馈。然而，认知科学表明，人类在潜在空间中纯粹地维持心理模型，并通过预测编码不断对其进行细化。受此启发，我们提出了	extbf{ThinkFlow}，一种用于终身对话代理的新型端到端潜在记忆框架。ThinkFlow通过将对话流动态压缩为概率潜在记忆技能来绕过文本瓶颈，自主地将复杂的用户状态整合为解耦的、连续的向量，而不会产生语义干扰。为了打破这一障碍，我们引入了一种测试时进化范式。通过将教师引导的潜在对齐来引导初始状态与自监督的下一个用户话语预测任务相结合，以实现持续细化，该框架成功克服了冷启动挑战，并实现了无标签的终身个性化。在长期对话基准上的大量实验表明，ThinkFlow显著优于主流记忆系统，在扩展的多会话交互中提供高度个性化和上下文准确的响应。

## Abstract
Lifelong conversational agents rely on memory systems to maintain deep, context-aware interactions with users. However, existing explicit textual memory pipelines suffer from a severe information bottleneck, often losing subtle behavioral patterns and emotional shifts. Furthermore, being typically static post-deployment, they cannot autonomously adapt to personal habits and preferences without manual feedback. Cognitive science, however, suggests that humans maintain mental models purely in a latent space and continuously refine them through predictive coding. Inspired by this, we propose \textbf{ThinkFlow}, a novel end-to-end latent memory framework for lifelong conversational agents. ThinkFlow bypasses the text bottleneck by dynamically compressing conversational flows into probabilistic latent memory skills, autonomously consolidating complex user states into disentangled, continuous vectors without semantic interference. To break this barrier, we introduce a test-time evolution paradigm. By coupling teacher-guided latent alignment to bootstrap the initial state with a self-supervised next-user-utterance prediction task for continuous refinement, the framework successfully overcomes cold-start challenges and achieves label-free lifelong personalization. Extensive experiments on long-term conversation benchmarks demonstrate that ThinkFlow significantly outperforms prevailing memory systems, providing highly personalized and contextually accurate responses over extended multi-session interactions.

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心思想
- **ThinkFlow**：将对话历史压缩为**概率潜在记忆技能（Probabilistic Latent Memory Skills, PLMS）**，每个技能是解耦的连续向量（如事实、情感、偏好等维度）。
- 通过**自监督测试时演化（Self-Supervised Test-Time Evolution）**，利用“预测用户下一句”作为监督信号，实现无标签的持续学习。

### 2.2 关键技术细节
#### （1）Probabilistic Latent Memory Skills (PLMS)
- 对当前轮次的隐藏状态 $E_t \in \mathbb{R}^{L \times D}$，使用可学习的记忆技能 $S \in \mathbb{R}^{K \times D}$ 进行**交叉注意力**，输出压缩表示：
  $$C_t = \left( \text{Softmax}\left(\frac{S E_t^T}{\sqrt{D}}\right) E_t \right) \times \frac{1}{\sqrt{c}}$$
  其中 $c = L/K$ 为压缩率。
- 通过两个线性层输出均值 $\mu_t$ 和 log-方差 $\log \sigma_t^2$，采用**重参数化技巧**采样新技能 $\hat{S}_{new} = \mu_t + \sigma_t \odot \epsilon$，并用 KL 散度正则化使分布接近标准高斯。

#### （2）Gated Latent Consolidator (GLC)
- 用于过滤噪声、控制信息更新的门控机制。计算信息增益门 $g_t \in (0,1)^{K \times D}$：
  $$g_t = \sigma\left( W_2 \text{ReLU}\left( W_1 [\hat{S}_{new} \| S_{old}] \right) \right)$$
- 使用 GRU 按时间更新记忆：$S_t = g_t \odot \text{GRU}(\hat{S}_{new}, S_{old}) + (1 - g_t) \odot S_{t-1}$，实现条件性更新与遗忘。

#### （3）Context-Aware Hyper-Aligner (CAHA)
- 弥合历史潜在技能与当前 LLM 语义空间的分布差距。通过超网络生成低秩变换矩阵：
  $$W_{adapt} = W_{down}(x_t) \times W_{up}(x_t)$$
  其中 $W_{down}\in\mathbb{R}^{D\times r}$、$W_{up}\in\mathbb{R}^{r\times D}$，最终对齐技能：$S_{aligned} = S_t + S_t \times W_{adapt}$，作为软提示注入 LLM。

### 2.3 训练流程（两阶段）
- **Phase 1：教师引导的潜在对齐（冷启动）**
  - 教师模型（访问完整历史 $H_{<t}$）输出目标分布 $P_T(y|H_{<t}, x_t)$，学生模型（仅访问当前查询和潜在技能）输出 $P_S(y|S_t, x_t)$。
  - 损失：$L_{Phase1} = D_{KL}(P_T \| P_S) + \alpha L_{KL}$。
- **Phase 2：下一用户话语预测（在线演化）**
  - 教师模型离线，利用用户实际反应作为监督。预测用户下一句 $x_{t+1}$，损失：
    $$L_{Phase2} = L_{CE}(x_{t+1}|S_{t+1}, a_t) + \beta L_{Conf} + \alpha L_{KL}$$
    其中 $L_{Conf}$ 为最小熵置信先验，鼓励模型保持确定性。

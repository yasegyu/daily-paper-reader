## 摘要
终身对话智能体依赖记忆系统来维持与用户深度且上下文感知的交互。然而，现有的显式文本记忆流水线存在严重的信息瓶颈，往往会丢失细微的行为模式和情感转变。此外，它们在部署后通常是静态的，无法在没有人工反馈的情况下自主适应用户的个人习惯和偏好。认知科学则表明，人类仅在潜在空间中维持心智模型，并通过预测编码不断对其进行细化。受此启发，我们提出 ThinkFlow，一种面向终身对话智能体的新型端到端潜在记忆框架。ThinkFlow 通过将对话流动态压缩为概率潜在记忆技能，绕过文本瓶颈，自主将复杂的用户状态整合为解耦的连续向量，且不产生语义干扰。为打破这一障碍，我们引入测试时演化范式。通过将用于引导初始状态的教师引导潜在对齐与用于持续细化的自监督下一用户话语预测任务相耦合，该框架成功克服了冷启动挑战，并实现了无需标签的终身个性化。在长期对话基准上的大量实验表明，ThinkFlow 显著优于当前主流的记忆系统，能够在扩展的多会话交互中提供高度个性化和上下文准确的响应。

## Abstract
Lifelong conversational agents rely on memory systems to maintain deep, context-aware interactions with users. However, existing explicit textual memory pipelines suffer from a severe information bottleneck, often losing subtle behavioral patterns and emotional shifts. Furthermore, being typically static post-deployment, they cannot autonomously adapt to personal habits and preferences without manual feedback. Cognitive science, however, suggests that humans maintain mental models purely in a latent space and continuously refine them through predictive coding. Inspired by this, we propose \textbf{ThinkFlow}, a novel end-to-end latent memory framework for lifelong conversational agents. ThinkFlow bypasses the text bottleneck by dynamically compressing conversational flows into probabilistic latent memory skills, autonomously consolidating complex user states into disentangled, continuous vectors without semantic interference. To break this barrier, we introduce a test-time evolution paradigm. By coupling teacher-guided latent alignment to bootstrap the initial state with a self-supervised next-user-utterance prediction task for continuous refinement, the framework successfully overcomes cold-start challenges and achieves label-free lifelong personalization. Extensive experiments on long-term conversation benchmarks demonstrate that ThinkFlow significantly outperforms prevailing memory systems, providing highly personalized and contextually accurate responses over extended multi-session interactions.

## 2. 论文提出的方法论

### 核心思想
- 提出 **ThinkFlow**：端到端潜在记忆框架，将连续对话流动态压缩为 **概率潜在记忆技能（PLMS）**，以解耦的连续向量表征用户的事实、情感、偏好等不同侧面，完全绕过文本生成与检索。
- 引入 **自监督测试时演化范式**：结合教师引导潜在对齐与下一用户话语预测，实现无标签的终身个性化。

### 关键技术细节

- **Probabilistic Latent Memory Skills (PLMS)**
  - 对当前轮隐藏状态 \(E_t \in \mathbb{R}^{L \times D}\)，用 K 个可学习潜在技能 \(S \in \mathbb{R}^{K \times D}\) 做交叉注意力，压缩为 K 个稠密技能向量。
  - 引入分布保持缩放因子 \(1/\sqrt{c}\)（\(c = L/K\)），防止方差塌缩为确定性点质量。
  - 通过两个并行线性层输出均值 \(\mu_t\) 与对数方差 \(\log\sigma_t^2\)，用重参数化技巧采样：\(\hat{S}_{\text{new}} = \mu_t + \sigma_t \odot \epsilon\)，\(\epsilon \sim \mathcal{N}(0,I)\)。
  - 用 KL 散度损失将近似后验正则化至标准高斯先验。

- **Gated Latent Consolidator (GLC)**
  - 引入信息增益门 \(g_t \in (0,1)^{K \times D}\)，由 MLP 基于新旧技能拼接表示学习得到，量化新信息相对已有记忆的新颖性。
  - 使用 GRU 核心进行条件更新：\(S_t = g_t \odot \text{GRU}(\hat{S}_{\text{new}}, S_{\text{old}}) + (1-g_t) \odot S_{t-1}\)，实现时序维护与优雅遗忘。
  - 低门值（如 0.12）过滤噪声（如“哈哈/嗯/也许”），高门值（如 0.91）保留关键信息（如“酒店/巴黎/$200”）。

- **Context-Aware Hyper-Aligner (CAHA)**
  - 用超网络根据当前用户查询 \(x_t\) 生成低秩变换矩阵 \(W_{\text{adapt}} = W_{\text{down}}(x_t) \times W_{\text{up}}(x_t)\)，其中瓶颈秩为 \(r\)。
  - 残差投影得到对齐记忆技能：\(S_{\text{aligned}} = S_t + S_t \times W_{\text{adapt}}\)。
  - 将对齐技能作为软提示（soft prompt）前置注入语言模型，条件化生成过程。

- **自监督测试时演化**
  - **Phase 1 教师引导潜在对齐**：教师模型读取完整明文历史 \(H_{<t}\) 输出目标分布 \(P_T(y|H_{<t}, x_t)\)；学生模型仅读取当前查询与潜在技能 \(S_t\)，输出 \(P_S(y|S_t, x_t)\)；最小化 KL 散度 \(L_{\text{Phase1}} = D_{\text{KL}}(P_T \| P_S) + \alpha L_{\text{KL}}\)，解决冷启动。
  - **Phase 2 下一用户话语预测**：教师下线后，智能体用 \(S_{t+1}\) 与前一轮响应 \(a_t\) 预测用户下一话语 \(x_{t+1}\)；若记忆未捕捉核心上下文则交叉熵损失高，直接迫使 GLC 门关闭以避免污染；引入最小熵置信先验 \(L_{\text{Conf}}\) 防止语义塌缩；损失为 \(L_{\text{Phase2}} = L_{\text{CE}}(x_{t+1}|S_{t+1},a_t) + \beta L_{\text{Conf}} + \alpha L_{\text{KL}}\)。

### 算法流程（文字说明）
- 初始化潜在记忆技能为空。
- **Phase 1**：对冷启动会话每一轮，教师生成目标分布，学生经 CAHA 对齐、PLMS 压缩、GLC 整合后生成预测分布，以 KL 散度对齐并更新所有模块。
- **Phase 2**：从第 2 个会话起，逐轮用潜在技能与上一轮响应预测用户下一话语，以交叉熵、最小熵正则和 KL 正则联合优化，持续在线演化。

## 7. 优点

- **范式创新**：首次系统性地将终身对话记忆完全置于潜在空间，彻底绕过显式文本瓶颈，避免信息丢失与语义稀释。
- **解耦技能设计**：PLMS 将用户状态分解为 K 个概率技能向量，兼顾不确定性建模与特征解缠，防止多主题语义干扰。
- **门控整合机制**：GLC 通过信息增益门与 GRU 实现选择性存储与优雅遗忘，有效过滤噪声、保留关键信息。
- **动态对齐**：CAHA 用超网络生成低秩自适应变换，以极小参数代价桥接历史潜在技能与当前语义上下文。
- **无标签终身演化**：Phase 2 利用下一用户话语预测作为免费自监督信号，结合最小熵正则，实现部署后持续个性化。
- **效率卓越**：潜在空间操作避免大量中间文本生成，token 与时间开销远低于显式记忆流水线。
- **实验扎实**：多数据集、多骨干、多尺度、消融、缩放、效率、案例研究齐备，论证较为充分。

## 摘要
设计有效的记忆机制对于推进大语言模型驱动的多智能体系统（MAS）至关重要，有助于智能体共同学习并随时间表现更好。尽管近期工作已带来强大的合作能力，但大多数方法仍使用扁平、无结构的记忆，这类记忆容易被噪声填满，并抹去智能体之间的差异。为解决这一问题，我们引入集体-个体记忆协同的概念，并提出 CoMem，一种统一私有经验与共享知识以支持多智能体学习的架构。CoMem 具有以下特点：(i) 私有经验沉淀，使每个智能体能够随时间保留并更新自身有用的记忆；(ii) 集体智慧精选，仅精心选择被广泛验证的理念在智能体之间共享；(iii) 并行双流检索，允许智能体同时从自身记忆和群体智慧中获取信息，并利用聚类确保多样性。在 ALFWorld 和 PDDL 基准上的实验表明，CoMem 取得了强劲的整体性能，并稳健地避免了记忆污染。

## Abstract
Designing effective memory mechanisms is crucial for advancing LLM-driven Multi-Agent Systems (MAS), helping agents learn together and perform better over time. While recent work has led to strong cooperation skills, most methods still use flat, unstructured memories, which easily get filled with noise and erase differences between agents. To address this, we introduce the concept of collective-individual memory synergy and propose CoMem, an architecture that unifies both private experience and shared knowledge for multi-agent learning. CoMem features:(i) Private Experience Sedimentation, which lets each agent keep and update its own useful memories over time;(ii) Collective Wisdom Curation, which carefully selects only widely proven ideas to be shared among agents;(iii)Parallel Dual-Stream Retrieval, which allows agents to draw both from their own memory and the group's wisdom, using clustering to ensure diversity.Experiments on ALFWorld and PDDL benchmarks show that CoMem achieves strong overall performance and robustly avoids memory pollution.

## 2. 论文提出的方法论

- **核心思想**：构建双层记忆生态：
  - **私有层**：每个智能体独立保存、更新自身经验，避免跨智能体污染。
  - **集体池**：只存储经过重复验证、具有跨任务泛化价值的群体知识。
  - 两层通过“私有沉淀 → 经验提升 → 集体筛选 → 双流检索”形成双向循环。
- **关键技术一：私有经验沉淀**
  - 每个 episode 结束后，智能体用 LLM 蒸馏器把完整执行轨迹转成少量可操作文本洞察。
  - 每条私有记忆带有元数据：所属智能体、效用分 \(S\)、调用次数 \(n_{use}\)、成功次数 \(n_{succ}\)、提升标志 \(\iota_{prom}\)。
  - 使用滚动剪枝：若某条记忆连续 \(K_{miss}\) 次未被检索，则计数加一；超过阈值 \(K_{max}\) 后永久删除，保持私有记忆紧凑。
- **关键技术二：集体智慧精选**
  - 私有记忆只有满足经验提升门控才进入集体池：
    - 使用次数 \(N_{use}(m) \ge N_{min}\)；
    - 使用该记忆时的平均任务得分 \(\bar R_m\) 不低于环境移动基线 \(\bar R\)。
  - 提升后复制到集体池，并从原私有库移除，减少冗余。
  - 集体条目持续接受混合效用评估：
    - \(U_t(m)=w \cdot R_{norm}+(1-w)\cdot\) 多智能体 LLM 主观评分的归一化平均。
    - 长期效用用指数移动平均更新：\(S_{t+1}(m)=(1-\alpha)S_t(m)+\alpha \cdot (S_{max}\cdot U_t(m))\)。
    - 效用持续低于自适应阈值的条目被删除。
- **关键技术三：并行双流检索**
  - 新任务到来时，每个智能体同时检索私有记忆和集体池。
  - **私有流**：基于语义嵌入相似度，取 top-k 私有经验注入提示。
  - **集体流**：检索集体知识，并用在线层次聚类过滤语义重叠，选择各簇代表条目，保证多样性与简洁性。
  - 该设计避免顺序检索瓶颈，同时降低跨层污染风险。
- **整体流程**：个体执行任务 → 蒸馏私有经验 → 滚动剪枝 → 经验提升门控 → 集体池质量维护 → 双流检索辅助后续决策。

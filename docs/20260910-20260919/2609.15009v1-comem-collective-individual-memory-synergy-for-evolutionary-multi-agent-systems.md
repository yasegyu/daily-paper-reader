## 摘要
设计有效的记忆机制对于推动LLM驱动的多智能体系统（MAS）至关重要，有助于智能体共同学习并随着时间推移表现更佳。尽管近期工作已带来强大的协作能力，但多数方法仍采用扁平、无结构的记忆，这些记忆容易充斥噪声并抹平智能体间的差异。为此，我们引入集体-个体记忆协同的概念，并提出CoMem——一种统一个体经验与共享知识以支持多智能体学习的架构。CoMem包括：（i）个体经验沉淀，允许每个智能体随时间保留并更新其自身有用的记忆；（ii）集体智慧精选，仅挑选经广泛验证的想法在智能体间共享；（iii）并行双流检索，使智能体能够同时从自身记忆和群体智慧中汲取，并通过聚类确保多样性。在ALFWorld和PDDL基准上的实验表明，CoMem取得了强大的整体性能，并能稳健地避免记忆污染。

## Abstract
Designing effective memory mechanisms is crucial for advancing LLM-driven Multi-Agent Systems (MAS), helping agents learn together and perform better over time. While recent work has led to strong cooperation skills, most methods still use flat, unstructured memories, which easily get filled with noise and erase differences between agents. To address this, we introduce the concept of collective-individual memory synergy and propose CoMem, an architecture that unifies both private experience and shared knowledge for multi-agent learning. CoMem features:(i) Private Experience Sedimentation, which lets each agent keep and update its own useful memories over time;(ii) Collective Wisdom Curation, which carefully selects only widely proven ideas to be shared among agents;(iii)Parallel Dual-Stream Retrieval, which allows agents to draw both from their own memory and the group's wisdom, using clustering to ensure diversity.Experiments on ALFWorld and PDDL benchmarks show that CoMem achieves strong overall performance and robustly avoids memory pollution.

### 1. 核心问题与整体含义

**研究动机与背景：**
- 随着LLM驱动多智能体系统（MAS）的快速发展，记忆机制成为支持智能体持续学习、长期协作和群体智能积累的关键基础设施。
- 现有MAS记忆方法普遍采用**扁平化、无结构共享记忆**，缺乏集体记忆的显式建模，也未考虑个体与集体记忆之间的协同关系。
- 这种设计导致两个相互强化的退化过程：
  - **噪声积累（Noise Accumulation）**：未经验证的试错行为、低质量决策大量涌入共享存储，降低存储可靠性；
  - **行为同质化（Behavioral Homogenization）**：跨智能体无差别读写使异质智能体逐渐丧失角色特异性，技能差异被平均化。
- 上述问题统称为**记忆污染（Memory Pollution）**，使共享记忆方法在实践中往往劣于无记忆基线。
- 论文从人类社会知识演化过程（"个体提议→集体筛选→共识结晶"）获得启发，主张**可持续的群体智能需要个体学习与群体知识之间精心设计的平衡**。

**核心问题**：如何设计一种记忆架构，既能保留个体智能体的专业化经验，又能安全地累积经过验证的集体智慧，从而规避记忆污染？

### 2. 方法论

**核心思想：**
- 提出**集体-个体记忆协同（Collective-Individual Memory Synergy）**概念，将记忆空间解耦为两大层级：
  - **私有记忆层**（Private Layer）：每个智能体拥有独立、隔离的经验库，保证零跨智能体交叉污染；
  - **集体记忆池**（Collective Pool）：仅存放经过严格实证验证的、可泛化的群体智慧。
- 两大层级通过"私有沉淀→经验提升→集体精炼"的双向流转形成良性循环，模拟人类社会的知识结晶过程。

**三大核心组件：**

**(i) 私有经验沉淀（Private Experience Sedimentation）**
- 每个agent在每轮任务结束后，由LLM蒸馏器将完整执行轨迹提炼为3条精炼的、可迁移的个人经验洞察；
- 私有记忆存储为结构化元组：`m = ⟨doc_content, metadata⟩`，其中metadata包含效用分数S、使用次数n_use、成功次数n_succ、提升状态ι_prom等；
- 引入**滚动剪枝策略**：每条记录有连续未命中计数器K_miss，当超过阈值K_max即被永久移除，保证私有记忆精简、聚焦、免干扰。

**(ii) 集体智慧精选（Collective Wisdom Curation）**
- 私有记忆条目需经过**经验提升门控（Empirical Promotion Gate）**才能进入集体池，条件为：
  - 使用次数满足统计下限：`N_use(m) ≥ N_min`（默认3次），防止偶然激活；
  - 平均任务得分需不低于环境历史基线：`R̄_m ≥ R̄`，确保有持续高于平均水平的实际贡献。
- 集体记忆持续接受**混合效用跟踪（Hybrid Utility Tracking）**：综合客观奖励与LLM主观评分，通过EMA平滑更新长期效用分数：
  - `U_t(m) = w·R_norm + (1-w)·(1/|A_m|)·Σ_a LLM_a(m)/L_max`
  - `S_{t+1}(m) = (1-α)·S_t(m) + α·(S_max·U_t(m))`
  - 分数持续低于自适应阈值的条目被系统性清除。

**(iii) 并行双流检索（Parallel Dual-Stream Retrieval）**
- 当新任务查询到达时，智能体**同时**从私有记忆（基于语义嵌入相似度，取top-k相关条目）和集体池（同样取top-k）中检索；
- 集体流检索通过**在线层次聚类过滤器**，按语义距离分组并选取每个簇的最具代表性条目，消除冗余、保证多样性；
- 两流结果的注入使智能体决策同时获得个性化战术知识与经过验证的组织级智慧。

**关键公式说明：**
- 记忆污染问题的正式化：共享记忆质量随时间退化，且存在 `lim_{t→∞} H(π_ai ‖ π_aj) = 0`——即智能体策略分布趋于同质化；
- CoMem目标为维持解耦记忆空间 `M = {M_priv^(i)}_i=1^|A| ∪ M_coll`，同时保持个体学习纯度与集体知识质量。

### 6. 主要结论与发现

- **CoMem在全部4个MAS框架上持续提升性能**：在MacNet上，将ALFWorld成功率从79.85提升至89.55（+9.70），PDDL从60.78提升至70.19（+9.41）；平均增益为ALFWorld +8.02、PDDL +4.70个百分点。
- **传统共享记忆方法常劣于无记忆基线**：多组配置下，Voyager、MemoryBank、MetaGPT等共享记忆方法出现显著的负增益，实证了一致性记忆污染问题。

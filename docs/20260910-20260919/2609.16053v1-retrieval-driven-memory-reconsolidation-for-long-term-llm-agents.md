## 摘要
长期记忆对于在扩展交互中运行的基于LLM的智能体至关重要。现有记忆系统主要在新信息到达时更新记忆，将检索视为记忆访问的终点，而非记忆演化的驱动力。因此，检索反馈很少被用于持续重组记忆以支持未来访问。此外，大多数现有方法依赖预定义的记忆结构以及固定的检索流水线，限制了智能体自主组织和演化自身记忆的能力。受认知神经科学中记忆再巩固的启发，我们提出REALM，一个再巩固-演化智能体长期记忆（reconsolidation-evolution agentic long-term memory）框架。它将长期记忆建模为一个持续生命周期，通过自主将记忆组织为异质认知图，经由自适应组合的图搜索原子检索证据，并基于检索反馈持续再巩固记忆。REALM在LoCoMo上达到75.97%的平均准确率，在LongMemEval上达到65.11%，分别比最强基线高出7.17和1.31个百分点。消融研究证实，记忆再巩固持续提升性能，进一步分析表明，它会逐步将相关记忆单元重组为更连贯的局部结构，以便在推理过程中集体召回和利用证据。这些结果表明，检索驱动的记忆再巩固为LLM智能体中长期记忆的持续演化提供了一种有效机制。

## Abstract
Long-term memory is essential for LLM-based agents operating over extended interactions. Existing memory systems primarily update memory when new information arrives, treating retrieval as the endpoint of memory access rather than a driver of memory evolution. Consequently, retrieval feedback is rarely exploited to reorganize memory for future access continuously. Moreover, most existing approaches rely on predefined memory structures together with fixed retrieval pipelines, limiting the agent's ability to organize and evolve its own memory autonomously. Inspired by memory reconsolidation in cognitive neuroscience, we propose \textbf{REALM}, a \textbf{r}econsolidation-\textbf{e}volution \textbf{a}gentic \textbf{l}ong-term \textbf{m}emory framework. It models long-term memory as a continual lifecycle by autonomously organizing memories into a heterogeneous cognitive graph, retrieving evidence via adaptively composed graph-search atoms, and continually reconsolidating memories based on retrieval feedback. REALM achieves an average accuracy of 75.97\% on LoCoMo and 65.11\% on LongMemEval, outperforming the strongest baselines by 7.17 and 1.31 points respectively. Ablation studies confirm that memory reconsolidation consistently boosts performance, with further analyses revealing that it progressively reorganizes related memory units into more coherent local structures for collective evidence recall and utilization during reasoning. These results suggest that retrieval-driven memory reconsolidation provides an effective mechanism for continually evolving long-term memory in LLM agents.

  - `e_ij = (v_i, v_j, κ_ij, des_ij, w_ij)`

### 2.3 记忆检索：策略原子组合

- 将图搜索形式化为三阶段动态流水线：
  - `π = π_seed ⊕ π_expand ⊕ π_filter`
  - 分别对应种子定位、证据扩展、证据聚合。
- **种子定位**：
  - 智能体生成多个参数化检索计划 `p_i = (Q_i, K_i, T_i, τ_i)`。
  - 匹配模式包括：
    - `query_match`：仅查询嵌入相似度。
    - `keywords_match`：仅关键词词法匹配。
    - `hybrid_match`：嵌入与关键词加权融合。
  - 节点类型和时间范围作为过滤条件，必要时可放松。
- **自适应证据扩展**：
  - 从种子节点出发迭代扩展。
  - 每轮判断当前证据 `R_t` 是否足够回答查询；足够则停止。
  - 否则选择前沿节点 `F_t`，为每个节点预测扩展动作：
    - `a_v = (mode, predicate, decay, inhibit)`
    - 控制遍历模式、边类型谓词、时间衰减、路径抑制。
  - 新节点访问分数：
    - `s_aces(v) = β·s_sim(q, des_ij) + (1-β)·w_ij - Δ_decay(t_v)`
    - 融合查询-边描述语义相似度、拓扑置信度和时间惩罚。
- **证据聚合**：
  - 最终节点分数：
    - `Score(v) = α·s_aces(v) + (1-α)·s_sim(v, q)`
  - 取 Top-K 节点构成证据集 `V_q`，并诱导激活子图：
    - `G_q = (V_q, E_q)`，其中 `E_q = {(u,v) ∈ E | u,v ∈ V_q}`。

### 2.4 记忆再巩固：拓扑演化

- **检索诱导结构反馈**：
  - 每次交互产生激活子图 `G_q` 和任务反馈 `f`。
  - 智能体推断主题结构：
    - `T_q = InferTopicStructure(q, V_q)`
  - 用于指导局部拓扑精炼。
- **局部拓扑再巩固**：
  - 智能体生成修改决策集 `D = {d_1, ..., d_n}`。
  - 每个决策为五元组：
    - `d = (v_i, v_j, a, r, c)`
    - `a ∈ {add, strengthen, weaken}` 表示原子边操作。
  - 语义：
    - 同一推理上下文中反复共同激活的记忆之间可新增连接。
    - 持续支持成功检索的关系可增强。
    - 反复引入无关证据的弱关系或误导关系可削弱。
- **置信度引导的拓扑更新**：
  - 当前边权 `w_ij`，最小阈值 `w_min`，有界表示 `w_b = max(w_min, min(1, w_ij))`。
  - 更新规则：
    - `w_ij ← Clip(w_ij + η·c, w_min, 1)`
  - `η` 取值：
    - `add`：`η = 0.8`
    - `strengthen`：`η = 1 - w_b`
    - `weaken`：`η = -(w_b - w_min)`
  - 该设计使权重在边界附近平滑变化，避免单次或重复检索导致拓扑失稳。
- **闭环演化**：
  - `G_t --Retrieve--> (G_q, f) --Reconsolidate--> G_{t+1}`
  - 频繁共用的记忆路径被强化，无效检索路径被削弱，记忆图从初始语义组织逐步变为使用感知的认知结构。

  - Nemori：情节整合与语义蒸馏，基于预测误差残差。
  - MAGMA：四类正交关系图，策略引导图遍历。

## 5. 实验数量与充分性

- **主要实验组**：
  - RQ1：两个 benchmark 上的整体性能对比，覆盖多个问题类别。
  - RQ2：再巩固消融实验，覆盖 LoCoMo 和 LongMemEval 多类别。
  - RQ2：LoCoMo 随机问题顺序鲁棒性实验。
  - RQ3：节点/关系分布分析、检索深度分析、自适应策略选择对比。
  - RQ4：再巩固前后证据发现与利用增益分析。
- **具体结果**：
  - LoCoMo 平均准确率 75.97%，超最强基线 7.17 个百分点。
  - LongMemEval 平均准确率 65.11%，超最强基线 1.31 个百分点。
  - 再巩固消融：LoCoMo 提升 2.01 个百分点，LongMemEval 提升 2.13 个百分点。
  - 随机问题顺序下性能稳定。
  - 节点分布差异低于 1.5 个百分点；因果和逻辑关系在检索中分别增加 13.39 和 6.57 个百分点。
  - LoCoMo 84.87% 证据从种子节点直接找到；LongMemEval 40.52% 直接从种子层找到。
  - 自适应策略准确率 43.36%，略高于 path_search 的 39.84% 和 subgraph_beam 的 43.09%。
  - 再巩固后，证据发现比例提升 3.70% 和 5.41%，正确回答比例提升 20.83% 和 19.23%。
- **充分性评估**：
  - 覆盖两个主流 benchmark、多个问题类别、多种基线范式。
  - 包含消融、鲁棒性、机制分析和效率分析，整体较充分。
  - 但存在以下限制：
    - 仅使用 **GPT-4o-mini** 作为主干和 judge，未验证其他模型。
    - 部分基线结果复用文献，A-Mem 为自行复现，协议一致性受限于原文设置。
    - LongMemEval 单题样本通过 GPT-4o-mini 和 GPT-4.1 生成 1-6 个额外问题来模拟历史记忆使用，可能引入生成偏差。
    - 未报告多次独立运行的方差或统计显著性检验。
    - 未系统分析不同超参数（如 α、β、扩展深度）的敏感性。

## 6. 主要结论与发现

- **整体性能**：
  - REALM 在 LoCoMo 和 LongMemEval 上均取得最佳平均性能。
  - 在 LoCoMo 四个类别均排名第一。
  - 在 LongMemEval 的 temporal reasoning 和 knowledge update 上表现最佳。
- **再巩固有效**：
  - 移除再巩固模块后性能持续下降。
  - 再巩固在 Multi-Hop、Open-Domain、Single-session Preference、Knowledge Update 上增益明显。
- **顺序鲁棒**：
  - 随机打乱问题顺序后性能保持稳定，说明增益不依赖特定查询序列。
- **组织与利用**：
  - 异质节点类型在图中和检索中分布一致，无明显检索偏差。
  - 因果关系和逻辑关系在检索中被选择性增强，关联关系更多维持广泛语义连接。

## 摘要
长期记忆对于在长时间交互中运行的基于LLM的智能体至关重要。现有的记忆系统主要在新信息到来时更新记忆，将检索视为记忆访问的终点而非记忆演化的驱动力。因此，检索反馈很少被利用来持续重组记忆以供未来访问。此外，大多数现有方法依赖预定义的记忆结构和固定的检索流程，限制了智能体自主组织和演化自身记忆的能力。受认知神经科学中记忆再巩固的启发，我们提出了REALM，一种再巩固-演化智能体长期记忆框架。它通过将长期记忆建模为一个持续的生命周期，自主地将记忆组织成异质的认知图，通过自适应组合的图搜索原子来检索证据，并基于检索反馈持续再巩固记忆。REALM在LoCoMo上达到75.97%的平均准确率，在LongMemEval上达到65.11%，分别比最强基线高出7.17和1.31个百分点。消融研究证实记忆再巩固一致地提升性能，进一步分析显示它逐步将相关记忆单元重组为更连贯的局部结构，以便在推理过程中进行集体证据回忆和利用。这些结果表明，检索驱动的记忆再巩固为LLM智能体中长期记忆的持续演化提供了一种有效机制。

## Abstract
Long-term memory is essential for LLM-based agents operating over extended interactions. Existing memory systems primarily update memory when new information arrives, treating retrieval as the endpoint of memory access rather than a driver of memory evolution. Consequently, retrieval feedback is rarely exploited to reorganize memory for future access continuously. Moreover, most existing approaches rely on predefined memory structures together with fixed retrieval pipelines, limiting the agent's ability to organize and evolve its own memory autonomously. Inspired by memory reconsolidation in cognitive neuroscience, we propose \textbf{REALM}, a \textbf{r}econsolidation-\textbf{e}volution \textbf{a}gentic \textbf{l}ong-term \textbf{m}emory framework. It models long-term memory as a continual lifecycle by autonomously organizing memories into a heterogeneous cognitive graph, retrieving evidence via adaptively composed graph-search atoms, and continually reconsolidating memories based on retrieval feedback. REALM achieves an average accuracy of 75.97\% on LoCoMo and 65.11\% on LongMemEval, outperforming the strongest baselines by 7.17 and 1.31 points respectively. Ablation studies confirm that memory reconsolidation consistently boosts performance, with further analyses revealing that it progressively reorganizes related memory units into more coherent local structures for collective evidence recall and utilization during reasoning. These results suggest that retrieval-driven memory reconsolidation provides an effective mechanism for continually evolving long-term memory in LLM agents.

## 1. 核心问题与研究动机

**核心问题**：现有LLM智能体的长期记忆系统将检索视为记忆访问的"终点"而非记忆演化的"驱动力"，导致记忆结构无法通过使用而持续优化。

**研究动机**：
- 现有长期记忆研究主要遵循"前向演化"范式：记忆更新（增删、合并）仅由新到达的信息触发，检索被视为被动的终端环节。
- 大多数方法依赖**预定义的记忆结构**（如树、图、时间线）与**固定的检索流程**，限制了智能体自主组织和演化记忆的能力。
- 认知神经科学中的**记忆再巩固（memory reconsolidation）** 理论指出：记忆被回忆后会进入不稳定状态（labile state），在此期间连接可被增强、削弱或新建，使记忆网络通过使用而持续适应。这一机制启发作者将记忆视为动态生命周期，而非静态存储。

## 2. 方法论：REALM框架

REALM（**r**econsolidation-**e**volution **a**gentic **l**ong-term **m**emory）将长期记忆建模为闭环生命周期，包含三个互补组件：

### 2.1 记忆组织：统一认知图（Memory Organization）

- 将记忆建模为异构图 **G = (V, E)**，节点分为四类：**entity、event、episode、fact**；边分为四类：**logical、causal、hierarchical、associative**。
- 每个节点包含类型、源内容、语义描述、关键词、时间跨度等字段；每条边包含关系类型、关系描述和置信度权重 **w ∈ [0,1]**。
- **统一集成阶段**：将插入、合并、遗忘统一为一个操作。智能体自动决定新观测是"新增节点"、"合并到现有节点"还是"跳过"，并推断关系边。

### 2.2 记忆检索：策略原子组合（Memory Retrieval）

检索由三个连续阶段组成：**定位种子节点 → 自适应图扩展 → 证据聚合**，整体策略为：

> **π = π_seed ⊕ π_expand ⊕ π_filter**

- **种子定位**：生成多个参数化检索计划（含查询串、关键词、节点类型、时间约束），通过关键词、语义或混合模式定位起始节点。
- **自适应扩展**：迭代评估已收集证据是否充分；若不充分，LLM为每个前沿节点预测个体化扩展动作（遍历模式、谓词约束、时间衰减、路径抑制）。新节点的访问得分综合了语义相似度、边置信度和时间衰减。
- **证据聚合**：全局重排序后取Top-K节点作为最终证据集，并诱导出**激活的局部认知子图** G_q，作为再巩固阶段的输入。

### 2.3 记忆再巩固：拓扑演化（Memory Reconsolidation）

- 每次交互后，对激活子图执行局部拓扑更新，决策表示为五元组 **d = (v_i, v_j, a, r, c)**，其中 a ∈ {add, strengthen, weaken}。
- 采用**置信度引导的自适应有界更新**：

> w_ij ← Clip(w_ij + η·c, w_min, 1)

其中 η 根据操作类型取不同值（add=0.8，strengthen=1-w_b，weaken=-(w_b-w_min)），避免拓扑因单次或重复检索而不稳定。
- 整体闭环演化公式：**G_t+1 = Reconsolidating(G_t \ G_q ∪ G'_q, f)**，其中 f 为任务反馈。

## 6. 主要结论

1. 检索驱动的记忆再巩固为LLM智能体长期记忆持续演化提供了有效机制。
2. 将记忆从"静态存储"转向"持续演化的生命周期"是正确定位。
3. 再巩固的主要价值**不在于扩大可检索记忆空间**，而在于**持续改善记忆组织质量**——使检索到的证据更加相关和具有信息量，支持集体证据回忆和利用。
4. 智能体自主构建的异构认知图能够与检索需求良好对齐，自适应检索策略能够保持灵活性的同时，学到最强的默认策略。

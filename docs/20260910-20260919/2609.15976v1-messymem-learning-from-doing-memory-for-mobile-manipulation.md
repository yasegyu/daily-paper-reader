## 摘要
部署在众多房间、经历多次到访的移动操作机器人应当能够随经验积累而不断改进：在发现某个柜子被锁上，或在抽屉里找到某个物体之后，机器人应当复用这些知识，而不是每次任务都从头开始。然而，如今的机器人往往把每个任务都当作全新的任务来处理：紧凑的场景表示忽略了由交互获得的知识，原始视频历史难以查询，而 VLM 规划器仅在推理时进行推理，并不会持续更新机器人所掌握的知识。我们提出 MessyMem，一种持久记忆系统，使移动操作机器人能够从经验中学习，并在未来任务中复用这些知识。它维护一个具有空间定位的物体与位置三维场景图，用通过交互学到的属性与结果对其加以增强，并关联视觉观测以实现细粒度回忆。我们在仿真环境和真实移动操作机器人上对 MessyMem 进行评估。在一段持续 3 小时以上、包含 25 个连续任务的仿真中，MessyMem 取得 80.0% 的任务进度，分别比最强的消融版本高出 14.8 个百分点、比最强的外部基线高出 28.9 个百分点，同时能够从数千个存储的关键帧以及一小时以上的历史中检索与任务相关的证据。

## Abstract
Mobile manipulators deployed across many rooms and visits should improve with experience: after discovering that a cabinet is locked or finding an object in a drawer, the robot should reuse that knowledge rather than start each task from scratch. Yet today's robots often treat each task as new: compact scene representations omit interaction-derived knowledge, raw video histories are difficult to query, and VLM planners reason at inference time without persistently updating what the robot knows. We present MessyMem, a persistent memory system that enables mobile manipulators to learn from experience and reuse that knowledge across future tasks. It maintains a spatially grounded 3D scene graph of objects and locations, augments it with properties and outcomes learned through interaction, and links visual observations for fine-grained recall. We evaluate MessyMem in simulation and on a real mobile manipulator. In a continuous 25-task simulation spanning over 3 hours, MessyMem achieves 80.0% task progress, outperforming the strongest ablation by 14.8 percentage points and the strongest external baseline by 28.9 points, while retrieving task-relevant evidence from thousands of stored keyframes and over an hour into the past.

- **现有方案的三大缺陷**：
  - 紧凑的场景表示（如 3D 场景图）只捕捉被动观测到的几何与语义，**遗漏了必须通过物理交互才能获知的属性**（如柜子是否上锁、物体重量、抽屉是否可开）。
  - 原始视频历史虽保留细粒度信息，但**难以在大规模、长时间跨度下查询**。
  - VLM 规划器仅在推理时进行推理，**不会持久更新机器人所掌握的知识**。
- **记忆应满足的三个要求**（论文提出的设计纲领）：
  1. **全局可查询且空间锚定**：能跨房间、跨会话高效检索，并返回“去哪找”的位置信息。
  2. **可由交互更新**：能学习并保存每次交互揭示的属性与结果。
  3. **细粒度**：能按需检索具体视觉证据（如某容器上的标签、某物体所在的确切货架）。
- **整体含义**：论文主张让机器人像人一样“从做中学”，把交互经验持久化、结构化并复用，从而在长时程任务中持续累积能力。

## 2. 方法论

### 核心思想
将**结构化空间记忆**（3D 场景图）、**交互派生状态**（VLM 交互分析器）与**细粒度视觉证据**（链接关键帧）三者结合，形成一个可持久累积、可被规划器查询的“对象级记忆接口”，执行流程为闭环：检索记忆 → 规划并执行原语 → 分析结果 → 更新记忆 → 重新规划。

### 关键技术细节

- **（1）全局可查询且空间锚定的文本记忆：3D 场景图**
  - 用 SAM3 按类别提示对 RGB-D 图像做实例分割，将掩码反投影为 3D 点云。
  - 同标签检测经聚类与空间邻近关联到已有节点，新观测以滑动平均更新质心；物体离开视野后仍保留在图中。
  - 每个节点存储：对象 ID（如 `drawer_3`）、3D 质心、属性字典（`accessible`、`pickable`、`pushable`、`fullness`、`openable` 等）、`contents`、`task_history`。
  - 场景图同时作为交互属性与关键帧的**索引枢纽**。

- **（2）交互更新的文本记忆：VLM 交互分析器**
  - 每次操作原语后，收集**动作窗口内的多帧拼贴图**（前、中、后 + 峰值帧），而非仅单张前后对比图。
  - 分析器区分**执行失败**（如抓空、滑脱，记为可重试的 failure）与**持久物体属性**（如用力拉但柜门不动，记为 locked）。
  - 输出严格 JSON：`task_success`、`failure_reason`、`property_updates`、`new_properties`（开放词汇，如 `material`、`has_handle`）、`contents_updates`。
  - **新证据覆盖旧值**（结构化属性可被纠正），而关键帧保留完整视觉历史不被覆盖。

- **（3）细粒度视觉记忆：链接关键帧**
  - 关键帧来源：交互前/中/后/峰值帧 + 感知触发的场景图增量帧。
  - 每帧存储全分辨率图、缩略图及元数据（时间戳、相机、触发源、关联场景图节点、动作、标签、caption）。
  - 交互帧额外由分析器写入自由文本标签（如 `spoiled bananas`、`open drawer interior`）作为检索线索。
  - 通过去重（过滤空白、模糊、近重复帧）控制记忆规模。

- **（4）记忆检索与 VLM 任务规划**
  - **候选池三来源**：与场景图节点链接的关键帧、分析器标签匹配任务文本的关键帧、近期交互关键帧；按来源设上限防止近期观测淹没检索池。
  - **两阶段检索**：
    - 第一阶段（纯文本）：VLM 依据候选目录（关联节点、标签、动作、元数据）+ 任务 + 场景图摘要，选出短名单。
    - 第二阶段（多模态）：VLM 查看短名单缩略图，选出少量清晰、非冗余的帧。
  - **规划器输入**：检索到的全分辨率帧 + 选择理由、完整场景图 JSON、当前相机观测、任务描述、可用运动原语；输出下一步原语与目标节点。

## 3. 实验设计

### 场景与 Benchmark

  - **Locked-and-Unlocked Cabinets**：3 个柜子中 1 个上锁，需先找香蕉再找番茄酱，考验锁状态与内容物的持久记忆。

## 6. 主要结论与发现

- **综合性能**：25 任务长时程中 MessyMem 达 **80.0% 任务进度**，比最强消融 SG+IA（65.2%）高 **14.8 个百分点**，比最强外部基线 RoboEXP（51.1%）高 **28.9 个百分点**。
- **组件互补性**：任何单一记忆组件都不足以覆盖全部场景——交互派生状态对“复用动作揭示的属性”关键，链接关键帧对“紧凑结构难以表达的视觉信息”关键。
- **交互分析器的价值**：Locked/Unlocked 中 MessyMem 达 99%，SG+KF 仅 43%；单张图像无法区分“上锁”与“抓取失败”，多帧拼贴推理可正确区分。
- **细粒度视觉记忆的价值**：Cluttered Pick 中 MessyMem 达 84%，SG+IA 仅 58%；无关键帧时知道番茄酱在哪却无法判断哪个更易取。
- **外部基线局限**：RoboEXP 的预定义关系模式（inside/on）无法做实例级区分（如 Froot Loops vs. Trix）；MemER 类方法因缺乏持久空间索引与递归偏差，在移动操作中表现极差（1.8%、0.7%）。
- **记忆随增长仍有效**：数千关键帧下仍能通过目标与场景图关联先缩小候选集，再视觉重排，保持长时程可检索性。
- **真实世界可迁移**：Office Drawer Search 达 1.00 进度、10.8 步、SPL 0.92；Sock Pairing 达 1.00（对比 SG+IA/SG+KF 0.67、SG 0.50）。

## 7. 优点

- **问题定义清晰**：明确提出移动操作记忆的三条设计纲领（全局可查询、可交互更新、细粒度），并逐一用组件对应实现。
- **记忆结构设计精巧**：场景图作为索引枢纽，把结构化状态与视觉证据解耦又关联，兼顾紧凑性与可检索性。
- **交互分析器的判据设计扎实**：通过多相机拼贴、腕部视角接触证据、列间一致性来区分“抓取失败”与“物体上锁”，并给出明确的优先级规则（歧义时偏向 locked），避免误判导致重复无效尝试。
- **两阶段检索高效**：先文本后多模态，用结构化记忆把数千帧缩到短名单，再视觉重排，显著降低长时程检索成本。
- **实验对比公平**：统一规划器、感知、原语与成功判定，消融正交，外部基线适配到同一执行栈，统计上做了 Holm 校正。
- **仿真 + 真实双验证**：从 RoboCasa365 迁移到 TidyBot++ 真实平台，增强结论可信度。

## 8. 不足与局限

- **感知为闭集**：场景图使用预定义的闭集 SAM3 提示词，真实实验中刻意排除某些类别（如游戏手柄、剪刀）以展示局限；无法捕捉开放词汇的多样物体与属性。
- **交互分析器仅面向机器人自主动作**：未覆盖人类动作，难以直接扩展到 HRI 场景中需要由人机共同活动更新记忆的情形。
- **未接入 VLA 策略**：当前记忆接口面向高层原语，尚未扩展到更丰富的策略原语（如 VLA 模型）。
- **真实世界样本量小**：n=5、n=6 的试验规模难以支撑强统计结论，且真实任务为操作员门控（operator-gated），可能引入人为干预影响。
- **算力信息缺失**：未报告 GPU 型号、数量与训练时长，难以评估方法成本与可复现性。
- **长时程评估单一环境**：25 任务序列仅在一个 10 柜厨房中执行，跨房间、跨楼层、跨建筑的大规模空间泛化尚未验证。
- **检索延迟仍不低**：中位检索延迟 8.6 秒，在实时性要求更高的场景中可能成为瓶颈。
- **潜在偏差风险**：仿真场景与真实场景均由作者自定义设计，任务分布可能偏向有利于本方法记忆结构的形态。

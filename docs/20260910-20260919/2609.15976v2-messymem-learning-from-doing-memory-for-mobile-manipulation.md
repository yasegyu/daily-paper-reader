## 摘要
部署在多个房间并多次访问的移动操作机器人应能通过经验改进：在发现柜子被锁或从抽屉中找到物体后，机器人应复用该知识，而非每次从零开始执行任务。然而，当今的机器人常常将每个任务视为新任务：紧凑的场景表示忽略了从交互中获取的知识，原始视频历史难以查询，而VLM规划器在推理时进行推理，而不持续更新机器人所知的内容。我们提出MessyMem，一种持久记忆系统，使移动操作机器人能够从经验中学习并在未来任务中复用知识。它维护一个空间锚定的三维场景图，包含物体和位置，通过交互学习到的属性和结果对其进行增强，并链接视觉观察以实现细粒度回忆。我们在仿真和真实移动操作机器人上评估了MessyMem。在持续25个任务、时长超过3小时的仿真中，MessyMem实现了80.0%的任务进度，比最强消融方法高出14.8个百分点，比最强外部基线高出28.9个百分点，同时从存储的数千关键帧和超过一小时的历史中检索任务相关证据。

## Abstract
Mobile manipulators deployed across many rooms and visits should improve with experience: after discovering that a cabinet is locked or finding an object in a drawer, the robot should reuse that knowledge rather than start each task from scratch. Yet today's robots often treat each task as new: compact scene representations omit interaction-derived knowledge, raw video histories are difficult to query, and VLM planners reason at inference time without persistently updating what the robot knows. We present MessyMem, a persistent memory system that enables mobile manipulators to learn from experience and reuse that knowledge across future tasks. It maintains a spatially grounded 3D scene graph of objects and locations, augments it with properties and outcomes learned through interaction, and links visual observations for fine-grained recall. We evaluate MessyMem in simulation and on a real mobile manipulator. In a continuous 25-task simulation spanning over 3 hours, MessyMem achieves 80.0% task progress, outperforming the strongest ablation by 14.8 percentage points and the strongest external baseline by 28.9 points, while retrieving task-relevant evidence from thousands of stored keyframes and over an hour into the past.

## 一、论文的核心问题与整体含义（研究动机和背景）

**核心问题：** 移动操作机器人在跨房间、多访问周期的部署场景中，亟需一种能随经验提升、跨任务长期复用知识的持久记忆机制。然而，现有机器人系统存在三大缺陷：

- **紧凑场景表示遗漏交互知识**：物体属性（如锁定、空满、可拾取性）往往只能从物理交互中获取，无法通过被动感知得到。

**研究动机的背景**：文中设想一个家庭机器人——比如被要求“拿小孩最喜欢的杯子”时，它应能复盘前一天清理时发现的“手柄上恐龙贴纸”这一细节；被要求“做咖啡”时应直奔咖啡粉所在的柜子；找糖时应记起哪些柜子是上锁的并直接跳过。这背后即是说明——**当前移动操作机器人缺少一个空间锚定、能从物理交互中持续更新且支持细粒度视觉回唤的持久记忆系统**。

**整体含义：** 与多数现有工作相异，MessyMem首次在同一系统中通过 3D 场景图同时实现三大记忆属性：全局可查询且空间锚定、可从交互更新、以及细粒度视觉回溯。

## 二、论文提出的方法论：核心思想、关键技术细节与算法流程

### 总体框架
MessyMem构建了一个持久记忆系统，通过感知－规划－执行－交互分析－记忆更新的闭环持续累积知识。系统在三种记忆载体间协同工作。

### 关键技术细节

1. **全局可查询且空间锚定的3D场景图**
   - 使用SAM3对RGB-D观测中的预定义类别进行分割，通过深度图反投影到3D，按空间邻近性对同标签检测进行聚类与关联。
   - 每个节点存储**对象ID**、**3D质心**（空间锚定）和**属性字典**。
   - 场景图全局存储已观测的对象，不会因为对象离开视野而遗忘。

2. **交互更新的文本记忆（VLM交互分析器）**
   - 操作原语执行后，收集对应交互窗口的多帧拼贴图（前后帧+多相机拼贴），查询VLM分析器。
   - 输出结构化JSON，更新目标场景图节点的属性（如可打开、可拾取、满度等），新增开放词表属性（如材质、把手数量），记录执行结果与失败原因，刷新容器内容。
   - **核心创新的细节**：通过多帧上下文区分看似相同但来源不同的终态——例如“抓取失败”与“抽屉被锁”的区别。此外，较新证据会覆盖过期结构化属性，而关键帧保留底层视觉历史不被覆盖。

3. **细粒度视觉记忆（链接关键帧）**
   - 关键帧从交互事件和场景更新中产生，存储全分辨率RGB图像与缩略图，记录时间戳、来源动作、关联场景图节点等元数据。
   - 交互派生关键帧可附加分析器的文本标签（如“变质的香蕉”），这些标签作为检索线索，可捕捉不直接对应场景图对象标签的视觉内容。

4. **记忆检索与VLM规划**
   - **候选池构建**：从场景图链接关键帧、分析器标签匹配关键帧、近期交互关键帧三个互补来源，合并去重并加以容量封顶。
   - **两阶段检索**：第一轮文本检索——VLM基于任务和元数据目录选择简短列表；第二轮多模态检索——VLM审阅缩略图，选出一小组清晰、无冗余的观察提供给规划器。

### 算法流程简述
1. 从任务描述和当前场景图出发，构建候选关键帧池；
2. 两阶段检索选出任务相关证据；
3. VLM规划器将检索到的全分辨率帧 + 场景图JSON + 当前相机观测 + 任务描述 + 可用原语作为输入，选择下一个原语与场景图目标；
4. 执行原语；
5. 交互分析器基于交互拼贴更新场景图；
6. 返回步骤1，在下一次规划步骤中基于更新后的状态重新检索。

## 六、论文的主要结论与发现

- **MessyMem在全部三个模拟场景中最高**：25任务长程分析中任务进度达到80.0%（最强消融SG+IA为65.2%，强烈高于外部基线RoboEXP的51.1%）。
- **各记忆组件互补**：仅在特定任务上单独使用某一类记忆是不够的；交互派生态（IA）适用于需要复用动作习得状态的场景，链接关键帧（KF）在实例级视觉区分场景不可或缺。
- **RoboEXP的结构化图表示不足以处理实例级区分**：仅记录某盒子在柜内无法区分相似外观的对象（如Froot Loops与Trix），需要关键帧才能提供精准视觉信息。
- **MemER在移动操作中的不适配**：缺乏持久空间索引，视觉记忆存在偏向近期证据的徒劳倾向，难以在超过3小时的序列中检索旧证据。
- **记忆规模大时仍保持可查询**：在存储约9669个关键帧的情况下，检索延迟中位数为8.6秒，可回溯中位数62.7分钟前的证据，表明当前目标与场景图关联能有效缩小候选集。
- **真实世界验证**：MessyMem在Office Drawer Search和Sock Pairing两个场景均达到1.00任务进度，优于所有消融与基线。
- **记忆必须可编辑**：较新观测覆盖旧属性，关键帧保留底层视觉历史，这一设计令记忆能在“动态失效”情况下及时修正。

## 七、优点：方法与实验设计的亮点

1. **记忆架构设计的互补性**：结构化文本记忆与细粒度视觉记忆的级联，使每种载体各司其职——结构记忆支持全局查询与空间导航，视觉记忆支持实例级区分。

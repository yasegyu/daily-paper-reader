## 摘要
大语言模型智能体被期望能够在其生命周期内通过复用过往经验，持续适应新任务和新环境。然而，现有的基于记忆的智能体难以跨环境迁移可复用的经验，并且随着经验不断积累会遭遇灾难性遗忘。为应对这些挑战，我们提出了LifeMem，一个使智能体能够在多个环境之间迁移知识的终身学习框架。在学习过程中，LifeMem根据底层工作流对积累的交互轨迹进行聚类，以提取可复用技能。在推理时求解新任务时，智能体回忆相关技能和轨迹来指导动作。为验证我们的方法，我们在10个环境和超过13,000个任务上开展实验，并包含2,000条新标注的交互轨迹。结果表明，LifeMem能够在终身学习中实现有效的经验复用，既降低已学任务上的遗忘，又实现更优的跨任务迁移。进一步分析揭示，任务流会影响学习，而在记忆中整合结构相似的轨迹能够提升性能。

## Abstract
Large language model agents are expected to continuously adapt to new tasks and environments over their lifetime by reusing past experience. However, existing memory-based agents struggle to transfer reusable experience across environments and suffer from catastrophic forgetting as experience accumulated. To address these challenges, we propose LifeMem, a lifelong learning framework that enables agents to transfer knowledge across multiple environments. During learning, LifeMem clusters accumulated interaction trajectories based on underlying workflows to extract reusable skills. When solving a new task at inference time, the agent recalls relevant skills and trajectories to guide actions. To validate our method, we conduct experiments across 10 environments and over 13k tasks with 2k newly annotated interaction trajectories. Results show that LifeMem enables effective experience reuse in lifelong learning, achieving both reduced forgetting on learned tasks and superior cross-task transfer. Further analysis reveals that task streaming impacts learning, while consolidating structurally similar trajectories within memory boosts performance.

# LifeMem 论文深度总结

## 1. 核心问题与研究动机

- **背景**：追求 AGI 需要智能体在其生命周期内持续适应多样化、不断演变的环境（具身控制、网页导航、工具调用等），即**终身学习（lifelong learning）**能力。
- **关键挑战**：在**跨环境（inter-environment）**设定下，交互轨迹来自动作空间与观测空间均不同的异构环境，经验复用尤为困难。智能体必须在不遗忘旧经验的前提下学习新轨迹。
- **现有方法的两类缺陷**：
  - **内部记忆方法**（如 Retroformer）：在预定义环境上微调，泛化受限、训练成本高。
  - **外部记忆方法**：
    - *纯轨迹检索*（如 Synapse）：原始轨迹无法跨越不匹配的动作空间，且数据库增长后检索精度下降，导致对早期环境的**灾难性遗忘**。
    - *通用轨迹抽象*（如 ExpeL、AutoSkill）：在未组织的记忆池上做全局技能蒸馏，无关轨迹引入严重的**跨环境噪声**，产出的技能过于粗糙，反而损害性能。
- **整体含义**：论文主张记忆应按**底层工作流（workflow）**而非表层语义相似度组织，从而在异构环境中同时缓解遗忘并实现跨任务迁移。

## 2. 方法论：LifeMem 框架

### 2.1 核心思想
将智能体记忆建模为**动态组件**：一次性初始化，随新经验增量更新，推理时被查询。记忆采用**两层结构**——底层是工作流聚类（轨迹级），上层是环境无关的技能抽象。

### 2.2 问题形式化
- 环境 E = (S, A, Ω, T)，动作 a_t = P_θ(g, M, o_t)。
- 任务 T_i = ⟨E_i, o_i^0, g_i⟩，求解产生轨迹 ξ_i。
- 记忆更新：M_i = M_{i-1} ∪ {ξ_i}。
- 目标：利用累积经验提升新任务表现，同时缓解旧行为遗忘。

### 2.3 记忆初始化
- 用 LLM 将初始轨迹集划分为聚类集合 C = {c_1, …, c_M}，识别共同工作流模式。
- 为每个聚类生成简洁描述 d_i，构成初始记忆。

### 2.4 记忆演化：工作流聚类
- 新轨迹 ξ 到达时，检索 top-k 相关轨迹，收集其所属聚类 C_ξ。
- LLM 以 ξ 与 C_ξ 为条件做二选一决策：
  - **ADD**：ξ 与已有聚类 c ∈ C_ξ 对齐 → 加入并更新描述 d_c。
  - **NEW**：与 C_ξ 不匹配 → 新建聚类。
- **几何多样性约束（MRL，平均合成向量长度）**：将轨迹嵌入归一化为单位向量 x_i，定义方向集中度
  - R = (1/n)‖Σ_{i=1}^{n} x_i‖，R ∈ [0,1]
  - R→1 表示结构高度同质（如模板重复），R 低表示行为多样。
- **自适应分裂条件**：当且仅当 **n > L 且 R < τ_mrl** 时，将聚类拆分为更细粒度子聚类，避免异质行为稀释技能特异性。

### 2.5 技能蒸馏
- 对每个工作流聚类 c_i 蒸馏出高层、环境无关的文本技能：s_i = f(c_i)。
- 分层记忆形式化：H = {(c_i, s_i) | c_i ∈ C}。
- 技能捕捉共享约束、逻辑依赖与泛化执行原则，剥离低级环境细节。

### 2.6 推理阶段（双轨机制）
- 检索 top-k 最相似的历史轨迹 {ξ_0, …, ξ_{k-1}}，且**限定同一环境 E**，提供环境对齐的操作范例。
- 同时激活这些轨迹所属聚类的技能：S_ξ = {s_i | c_i ∈ C_ξ}，提供跨环境可迁移的宏观指导。
- 最终动作：a = P_θ(g, M_act, o)，其中 M_act = ({ξ_j}, S_ξ)。

### 2.7 实现细节
- SQLite 存储聚类，FAISS 做轨迹索引与检索，嵌入模型 all-MiniLM-L6-v2。
- 初始轨迹数 5；检索 top-4；分裂阈值 L = 50，τ_mrl = 0.95。
- GPT-5-mini 负责新轨迹的聚类归属判断；GPT-4.1 负责聚类分裂与技能抽象。
- 所有模型温度设为 0.3；DeepSeek-v3.2-exp 与 Qwen3-32B 不启用推理模式。

## 6. 主要结论与发现

- **整体性能全面领先**：LifeMem 在 3 个骨干上均优于所有基线。
  - GPT-4o-mini：28.84（ReAct）→ **44.13**（+5.45% vs 次优 ExpeL 41.85）
  - DeepSeek-v3.2-exp：41.14 → **48.02**（+3.54%）
  - Qwen3-32b：33.98 → **46.52**（+7.46%）
- **遗忘显著缓解**：LifeMem 平均 BwT 为正（+5.66 / +3.11 / +6.68），而 Synapse、AutoSkill 多为负值，说明结构化聚类有效抑制了跨任务干扰。
- **弱模型获益更大**：经验学习对 GPT-4o-mini 的提升（+15.29）远大于 DeepSeek（+6.88），部分缩小了骨干模型间的性能差距。
- **组件协同**：轨迹提供环境对齐的行为示范（w/o skills：42.84），技能提供跨环境宏观指导（w/o examples：37.61），二者结合最优（44.13）；技能生成器能力影响较小。
- **零样本迁移有效**：FEVER 上较 ReAct 提升 22.5%（GPT-4o-mini）与 17.9%（DeepSeek）；τ-bench airline 上提升 18.8% 与 15.8%；仅用技能（w/o trajs）也能保持大部分增益。
- **任务流顺序重要**：similarity > buffer-based > random；buffer-based 策略可将随机流下的性能损失恢复 44.7%–64.9%。

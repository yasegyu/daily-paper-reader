## 摘要
近年来，大型语言模型的进展显著增强了智能体在长期对话建模方面的能力。尽管取得了这些成功，现有方法通常采用静态启发式范式，即信息被被动归档，缺乏自适应记忆价值评估。因此，这些方法无法自我演化，也无法使其记忆管理与不断变化的用户需求保持一致。为解决这一问题，我们提出 ICML（InteraCtive Memory Learning，交互式记忆学习），一种多智能体框架，将记忆机制从被动档案转变为可学习的交互式记忆策略。具体而言，我们首先采用会话合成流水线生成专家数据，以促进在未见场景中的快速测试时适应。在此基础上，ICML 利用在线强化学习机制，其中 Planner 智能体选择性编码高价值信息，Trigger 智能体动态检索这些信息以优化回复质量，两个智能体通过持续交互反馈共同演化。关键的是，两个智能体通过延迟奖励机制同步，该机制将未来反馈传播回早期存储决策，确保记忆策略与用户期望精确对齐。实验结果表明，ICML 显著优于强基线，并展现出随着交互累积而持续提升回复质量的独特能力。

## Abstract
Recent advancements in large language models have significantly enhanced the capabilities of agents in modeling long-term conversations. Despite these successes, existing approaches typically adopt a static heuristic paradigm, where information is passively archived without adaptive memory valuation. Consequently, these methods fail to self-evolve or align their memory management with evolving user needs. To address this, we propose ICML (InteraCtive Memory Learning), a multi-agent framework that transforms the memory mechanism from a passive archive into a learnable, interactive memory policy. Specifically, we first employ a session synthesis pipeline to generate expert data, facilitating rapid test-time adaptation in unseen scenarios. Building on this, ICML utilizes an online reinforcement learning mechanism where a Planner agent selectively encodes high-value information and a Trigger agent dynamically retrieves it to optimize response quality, whereby the two agents co-evolve through continuous interaction feedback. Crucially, both agents are synchronized through a delayed reward mechanism that propagates future feedback back to earlier storage decisions, ensuring memory policies are precisely aligned with user expectations. Experimental results demonstrate that ICML significantly outperforms strong baselines, exhibiting the unique capability to continuously improve response quality as interactions accumulate.

  - 无法区分**高价值记忆**（如关键健康警告"心跳加速"）与**低价值噪声**（如临时状态"下雨天"）；

- **理论依据**：认知心理学（Schank, Tulving, Anderson 等）指出人类记忆是**可学习的过程**——人会有选择地编码对未来决策有价值的信息，并通过反馈持续更新心智模型，新约束可覆盖过时偏好。
- **核心主张**：长期对话的关键在于把被动启发式范式转变为**交互式记忆学习范式**，让智能体基于持续的环境反馈学习"记什么"与"何时触发"。
- **整体含义**：论文提出 ICML（InteraCtive Memory Learning），把记忆机制从"被动档案"改造为"可学习、可交互的记忆策略"，实现无人工干预的测试时自主适应与自我演化。

## 2. 方法论

### 2.1 问题建模（POMDP）
- 将交互式记忆学习形式化为 POMDP 五元组 ⟨S, A, O, R, γ⟩：
  - **状态/观测**：观测 $o_k$ 由当前用户查询 $u_k$、近期对话历史 $H_k$、外部记忆状态 $M_k=\{m_1,...,m_N\}$ 组成；
  - **联合动作**：$a_k=(a^p_k, a^t_k)$，其中 Planner 的记忆规划动作 $a^p_k\in\{0,1\}$（保存/丢弃），Trigger 的记忆触发动作 $a^t_k\in\{0,1,...,N\}$（选 0 表示不需记忆）。

### 2.2 回顾式会话合成（Retrospective Session Synthesis）
- **目的**：解决新环境首次交互时的冷启动问题（缺少相关记忆导致次优回复），并提供带**稠密因果记忆依赖**的专家数据。
- **反向故事线生成**：以用户首次暴露约束/偏好的会话为**种子会话 $S_{seed}$**，用 LLM 作为用户模拟器递归反向生成前序会话 $S_{prev}$（如生成"喝咖啡导致心跳加速"的过往事件），得到严格逻辑一致的生成历史 $H_{gen}$。
- **正向依赖标注**：
  - 为 **Planner** 标注二值标签 $y_p\in\{0,1\}$，判断该轮是否含值得保存的高价值信息；
  - 为 **Trigger** 标注目标检索索引 $y_t$，并混入**硬负例**（同会话无关轮次）与**软负例**（随机全局记忆）以增强抗噪辨别力；
  - 产出专家数据集 $D_{expert}$，用于在线部署前的策略初始化。

### 2.3 ICML 框架（双智能体协作）
- **Planner 智能体（记忆规划）**：作为长期记忆的主动守门人，基于查询 $u_k$ 输出保存/丢弃的二元分布。采用 LLM 提供的**即时代理奖励** $r^{proxy}_k\in[0,1]$ 作为稠密信号，并对"丢弃高价值轮次"施加**漏检惩罚** $-\alpha r^{proxy}_k$。
- **Trigger 智能体（记忆触发）**：观测查询、对话历史与候选记忆集合，在记忆索引上输出类别分布，学习选择能最大化最终回复质量的记忆；由 LLM 对最终回复多维度打分得到**质量奖励** $r^{qual}_k\in[0,1]$。
- **回复生成**：$r^* \sim P_{LLM}(\cdot \mid H_k, u_k, m_{a^t_k})$，桥接跨会话时间鸿沟并产生 $r^{qual}$。

### 2.4 跨会话真实奖励（Cross-Session Truth Reward）
- 维护 **Pending Reward Buffer** 存储 Planner 的潜在经验（已存但待验证的记忆）。
- 当 Trigger 在未来第 $k_{future}$ 轮激活某记忆 $m_i$ 时，回溯其创建轮 $k_{past}$，把未来质量评估传播回 Planner：
  $$r^{truth}_{k_{past}} = r^{proxy}_{k_{past}} + \lambda \cdot r^{qual}_{k_{future}} \cdot \mathbb{I}(m_i \text{ is triggered})$$
- 该机制把"存储决策"与"记忆的长期实际效用"对齐，使两智能体通过延迟奖励互相适应、共同收敛。

### 2.5 在线优化
- 采用 **PPO** 端到端优化，共享 Actor-Critic 结构，分别对 Planner/Trigger 计算回报 $R^j_k=\sum \gamma^{t-k} r^j_i$（$j\in\{p,t\}$）。
- **Critic 损失**：最小化估计值 $V^j_\phi$ 与实际回报的均方误差；
- **Actor 损失**：使用裁剪代理目标 $\min(\rho^j_k A^j_k, \text{clip}(\rho^j_k,1-\epsilon,1+\epsilon)A^j_k)+\beta S[\pi^j_\theta]$，$\rho$ 为重要性采样比，$A$ 为优势，$S$ 为熵奖励。
- **关键超参**：Actor lr $1\times10^{-6}$、Critic lr $1\times10^{-5}$、γ=0.99、GAE λ=0.95、PPO clip ε=0.2、奖励归一化 [0,1]、LoRA rank 8/alpha 16/dropout 0.1；冷启动阶段 lr $2\times10^{-5}$、3 epochs。

## 6. 主要结论与发现

- **演化式记忆优于静态启发式**：ICML 在三个数据集上全面超越管理为中心、生成为中心及长上下文基线，证明"主动选择高价值记忆"比"处理全部含噪历史"更有效。
- **与 LLM 判断和人类偏好一致**：LLM 交叉评估各维度全面提升，人工评估中 ICML 对最强基线 THEANINE 的胜率约 66%（生成）与 70%（记忆检索），统计显著。
- **整体完整性维持演化循环**：消融显示 **Cross-Session Truth Reward 贡献最大**（去除后跌幅最明显），其次为 Evolution（静态训练不足）、合成数据（解决冷启动）、Planner/Trigger 协作。
- **学习到清晰决策边界**：Planner 演化后能对高价值信息给出高概率、压制低价值噪声；Trigger 的 t-SNE 显示查询与真值记忆形成紧密语义簇，与无关噪声分离。
- **均衡缩放更高效**：Planner 与 Trigger 规模匹配时性能峰值，呈对角线模式；较大模型亦带来额外增益。
- **持续共演化**：扩展至 10 个会话，Planner 精度与 Trigger 召回率持续上升，训练奖励稳定收敛无剧烈震荡。
- **适度预热最优**：0.25K–0.5K 合成数据效果最佳，过少无法克服冷启动，过多则过拟合固定模式、降低对齐灵活性。
- **高效性**：推理 token 稳定不随会话深度线性增长，存储增长极小；构造/检索延迟达毫秒级（Session 5 总处理时间 10.22s vs MemoryOS 的 826.61s，约 80× 缩减）。
- **鲁棒性**：更换奖励模型（Gemini2.5/GPT-3.5/GPT-4o-mini）或使用 1B 级微型 judge，性能仅轻微下降，系统不崩溃；λ=0.5 为最优。
- **反向合成优于正向**：反向故事线生成在所有数据集和指标上均优于前向生成，验证目标驱动的因果初始化价值。

## 7. 优点

- **范式创新**：首次将长期对话记忆从"被动存储/检索"重构为**可学习的交互式记忆策略**，并给出严格的 POMDP 形式化。
- **机制巧妙**：**跨会话延迟真实奖励 + Pending Reward Buffer** 把未来检索成功与否回溯传播给历史存储决策，是解决"记忆效用延迟验证"问题的核心设计；配合即时代理奖励与漏检惩罚，缓解早期探索失败。
- **即插即用**：可与顶级闭源 LLM 直接集成，无需访问其内部

参数或梯度，仅依赖文本输入输出接口即可工作；因此方法不绑定特定模型架构，便于迁移到不同骨干 LLM 上。

- **轻量且可部署**：LoRA 微调、小规模合成数据、低推理与存储开销，使 ICML 不依赖大规模在线训练集群，具备较强工程可行性。
- **数据构造有针对性**：回顾式会话合成通过反向故事线显式制造因果记忆依赖，比随机采样历史更能暴露“何时需要记忆、何时应丢弃”的决策边界。
- **评估较全面**：自动指标、LLM-as-a-Judge、人工胜率、消融、规模缩放、鲁棒性与效率分析相互印证，结论可信度较高，且与人类偏好方向一致。

## 8. 局限性

- **算力披露不足**：论文未给出 GPU 型号、数量、总训练时长与总能耗，虽可推断方法轻量，但难以精确复现完整训练成本。

- **理论保证有限**：POMDP 建模与 PPO 优化提供了形式化框架，但未给出收敛性、最优性或记忆效用上界的理论分析。

## 9. 对研究与实践的启示

- **记忆应被建模为策略而非数据库**：长期对话系统的关键不只是“存什么、取什么”，而是让智能体通过反馈学习记忆的编码、触发与更新策略。
- **延迟奖励是连接存储与效用的关键**：把未来检索后的回复质量回溯到历史存储决策，可缓解“存储时无法立即判断价值”的信用分配难题。
- **合成因果依赖数据可缓解冷启动**：反向故事线生成提供了一种低成本构造专家轨迹的方式，对需要长期一致性的对话、推荐、教育等场景有借鉴意义。
- **评估应兼顾自动、LLM 与人工**：长期对话的记忆价值难以由单一指标衡量，多维度主观评估与消融分析应成为标准配置。
- **工程部署需权衡效率与自适应**：ICML 的轻量化设计说明，长期记忆系统不必无限扩大上下文或存储，而可通过策略学习实现更优的 token/延迟/质量平衡。

## 10. 总体评价

ICML 是一篇在问题重构、机制设计和实验验证上较完整的长期对话记忆研究。它将记忆从静态启发式模块提升为可交互、可学习、可演化的策略系统，并以跨会话真实奖励和 Pending Reward Buffer 解决延迟信用分配，具有较强的概念创新性与工程启发性。其主要不足在于算力披露、真实长期部署验证、隐私安全与理论分析仍不充分。总体而言，该工作为“学习如何记忆”的长期对话智能体提供了清晰范式与可复现的实验基线，值得后续在更大规模、更真实和更安全约束下继续推进。

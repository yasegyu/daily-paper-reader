## 摘要
视觉语言模型（VLM）智能体结合专用感知、工具和推理来应对复杂的视觉任务。在多智能体场景中，不同智能体检查不同的图像区域、视频帧或视觉表征，因此协作不仅涉及分布式推理，还涉及分布式感知。这使得共享视觉上下文成为VLM智能体协作的核心问题。在本文中，我们围绕调和解释与更新依赖推理的需求，构建了记忆层级、跨智能体共享和一致性机制。有效的协作要求智能体能够基于其他智能体的贡献进行构建，恢复缺失的视觉上下文，并在新证据出现时调和不同解释。共享视觉记忆不仅保留图像或文本摘要，还保留观察结果、智能体解释及后续推理之间的依赖关系。这些设计考虑共同塑造了信息在VLM智能体间的流动与演变方式。所提出的框架为构建可靠且资源高效的智能体团队提供了基础。

## Abstract
Vision-language model (VLM) agents combine specialized perception, tools, and reasoning to address complex visual tasks. In multi-agent settings, different agents inspect different image regions, video frames, or visual representations, so collaboration extends beyond distributed reasoning to distributed perception. This makes shared visual context a central problem in VLM agent collaboration. In this paper, we frame memory hierarchy, cross-agent sharing, and consistency mechanisms around the need to reconcile interpretations and update dependent reasoning. Effective collaboration requires agents to build on contributions from other agents, recover missing visual context, and reconcile differing interpretations as new evidence emerges. Shared visual memory preserves not only images or textual summaries but also the dependencies among observations, agent interpretations, and subsequent reasoning. Together, these design considerations shape how information flows and evolves across VLM agents. The proposed framework provides a foundation for building reliable and resource-efficient agent teams.

## 2. 论文提出的方法论

### 核心思想：基于依赖关系的协作记忆框架
该文主张将共享视觉记忆构建在**观察（observations）、解释（interpretations）与下游推理（downstream reasoning）之间的连接（dependency links）** 之上，而非简单的图像/文本存档。核心框架包含三个相互依赖的维度：

### 技术细节与组成部分

1. **记忆层级（Memory Hierarchy）**
   - 分为三层：**智能体本地缓存**（近期观察与模型特有特征）、**共享工作记忆**（证据、声明及未解决请求的状态）、**持久存储**（任务间可复用的团队经验和证据）。
   - 访问范围与保留生命周期是两个独立设计选择，例如：持久记录也可以设权限、限制为部分智能体私有。
   - 流媒体场景中需区分“已检查区间”与“待检查区间”，以避免将延迟处理误判为目标信息不存在。

2. **表示与链接（Linked Representations）**
   - 共享记忆保留多种表示，各自保留不同信息：
     - **视觉证据**（原始图像/裁剪区域，带有源ID和区域坐标）
     - **结构化观察**（含边界框的识别文本、表格单元、区域间关联）
     - **视觉特征**（视觉编码器产生的向量）
     - **声明（Claims）**（智能体做出的高层解释，附有来源记录）
   - **来源追溯（Provenance）** 记录来源区域、贡献智能体、引用的先前观察，支持从较紧凑的声明溯源到可验证的视觉上下文。

3. **选择性共享（Selective Sharing）**
   - 共享内容与形式取决于接收智能体当前执行的**操作、模型接口、可用工具和预算**。例如：检查一个数值与验证图例关联需要完全不同的上下文。
   - 跨模型特征共享设计了**适配器（Adapters）** 机制，将存储的视觉特征映射到接收模型的输入空间，以此复用编码特征、减少重复视觉处理。但对不同VLM家族（维度、位置编码、接口差异），需保留与视觉来源间的联系。

4. **一致性机制（Consistency and Reconciliation）**
   - 承认不同智能体间解释的冲突根因可能是证据、来源状态或语境假设的不一致；协调应回到“证据层面”进行调和，并支持**定向重新检查**，而非仅仅寻求共识（多智能体可能继承同一个错误）。
   - **修订传播（Revision Propagation）**：当B智能体修订检测器温度关联（图3场景），D智能体需要重新计算比较结果。共享记忆记录链接派生声明与其支撑解释，向依赖旧版本的智能体发出**审查请求**（review request），但不直接给出替代答案。
   - **同步策略**中，需权衡延误与错误传播：等待每条观察被验证会阻塞协作，而采用未验证声明又可能传播错误；需保留备择解释、明确标记版本，并使得修订可见。

## 6. 论文的主要结论与发现

- 多智能体VLM协作系统的关键系统挑战是**分布式感知下的共享视觉上下文**——需要让中间观察和解释对跨智能体保持可访问、可验证、可修订。
- 有效的协作记忆不能只保存图片或文字摘要，还必须保留**观察、解释、后续推理之间的依赖结构**。
- 通过记忆层级（访问范围与生命周期分离）、链接表示与来源追溯、选择性共享（面向操作和接收模型定制上下文）、一致性机制（修订传播与依赖审查请求）这四组设计要素，可以支撑智能体构建在彼此的贡献之上、恢复缺失的视觉上下文，并在新证据出现时修订依赖结论。
- 提议框架为构建**可靠且资源高效**的VLM智能体团队提供了基础。

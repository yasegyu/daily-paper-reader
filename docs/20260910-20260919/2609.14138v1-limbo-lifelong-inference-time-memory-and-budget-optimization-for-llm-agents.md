## 摘要
随着 LLM 智能体被集成到日益复杂的工作流中，它们必须持续获得新能力，同时保持在先前学习任务上的能力。终身智能体通过经验回放来应对这一问题，即将过去的交互注入提示中，以便在推理时利用先验经验。然而，回放并非没有代价：每条被回放的轨迹都要与检索、推理、工具使用和验证争夺同样有限的提示和计算预算，因此有效的资源分配至关重要。现有方法使用固定的回放策略来分配这些资源，而不管回放是否对当前任务有益。我们将此识别为推理时记忆分配，这是终身智能体的一个独特问题类别，并提出 LIMBO：据我们所知，这是首个将记忆视为可控的推理时资源，并针对每个新到来的任务联合优化记忆策略与推理预算的在线框架。与固定回放策略或需要模型权重、教师监督或离线再训练的先验方法不同，LIMBO 在一次执行中在线学习这种分配，明确平衡任务性能与推理成本，且无需修改底层智能体。在 LifelongAgentBench 上的三个 LLM 骨干模型上，LIMBO 取得了比最先进的记忆增强基线更好的成本-准确率权衡，并在推理成本最多降低约 83%（平均约 53%）的情况下，几乎匹配所有这类最强基线。LIMBO 无需重新训练即可在不同模型和环境中自适应其策略，表明有效分配可以在线学习，而无需手动指定。

## Abstract
As LLM agents become integrated into increasingly complex workflows, they must continually acquire new capabilities while retaining competence on previously learned tasks. Lifelong agents address this through experience replay, injecting past interactions into the prompt to leverage prior experience during inference. However, replay is not free: every replayed trajectory competes with retrieval, reasoning, tool use, and verification for the same limited prompt and compute budget, making effective resource allocation essential. Existing approaches allocate these resources using fixed replay policies, regardless of whether replay is beneficial for the current task. We identify this as inference-time memory allocation, a distinct problem class for lifelong agents, and introduce LIMBO: the first online framework to our knowledge that treats memory as a controllable inference-time resource and jointly optimizes memory strategy and inference budget for each incoming task. Unlike prior approaches that fix the replay policy or require model weights, teacher supervision, or offline retraining, LIMBO learns this allocation online in a single pass, explicitly balancing task performance and inference cost without modifying the underlying agent. Across three LLM backbones on LifelongAgentBench, LIMBO achieves better cost-accuracy tradeoffs than state-of-the-art memory-augmented baselines and nearly matches all strongest such baselines at up to ~83% lower inference cost (~53% on average). LIMBO adapts its policy across models and environments without retraining, demonstrating that effective allocation can be learned online rather than manually specified.

## 2. 方法论

### 2.1 核心思想

- 将回放从"固定的预处理步骤"转变为**在线计算分配决策**：在每个任务执行前，基于提示与运行时特征选择一个"记忆模式 + 计算预算"动作。
- 采用**免梯度上下文老虎机（contextual bandit）**而非完整强化学习或监督学习：
  - 满足黑盒兼容（无需权重/梯度/内部激活）；
  - 每任务决策后立即获得标量奖励，无长程信用分配问题；
  - 无真值最优动作，监督学习不可行。

### 2.2 问题形式化

- 任务流 \(T = (T_1, \dots, T_N)\)；第 i 步执行后获得二值正确性 \(y_i \in \{0,1\}\) 与实测成本 \(c_i \ge 0\)。
- 完整会话 \(\sigma_i = (T_i, y_i, c_i, \tau_i)\)，其中 \(\tau_i\) 为完整交互轨迹。
- 记忆库 \(M_i = \{\sigma_j : j < i, y_j = 1\}\)，仅存储成功会话。
- 成本归一化：维护运行最大值 \(C_{\max,i} = \max_{j \le i} c_j\)，令 \(\hat{c}_i = c_i / C_{\max,i} \in [0,1]\)。
- 成本权重 \(\lambda \ge 0\)：\(\lambda=0\) 为纯精度最大化，\(\lambda\) 大则偏向最便宜动作；实验中统一取 \(\lambda=0.5\)。

### 2.3 记忆动作空间

- 四种记忆模式 \(m_i \in \{\text{none}, \text{full}, \text{compressed}, \text{retrieved}\}\)：
  - **none**：不注入历史轨迹；
  - **full**：注入固定数量的最近成功轨迹原文；
  - **compressed**：用 LongLLMLingua 风格的问题感知压缩后注入；
  - **retrieved**：从更大记忆库中按相关性检索 top-k 轨迹注入。
- 检索打分（DBBench 实现）：
  \(r(\sigma_j, T_i) = w_\ell \mathrm{Jac}(q_i, q_j) + w_s \mathrm{Jac}(S_i, S_j) + w_b \mathbf{1}[b_i = b_j] + \epsilon\)
  其中 \(q\) 为指令 token、\(S\) 为技能集、\(b\) 为表标识，\(\epsilon\) 为近期性 tie-breaking 奖励。
- 轨迹渲染：支持原文（raw）与确定性裁剪轨迹（trimmed-trace，压缩冗长工具输出但保留动作格式）。

### 2.4 控制器设计（双头 LinUCB）

- **特征向量（12 维）** \(x_i = [1, \tilde{p}_i, \tilde{u}_i, \tilde{s}_i, \tilde{f}_i, u_i/p_i, \tilde{\ell}_i, \bar{c}_i, \bar{r}_i, \hat{c}_{i-1}, \mathbf{1}[y_{i-1}=1], \mathbf{1}[\mathrm{err}_{i-1}]]^\top\)，分三组：
  - 提示形状特征：全提示、末用户轮、系统提示、脚手架的对数归一化 token 数，末用户占比，归一化技能数；
  - 运行时状态特征：归一化成本的 EMA \(\bar{c}_i\)、运行准确率 \(\bar{r}_i\)、上一任务归一化成本 \(\hat{c}_{i-1}\)；
  - 前次结果特征：上次是否成功、上次是否报错。
- **双头参数**：每个动作维护精度矩阵 \(A_a \in \mathbb{R}^{d \times d}\) 与两个参数向量 \(b_a^{acc}, b_a^{cost}\)；
  \(\hat{\theta}_a^{acc} = A_a^{-1} b_a^{acc}\)，\(\hat{\theta}_a^{cost} = A_a^{-1} b_a^{cost}\)。
  - 头 1：正确性概率 \(\hat{p}_a(x) = \sigma(\hat{\theta}_a^{acc\top} x)\)；
  - 头 2：归一化期望成本 \(\hat{c}_a(x) = \max(\hat{\theta}_a^{cost\top} x, 0)\)。
- **动作选择**：
  \(a_i^* = \arg\max_{a \in \mathcal{A}} [\hat{p}_a(x_i) - \lambda \hat{c}_a(x_i)] + \alpha \sqrt{x_i^\top A_a^{-1} x_i}\)
  选择在回放注入之前完成，使记忆使用成为首要决策变量。
- **在线更新**：\(A_{a_i} \leftarrow A_{a_i} + x_i x_i^\top\)，\(b_{a_i}^{acc} \leftarrow b_{a_i}^{acc} + y_i x_i\)，\(b_{a_i}^{cost} \leftarrow b_{a_i}^{cost} + \hat{c}_i x_i\)；逆矩阵用 Sherman–Morrison 秩一更新，复杂度 \(O(d^2)\)。
- **复杂度**：每任务 \(O(|\mathcal{A}| d^2)\)，\(d=12\)、\(|\mathcal{A}| \le 12\)；单 CPU 核开销 <0.5 ms，每臂内存约 1.2 KB。

### 2.5 四项设计约束（D1–D4）

- **D1 黑盒兼容**：不要求模型权重、梯度或内部激活，兼容开源与商用 API 骨干。
- **D2 单次在线学习**：在任务流中自适应，无需离线训练或热启动数据集。
- **D3 每任务开销有界**：决策成本远小于所调度的 LLM 调用，不随任务数增长。
- **D4 显式成本目标**：精度与成本作为一等目标共同权衡。

## 3. 实验设计

- **Benchmark**：LifelongAgentBench（LAB），使用 DB（SQL）与 OS（bash）两个交互环境，各取官方发布的 500 任务顺序切片。
- **骨干模型**：Qwen2.5 7B Instruct、Llama 3.1 8B Instruct、GPT-4o mini，共 6 个 (模型, 环境) 设置。
- **随机种子**：所有 LIMBO 与基线点均为 3 个匹配种子（42、43、44）的均值，单元内比较使用匹配种子。
- **对比基线**：
  - No replay（每任务零样本）；
  - Fixed replay（k=N，注入最近 N 条成功轨迹，确定性裁剪渲染）；
  - LongLLMLingua（对同一最近回放缓冲做问题感知 token 级压缩）；
  - Group Self-Consistency（GSC，usc=1），LAB 原生投票稳定器。
- **LIMBO 配置**：统一控制器、统一特征向量、统一在线更新；4 种记忆动作 × 3 档生成预算（低 ≤512、中 768、高 ≥1024）。检索权重 \(w_\ell=0.35, w_s=0.50, w_b=0.15\) 固定；记忆库大小 64；DB 单元暴露 top-8、OS 单元暴露 top-1。
- **三种动作空间设计（渐进式研究）**：
  1. **压缩门控**：none / full / LongLLMLingua 压缩回放；
  2. **检索门控**：none / full / 相关性检索回放（k ∈ {4, 8, 16}）；
  3. **检索门控 + rescue**：对低置信样本用最大检索上下文二次执行。
- **评价指标**：准确率与 500 任务总 token 成本（USD 等值）。

## 6. 主要结论与发现

- **Pareto 前沿占优**：在所有 6 个设置中，LIMBO 均位于经验成本—精度 Pareto 前沿，没有固定方法同时更便宜且更准确。
- **匹配最强基线且大幅降本**：准确率与最强记忆增强基线的差距在 −3.8 至 +0.

个百分点之间，但总 token 成本相比固定回放下降约一个数量级——即在精度基本持平甚至略优的前提下，把回放带来的额外开销压缩到接近 no-replay 的水平。
- **策略随骨干与环境自适应分化**：控制器在 6 个设置中学到了显著不同的动作偏好（图 4）——例如在较弱的 7B/8B 骨干上更倾向使用压缩或检索回放以补偿能力缺口，而在 GPT-4o mini 上更频繁选择 none 或低预算动作，因为额外上下文带来的边际精度收益不足以覆盖成本。
- **在线适应过程可观测**：图 5 显示动作混合在任务流上逐步从探索性、偏保守的选择收敛到稳定的"任务类型—动作"映射；UCB 不确定性奖励从首 100 任务的 0.347 衰减到末 100 任务的 0.115（下降约 67%），且跨种子标准差 <0.017，说明学到的策略稳定可复现，而非随机波动。
- **动作空间设计的影响**：三种渐进式动作空间中，"检索门控 + rescue"总体最优——对低置信样本追加最大检索上下文二次执行，能以较小额外成本挽回一部分原本失败的任务；单纯压缩门控在强骨干上收益有限，单纯扩大 k 在弱骨干上易触发"上下文过载"反而损害精度。
- **成本权重 λ 的调节作用**：λ 控制精度—成本的权衡斜率，实验统一取 0.5 时已能在多数设置上取得接近 Pareto 拐点的折中；论文指出 λ 可作为一种部署期旋钮，按实际预算偏好调节。
- **总体论断**：回放的价值是**条件性的**，"何时回放、回放多少"与"回放什么"同等重要；把记忆分配显式建模为推理时决策，可以在不触碰模型参数、不增加显著算力的前提下，系统性地改善终身智能体的成本—精度权衡。

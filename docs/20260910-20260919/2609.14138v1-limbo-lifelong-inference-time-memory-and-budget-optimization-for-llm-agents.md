## 摘要
随着LLM智能体被整合进日益复杂的工作流中，它们必须持续获取新能力，同时保持在先前学习任务上的熟练度。终身智能体通过经验回放来解决这一问题，即将过去的交互注入提示中，以便在推理时利用先前的经验。然而，回放并非免费：每条回放的轨迹都与检索、推理、工具使用和验证竞争同一有限的提示和计算预算，因此有效的资源分配至关重要。现有方法使用固定的回放策略来分配这些资源，而不考虑回放是否对当前任务有益。我们将其识别为推理时记忆分配，这是终身智能体面临的一个独特问题类别，并引入LIMBO：据我们所知，这是第一个将记忆视为可控推理时资源，并为每个传入任务联合优化记忆策略和推理预算的在线框架。与先前固定回放策略或需要模型权重、教师监督或离线再训练的方法不同，LIMBO在线单次通过中学习这种分配，明确平衡任务性能和推理成本，而无需修改底层智能体。在LifelongAgentBench上的三个LLM骨干网络上，LIMBO相比最先进的记忆增强基线实现了更好的成本-准确性权衡，并以高达约83%的更低推理成本（平均约53%）几乎匹配所有最强的此类基线。LIMBO无需再训练即可在不同模型和环境间调整其策略，表明有效的分配可以在线学习，而非手动指定。

## Abstract
As LLM agents become integrated into increasingly complex workflows, they must continually acquire new capabilities while retaining competence on previously learned tasks. Lifelong agents address this through experience replay, injecting past interactions into the prompt to leverage prior experience during inference. However, replay is not free: every replayed trajectory competes with retrieval, reasoning, tool use, and verification for the same limited prompt and compute budget, making effective resource allocation essential. Existing approaches allocate these resources using fixed replay policies, regardless of whether replay is beneficial for the current task. We identify this as inference-time memory allocation, a distinct problem class for lifelong agents, and introduce LIMBO: the first online framework to our knowledge that treats memory as a controllable inference-time resource and jointly optimizes memory strategy and inference budget for each incoming task. Unlike prior approaches that fix the replay policy or require model weights, teacher supervision, or offline retraining, LIMBO learns this allocation online in a single pass, explicitly balancing task performance and inference cost without modifying the underlying agent. Across three LLM backbones on LifelongAgentBench, LIMBO achieves better cost-accuracy tradeoffs than state-of-the-art memory-augmented baselines and nearly matches all strongest such baselines at up to ~83% lower inference cost (~53% on average). LIMBO adapts its policy across models and environments without retraining, demonstrating that effective allocation can be learned online rather than manually specified.

### 一、论文的核心问题与整体含义

- **研究动机**：LLM智能体在部署中需持续面对演化任务流，依赖经验回放机制来复用历史轨迹（工具调用模式、SQL命令格式等）以提升新任务性能。但回放并非免费——每条注入的轨迹都占用有限的上下文窗口和计算预算，与检索、推理、工具使用、验证等环节竞争资源。
- **核心问题**：现有方法使用**固定回放策略**（如统一回放k条轨迹），无论回放对当前任务是否有益，导致明显的"成本-价值错配"：增大固定回放缓冲会带来显著推理成本增长，但性能提升迅速边际递减（论文图1实证显示：从k=8到k=16，成本增加1.7×，准确率仅+0.35点）。

- **整体含义**：通过将记忆分配从固定预处理步骤转化为**在线可学习的推理资源分配决策**，以实现成本-准确率的帕累托最优，而不修改底层LLM智能体。

### 二、论文提出的方法论：LIMBO框架

#### 2.1 核心思想
LIMBO将记忆分配构建为**上下文老虎机（contextual bandit）**学习问题，在每到来一个新任务时，从候选动作集A中选择一个"记忆模式+计算预算"的组合，并在任务完成后根据真实结果（正确性、成本）在线更新策略。其核心设计理念为：

- **黑盒兼容**：不依赖模型权重、梯度或内部激活，适用于开源模型和商用API模型。
- **单遍在线学习**：在任务流中直接自适应，无需离线训练阶段或预热数据集。
- **有界单任务开销**：控制器决策本身开销极小（<0.5ms/任务），不影响主流水线。
- **显式成本目标**：将准确率和成本作为一阶目标联合权衡。

#### 2.2 记忆动作空间（Memory Actions）
控制器在四个记忆模式中选择：
| 模式 | 说明 |
|---|---|
| none（无回放） | 零样本直接求解 |
| full（完整回放） | 注入最近的k条成功轨迹（verbatim） |
| compressed（压缩回放） | 使用LongLLMLingua式问题感知压缩后再注入 |
| retrieved（检索回放） | 从64条记忆库中按相关性评分检索top-k轨迹注入 |

每个模式与三种生成预算档（低/中/高，对应不同token上限、回合数与工具调用数）组合成动作原语。

#### 2.3 特征向量（Feature Vector）
每个任务前构建**12维特征**，分为三组：
- **提示形状特征**：log归一化的全提示token数、最后用户轮token数、系统提示长度、脚手架长度、最后用户占比、技能数（用于区分检索密集型vs工具密集型任务）
- **运行时状态特征**：归一化成本的EMA、运行准确率、上一样本的归一化成本（捕捉流内漂移）
- **前序结果特征**：上一任务是否成功、是否出现错误终止（驱动计算预算档位调整）

#### 2.4 双头LinUCB控制器（Two-Head LinUCB）
- **每个动作维护**一个精度矩阵A_a（d×d）和两个参数向量b_acc_a、b_cost_a：
  - 头1：估计正确率概率，ŷp_a = σ(θ_acc^T x)
  - 头2：估计归一化期望成本，ĉ_a = max(θ_cost^T x, 0)
- **动作选择公式**：
  score(a) = ŷp_a(x_i) - λ·ĉ_a(x_i) + α·√(x_i^T A_a^{-1} x_i)

  其中：λ为成本权重（实验取0.5），α为探索系数，最后一项为UCB探索奖励。
- **在线更新**：任务完成后，用Sherman-Morrison秩一更新（O(d²)）维护矩阵逆，并累加参数向量。无梯度计算，不修改任何模型权重。

### 四、论文的主要结论与发现

1. **确认"推理时记忆分配"为独立问题类别**：固定回放策略产生严重成本-价值错配（图1），而该问题在现有文献中未被系统研究。

2. **LIMBO实现成本-准确率帕累托前沿**：在全部6个设置中，LIMBO均位于成本-准确率前沿上，没有任何固定方法能同时更便宜且更准确。

3. **显著的成本节约**：相比最强固定记忆基线，LIMBO最高降低约83%推理成本（平均约53%），同时准确率差距控制在-3.8~+0.6点之内：
   | 单元 | 准确率变化 | 成本降低 |
   |---|---|---|
   | Qwen DB | 74.4 vs 74.85（-0.45） | -82.8% |
   | Qwen OS | 51.4 vs 51.5（-0.1） | -34.1% |
   | Llama DB | 66.2 vs 70.0（-3.8） | -54.4% |
   | Llama OS | 43.0 vs 44.4（-1.4） | -26.3% |
   | GPT-4o mini DB | 67.4 vs 69.0（-1.6） | -82.3% |
   | GPT-4o mini OS | 62.4 vs 61.8（+0.6，严格帕累托超越） | -40.5% |

4. **学习到的策略因骨干和环境而显著不同**：
   - 强骨干（Qwen/GPT在DB上）→ 约78%任务选择无回放+最低计算档（记忆边际收益低）。
   - Llama在DB上→ 85%任务选择检索回放（记忆是刚需，弥补基础能力不足）。
   - OS环境→ 检索回放+完整回放的混合策略。

5. **在线学习确实发生**：动作混合从早期探索（17.3% no replay）收敛到稳定态（3.8%），UCB探索奖励从前100任务到后100任务单调衰减67%，证明策略是任务流中逐步学到的而非预置。

### 五、优点（方法与实验设计亮点）

1. **问题定义具有原创性和实用价值**：将"何时用多少记忆"从"用哪个记忆"中剥离独立研究，指出了固定回放策略的隐性资源浪费。

2. **方法设计高度匹配约束**：Limbo很好地满足终身智能体四项硬性约束（黑盒兼容、单遍在线、低开销、显式成本目标），轻量级设计（12维特征、O(d²)更新）使其可部署性极强。

3. **双头预测的bandit设计简洁有效**：在同一个精度矩阵下并行预测正确率和成本，实现多目标联合优化，避免了复杂奖励塑形。

4. **实证分析扎实**：不仅报告最终准确率/成本，还剖析了学习到的策略分布（图4）、在线演化轨迹（图5）等内部机制，提供了策略可解释性。

5. **检索权重共享**：所有检索变体使用相同权重，防止"per-method retuning"带来的不公平对比。

### 六、不足与局限

1. **记忆表示维度未充分探索**：LIMBO聚焦于"何时用记忆、用多少"的分配层，未深入优化记忆本身的内容选择或压缩表示。作者提及可与MemRL、SuRe等结合，但缺乏联合实验验证。

2. **消融实验缺失**：没有系统评估各特征组的贡献、λ敏感性、不同检索k的影响，这降低了结论的精确性。

3. **检索评分对专家先验的依赖**：SQL检索相似度评分（语义×技能×表ID的加权和）依赖人工选择的权重和特征，在OS环境未提供相同的评分明细——泛化性有待验证。

4. **实验方差与规模**：三颗种子对随机性较强bandit场景偏少；GSC等基线在部分单元缺测，削弱了对比完整性（尽管GSC在4/4匹配单元被LIMBO严格支配）。

5. **成本归一化与跨环境可比性**：归一化成本（除以Cmax）虽然解决了量纲差异，但可能掩盖不同环境的绝对成本结构差异；本地模型的"标准化"价格（$0.04/$0.10每百万token）是代理值而非实际服务成本，其绝对数字的普适性有限。

6. **潜在时间偏差风险**：论文中引用的部分工作（如MemRL 2026年1月、CER 2025年6月等）在排版截至日期与核心方法存在时间重叠，需读者注意文献时效性。

### 总结
LIMBO以轻量、在线、黑盒化的方式，创新性地将终身LLM智能体的经验回放从固定预处理步骤转化为可控的推理时资源分配决策，在6个（模型×环境）单元中实现了成本-准确率的帕累托前沿竞争，最高降低83%（平均53%）推理成本。实验充分展示了策略随骨干能力和环境需求的在线自适应——这是对"终身学习+推理时资源控制"交叉领域的有价值的贡献。但还需在消融实验、方差分析、更大规模设置、以及与其他记忆表示方法的联合优化方面进一步补强。

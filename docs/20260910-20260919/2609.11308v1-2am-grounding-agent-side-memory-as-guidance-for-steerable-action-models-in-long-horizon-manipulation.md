## 摘要
长时程机器人操作需要记忆，但不一定需要将记忆置于动作策略内部。为应对此类任务，当前的智能体系统通常将 VLA 与规划器和几何工具结合，有时还会使用额外深度或标定几何。这些系统混淆了归因：性能提升可能来自更丰富的观测或替代的运动工具，而失败则可能源于策略或定义不足的语言接口。我们通过一种刻意受限的设计来隔离这一问题：更少的工具广度，但更大的接口带宽。2AM 让一个多模态智能体成为任务记忆的唯一持有者，并让一个基于 RGB、按回合无状态的单一动作模型成为任务相关运动的唯一执行者。智能体将交互历史编译为子任务语言以及可选的 2D 抓取、放置和移动提示，这些提示在不同时间尺度上绑定其物理意图。为了将这种可引导性教给 VLA，我们用结构化提示标签增强演示，并在条件 dropout、空间噪声和时间抖动下训练，以容忍不完美的智能体输出。在 LIBERO-Mem 上，在不使用深度、在线几何或基于规划器的物体运动的情况下，2AM 达到 76.3% 的平均完成率，相比报告的最强基线 14.8% 提升了 61.5 个百分点，并取得 63.0% 的宽松成功率和 11.8% 的严格成功率。这些结果表明，任务记忆可以保留在智能体侧。它们进一步表明，动作模型的能力不仅取决于策略学到了什么，还取决于智能体能多精确地引导它。

## Abstract
Long-horizon robot manipulation requires memory, but not necessarily inside the action policy. To address such tasks, current agentic systems often combine VLAs with planners and geometric tools, sometimes using additional depth or calibrated geometry. These systems confound attribution: gains may come from richer observations or alternative motor tools, while failures may stem from either the policy or an under-specified language interface. We isolate this question through a deliberately constrained design: less tool breadth, but greater interface bandwidth. 2AM makes a multimodal Agent the sole holder of task memory and a single RGB-based, episodically stateless Action Model the sole executor of task-relevant motion. The Agent compiles interaction history into subtask language and optional 2D grasp, place, and move hints that bind its physical intention at different time scales. To teach this steerability to the VLA, we augment demonstrations with structured hint labels and train under condition dropout, spatial noise, and temporal jitter to tolerate imperfect Agent outputs. On LIBERO-Mem, without depth, online geometry, or planner-based object motion, 2AM reaches 76.3% average completion, a 61.5-point improvement over the strongest reported baseline of 14.8%, together with 63.0% relaxed and 11.8% strict success. These results show that task memory can remain Agent-side. They further show that Action Model capability depends not only on what the policy has learned, but on how precisely the Agent can steer it.

## 1. 核心问题与整体含义（研究动机与背景）

- **长时程操作需要记忆，但记忆应放在哪里尚未解决。** 当前主流做法有两类：
  - 把视觉历史/循环状态/学习式记忆**塞进 VLA 策略内部**（MemoryVLA、SlotSSM 等），但演示训练的策略一旦记住失败轨迹，重试时会"继承"失败的隐状态。
  - 把 VLA 放进**智能体工具箱**，与规划器、几何原语、任务专用策略并列，并常引入深度或标定几何（Hi Robot、RoboClaw、Goal2Skill、Harness VLA 等）。
- **归因被混淆（核心痛点）。** 上述系统同时改变了感知输入、运动工具与语言接口，因此成功可能来自更丰富的观测或替代运动路径，失败也可能只是"语言接口描述不足"而非策略能力不足。
- **论文主张的对照设计点：** 更少的工具广度，但**更大的接口带宽**。
  - 让多模态 Agent 成为**任务记忆的唯一持有者**；
  - 让**单一、仅用 RGB、回合内无状态（episodically stateless）的 Action Model** 成为任务相关运动的**唯一执行者**；
  - 二者之间用一条显式的"引导契约"连接。
- **研究问题形式化：** 是否存在一个紧凑命令 $c_k$，使得下一步局部动作在给定 $c_k$ 后**条件独立于完整历史 $H_k$**。作者明确承认这比"所有物理行为都无记忆"的强主张更窄——精确时序、隐藏力状态、轨迹模仿仍可能需要策略内部的时间状态。

## 2. 方法论

### 2.1 双模型分解与契约

- **Agent Model**：输入任务语言 $g$、当前 agent 视角 RGB $I^a_k$、压缩后的历史记录 $H_k$，输出引导命令
  $$c_k = \mathrm{AM_{agent}}(g, I^a_k, H_k)$$
- **Action Model**：输入 agent 视角 RGB、腕部视角 RGB $I^w_t$、机器人状态 $s_t$ 与 $c_k$，预测 $L$ 步绝对末端执行器动作块
  $$\hat a_{t:t+L-1} = \mathrm{AM_{action}}(I^a_t, I^w_t, s_t, c_k)$$
- 两个模型**时钟不同**：Agent 每执行一个短动作块更新一次；Action Model 在块内自主完成局部控制，**不接触 $H_k$，不跨 Agent 调用保留回合状态**。
- Agent 输出**不含**末端位姿、夹爪指令、时长或轨迹；只规定"做什么行为"与"视觉参数"，接近/对准/闭合/搬运/避障/释放仍由 Action Model 负责。
- **部署约束：** 只允许任务语言、双 RGB、机器人状态进入两个模型；不使用深度、在线掩码、物体位姿、像素到 3D 反投影或解析式物体运动。复位/归位/宿主安全可留在学习系统外，但所有任务相关运动必须经过同一 Action Model。

### 2.2 组合式引导契约

命令由局部语言指令 $\ell_k$ 与零个或多个归一化 2D 提示组成：
$$c_k = (\ell_k,\ q^{\text{grasp}}_k,\ q^{\text{place}}_k,\ q^{\text{move}}_k)$$

- 坐标为当前 agent 视角图像、左上原点、$[0,1000]$ 范围；**缺失字段直接省略**，而非用特殊点表示（可用性本身随阶段变化）。
- 三类提示对应**不同时间尺度**：

| 字段 | 回答的问题 | 典型有效期 | 不负责的部分 |
|---|---|---|---|
| Language | 做什么行为？ | 当前语义阶段 | 实例绑定 |
| grasp target | 下一个抓哪个物体？ | 抓取前 | 抓取几何 |
| place target | 目的地是哪里？ | 整个搬运过程 | 无碰撞路径 |
| move target | 哪里有有用的进展？ | 未来若干步 | 完整轨迹 |

- **grasp**：绑定下一个物体实例，接触后或阶段切换即消失（滞留旧抓取点会把控制器拉回物体原图像位置）。
- **place**：跨搬运维持长程承诺，解决腕部视角看不到/被机械臂遮挡的远端目的地。
- **move**：近端方向线索（演示中若干步后的夹爪位置），**不是**必须到达的路径点或轨迹；Action Model 可因几何或接触偏离图像空间直线。
- 三者为**互补**而非同一目标的不同编码：接近阶段可用语言+抓取+移动；搬运阶段去掉抓取保留放置+移动；释放/稳定阶段可能只需放置。缺失或含噪字段只降级某一角色，而非使整条命令失效。

### 2.3 训练监督的构造（无需模型教师）

- **从演示确定性反推标签**，而非让 VLM 叙述轨迹。每条同步轨迹提供 RGB、机器人状态、动作、演示阶段、物体框/掩码、夹爪接触、物体运动。
- **抓取/放置监督**：对图像宽 $W$ 高 $H$ 中可见物体框 $(x,y,w,h)$，取归一化中心
  $$q = 1000\left(\frac{x+w/2}{W},\ \frac{y+h/2}{H}\right)$$
  强调这是**语义目标**，并非声称几何中心是最优接触点。
- **移动监督**：由投影末端轨迹 robot_xy 采样，$\Delta \sim U\{10,\dots,20\}$，$q^{\text{move}}_t = \mathrm{robot\_xy}_{t+\Delta}$，索引在回合边界截断。采样窗口可避免模型把某一固定时间偏移当作"移动点"的定义，也匹配 Agent 延迟波动。
- 动作标签沿用原 VLA 对齐方式（下一帧绝对末端位姿 + 原夹爪指令），窗口可跨越子任务边界，避免教出"等待 Agent"的停顿行为。

### 2.4 面向不完美引导的鲁棒训练

- 用 $v_t \in \{0,1\}^4$ 标记各字段语义上是否可用，在**可用性约束**下独立掩码：
  $$m_t \sim p_{\text{mask}}(m\mid v_t),\quad m_t \preceq v_t,\quad \|m_t\|_0 \ge 1,\quad \tilde c_t = \mathrm{Mask}(c_t; m_t)$$
  即产生纯语言、纯点、混合命令，但**永不删除全部意图来源**；抓取/放置/移动可独立消失，而非当作不可分割的空间提示整体处理。掩码概率是训练超参，不属于接口定义。
- **空间噪声**：对每个保留点加各向同性高斯坐标噪声并裁剪
  $$\tilde q = \mathrm{clip}_{[0,1000]^2}(q + \epsilon),\quad \epsilon \sim \mathcal N(0,\sigma^2 I_2)$$
- 上述三类扰动分别覆盖接口的三种主要错误：**遗漏、定位误差、时间错位**。
- 实现：**Qwen3-VL-4B** 骨干 + **flow-matching Action Expert**，16 步动作块；**没有**独立的抓取/放置/移动控制器。控制器可为任何带语言条件接口的策略（VLA/WAM 均可）。
- **闭环执行**：每个动作块后 Agent 观察新全局 RGB、更新 $H_{k+1}$，可修正子任务或任一提示；不暴露任何 benchmark 状态或学习式完成判据。

## 6. 主要结论与发现

- **任务记忆可以完全保留在 Agent 侧**，Action Model 只需保留执行当前动作块所需的短时状态。
- **接口带宽本身是关键变量：**
  - 2AM 相对对齐的 π0 复现：completion **70.79% → 76.29%（+5.50 点）**，relaxed SR **37.42% → 63.00%（+25.58 点）**，strict SR 基本持平但略低（12.25% → 11.83%）。
  - 相对最强公开基线 14.8% completion，提升 **61.5 个百分点**（但作者以复现 π0 作为主对比）。
  - **语言仅消融**：strict 7.25%、relaxed 19.42%、completion 53.72%；加入 grounded 提示后分别提升 **+4.58 / +43.58 / +22.57 点**。relaxed 的巨大增益说明 2D 提示主要帮助 Agent **把记忆意图贯穿到完整有序流程**，而非解决"精确停在正确状态"。
- **任务级模式：** 2AM 在**全部 10 个任务**上 relaxed SR 更高，在 **7 个任务**上 completion 更高；π0 复现在 T1–T6 的 strict 上更强，2AM 在 T7–T10（关系与遮挡更重，物体/目的地绑定负担更大）更强。
- **终止问题未解决：** 2AM 的 relaxed 63.0% 与 strict 11.8% 之间存在巨大落差，说明"到达意图状态"与"恰好停在该状态"是**两个不同问题**；当前接口改善任务推进，但不解决语义终止。
- **鲁棒训练的边界：** dropout 与空间噪声能让 Action Model 容忍提示缺失或定位不准，但**无法纠正已经编码错误高层意图的子任务选择或物体绑定错误**。
- **总体结论：** 动作模型的能力不仅取决于策略学到了什么，还取决于 Agent 能多精确地"要求"它行动。

## 7. 优点

- **归因设计干净：** 刻意削减工具广度（无深度、无在线几何、无规划器物体运动、无分割/框/oracle），把变量集中在"接口带宽"上，使性能提升更可归因于 Agent–Action Model 契约本身。
- **接口设计有洞察力：** 把记忆的"当前后果"编码为语言 + 三个**时间尺度互补**、**可独立缺失**的 2D 提示，而非单一目标编码；缺失字段被省略而非填充特殊值，与阶段可用性自然对齐。
- **监督可扩展、无需模型教师：** 全部引导标签由演示确定性反推（阶段、物体框/掩码、接触、物体运动、投影末端轨迹），避免了 VLM 叙述带来的噪声与成本。

- **评测协议区分"推进"与"终止"：** 同时报告 strict / relaxed / completion 三个指标，使"达成有序目标"与"精确停在目标状态"这两类失败被明确分离，避免了单一成功率掩盖接口的真实作用点。
- **主对比选择克制：** 没有用自建复现去碾压公开基线数字来制造提升幅度，而是明确把公开基线标注为"当前实现下的低估"，主结论建立在同骨干、同观测、同块长的对照上。
- **消融直击核心变量：** "语言仅 vs 语言 + 2D 提示"的消融保持了 Agent、Action Model、观测与块长不变，唯一变量就是接口带宽，归因链清晰。
- **定性错误分析有诊断价值：** 图 3 将失败分为抓取定位不准、子任务选择错误、目的地绑定错误三类，分别对应"接口噪声可被鲁棒训练吸收"与"高层意图已错、控制器无法挽救"两种性质，与第 6 节的结论自洽。

## 8. 缺点与局限性

- **实证范围过窄：** 仅在 LIBERO-Mem 这一单一仿真 benchmark 上评测，且任务均属桌面操作。没有真机实验，也没有跨环境、跨本体或长时程（数十步以上）任务的验证，外部效度受限。
- **strict SR 未获得提升：** 2AM 的 strict SR（11.83%）略低于对齐的 π0 复现（12.25%），且 relaxed 与 strict 之间存在 51 个百分点的落差。这说明论文实际改善的是"任务能否被推进"，而**语义终止**问题被明确搁置，接口并未解决"何时该停"。
- **逐提示贡献未隔离：** grasp / place / move 三类提示只做了"全部提示 vs 全无提示"的对比，没有分别移除某一类，因此无法判断是哪一类提示驱动了 relaxed SR 的大幅提升，也无法验证三者"互补而非冗余"的设计假设。
- **鲁棒性扰动的贡献未单独量化：** 条件 dropout、空间高斯噪声、时间错位采样被合并为"鲁棒训练"，但各自对最终性能的边际贡献、以及最优噪声强度均未报告。
- **Agent 能力被当作给定条件：** 接口的可用性直接依赖 Agent 能否把历史压缩成正确的局部意图与 2D 定位。论文只用 Qwen3.8-27B 一个骨干，未做规模或更强 VLM 的对比，因此"接口带宽收益是否随 Agent 能力增长"这一关键问题未被回答。
- **监督标签依赖演示结构：** 抓取/放置点来自物体框/掩码中心，移动点来自演示末端轨迹投影采样。这些标签隐含了演示的采集视角、阶段划分与轨迹风格，在演示未覆盖的布局或需要偏离演示路径的场景下可能引入系统性偏差。
- **双时钟引入的延迟未评估：** Agent 与 Action Model 更新频率不同，引导延迟、引导频率与任务成功率/完成时间之间的权衡被作者列为未测量项，实际部署中的实时性与稳定性因此无从判断。
- **任务级结果分化未解释：** T1–T6 上 π0 复现的 strict 更强、T7–T10 上 2AM 更强，论文仅以"关系与遮挡更重"作定性解释，缺少针对任务属性（M/S/R/O 标签）的定量归因。
- **缺少与"工具箱式"方法的直接对照：** 论文的核心论点之一是"更大的接口带宽优于更广的工具广度"，但实验中没有把同等的规划器/几何原语/深度输入引入对照，因此该论点更多是设计选择而非被实验证伪过的结论。

## 9. 启发与可延展方向

- **"记忆归属"可作为独立设计维度：** 论文把"谁持有任务记忆"从"策略学到什么"中剥离出来，提示后续工作可以系统研究记忆放在 Agent 侧、策略侧、还是混合侧对鲁棒性、可解释性与重试行为的影响。
- **接口带宽是低成本、可插拔的改进轴：** 2D 提示不改变控制器架构，只改变输入契约，因此原则上可叠加到任意带语言条件的 VLA/WAM 之上，作为"不重训大模型也能提升长时程任务"的通用手段。
- **终止判据值得独立研究：** relaxed 与 strict 的巨大落差表明，把"推进任务"与"判定完成"解耦后，后者是一个尚未被该接口覆盖的独立问题，可能需要专门的终止信号或验证机制。
- **鲁棒训练与意图纠错的边界值得刻画：** 论文观察到扰动训练只能吸收遗漏与定位误差，无法修正已错的语义绑定。这一"可恢复错误 / 不可恢复错误"的划分，为后续研究接口容错的上限提供了切入点。
- **监督构造范式可复用：** "从演示的确定性结构反推接口标签"避免了 VLM 叙述的噪声与成本，这一思路可迁移到其他需要中间接口监督（如子目标、进度、可供性提示）的工作中。

## 10. 总体评价

2AM 是一篇**问题设定清晰、归因设计克制、结论表述诚实**的工作。它的主要贡献不在于刷新某个 benchmark 的数字，而在于提出并验证了一个可操作的设计原则：在多模态 Agent 与动作策略之间，**扩大显式接口的带宽**比**扩大 Agent 的工具广度**更能提升长时程任务的任务推进能力。其方法论上的亮点是把记忆归属、接口时间尺度、监督来源三者解耦，并用对齐的复现基线而非公开数字作为主参照；其主要短板则是实验面偏窄（单一仿真、单骨干、无真机）、逐字段消融缺失，以及 strict SR 未获提升所暴露的终止问题被明确留下未解。整体而言，它更像是一份**关于接口设计的原则性论证与可行性验证**，而非一个在性能上全面领先的系统，其价值将取决于后续工作能否在真机、更强 Agent 与更细消融下复现并拓展这一结论。

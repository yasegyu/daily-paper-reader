## 摘要
长时程机器人操作需要记忆，但不一定在动作策略内部。为了解决这类任务，当前的代理系统通常将VLA与规划器和几何工具相结合，有时使用额外的深度信息或标定几何。这些系统混淆了归因：改进可能来自更丰富的观测或替代的运动工具，而失败可能源于策略或未充分指定的语言接口。我们通过一种刻意约束的设计来孤立这个问题：更少的工具广度，但更大的接口带宽。2AM使多模态代理成为任务记忆的唯一持有者，并使单个基于RGB、情节上无状态的动作模型成为任务相关运动的唯一执行者。代理将交互历史编译为子任务语言和可选的2D抓取、放置和移动提示，这些提示在不同时间尺度上绑定其物理意图。为了教会VLA这种可引导性，我们用结构化提示标签增强演示，并在条件丢弃、空间噪声和时间抖动下训练，以容忍不完美的代理输出。在LIBERO-Mem上，不使用深度、在线几何或基于规划器的物体运动，2AM达到了76.3%的平均完成率，比最强的报告基线14.8%提高了61.5个百分点，同时实现了63.0%的宽松成功率和11.8%的严格成功率。这些结果表明，任务记忆可以保持在代理端。它们进一步表明，动作模型的能力不仅取决于策略所学到的东西，还取决于代理能如何精确地引导它。

## Abstract
Long-horizon robot manipulation requires memory, but not necessarily inside the action policy. To address such tasks, current agentic systems often combine VLAs with planners and geometric tools, sometimes using additional depth or calibrated geometry. These systems confound attribution: gains may come from richer observations or alternative motor tools, while failures may stem from either the policy or an under-specified language interface. We isolate this question through a deliberately constrained design: less tool breadth, but greater interface bandwidth. 2AM makes a multimodal Agent the sole holder of task memory and a single RGB-based, episodically stateless Action Model the sole executor of task-relevant motion. The Agent compiles interaction history into subtask language and optional 2D grasp, place, and move hints that bind its physical intention at different time scales. To teach this steerability to the VLA, we augment demonstrations with structured hint labels and train under condition dropout, spatial noise, and temporal jitter to tolerate imperfect Agent outputs. On LIBERO-Mem, without depth, online geometry, or planner-based object motion, 2AM reaches 76.3% average completion, a 61.5-point improvement over the strongest reported baseline of 14.8%, together with 63.0% relaxed and 11.8% strict success. These results show that task memory can remain Agent-side. They further show that Action Model capability depends not only on what the policy has learned, but on how precisely the Agent can steer it.

### 二、方法论

- **核心思想**：2AM采用双模型分解，通过明确的“契约”（steering command）连接Agent与Action Model：
  - **Agent Model**：多模态智能体，唯一持有任务记忆，负责推理任务状态并输出引导命令
  - **Action Model**：仅基于RGB、情节上无状态（episodically stateless）的单一动作模型，是任务相关运动的唯一执行者
- **组合式引导契约**：每轮命令包含子任务语言指令ℓk 和零个或多个2D提示，具体包括：
  - **抓取目标（grasp target）**：绑定下一个物体实例，在接触前最有效
  - **放置目标（place target）**：维持更长时间的承诺，常用于运输阶段
  - **移动目标（move target）**：近端方向提示，表示未来若干演示步后的握爪位置
  - 不同字段互补而非冗余，缺失字段被省略而非用特殊点表示
- **训练方法**：
  - 从演示中恢复监督信号而非使用VLM生成标签：利用阶段标签、物体标注、接触与物体运动信息

  - 加入空间噪声（Gaussian坐标扰动）和时间抖动（未来窗口采样），以容忍Agent输出的不完美
- **闭环执行**：Agent每次只预测一个短动作块（16步），执行后Agent观察新RGB图像、更新历史、必要时重新引导

### 六、主要结论与发现

- **性能结论**：2AM在LIBERO-Mem上达到76.3%的平均完成率，比最强基线14.8%提升61.5个百分点；宽松成功率为63.0%，严格成功率为11.8%。
- **与对齐π0比较**：2AM将完成率提升5.5个百分点（70.79%→76.29%），宽松成功率提升25.58个百分点（37.42%→63.00%），但严格成功率略有下降（11.83% vs 12.25%）。
- **接口带宽的重要性**：语言only消融仅达到7.25%严格成功率、19.42%宽松成功率和53.72%完成率；加入2D提示后三项指标分别提升4.58、43.58和22.57个百分点。宽松成功率不成比例的提升表明，抓取、放置和移动参数主要帮助Agent通过请求的进度携带所记忆的意图，但并未解决准确停止这一独立难题。
- **任务类型差异**：2AM在T7-T10（关系与遮挡任务）上更强，而π0在T1-T6（简单取放循环）上严格成功率更高。
- **核心结论**：任务记忆可以完全保留在Agent侧；动作模型的能力不仅取决于策略所学，更取决于Agent能否精确引导它。

### 七、优点

1. **受控实验设计**：刻意限制工具种类（仅RGB、无深度/在线几何/规划器），使性能提升可以准确归因于Agent-Action Model接口本身
2. **清晰的归因逻辑**：通过语言only消融，分离了接口带宽与系统整体性能的贡献
3. **恢复监督信号的有效策略**：利用演示自动生成训练标签，无需VLM教师模型，避免了昂贵的人工标注
4. **对不完美引导的鲁棒性训练**：条件丢弃、空间噪声和时间抖动覆盖了三类主要接口错误（遗漏、定位误差、时间错位）
5. **引入了更强的对齐基线**：坦诚指出基准报告数值低估实际性能，使用同骨干网络的自建再现进行对比，增加了比较的公平性
6. **优化的问题分解**：提出记忆-执行分离的架构，为层级控制提供了新的设计空间

### 八、不足与局限

1. **实验覆盖有限**：仅使用单一仿真基准（LIBERO-Mem），缺乏在真实机器人或更广泛基准（如RMBench、RoboMemArena、RoboMME）上的验证
2. **严格成功率未提升**：与π0相比严格成功率几乎没有改进，广义上的操作终止（精确停止）问题未得到解决
3. **未充分探索各提示的独立贡献**：没有逐一消融仅移除抓取/放置/移动提示时各自的贡献，无法量化每种提示对最终指标的边际影响
4. **Agent能力受限**：当前Agent（Qwen3.8-27B）相对较弱，且未比较不同Agent骨干网络的性能差异；Agent的错误（如错误子任务选择、错误对象绑定）无法被下游训练的鲁棒性纠正
5. **2D接口的固有局限**：2D坐标无法暴露隐藏几何、力信息或连续运动历史，对需要精确3D空间信息的任务适应性有限
6. **频率/延迟权衡未分析**：未测量Agent引导频率对系统延迟与能力的影响，实际部署时导航频率的取舍尚未明确
7. **仅限仿真**：无真实机器人实验，未验证在真实环境中的泛化能力和可靠性

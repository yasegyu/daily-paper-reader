## 摘要
主流机器人策略常采用马尔可夫公式，但许多复杂的现实世界操作任务本质上非马尔可夫，需要超出当前观测的长时记忆。现有记忆机制通常依赖语言摘要、增长的视觉窗口或其组合，因此可能丢失细粒度视觉证据，或在历史覆盖与执行效率之间面临权衡。我们提出MaP-WAM，一种“记忆即计划”框架，将依赖记忆的世界-动作建模分解为记忆锚定的规划和计划条件化的执行，并使用长期多模态情节上下文作为规划时证据，而非反复以完整历史条件化执行器。MaP-WAM将记忆表示为包含语言指令和稀疏视觉上下文的已完成片段记录，并将这种情节记忆转化为包含下一片段级语言计划和相应视觉引导的紧凑计划。一个世界-动作-进展（WAP）模型在推理时通过联合预测动作块和相应的执行进展来执行每个计划，持续时间未知，并通过计划-观测对齐校准预测进展，以实现自适应片段转换和闭环上下文更新。MaP-WAM保持执行器上下文长度固定，同时结构化注意力进一步在规划和执行中实现键值缓存。MaP-WAM在RMBench上以83.3%的成功率达到最先进性能，在真实机器人任务上达到78.0%的成功率，同时随着任务历史增长保持执行器推理延迟近似恒定。

## Abstract
Mainstream robotic policies often adopt a Markovian formulation, but many complex real-world manipulation tasks are inherently non-Markovian, requiring long-horizon memory beyond the current observation. Existing memory mechanisms often rely on language summaries, growing visual windows, or their combinations, and may therefore lose fine-grained visual evidence or face a trade-off between history coverage and execution efficiency. We introduce MaP-WAM, a Memory-as-Plans framework that decomposes memory-dependent world-action modeling into memory-grounded planning and plan-conditioned execution, and uses long-term multimodal episodic context as planning-time evidence rather than repeatedly conditioning the executor on the full history. MaP-WAM represents memory as completed segment records containing language instructions and sparse visual context, and converts this episodic memory into compact plans comprising the next segment-level language plan and corresponding visual guidance. A World-Action-Progress (WAP) model executes each plan over an unknown duration by jointly predicting action chunks and corresponding execution progress at inference time, calibrating predicted progress through plan-observation alignment for adaptive segment transitions and closed-loop context updates. MaP-WAM keeps the executor context length fixed, while structured attention further enables key-value caching in both planning and execution. MaP-WAM achieves state-of-the-art performance on RMBench with an 83.3% success rate and attains 78.0% success on real-robot tasks, while maintaining approximately constant executor inference latency as task history grows.

- **背景**：主流机器人策略（如VLA模型和WAM）普遍采用马尔可夫假设，即认为当前观测或固定短序列足以支撑动作预测。然而，许多真实世界的复杂操控任务本质上是**非马尔可夫**的——关键决策信息可能存在于过去的观测中，例如物体初始位置、先前操作步骤或视觉上相似但语义不同的执行阶段。
- **核心问题**：如何让机器人策略在长时程任务中有效利用历史信息（记忆），同时保持实时控制所需的推理效率？
- **既有方案的不足**：

### 二、方法论

#### 核心思想：记忆即计划（Memory-as-Plans）

MaP-WAM提出将记忆依赖的世界-动作建模解耦为两个阶段，以解决上述矛盾：

1. **记忆锚定的规划（Memory-Grounded Planning）**：在规划时利用长期多模态情节上下文生层紧凑的“计划”。
2. **计划条件化的执行（Plan-Conditioned Execution）**：执行器仅依赖当前计划与当前观测动作预测，上下文长度固定，与历史长度无关。

#### 关键技术细节

- **结构化多模态情节上下文**：记忆以“已完成片段记录”组织——每个片段 i 的记录 Ci = {li, Gi} 包含片段语言指令 li 和稀疏视觉上下文 Gi（从真实执行轨迹均匀抽取8帧）。初始帧存为 G0 = f0。全局指令 l 与记录序列 C<k 构成规划时的证据。
- **语言-视觉规划分解**：
  - **语言规划器 πlP**：基于VLM（Qwen3.5-4B），输入全局指令、已完成片段指令、紧凑关键帧集（初始帧和各片段末帧），预测下一片段的语言计划 lk。
  - **视觉规划器 πvP**：一个因果世界模型（CWM），基于WAN-2.2-5B视频生成模型，以流匹配目标 LFM 训练，在语言计划与长程视觉上下文条件下生成视觉计划 Ĝk（即未来片段的可视化引导）。
- **世界-动作-进展（WAP）模型**：
  - 将预训练视频DiT扩展为Mixture-of-Transformers（MoT）架构，涵盖视频专家、动作专家（1.02B参数）和进展专家（207M参数）。
  - 给定当前帧、本体感知状态、当前进展 pt 与计划，WAP联合预测未来视觉状态（辅助世界建模）、动作块和进展序列，目标函数为 LE = λv LvE + λa LaE + λp LpE 的加权和。
  - **进展作为“一等模态”**：进展建模提供执行时间坐标，解决视觉相似但语义不同的状态歧义（如“按压”与“释放”）。训练中通过添加均匀偏移 [−0.1, 0.1] 增强鲁棒性。
- **闭环规划与执行**：
  - **计划-观测对齐**：利用视觉计划（帧按进展索引）在当前观测与接近预测进展的原型帧之间进行像素级RGB匹配，选择最相似帧的进展索引来校准递归预测的进展值，避免长时间跨度中的进展漂移。
  - **进展门控片段转换**：当预测进展均值超过阈值 τ=0.95 时，判定当前片段完成，触发执行器终止当前计划，将真实观测重新采样为8帧稀疏视觉上下文并写入情节记忆，再调用规划器生成下一片段计划。推理流程如Algorithm 1所示。
- **结构化注意力与KV缓存**：CWM采用块级因果掩码使已完成片段前缀可缓存；WAP将视觉计划编码为静态干净前缀，动态token只关注计划和当前状态，计划前缀在每个片段中预填充一次并在多次动作块执行中复用。

### 三、实验设计

- **模拟基准——RMBench**：专为长时程记忆依赖操控设计的仿真基准，包含5个 M(1) 任务（需1个历史观测）和4个 M(n) 任务（需多个历史观测）。每个任务仅提供50条专家演示用于训练，报告100次评估rollout的成功率。
- **对比方法**：差分策略（DP）、π0.5、X-VLA、Mem-0、WLA-0、LingBot-VA共6种代表性基线。
- **真实机器人**：7自由度Franka Research 3机器人，配第三视角和腕部RealSense D435i相机，两个任务共100条轨迹训练，每条任务50次独立试验。
  - **Find Button**：观察按钮颜色→被遮挡→按颜色指令打开对应盖子。
  - **Press Buttons**：观察数字指令→多次按压左/中按钮→按压右侧确认按钮。
- **消融实验**：
  1. 视觉规划消融（去掉CWM视觉计划 vs. 去掉视觉记忆，保留标准当前观测条件化的世界模型）——在Observe and Pick Up和Swap T任务上。
  2. 进展建模消融（分类替代 vs. 去掉进展条件 vs. 去掉进展校准）——在Blocks Ranking Try、Cover Blocks、Press Button任务上。
- **效率测试**：在单张A800上测量历史段数增长时规划器/执行器的推理延迟。

### 四、资源与算力

- 训练硬件：8块NVIDIA A800 GPU（各80GB显存）。
- VLM：LoRA微调Qwen3.5-4B（rank=32，alpha=64），学习率1×10⁻⁴，8个epoch。
- CWM：微调WAN-2.2-5B，学习率1×10⁻⁴，100个epoch。

- **实验规模**：8个仿真任务（9个RMBench任务中报告了9个成功率）+ 2个真实任务；3组消融实验；1组效率对比；共约15组主要比较数据。

### 六、主要结论

- MaP-WAM在RMBench上达到83.3%的平均成功率，明显优于最强基线LingBot-VA（77.1%）和Mem-0（42.0%）。
- 在Swap T和Press Button任务上分别持平或超越最强基线（96% vs. 88%和96% vs. 84%），证明细粒度视觉记忆与进展建模有效。
- 真实机器人任务上（Find Button 88%、Press Buttons 68%）显著优于基线。
- 消融证明：视觉计划需要记忆锚定（去掉视觉记忆会显著降低成功率）；进展条件可区分视觉相似状态；进展校准在长时程任务（平均423步）中尤为关键。
- 执行器保持约827ms/块的恒定推理延迟，而完整上下文变体在1500帧历史时延迟增加约4倍，1700帧时OOM。

### 七、优点

- **范式创新**：以“记忆→计划→执行”解耦替代“直接历史条件化”思路，概念清晰且实用，明确承认长程历史是规划时的需要而非执行时的需要。
- **两层记忆架构完整**：既有语义层的语言计划，又有感知层的视觉引导，兼顾紧凑性与信息保真。
- **进展建模设计巧妙**：将进展作为执行条件而非仅用于校验，结合轻量级计划-观测对齐实现闭环，设计动机和实验验证逻辑严谨。
- **工程效率突出**：MoT架构与块级因果注意力/计划前缀缓存使执行延迟不随历史增长，解决了原方法核心痛点。
- **实验叙事完整**：模拟-真实双验证，消融定位每个组件的作用，效率数据透明可验证。

### 八、不足与局限

- **依赖分段结构**：论文明确承认需要预定义片段边界（来自现有benchmark标注），无法处理无标注的连续演示，限制了在真实部署中的通用性。
- **轻量级校准指标**：计划-观测对齐使用训练无关的RGB像素差异匹配，在视觉复杂场景中鲁棒性存疑；论文也未做超参数敏感性分析。
- **真实任务规模有限**：仅两个按钮类任务，未包含更复杂的物体操控（如抓取/堆叠），外推能力证据不足。
- **训练需求高**：VLM（8 epochs）、CWM（100 epochs）、WAP（最多100 epochs）8×A800的算力需求可能限制可复现性，且多任务/单任务训练设置不一致（VLM多任务、WAP单任务）引入潜在混淆变量。

- **WAP删除了未来视觉推理（遵循FastWAM）**，但论文未提供该选择对实际操控质量影响的消融数据。
- **未报告方差或单任务性能分布**，仅给出平均成功率，对95%置信区间与rollout随机性评估不足。

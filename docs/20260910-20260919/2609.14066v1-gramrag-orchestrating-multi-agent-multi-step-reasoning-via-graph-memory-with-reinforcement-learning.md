## 摘要
尽管现有的多智能体检索增强生成（RAG）系统在复杂的多模态推理任务上展现出了潜力，但在回答知识密集型问题时，它们在推理深度和记忆结构上仍存在根本性的局限，常面临检索不足和状态盲区的问题。为克服这些局限，我们提出了GraMRAG，一种图记忆引导的多智能体RAG框架，它集成了动态多模态记忆图，以实现稳定、多步的多模态推理。我们引入了一种视觉-文本桥接的推理范式，将多尺度实体裁剪与类ReAct的视觉工具链统一起来，增强了长时跨模态推理能力。我们进一步构建了一个多模态记忆图，将智能体推理形式化为动态有向无环图（DAG），显式建模动作-观测依赖关系，以减轻状态盲区并抑制冗余检索。此外，我们提出了拓扑感知策略优化（TAPO），利用图拓扑进行关键路径识别和定向节点剪枝，从而在多步推理轨迹中实现细粒度的信用分配。在具有挑战性的多模态基准上的大量实验表明，我们的方法持续优于现有基线，并在复杂的长时推理任务上达到了最先进的性能。

## Abstract
Although existing multi-agent Retrieval-Augmented Generation (RAG) systems have demonstrated promise on complex multimodal reasoning tasks, they remain fundamentally limited in reasoning depth and memory structure, suffering from inadequate retrieval and state blindness when answering knowledge-intensive questions. To address these limitations, we propose GraMRAG, a graph memory-guided multi-agent RAG framework that integrates a dynamic multimodal memory graph to enable stable, multi-step multimodal reasoning. We introduce a vision-text bridged reasoning paradigm that unifies multi-scale entity cropping with a ReAct-style visual toolchain, enhancing the long-horizon cross-modal reasoning capability. We further construct a multimodal memory graph that formalizes agent reasoning as a dynamic directed acyclic graph (DAG), explicitly modeling action-observation dependencies to mitigate state blindness and suppress redundant retrieval. Moreover, we propose Topology-Aware Policy Optimization (TAPO) that leverages graph topology for critical path identification and targeted node pruning, enabling fine-grained credit assignment across multi-step reasoning trajectories. Extensive experiments on challenging multimodal benchmarks demonstrate that our approach consistently outperforms existing baselines and achieves state-of-the-art performance on complex long-horizon reasoning tasks.

## 一、核心问题与整体含义（研究动机与背景）

- **研究背景**：检索增强生成（RAG）通过引入外部知识库扩展了多模态大语言模型（MLLMs）的知识边界。基于MLLM的多智能体架构通过专业分工协作，在复杂多模态RAG任务上展现出优于单智能体框架的性能。
- **核心问题**：现有基于多智能体的RAG系统在复杂多模态推理任务中面临三大根本性局限：
  1. **推理深度不足**：当前系统的平均检索轮次有限（通常仅个位数），智能体在复杂任务上倾向于过早终止探索、仅获取部分证据，无法将文本深度研究的长时规划能力迁移至多模态场景；
  2. **记忆结构缺陷**：主流线性累积或迭代摘要式记忆范式（如ReAct、Mem1）缺乏对智能体推理状态的显式建模，随着交互轮次累积会导致**状态盲区**（state blindness）——智能体逐渐丢失历史检索路径信息，进而在多跳任务中产生重复查询和冗余检索；
  3. **信用分配困难**：传统基于最终结果的稀疏奖励机制将终止状态信号粗糙地传播至整个轨迹，导致有效检索步骤在负样本中被错误惩罚、冗余操作在正样本中被不应得地奖励，无法实现跨多步推理的细粒度信用分配。
- **整体含义**：本文提出的GraMRAG框架旨在同时解决上述三大问题，为多模态长时推理任务提供统一的图记忆驱动的解决方案。

## 二、方法论

### 2.1 视觉-文本桥接推理范式

- **多尺度视觉实体定位**：给定输入图像 I、用户查询 q 和视觉引导提示 pv，视觉探索器（Visual Explorer）在每个推理步骤 t 生成层级化区域候选集 Bt = {b¹t, b²t, ..., b^{Nt}t}，包含粗粒度上下文区域和细粒度实体级补丁，而非将整幅图像作为单一检索单元。
- **两级视觉工具链**：候选集触发视觉检索动作 Aᵥt = VSearch(Bt)，依次经过图像搜索模块（匹配裁剪区域与网络级索引、返回候选URL）和网页检索模块（以结构化markdown格式获取页面内容），得到观测 Oᵥt = VisChain(Aᵥt)。
- **Hit/No Hit判定**：独立的判定器（Judge）根据原始图像I和查询q对观测Ov输出二元接受信号 st = Judge(I, q, Oᵥt) ∈ {0, 1}。st=1（Hit）时检索内容加入有效证据池 Ev；st=0（No Hit）时触发更细粒度裁剪或查询重述。该解耦设计实现了探索策略与证据评估的清晰分离。
- **模态桥接与文本推理**：视觉探索阶段结束后，图像描述模块生成综合文本描述 D，替代原图像 I，生成桥接上下文并转发给文本研究员（Text Researcher），后者执行后续文本检索轨迹 τtext，完成跨模态推理。
- **证据聚合与完整轨迹构建**：证据验证器（Evidence Validator）聚合视觉与文本两阶段的全部证据，解决证据冲突、过滤幻觉内容，生成最终答案 aout，构建完整推理轨迹 τ。

### 2.2 多模态记忆图

- **图的定义**：记忆图 Gt = (Vt, Et) 将多智能体推理过程形式化为动态有向无环图（DAG），通过节点插入和边连接在推理过程中逐步演化，显式编码动作-观测依赖关系。
- **节点模式与模态分类**：每个节点 ni 编码为四元组 ni ≜ (μi, κi, σi, νi)，包含五种节点类型：
  - **根节点（nroot）**：以用户查询q和输入图像I初始化，作为推理图的全局锚点；
  - **视觉节点（nvis）**：由视觉探索器在每个视觉检索步骤生成，存储Hit/No Hit判定和证据摘要，νi保留匹配网页的多模态内容；
  - **桥接节点（nbrd）**：单例节点，存储图像描述 D 作为语义接口；
  - **文本节点（ntxt）**：由文本研究员生成，存储文本证据摘要；
  - **答案节点（nans）**：由证据验证器生成，存储最终答案，图终止于此。
- **迭代图扩展协议**：四阶段顺序扩展——
  1. 视觉扩展阶段（t ∈ [1, Tv]）：视觉探索器执行检索，判定器输出信号，插入视觉节点并连接顺序边；
  2. 模态桥接阶段：插入桥接节点并连至最后一个视觉节点；
  3. 文本扩展阶段（t ∈ [Tv+1, Tv+Tt]）：文本研究员执行网络检索，插入文本节点；
  4. 答案生成阶段：证据验证器插入答案节点终止推理。
- **效果**：每个智能体可高效查询完整历史推理状态，解决线性记忆范式中的状态盲区和冗余检索问题，同时为强化学习阶段提供拓扑骨架。

### 2.3 拓扑感知策略优化（TAPO）

- **图结构化轨迹分解**：每个推理步骤 t 的策略模型接收图序列化上下文 Ct = {ssys, q, Ht}（Ht = Serialize(Gt−1)），生成对应单个图节点的推理段 st = (Ct, ζt, At, Ot) → nt，完整rollout轨迹分解为有序段序列 Ψ = {s1, s2, ..., s_{Tv+Tt}, sans}。建立策略梯度信号与图拓扑间的直接结构对应。
- **拓扑驱动的信用分配**：结合二元结果奖励 r ∈ {0, 1}（答案是否匹配真实答案）：
  - **正轨迹（r=1）**：通过从 nans 沿有向边反向遍历至 nroot 识别关键推理路径 ρ*；不在 ρ* 上的节点构成拓扑死端（探索性步骤），抑制其梯度贡献，防止错误强化无目的探索；
  - **负轨迹（r=0）**：识别认识上有价值的节点集 Nval —— nvis类型节点中判定器显示 st=1 的节点确认为有价值，ntxt类型节点由专门的相关性评估器判定——排除 Nval 的负梯度更新，防止模型因其他推理环节的缺陷而错误惩罚有效的检索行为。
- **梯度掩码定义**：ψt = I(r=1)·I(nt ∉ ρ*) + I(r=0)·I(nt ∈ Nval)，ψt=1表示抑制梯度，ψt=0允许正常梯度更新。
- **TAPO目标函数**：J_TAPO(θ) = E[ (1/PG^g=1 ng) Σ^{PG}_{g=1} Σ^{ng}_{i=1} (1−ψg,i) · L_clip(ωg,i(θ), Âg,i) − β·KL[πθ ∥ πref] ]，其中(1−ψg,i)因子根据图的拓扑分析选择性门控各段的梯度贡献。
- **核心机制**：在正轨迹中掩码拓扑死端步骤的梯度，在负轨迹中保留有价值检索步骤的梯度，实现精确的步骤级信用分配，显著优于仅依赖最终结果信号的常规稀疏奖励方法。

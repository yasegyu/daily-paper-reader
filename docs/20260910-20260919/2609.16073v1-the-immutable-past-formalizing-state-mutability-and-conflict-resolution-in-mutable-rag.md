## 摘要
检索增强生成（RAG）作为长时程自主代理的主要记忆架构。然而，将共享记忆视为仅追加流会引入	extit{语义遮蔽}，这是一种关键失败模式，其中冲突的历史观察积累并在统计上主导有效的近期更新。在动态环境中，这导致代理检索并依据过时事实行动，从而产生严重的状态发散。本文形式化了状态可变性的机制，证明标准密集检索存在渐近召回衰减。此外，我们形式化地展示了多数投票陷阱，揭示在语义等价条件下，增加检索上下文窗口通过稀释注意力机制而矛盾地降低生成准确性。为解决此问题，我们引入GC-Mem（记忆垃圾回收），一种严格的推理时一致性协议。不同于启发式时间衰减机制——其不加区分地破坏有效的长期记忆——GC-Mem纯粹依赖时间支配算子（$\Phi_{\mathcal{T}}$）结合矛盾检测来精确切除被遮蔽的上下文。在包含137,760个记忆块和连续累积扫描的严格行为推断基准上进行评估，标准RAG和时间戳重排序基线遭受严重退化。相比之下，GC-Mem经验性地恢复了$>90\%$的冲突解决准确性。我们建立了严格的精确率和召回率部署阈值，确保在标准可变RAG根本失败的情况下实现状态收敛。

## Abstract
Retrieval-Augmented Generation (RAG) serves as the primary memory architecture for long-horizon autonomous agents. However, treating shared memory as an append-only stream introduces \textit{Semantic Shadowing}, a critical failure mode where conflicting historical observations accumulate and statistically dominate valid recent updates. In dynamic environments, this results in severe state divergence as agents retrieve and act upon obsolete facts. This paper formalizes the mechanics of State Mutability to prove that standard dense retrieval suffers from Asymptotic Recall Decay. Furthermore, we formally demonstrate a Majority Vote Trap, revealing that increasing the retrieval context window paradoxically degrades generation accuracy by diluting the attention mechanism under conditions of semantic equivalence. To resolve this, we introduce GC-Mem (Garbage Collection for Memory), a strict inference-time consistency protocol. Unlike heuristic time-decay mechanisms---which indiscriminately destroy valid long-term memory---GC-Mem relies purely on a temporal dominance operator ($Φ_{\mathcal{T}}$) paired with contradiction detection to surgically excise shadowed context. Evaluated across a rigorous, behaviorally inferred benchmark of 137,760 memory chunks and continuous accumulation sweeps, standard RAG and timestamp re-ranking baselines experience severe degradation. In contrast, GC-Mem empirically recovers $>90\%$ conflict resolution accuracy. We establish strict precision and recall deployment thresholds, ensuring state convergence where standard mutable RAG fundamentally fails.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：检索增强生成（RAG）已成为长时程自主代理（long-horizon autonomous agents）的共识性记忆架构。然而，标准 RAG 隐含假设知识库是静态的，但在真实世界部署中，记忆是"仅追加流"（append-only stream），实体的事实状态随用户交互不断改变（如用户偏好、项目目标、基础设施状态等）。
- **核心失败模式——语义遮蔽（Semantic Shadowing）**：当实体状态发生更新时，历史状态并未被删除。由于新旧状态在语义上等价但逻辑上矛盾，密集检索会将统计上占多数的过期（stale）块返回，导致代理基于过时信息行动，引发严重的状态发散（state divergence）。
- **三个核心理论贡献**：
  - **定理1（渐近召回衰减）**：有效状态的召回率随交互历史的增长而渐近趋近于零（\(E[X] = k\frac{M}{N+M} \to 0\)）。随着对某一属性的历史交互（N）无限增长，旧状态块在语义空间中占据统计主导，导致有效新状态块几乎无法被检索到。
  - **定理2（多数投票陷阱）**：即使有效块被成功检索（如 k−1 个旧状态块 + 1 个新状态块），LLM 注意力机制在语义等价条件下无法区分新旧状态，生成概率 \(P(y = S_{old}) \propto \frac{k-1}{k}\)，即注意力质量被稀释，生成仍然失效。
  - **定理3（多因素记忆评分根本违反状态收敛）**：引入使用频率（usage）、稳定性（stability）等多因素评分会系统地保护已扎根的历史错误，导致状态收敛失败。
- **整体含义**：论文首次形式化证明了"标准可变 RAG 在长期动态环境中根本性失败"这一论断，揭示了增大检索上下文窗口反而降低生成准确性的"悖论"。

## 2. 方法论：GC-Mem 协议（Garbage Collection for Memory）

### 2.1 核心思想
- GC-Mem 是一个轻量级的**推理时一致性协议**，在生成之前精确移除检索上下文中被遮蔽（shadowed）的过期矛盾块，而**不依赖**启发式时间衰减或参数编辑。

### 2.2 记忆架构与候选检索
- 每次多轮会话被分割并嵌入（使用 all-MiniLM-L6-v2 固定句编码器），填充中时记忆（MTM）向量索引；可选支持短时记忆（STM）FIFO 缓冲区（镜像最近 N 个块）。
- 查询时执行多查询扩展（multi-query expansion）以缓解单嵌入偏差；MTM 返回 top-k 相似块，与 STM 缓冲区块做并集并去重，形成冻结候选集 \(R_k\)。此 \(R_k\) 在所有对比方法中保持一致，确保实验严格对等。

### 2.3 冲突检测与时间支配
- 每个条目表示为元组 \(m_i = (c_i, \tau_i, r_i)\)，其中 \(\tau_i\) 为严格时序时间戳，\(r_i\) 为检索相关性。
- 定义冲突函数 \(\kappa(c_i, c_j) \in \{0,1\}\)，使用成对自然语言推理（NLI）启发式方法判断两句是否相对查询逻辑矛盾，复杂度为 \(O(|R_k|^2)\)。

### 2.4 时间支配算子 \(\Phi_{\mathcal{T}}\)
\[
\Phi_{\mathcal{T}}(R_k) = \{c_i \in R_k \mid \nexists c_j \in R_k : \kappa(c_i, c_j)=1 \land \tau_j > \tau_i\}
\]
- 该算子确保：只要至少一个有效新状态块被检索到，所有更旧的矛盾块均被精确剔除，打破多数投票陷阱，迫使 \(P(y = S_{new}) \to 1\)。
- 支持链式状态突变（A→B→C）：由于 \(\Phi_{\mathcal{T}}\) 强制执行 \(\tau_{new} > \tau_{old}\)，链式矛盾可动态收敛到最终有效状态。

### 2.5 关键设计原则
- **纯粹时间支配**：仅依赖时间戳 + 矛盾检测，**不引入**使用频率、稳定性等多因素评分（实验证明这些因素导致严重崩溃）。
- **推理时操作**：不修改模型参数（区别于 ROME/MEMIT 参数编辑），无训练成本。

## 6. 主要结论与发现

- **语义遮蔽是致命的**：标准 RAG 在长时程动态环境中，冲突解决精度低至 15-29%（甚至 10% 以下），且随历史累积恶化。
- **时间复杂度启发式失效**：时间戳重排序/时间衰减在 STM=off 时表现极差（与基线持平或更差），在 STM=on 时可达标但无法根治上下文矛盾。
- **GC-Mem 恢复 >90% 冲突解决精度**：在最优条件下（如 DeepSeek-V3 大数据集 97.3%、o4-mini 中数据集 92.1%），显著优于标准 RAG（56.8%、28.9%）和时间戳重排（20.3%、10.5%）。
- **STM 放大 GC-Mem 价值**：启用 STM 将新状态块召回率从 ~37% 提升至 ~98%，同时提升了标准 RAG 和 GC-Mem，但 GC-Mem 优势进一步扩大（ΔGC 从 +15.8p 增至 +22.0p）。
- **多因素评分数学性失败**：引入使用频率 (γ) 导致精度从 94.7% 崩溃至 10.5%，确认时间支配是唯一正确路径。
- **检测器依赖明确**：GC-Mem 的效力严格受底层模型矛盾检测能力的**召回率**约束。召回率 >50% 是有效部署硬性前提；召回率过低（如 gpt-4.1-mini 召回 0.7%）时协议无效。
- **Bag-of-Facts 暴露根本脆弱性**：当所有新旧块直接置于上下文，标准 RAG 准确率崩溃至平均 12%，而 GC-Mem 每查询平均剪除 13-15 个遮蔽块，提升 +42.4pp。

## 8. 不足与局限

- **合成数据偏差**：基准虽刻意设计行为推断约束，但仍为合成环境，聚焦于单属性突变（single-attribute mutations），未见实有机交互日志验证。
- **并发多实体突变未覆盖**：未验证当多个实体同时状态突变时的级联效应与检索相互干扰，这是多代理真实部署的关键场景。
- **冲突检测依赖模型能力**：GC-Mem 本质上是"认知卸载协议"，其上限被底层模型的 NLI 能力（尤其召回率）严格约束，对低能力模型（如 gpt-4.1-mini）完全失效，甚至可能恶化（混合上下文导致生成更混乱）。
- **延迟并非无条件可忽略**：启用 STM 后每实例延迟达 15.0-26.6 秒，虽低于自我反思循环，但对超低延迟实时交互场景可能无法满足（作者自行承认）。
- **粒度限制**：仅处理检索块层面的成对矛盾，未考虑一个块内部包含多个属性/多个状态转换的复杂情况。
- **标注与参数选择敏感性**：κ 检测采用启发式 NLI 提示（CONFLICT_DETECTION_SYSTEM_PROMPT），其阈值和措辞对结果有显著影响；"倾向 CONTRAICT（假阴性比假阳性更危险）"的设定可能引入特定方向偏差。
- **单属性假设**：多数实验以一个属性为查询目标，未充分评估跨属性交叉干扰（distractor 块被检索进来会进一步稀释注意力）。

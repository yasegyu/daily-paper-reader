## 摘要
记忆系统正成为大语言模型智能体的核心组件，但构建和维护记忆仍然代价高昂，因为这依赖于对大型专有语言模型的重复调用。这一成本为大规模部署具有记忆增强能力的智能体设置了主要障碍。在本文中，我们提出了伪自蒸馏（PSD）框架，该框架通过多阶段训练流程，使小语言模型（SLM）能够从强大的黑盒Oracle中蒸馏行为，从而构建层次化记忆表征。标准蒸馏方法需要访问教师模型的logits或隐藏状态，而封闭模型不会暴露这些信息。与传统的自蒸馏设置（其中监督信号来自模型自身的预测、采样轨迹或聚合输出）不同，PSD实现了单模型蒸馏设置，同时通过提示将外部Oracle知识注入。PSD在一个单一小模型中扮演两个角色：教师角色看到包含Oracle答案作为参考上下文的特权提示，而学生角色仅看到任务提示。学生学习重现教师的输出分布，在无需访问Oracle内部结构的情况下，将Oracle引导的行为吸收到自身权重中。在LoCoMo上，经过PSD训练的Qwen3-0.6B、1.7B和4B模型在下游检索任务上达到或超过GPT-4.1-mini，而部署成本仅为其一部分，其中离策略PSD在大多数条件下取得了最强结果。我们进一步证明，尽管学生仅在LoCoMo上训练且未接触LongMemEval数据，这种记忆构建能力仍可迁移至分布外的LongMemEval。

## Abstract
Memory systems are becoming a core component of LLM agents, but constructing and maintaining memory remains expensive because it relies on repeated calls to large proprietary language models. This cost creates a major barrier to deploying memory-enhanced agents at scale. In this paper, we present Pseudo Self-Distillation (PSD), a framework that enables small language models (SLMs) to construct hierarchical memory representations by distilling behavior from a strong black-box oracle through a multi-stage training pipeline. Standard distillation methods require access to teacher logits or hidden states, which closed models do not expose. Unlike conventional self-distillation settings, where supervision is derived from a model's own predictions, sampled rollouts, or aggregated outputs, PSD enables a single-model distillation setup while channeling external oracle knowledge through the prompt. PSD uses a single small model in two roles: a teacher that sees a privileged prompt containing the oracle's answer as reference context, and a student that sees only the task prompt. The student learns to reproduce the teacher's output distribution, absorbing oracle-guided behavior into its own weights without accessing the oracle's internals. On LoCoMo, PSD-trained Qwen3-0.6B, 1.7B, and 4B match or exceed GPT-4.1-mini on downstream retrieval at a fraction of the deployment cost, with off-policy PSD achieving the strongest results across most conditions. We further show that this memory-construction capability transfers out-of-distribution to LongMemEval, despite the students being trained exclusively on LoCoMo with no exposure to LongMemEval data.

- **背景**：LLM 智能体在长时交互中必须持续保留、组织和复用信息，记忆系统因此成为现代智能体架构的核心组件。层次化记忆架构（如 MEMORA）在长时基准上取得领先性能，但构建高质量记忆表征的代价极高。

- **直接挑战**：
  - 小模型直接替换专有模型时，结构化输出频繁失败（格式错误、无效 JSON、缺失字段、截断生成）。
  - 错误在管道各阶段之间传播累积，导致下游检索质量大幅下降。
  - 现有蒸馏方法大多假设可访问教师模型的内部信息（logits、隐藏状态），而专有黑盒模型不暴露这些信号。

## 2. 方法论：Pseudo Self-Distillation (PSD)

### 2.1 核心思想

PSD 的出发点是一个简单观察：**当模型获得高质量参考答案时，其输出分布会向与参考一致的方向偏移**。基于此，PSD 使用**单一小模型扮演两个角色**，通过提示不对称实现外部 Oracle 知识的注入与吸收：

- **教师角色**：看到任务提示 + 特权参考上下文（即 Oracle 的答案）
- **学生角色**：仅看到任务提示

训练目标是最小化两者的输出分布差异，从而无需访问 Oracle 内部结构即可将 Oracle 知识蒸馏到学生权重中。

### 2.2 技术流程

PSD 分为两大阶段，以 MEMORA 的五个记忆构建阶段（分割、情景记忆、事实提取、线索锚点、更新决策）为基础，全流程覆盖。

**阶段一：Oracle 数据收集**

以 GPT-4.1-mini 为骨干运行完整 MEMORA 管道，记录每个阶段的输入上下文和格式化输出，构建带阶段标签的 Oracle 数据集 D_oracle。

**阶段二：监督微调（SFT）**

- 使用 Qwen 调优提示词对 Qwen 学生模型进行监督微调，在 Oracle 数据上训练。
- 由于各阶段在数据集中分布不均（分割 ≪ 情景 ≪ 事实 ≈ 线索），采用**每阶段等量采样**进行均衡。
- SFT 同时实现双重目标：教会 Qwen 记忆构建任务，并使其输出 token 分布与 GPT-4.1-mini 的格式和措辞习惯对齐。

**阶段三：伪自蒸馏（PSD）**

- 从 SFT 检查点初始化教师和学生两个角色（θT ← θSFT，θS ← θSFT）。
- 仅更新学生适配器参数；教师适配器**冻结**，防止目标分布漂移并充当正则项。
- 学生仅获得任务提示；教师获得任务提示 + Oracle 答案作为特权上下文。
- 使用温度缩放 softmax 分布，默认采用 **Jensen–Shannon Divergence**（JSD，带权重参数 β）。
- 根据 rollout 由谁生成，分为三种变体：
  - **On-policy PSD**：学生生成 rollout，教师和学生对该轨迹打分——消除训练/推理分布不匹配。
  - **Off-policy PSD**（效果最好）：教师生成 rollout——轨迹由 Oracle 锚定，监督信号质量最高。
  - **Mixed PSD**：两者加权插值（超参 π 控制）。

## 6. 主要结论与发现

1. **PSD 显著优于 SFT**：在所有 Qwen3 规模上，PSD 相比 SFT 进一步提升 LLM-judge 得分（0.6B：0.7674→0.8211；1.7B：0.7805→0.8211；4B：0.7805→0.8699）。

3. **Off-policy 效果最好**：off-policy PSD > mixed PSD > on-policy PSD。on-policy 因学生自身错误的跨阶段传播导致性能低于 SFT 基准。
4. **OOD 迁移可行但有局限**：PSD 训练的 Qwen3-4B 在 LongMemEval 上达到 77.0% 平均分，超过 Full Context 和 Nemori，但低于 MEMORA 基线；**PSD 在 OOD 场景下未一致优于 SFT**——蒸馏的 LoCoMo 特有细化对跨数据集迁移贡献有限。

## 7. 方法优点

- **真正的黑盒蒸馏**：无需访问教师模型的 logits、隐藏状态或任何内部表示，仅通过文本级监督即可实现——解决了专有模型蒸馏的关键约束。
- **单模型双角色设计**：巧妙利用"参考答案改变输出分布"的观察，在一个模型内实现教师-学生分离，无需额外的大模型在线查询——同时降低训练和推理成本。
- **冻结教师策略**：防止目标分布漂移并提供正则化，保持学生靠近 SFT 解，训练稳定性好。
- **三种 rollout 变体提供灵活性**：off-policy 更利于监督质量，on-policy 更贴近推理分布，mixed 可自适应调度。
- **系统性验证 OOD 泛化**：通过在 LongMemEval 的零样本评估，证明了蒸馏的记忆构建能力可跨数据集迁移，而非简单的过拟合。
- **广泛的模型规模覆盖**：验证了从 0.6B 到 4B 不同规模下方法的有效性梯度。

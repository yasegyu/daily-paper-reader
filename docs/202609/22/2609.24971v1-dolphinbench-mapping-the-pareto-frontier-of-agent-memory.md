## 摘要
当前的智能体常常会执行依赖于长期记忆和随时间进行上下文回忆的真实世界行动。然而，大多数现有的记忆基准测试都是为对话式问答格式设计的，在这种格式中，问题本身提示必须检索某个事实，且往往还提示是哪一个。此外，基准测试很少要求提交内容在准确率之外的东西，使得记忆系统可以通过不合理的时间/成本权衡来取得更高的分数。我们提出了DolphinBench，一个通过智能体任务完成情况直接评估记忆的基准测试。DolphinBench包含三个知识工作人设，每个人设约有50万tokens的用户消息，并评估智能体在依赖于该历史信息的任务上的表现。我们通过分别在有和没有相关历史信息的情况下运行智能体来验证每个人设的所有200个任务，要求在具有历史信息时成功执行，而在缺乏历史信息时则失败。最后，我们要求所有评估在报告准确率的同时报告总成本与延迟，这使我们能够全面评估智能体记忆系统。没有现有的记忆基准测试能同时结合这三者。数据集和评估代码可在https://dolphinbench.ai获取。

## Abstract
Agents today often take real-world actions that depend on long-term memory and context recall over time. However, most current memory benchmarks are built for a conversational question-answer format, where the question itself signals that some fact must be retrieved, and often which one. Moreover, benchmarks rarely require anything beyond accuracy from submissions, allowing memory systems to make unreasonable cost/time tradeoffs to achieve higher scores.   We present DolphinBench, a benchmark that evaluates memory directly through an agent's task completion. DolphinBench includes three knowledge-work personas with roughly 500k tokens of user messages per persona and evaluates agents on tasks that depend on information from that history. We verify all 200 tasks per persona by running an agent with and without the relevant history, requiring success with it and failure without it.   Finally, we require all evaluations to report total cost and latency alongside accuracy, which enables us to evaluate agent memory systems holistically. No existing memory benchmark combines all three. The dataset and evaluation code are available at https://dolphinbench.ai.

## 1. 核心问题与整体含义（研究动机和背景）

- **现有记忆基准的三大缺陷**：
  - **格式偏差**：主流基准（如LoCoMo、LongMemEval、MemoryBank）采用对话问答格式，问题本身即向系统提示"需要检索事实"甚至具体是哪个事实，这使得最困难的一步——识别何时需要检索——由评测格式替系统完成了。实际智能体在收到行动指令时，不会获得这种显式检索信号。
  - **指标单一**：大多数基准只要求报告准确率，完全忽略成本和延迟。这使得系统可以通过在每次查询中重读全部历史等计算昂贵的方式提高准确率，而这种方式在真实生产部署中不可持续。
  - **测试有效性缺失**：大量合成生成的基准存在错误答案键、错误标注的证据、以及即使给定完整历史也无法回答的问题。没有基准验证每个测试项是否真正可由具备完美记忆的智能体解决，导致所有得分的上限未知。
- **DolphinBench的核心主张**：智能体记忆评测必须同时满足三个条件——以行动（而非问答）作为测试格式、同时报告准确率+成本+延迟、验证每个测试项在有无相关历史时分别成功与失败。

## 6. 主要结论与发现

- **最高分**：Hermes+GPT-5.6-Luna+Mem0达到最高准确率70.67%，显著领先其他配置。
- **记忆系统排名存在配置依赖性**：Mem0在Hermes（两个模型）下得分最高，Honcho在Claude Code下得分最高。这说明记忆系统不能脱离底层模型单独评价。
- **更准不必更慢**：Hermes+GPT-5.6-Luna+Mem0相比内置记忆提高5个百分点准确率的同时，中位延迟从44.35秒降至37.69秒（总成本从$61.48升至$96.21）。
- **更贵不必更准**：Hindsight比Honcho便宜且准确率高1个百分点，但延迟多10.65秒。Supermemory成本最高（$345.64）但准确率最低（59.17%）。
- **成本与延迟的分离**：准确率、成本、延迟三者在帕累托前沿上的分布非线性。

## 7. 优点

- **行动导向测试**：DolphinBench是首个将真实任务完成（而非问答）作为记忆评测信号的基准，要求智能体"知道何时需要回忆"。
- **三重可解性验证**：每个测试均经有/无历史信息的双条件验证，排除了错题、免记忆可解等问题，保证了有效的评测上限。
- **三维指标**：准确率+成本+延迟的同时报告使系统比较更全面，防止成本转嫁取分的投机行为，支持帕累托前沿分析。
- **分层可控的构建流程**：从角色到消息到测试的自顶向下流程，既有LLM辅助的扩展性，又有人工审阅的保真性。
- **面向实用性**：模拟历史数据量达50万tokens/人设，超过主流上下文窗口；场景覆盖多样工具，贴近真实知识工作。

## 8. 不足与局限

- **合成数据的固有偏差**：对话由LLM生成，可能无法完全反映真实用户的写作风格、语言多样性和交互模式。事实虽经检查，残留不一致难以完全避免。
- **领域覆盖有限**：仅三个知识工人设，未覆盖法律、医疗、长周期客服等需要记忆的领域，通用性有待扩展。
- **模拟环境的简化**：模拟应用仅支持选定的操作和错误，不包含停电、第三方并发变更等真实生产环境的复杂情况。
- **任务长度限制**：每个任务仅需1-4个已评分的行动，不测试多步依赖的长期流程，记忆在复杂工作流中的作用尚未充分评估。
- **摄取与测试分离**：智能体先处理全部历史再接受测试，不符合真实部署中持续摄入+间歇测试的模式，未测试记忆的持续性更新与维护。
- **配置结果不稳定**：记忆系统排名随底层模型而变化，提示当前记忆系统泛化能力有限，也对部署选择构成挑战。
- **未报告统计不确定性**：没有重复运行和置信区间，单一运行的结果可能存在方差。

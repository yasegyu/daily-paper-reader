## 摘要
智能体记忆对于长周期AI智能体正变得至关重要，然而许多现有系统依赖自回归LLM来控制记忆的组织、检索和使用方式，将昂贵的生成过程置于记忆操作的关键路径上。我们引入了\textbf{\method}，一种受系统一/系统二认知启发的新型智能体记忆架构。系统一负责快速、轻量级的决策，而系统二则执行较慢的、深思熟虑的推理。Jev-Mem通过专用的系统一控制平面、结构化的多关系记忆平面以及系统二推理平面，将这种分工引入到智能体记忆中。系统一控制器在构建阶段管理记忆类型和关系组织，并在检索阶段动态执行查询路由、检索预算分配、图遍历、候选评分和自适应停止。系统二仅在复杂推理和答案合成时被调用。这种设计同时提升了记忆效果和系统效率：在LoCoMo上，Jev-Mem的LLM-as-a-Judge综合评分为0.777，相比最强基线相对提升11.0%，同时将记忆构建时间缩短至158秒，比最快的竞争记忆系统提速6.6倍，并将平均查询延迟降至0.93秒，降低36.7%。

## Abstract
Agentic memory is becoming essential for long-horizon AI agents, yet many existing systems rely on autoregressive LLMs to control how memories are organized, retrieved, and used, placing expensive generation on the critical path of memory operations. We introduce \textbf{\method}, a new agentic memory architecture inspired by System-One/System-Two cognition. System One captures fast, lightweight decision-making, whereas System Two performs slower, deliberative reasoning. Jev-Mem brings this division of labor to agentic memory through a dedicated System-One control plane, a structured multi-relational memory plane, and a System-Two reasoning plane. The System-One controller governs memory typing and relational organization during construction, and dynamically performs query routing, retrieval-budget allocation, graph traversal, candidate scoring, and adaptive stopping during retrieval. System Two is invoked only for complex reasoning and answer synthesis. This design improves both memory effectiveness and system efficiency: on LoCoMo Jev-Mem achieves an overall LLM-as-a-Judge score of 0.777, an 11.0\% relative improvement over the strongest baseline, while reducing memory construction time to 158\,s, a 6.6$\times$ speedup over the fastest competing memory system, and lowering average query latency to 0.93\,s, a 36.7\% reduction.

## 1. 核心问题与研究动机

- **背景**：大语言模型（LLM）智能体需要在长期交互中持续积累用户偏好、任务历史和知识，但固定上下文窗口无法容纳日益增长的信息，扩大上下文长度也无法从根本上解决问题（模型无法可靠利用超长输入的全部位置）。
- **核心问题**：现有智能体记忆系统在控制记忆构建与检索时，要么依赖固定启发式规则（高效但缺乏灵活性），要么反复调用自回归LLM进行语义决策（灵活但产生大量token开销）。记忆控制因此沦为系统延迟和推理开销的主要来源。
- **关键洞察**：许多记忆操作（记忆分类、关系判断、查询路由、候选评分、停止决策）是**语义性但非生成性**的，输出空间受限（标签、概率、分数），无需LLM逐token生成。这为系统一（轻量快速）与系统二（深度推理）的架构分工创造了天然机会。

## 2. 方法论：Jev-Mem架构

### 核心思想
借鉴认知科学中的双过程理论（系统一/系统二），将**记忆控制**与**生成式推理**分离：专用系统一控制器负责高频、结构化、有界输出的记忆决策，系统二仅用于复杂推理和答案合成。

### 三大组件
1. **系统一控制平面**：基于类型化概率决策（typed probabilistic decisions）接口 `J(S, Q)`——给定结构化状态与一组显式决策问题，返回命题概率或互斥选项分布。一次批处理可并行评估多个共享状态的决策。
2. **共享记忆数据平面**：维护规范观察节点 Vₜ 及四种关系视图（语义、时序、因果、实体），各视图共享同一节点集合，多种类型边可共存。辅以向量索引和词法索引作为查询入口。
3. **系统二推理平面**：仅负责最终证据综合与答案生成。

### 记忆构建（写路径）
- 保留所有观察（不预设判断信息重要性），每个有效观察创建规范节点。
- 控制器预测四种重叠记忆类型：情境性、语义性、程序性、偏好性。
- **候选发现与关系判断分离**，避免成本随记忆规模线性增长：
  - 确定性检索（向量相似度、词法重叠、共享实体、时间邻近度）选出至多 K_w 个候选；
  - 系统一仅对候选对评估语义相关性、因果方向、同会话归属、实体等价性；
  - 关系得分 ≥ θ_rel 时插入对应类型边；时间戳排序直接产生时序关系，完全共享的实体标识直接产生实体关系。
- 定期维护在限定邻域内检测冗余、矛盾、过时和潜在链接；系统二仅在明确的合并/提升决策被批准后才用于生成更高层抽象。

Jev-Mem 是一篇**问题洞察深刻、架构设计优雅、工程实现完整**的论文。它以双过程认知理论为灵感，将“语义但非生成性”的记忆控制操作从代价高昂的LLM生成过程中剥离，巧妙地化解了记忆系统在灵活性与效率之间的矛盾。实验结果表明，这一设计思路不仅在效率上获得了显著提升（构建加速6.6倍、查询延迟降低36.7%），在质量上也超过了当前最强的基线（整体评分相对提升11%），尤其在高难度的多跳推理、开放域检索和对抗性干扰场景中表现突出。

论文的主要不足体现在实验验证的广度（单基准、无消融）和实现对专有系统的依赖上，但这并不妨碍其核心思想对后续记忆系统设计的重要参考价值。对于从事LLM智能体记忆、检索增强生成或认知架构研究的学者而言，这篇论文提供了一个值得深入借鉴的架构范式：**用更小、更快的专用模型承担结构性决策，让LLM专注于它真正擅长的生成式推理。**

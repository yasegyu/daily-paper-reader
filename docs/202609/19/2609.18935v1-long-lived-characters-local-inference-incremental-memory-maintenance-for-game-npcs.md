## 摘要
游戏角色不应在每次对话前重读其整个生命历程。然而，对于本地部署的语言模型角色，修改少量记忆可能使长可复用前缀失效。由此产生的准备成本与前景对话及其他角色的维护相竞争。当对话驱动游戏定义的动作和价值判断时，这一点尤为重要：一个流畅但错误地描述物品归属或转移是否已发生的叙述，可能破坏原本确定性规则的输入。我们研究了在量化Qwen混合循环注意力模型中，长寿命游戏NPC的增量记忆维护。我们的运行时移除被取代的注意力键值条目，在真实序列尾部计算替换记录，并保留持续的循环状态和未改变的键值。现有局部实验结合多更新对话重放、固定输入位置消融和注意力诊断。独立块组合削弱了查询条件记忆选择，没有统一的块初始注意力崩溃。真实尾部更新在八轮脚本化维护中保持了重要的当前状态和历史绑定；一个位置案例在三次重建中恢复了完全填充数量，而插槽保持替代方案重复了双重减法错误。仅凭注意力分布接近性无法解释这些语义差异。结果促使将角色的推理状态视为一种可维护的、依赖历史的资源，而非仅是其最新记忆文本的可丢弃编码。

## Abstract
A game character should not have to reread its entire life before every conversation. For locally deployed language-model characters, however, revising a few memories can invalidate a long reusable prefix. The resulting preparation cost competes with both foreground dialogue and the maintenance of other characters. This matters especially when dialogue feeds game-defined actions and value judgments: a fluent but incorrect account of who owns an item, or whether a transfer has already happened, can corrupt the input to otherwise deterministic rules. We study incremental memory maintenance for long-lived game NPCs in a quantized Qwen hybrid recurrent-attention model. Our runtime removes superseded attention KV entries, computes replacement records at the true sequence tail, and preserves the continuing recurrent state and unchanged KV. Existing local experiments combine multi-update dialogue replays, fixed-input placement ablations, and attention diagnostics. Independent block composition weakens query-conditioned memory selection without a uniform chunk-initial attention collapse. True-tail updates preserve important current-state and historical bindings across eight scripted maintenance rounds; a placement case recovers the full-refill quantity in three reconstructions, while slot-preserving alternatives repeat a double-subtraction error. Attention-distribution proximity alone does not explain these semantic differences. The results motivate treating a character's inference state as a maintained, history-dependent resource, rather than only a disposable encoding of its latest memory text.

## 论文核心问题与整体含义

**研究动机与背景**

- 游戏NPC（非玩家角色）在对话中需要长期记忆，但传统做法在每次对话时“重读整个生命历程”（即重新处理全部上下文），成本和效率问题突出。
- 对于一个本地部署的语言模型（LLM）角色，即使修改少量记忆内容，也会使此前计算好的长KV Cache前缀失效，迫使系统从头重建完整的上下文。
- 这种重建产生的“准备成本”既占用前台对话的计算资源，也影响其他NPC的维护工作。
- 更严重的是，当对话需要驱动游戏规则（如物品所有权、资源数量、交易是否已完成）时，一个流畅却语义错误（如把已有物品再次扣除）的叙述，会破坏确定性游戏规则的输入，导致逻辑层面错误。

**整体结论**

- 论文主张：**NPC的推理状态应被视为一种可维护的、依赖历史的资源**，而非一个可以随意丢弃的最新媒体文本编码。

## 论文方法论

**核心思想**

- 在量化Qwen混合循环-注意力模型上实现“增量混合状态维护”：在逻辑上删除被取代的记忆记录，在真实序列尾部计算替换记录的KV，并保留未被修改部分和循环状态，从而避免全量重算。

**关键技术细节**

1. **两种状态结构，两种生命周期**
   - 注意力KV元组（Attention Cache）与循环/卷积状态（Recurrent/Convolution State）具有不同的生命周期。
   - 更新时，移除被替代记录的直接KV（公式(2)），然后从尾部追加新记录，计算新的KV和循环状态（公式(3)）。
   - 删除了旧记录的直接KV，并不能完全“抹除”其在循环状态中的间接历史影响——这是访问控制，不等同于彻底遗忘。

2. **记录寻址运行时**
   - 每条记录都有稳定的语义ID和动态token跨度映射，运行时校验删除范围，保留无关KV。
   - 更新记录的RoPE位置使用真实的新尾位置，而非将旧位置旋转回旧槽位。
   - 位置元数据继续单调增长，KV占用则保持有界。

3. **计算节省**
   - 未修改记录不重新编码，只有替换文本的编码和注意力计算需要新开销；这与全量重算有本质区别。

## 主要结论

1. **独立块组合会削弱选择性记忆检索**：目标记忆受注意力比例从57.4%（计算链式）降至21.5%，且出现事件-时间绑定错误（“昨夜”与“今晨”混淆）。
2. **真尾维护能保持历史与当前绑定**：8轮有损更新后仍能正确回答“过去温情与现在危险并存”等复杂关系，也能正确推导药材剩余数量。
3. **位置安排影响状态-事件绑定**：保留原槽位导致重复扣减错误，尾部计算正确恢复数量；`tail-and-relocate` 方法仍出错，说明纯key旋转不足以修复。
4. **注意力分布接近 ≠ 语义正确**：分布差异小的维护路径反而变错误，差异大的反而正确；注意力相似性不能作为语义验证。

## 优点

1. **问题定义清晰、切中实际部署痛点**：从用户本机算力有限出发，而非抽象地追求benchmark分数。
2. **方法不修改权重**，纯运行时干预，实用性强。
3. **实验分层合理**：固定输入与自由生成分开，注意力诊断与行为记录分开，避免误导性归因。
4. **坦承风险与局限**：不夸大遗忘能力，不声称普遍准确，不混淆速度与正确性。
5. **对游戏逻辑的考虑深入**：将记忆错误与规则引擎输入直接关联，提出“语义连续性”而非“输出一致性”这一合理指标。

## 不足与局限

1. **实验规模有限**：仅一个角色、单一世界观、有限次数的更新；无多角色团体评价，无大规模用户研究。
2. **量化本身带来的误差**：Q3_K量化会带来数值偏差，未讨论量化对维护操作敏感性的影响。
3. **无完全配对的8轮更新对照**：缺乏free-run对话的full-refill对照轨迹，无法将部分下游错误明确归因于维护。
4. **遗忘保证缺失**：保留循环状态可能残留已删除记录的影响，未做对抗性删除测试。
5. **计算规模未扩展**：模型未做大模型或不同参数量级、不同量化精度的系统比较。
6. **位置轨迹无限增长**：位置ID单调递增，无长期处理方案，限制了超长寿命角色。

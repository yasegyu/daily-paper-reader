## 摘要
个性化智能体需要推理长期历史交互，以推断显性偏好和隐性行为证据。早期的扁平检索方法独立地对记忆片段进行评分，忽略了分布式信息，而当前的结构化记忆框架依赖于与查询无关的静态图，无法捕捉上下文相关的关联。关键在于，原始文本记忆本质上具有纠缠性和噪声性，使得细粒度个性化和跨会话推理在计算上难以实现。为此，我们提出LGM，一种新颖的神经符号框架，将长期记忆解缠转移到连续潜在空间中。具体而言，(i) 我们不持久化固定图，而是设计了一种带有稀疏自编码器的定制潜在图构建。针对每个查询，它将历史交互映射到潜在记忆节点，并将记忆痕迹解缠为稀疏概念激活，动态合成查询感知的关系边权重。(ii) 随后，图编码器将查询嵌入视为条件偏好，以指导跨任务特定潜在子图的非线性消息传递。这产生了高度表达性的记忆表示，用于有效激活。在长期个性化基准上的大量实验表明，LGM在捕获显性和隐性偏好方面显著优于最先进的基线，同时能够实现个性化响应。

## Abstract
Personalized agents are required to reason over long-term history interactions to infer both explicit preferences and implicit behavioral evidence. While early flat retrieval methods score memory fragments independently and neglect the distributed information, current structured memory frameworks rely on query-agnostic static graphs that fail to capture the context-dependent relations. Crucially, raw textual memories are inherently entangled and noisy, making fine-grained personalization and cross-session reasoning computationally prohibitive. To this end, we present LGM, a novel neuro-symbolic framework that shifts long-term memory disentanglement into a continuous latent space. Specifically, (i) instead of persisting fixed graphs, we design a tailored latent graph construction with a sparse autoencoder. Subject to each query, it maps historical interactions into latent memory nodes and disentangles the memory traces into sparse concept activations, dynamically synthesizing query-aware relational edge weights. (ii) A graph encoder then treats the query embedding as a conditioning preference to direct non-linear message passing across the task-specific latent subgraph. This yields a highly expressive memory representation for effective activations. Extensive experiments on long-term personalization benchmarks demonstrate that LGM significantly outperforms state-of-the-art baselines in capturing both explicit and implicit preferences while enabling personalized responses.

### 1. 论文核心问题与整体含义（研究动机与背景）

个性化智能代理（Personalized Agents）在长期人机交互中需要保持连贯性和一致性，其核心挑战是推理用户的历史交互记录，以同时捕捉**显式偏好**（如具体指令、约束条件）和**隐式偏好**（如行为习惯、潜在决策模式）。

现有方法存在两类根本性缺陷：

- **平面检索范式**：将历史交互视为独立记忆片段，通过向量相似度单独评分，无法整合分布在不同会话中的分布式弱证据（多跳推理能力缺失）。
- **静态结构化记忆范式**（如 GraphRAG 等）：虽然引入图结构，但图的拓扑在构建后即固定不变，与具体查询无关，无法捕捉只有在特定上下文触发下才显现的动态关联。

**根本矛盾**：原始文本记忆天然具有纠缠性（一个交互同时编码主题、意图、情感、习惯等多个因素）和噪声性，在文本空间中做细粒度偏好解缠和跨会话推理会带来不可承受的计算开销（KV缓存膨胀、重复 LLM 调用等）。因此论文提出核心研究问题：**能否按需对用户长期记忆进行解缠和组织，而无需重复回放全部文本历史？**

### 2. 方法论：LGM（Latent Graph Memory）框架

**核心思想**：将长期记忆的解缠、关联推理和利用过程整体迁移到连续潜在空间（latent space），实现端到端可微的神经符号推理。

**关键技术细节与流程**：

- **潜在记忆解缠（Latent Memory Disentanglement）**
  - 将每个交互单元和当前查询映射为共享低维空间中的潜在节点 $z_x$。
  - 使用**稀疏自编码器（Sparse Autoencoder, SAE）**将稠密表示解缠为稀疏概念激活码 $c_x$：
    $$c_x = S(ReLU(W_{enc} z_x)), \quad \hat{z}_x = W_{dec} c_x$$
  - 显式偏好陈述和隐性行为线索在**共享概念空间**中对齐，不受表面词项差异的限制。
  - 多层层级隐藏状态平均聚合（跨层聚合），兼顾低层的词汇线索和高层的语义行为抽象。

- **查询条件潜在图构建（Query-Conditioned Latent Graph Construction）**
  - 不持久化固定图，而是对**每个查询动态构建**其专属潜在图 $G(q)$。
  - 边权重由查询概念码与记忆概念码的**概念重叠度**决定：
    $$\omega_{q \to i} = \phi(c_q, c_i) \in [0,1]$$
  - 同一记忆池在不同查询下可形成不同拓扑结构，实现真正的上下文依赖动态建图。

- **图条件推理（Graph-Conditioned Reasoning）**
  - 使用**关系图神经网络（Relational Graph Network）**进行 $T$ 步消息传递，将分散的弱线索汇聚为紧凑图状态 $g$。
  - 通过投影器将 $g$ 映射为少量潜在前缀 token（默认16个），预置于查询嵌入之前，以紧凑通道影响生成，避免回放完整历史。
  - 引入**证据重构损失（Evidence Reconstruction Loss）**防止潜在表示坍缩（信息折叠），确保图状态忠实锚定于历史事实：
    $$\mathcal{L}_{recon} = -\sum_t \log f_\theta(e^\star_t | e^\star_{<t}, [\tilde{P}; E(\rho)])$$

**总体训练目标**：$\mathcal{L} = \mathcal{L}_{gen} + \mathcal{L}_{recon} + \mathcal{L}_{sae}$，整个记忆生命周期（选择、关联、聚合、利用）统一为端到端可微优化。

### 6. 主要结论与发现

- **显著性能提升**：LGM 在 Qwen2.5-7B 上平均准确率达 72.28（较最强基线 MemCoE 提升 +11.20），在 Gemma3-4B 上达 66.16（提升 +11.70）。

- **超越强闭源模型**：仅用 Qwen3-4B 开源 backbone，在 PersonaMem-v2 上以 62.9（32K）/ 51.9（128K）超越 GPT-5 和 GPT-4.1 系列，超过同骨干的 Agentic Memory SOTA +7.7。
- **效率前沿**：LGM 在保持最高准确率的同时，在 LLM 调用次数、Token 消耗和首 token 延迟方面均处于最低成本前沿。
- **证据重构是唯一必需的组件**：消融中去除该损失导致的性能下降最大，是防止潜在表示坍缩的关键。

### 7. 方法优点

- **框架新颖性**：首次将长期记忆解缠和推理系统性地迁移到潜在空间，打破文本空间的局限，属于神经符号（neuro-symbolic）交叉方向。
- **动态查询感知**：摒弃静态图，每个查询诱导专属潜在拓扑，真正实现了上下文依赖的关系捕捉。
- **端到端可微**：记忆的选择、关联、聚合和利用统一为可微优化流程，相较 RL 离散策略更具学习效率。
- **效率导向设计**：潜在前缀 token + 分块编码机制，使记忆增长体现在节点数量而非上下文窗口，在准确性前沿同时占据低成本角落。
- **防坍缩机制**：证据重构损失设计巧妙，直接锚定事实，有效避免了潜在记忆方法常见的"模型忽略前缀"问题。

### 8. 不足与局限

- **推理过程不可解释性**：潜在空间推理虽然高效，但图状态和概念激活的语义可解释性有限，"忠实锚定"的有效性难以从结构上保证（仅由损失函数隐式约束）。
- **隐式偏好评估的覆盖局限**：虽然包含 PersonaMem-v2 的隐式偏好设置，但评估场景仍限定于特定基准，真实世界的隐性偏好模式可能更加多样化和复杂。
- **与闭源模型的比较不完整**：论文中针对同一实验设置的闭源模型对比数据较少，对闭源最佳模型的性能验证主要在 PersonaMem-v2 上。
- **硬件资源门槛高**：默认配置为 7B/4B 模型全量微调，需要 8× H800 等高端算力；虽然提供了 LoRA 变体，但未报道其效果对比。

- **缺乏跨语言和跨域泛化分析**：实验全为英文场景，未讨论在非英文交互中的表现。
- **图状态的信息瓶颈**：理论上潜在图状态的大小是固定的，长历史下是否会出现信息到达瓶颈（尤其当历史规模超出训练分布范围时）未充分验证。

## 摘要
长期记忆正成为个性化AI的核心基础，然而大多数系统仍将个性化表示为静态潜空间中的离散记录，并在单一的全局相似性概念下进行访问。对于数据挖掘而言，这造成了错配：证据是时间事件流，而主导抽象是可搜索的记录集。我们认为，长时程个性化应将记忆建模为具有局部异质几何结构的用户特定动态状态空间。这里的几何是一种计算语言，而非对认知的字面论断：它捕捉稳定区域与易变区域、变速率漂移、异质邻域以及对当前用户状态的不确定性。轮廓和孤立事件作为点仍有价值，但交互、反馈和经过的时间诱发轨迹。记忆访问因此成为轨迹条件下的相关用户状态重建，而不仅仅是最近邻查找。

## Abstract
Long-term memory is becoming a core substrate for personalized AI, yet most systems still represent personalization as discrete records in a largely static latent space, accessed under one global similarity notion. For data mining, this creates a mismatch: the evidence is a temporal event stream, while the dominant abstraction is a searchable record set. We argue that long-horizon personalization should instead model memory as a user-specific dynamical state space with locally heterogeneous geometry. Geometry here is a computational language, not a literal claim about cognition: it captures stable versus volatile regions, variable-rate drift, heterogeneous neighborhoods, and uncertainty about current user state. Profiles and isolated events remain useful as points, but interaction, feedback, and elapsed time induce trajectories. Memory access then becomes trajectory-conditioned reconstruction of the relevant user state, not only nearest-neighbor lookup.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心困境**：个性化AI虽已能支撑数月甚至终身互动，但记忆基础设施严重滞后。对话系统、个性化大模型、自主代理和推荐系统均面临同一瓶颈：当历史数据从会话尺度扩展至终身尺度，个性化效果受限于经验**如何存储、结构化与访问**，而非模型容量本身。
- **本质矛盾**：这是一个数据挖掘问题——源数据是异质、异步、弱标注的用户事件时间流，而现有系统将其抽象为可搜索的静态记录集。这种"时间事件流 vs. 静态记录集"的结构性错配导致：
  - 后续证据会改变早期事件的相关性（时态依赖被忽略）；
  - 局部修正并不需要全局泛化（局部性被破坏）；
  - 检索即使找到相关证据，仍可能估计出错误的当前用户状态。
- **三个隐藏假设（即作者要挑战的对象）**：
  - **A1—离散记录**：记忆是消息、槽位、画像、摘要或嵌入的集合；
  - **A2—均匀几何**：所有条目共享一个潜空间和单一全局相似度度量；
  - **A3—条目级访问**：通过检索或注意力访问存储条目，而非重建用户状态。
- **作者主张**：应当将长时程个性化记忆建模为**用户特定的动态状态空间**，具有**局部异质几何**——即"几何记忆"（Geometric Memory）。几何在此是计算语言而非认知论断，用于捕捉稳定与易变区域、变速率漂移、异质邻域和状态不确定性。

### 2. 论文提出的方法论

#### 核心思想

将个性化记忆形式化为**几何动力系统**：状态空间为流形，其带有的度量张量场在每个位置编码不同的尺度与各向异性，曲率由度量变化导出，不确定性单独建模。

#### 关键技术细节

**形式化定义**：
- 设 \((M, G)\) 为个性化记忆状态空间，其中：
  - \(M\)：类流形状态空间；
  - \(G = \\{g_x\\}_{x\\in M}\)：正定局部度量场，编码各位置的尺度与各向异性。
- 用户在某时刻 \(t\) 的记忆状态为 \(x_t \\in M\)。
- 事件 \(e_t = (o_t, \\Delta t_t)\) 包含交互证据 \(o_t\) 与经过时间 \(\\Delta t_t\)。

**状态更新方程**：
\[
x_t = \\text{Exp}_{x_{t-1}}\\left(g^{-1}_{x_{t-1}} f_\\theta(x_{t-1}, e_t)\\right)
\]
- \(f_\\theta\) 提出切余向量（tangent covector）；
- 逆度量 \(g^{-1}_{x_{t-1}}\) 将其转换为位移；
- 当度量为单位阵时退化为欧氏加法更新（identity-metric 消融的基线）；
- 度量和状态的后验分布表示认知不确定性；更新速率单独学习（类似连续时间动力学，如 Neural ODE）。

**记忆访问方式的转变**：
- 传统记忆访问（记录检索）：\(R(q_t, D_t) = \\text{TopK}_{m_i \\in D_t}\\, s(q_t, m_i)\)
- 几何记忆访问（轨迹条件重建）：
  \[
  \\hat{r}_t = \\int h_\\theta(q_t, x_t, z)\\, p(z \\mid q_t, x_t, \\Gamma)\\, dz
  \]
  - \(z\) 为相关轨迹段；\(\\Gamma = \\{\\gamma_k\\}\) 为轨迹族，每条轨迹追踪用户状态的一段连贯演化（偏好体制、项目、常规或片段）；
  - 输出 \(\\hat{r}_t\) 可驱动响应生成、推荐、行动、适应、置信度判断或弃权决策。

**具体实例——双曲记忆**：
- 双曲空间支持从粗到细的分支结构：粗尺度为广泛稳定倾向，细尺度为具体兴趣、项目或临时体制；
- 用户的初始状态经双曲指数映射/对数映射演化，重建通过测地线段推理完成；
- 但不限定于双曲空间——欧氏、球面、混合曲率、图结构或混合空间均可，核心是**学习几何而非预设某一种度量**。

### 3. 实验设计

**重要说明：这是一篇 BlueSky 议程论文，未开展实际实验**，但提出了详细的未来验证方案。

**提出的验证协议（constructive validation protocol）**：
- 构建带时间戳的事件流，包含：循环角色、渐进偏好漂移、临时例外、休眠项目复苏、真实体制切换；
- 使用已知状态的受控流和用户同意的标注建立可识别行为，再扩展到自然交互日志；
- 按时间划分训练/测试，留出用户，变化时间间隔和证据密度。

**对比基准**：
- 传统记录检索（binary retrieval）；
- 强动态潜状态模型（如 JODIE）；
- 与几何模型共享编码器、路由和转移模型、但使用 identity metric（恒等度量）的消融版本——控制参数数、数据量和记忆预算。

**评估指标**：
- 状态预测误差、陈旧偏好误差、跨角色泄漏、Brier 分数、选择性风险（selective risk）、编辑溢出（edit spillover）、延迟；
- 报告用户级置信区间。

**端到端探针案例（end-to-end probe）**：
- 用户偏好简洁工作邮件 → 要求一次详细拨款提案 → 恢复常规邮件写作；
- 正确的路由应将提案置于临时项目路径上，应保持"简洁邮件"偏好区域与"项目提案"路径之间的位移代价，重建时应两不相误。

**理论假设**：
- H1（horizon sensitivity）：随间隔和体制切换增大，陈旧状态误差更低；
- H2（calibration）：匹配覆盖率下的选择性风险更优；
- H3（sparse evidence）：达到固定状态预测误差所需事件数更少。

### 6. 论文的主要结论与发现

- 长时程个性化的根本瓶颈不是检索质量，而是**抽象本身**——将时间事件流抽象为静态记录集是错误方向。
- 记忆应当建模为**用户特定的动态状态空间，具有非均匀局部几何结构**；几何是计算语言，用于表达稳定与易变区域、变速率漂移、异质邻域与状态不确定性。
- 记忆访问应从"Top-K 检索"转变为**轨迹条件重建**——推断用户当前状态，而非仅找相似条目。
- 关键转变是概念性的但影响深远：记忆访问从"条目查找"变为"轨迹推断"。
- 实现路径明确：公共事件编码器与转移模型 + 用户特定小度量适配器 + 轨迹路由 + 重建解码器；可通过低秩适配、缓存局部图册、近似轨迹搜索实现规模化。
- 可行性保障：身份度量收缩稳定冷启动、决策级可辨识性接受坐标等价模型、离线回放和影子部署供评估后再上线。

### 8. 不足与局限

- **无实证验证**：所有核心主张（包括 H1–H3）均处于假设层面，缺乏任何数据集上的定量结果。作为蓝路论文虽可理解，但实际有效性完全未知。
- **几何隐喻风险**：论文明确指出"几何是计算语言"而非认知论断，但该方法的具体益处——相对于动态嵌入模型的实际优势——尚未被证明。文中自身也承认需要 identity-metric 消融才能隔离几何的贡献。
- **工程复杂度未充分估计**：指数映射、平行传输、曲率估计、轨迹边际化在实时服务中的成本远高于扁平内积；论文虽提及效率工具，但无端到端延迟分析。
- **弱标注问题**：事件流是弱监督数据，路由、分支、合并的决策依赖预测似然和上下文兼容性，这类决策的不确定性如何在实际中控制尚不明确。
- **轨迹分段定义模糊**：什么是"一条轨迹"、何时分支/合并、轨迹粒度如何选择——这些问题缺少形式化准则。
- **跨用户对齐困难**：用户特定的度量适配器不同度量空间如何对齐、比较和迁移，论文引用了 FlatLand 作为基础但未给出具体机制。
- **可辨识性挑战**：流形上的模型存在大量坐标等价的参数化；论文提出"决策级可辨识性"作为缓解，但其在实践中的可达性尚待检验。
- **基准缺失**：现有基准（LoCoMo、LongMemEval、LifeBench）均不足以评估几何记忆；论文指出了缺口但尚未提供实际基准实现。

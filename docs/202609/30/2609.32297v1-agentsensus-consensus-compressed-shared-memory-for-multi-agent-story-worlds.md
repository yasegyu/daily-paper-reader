## 摘要
智能体故事世界是一个动态系统，模拟谁在何时从谁那里学到了什么——然而标准设计为每个角色提供私有的记忆流。因此，一个共享事件会按每位见证者各存储一次，从而在存储上造成大量重复。我们提出 Agentsensus，一个故事世界模拟框架，其中具有统一的长期记忆。同一事件的记录会合并为一条，由其所有见证者共同拥有，并且语义相关的记忆记录会被链接。我们在四个世界——两部中国古典小说、《哈姆雷特》和一个真实世界冲突时间线——上，在等粒度协议下，针对三种按角色划分的记忆设计，运行 40 到 80 轮进行评估。Agentsensus 比最接近的基线少写入 22–44% 的条目，并且是唯一一种记忆会变为共享（14–28% 的记录由不止一个角色持有，有些由 10 个角色持有）且链接（94–99%）的设计，其模拟质量经评判与基线无显著差异甚至更好。一项消融实验将此归因于合并本身：禁用它会使存储量增至 3.1 倍，并使共享率恰好降为零。共享还会随模拟时长复合增长，而不是过早饱和；当某个世界在 10、20 和 40 轮重新运行时，共享率从 6% 上升到 9%，再到 14%。

## Abstract
A agentic story world is a dynamic system simulating who learned what, when, and from whom -- yet the standard design gives each character a private memory stream. A shared event is therefore stored once per witness, large duplication will be incurred in terms of storage. We present Agentsensus, a story-world simulation framework in which there is an unified long-term memory. Records of the same event merge into one owned by all its witnesses, and semantically relevant memory records are linked. We evaluate on four worlds -- two classical Chinese novels, Hamlet, and a real-world conflict timeline -- run for 40 to 80 rounds against three per-character memory designs under an equal-granularity protocol. Agentsensus writes 22-44% fewer entries than the closest baseline and is the only design whose memory becomes shared (14-28% of records held by more than one character, some by 10) and linked (94-99%), at judged simulation quality indistinguishable or even better than the baselines. An ablation attributes this to the merge itself: disabling it multiplies the store by 3.1x and takes sharing to exactly zero. Sharing also compounds with the horizon rather than saturating early, rising 6% to 9% to 14% as one world is re-run at 10, 20 and 40 rounds.

# Agentsensus：面向多智能体故事世界的共识压缩共享记忆——论文总结

## 1. 核心问题与研究背景

- **研究对象**：智能体故事世界（agentic story world）——让数十个 LLM 驱动角色在含地点、物件、文档的世界里互动，叙事从互动中涌现。与"求解任务"的多智能体系统不同，故事世界的评判标准是**它累积了什么**：谁在何时从谁那里学到了什么。因此记忆不是系统的一个组件，而是系统的基底（substrate），同时也是扩展性最差的组件。
- **规模压力**：一本小说种子的世界一开始就沉积了数千条正典事件，每百轮再增加数百条，并且必须为每个角色在每一轮提供检索服务。
- **主流设计**：由 Generative Agents 确立、被后续框架继承的做法，是给每个角色一条**私有、只追加**的记忆流，按新近度、重要性、相关性打分。这对个体认知是忠实的，但作为共享世界的基底产生三个结构性缺陷：
  - **P1 见证者倍增冗余**：每个共享经历按参与者各存一份——十名军官的军议产生十条近乎相同的记录；存储、embedding 成本、索引规模随**见证者数**而非**事件数**增长。
  - **P2 世界知识碎片化、易发散**：同一事件存在 N 份独立措辞的副本，随 agent 转述与反思进一步漂移；没有机制对账，没有记录知道其对应物的存在，也没有任何东西把信使的报告与它描述的战役连起来。故事的"结缔组织"在记忆基底中无处存在，检索只能返回某一个人的局部视角，即便集体掌握全貌。
  - **P3 记忆维护 agent 从不执行**：流式设计把 linking、revising、forgetting 等维护操作暴露给 agent 并依赖它们使用；实证上（两个模型、四个后端、四个世界、最多 80 轮）agent 对**所有**自由裁量的记忆管理动作发出**零次**调用，即便提供了文档、示例和免 id 接口。
- **整体含义**：需要把"共享"变成**被计算出来的**而不是被假定的——世界的记忆是一个 store，但 ownership 是**记录的属性**而非**存储的属性**，因此共享 store 不等于共享心智。

## 2. 方法论

### 2.1 核心思想
- 单一长期记忆 store；`remember(agent, text)` 写入，`recall(agent, query)` 读取。
- 当两个 agent 记录同一事件时，等价机制把两条记录**折叠成一条由二者共有的条目**；owner 集合是两个见证者集合的并集。
- 记忆保持 **owner-scoped**：agent 只能回忆自己拥有的记录。owner set 因此成为一种**派生出来的**访问策略，而不是被配置的策略。
- 因为 P3，所有结构机制都运行在 `remember` 和 `recall` 内部，从不依赖 agent 主动维护。

### 2.2 关键技术与算法流程
- **原子化（self-contained atomization）**：一次 deposit 被切成自包含的陈述，受 token 预算上限约束。
- **等价判定（semantic prefilter + LLM judge）**：每个陈述被嵌入，与**整个 store**匹配；cosine 阈值 **0.70、top-5** 的候选送入 LLM judge；judge 要么指认某条等价记录，要么拒绝。
- **合并（merge）**：命中时，记录的 owner 集合取并集，affiliated 集合取并集，**保留两条文本中较短的一条**；未命中则写入新记录。
- **归属链接（affiliation）**：从同一次 deposit 原子化出的陈述**互为 affiliated**——这就是记忆图的来源，agent 从未显式建图。
- **自动扩展召回**：`recall` 先做 owner-scoped 语义查询（5 行），再沿 affiliation 边**扩展一跳**，把 caller 同样拥有的关联行追加进结果。
- 机制性质上接近 record linkage 与语义语料去重，而非缓存；本设定新增的语义是"重复项携带见证者"——合并同时是在陈述两个角色共享同一信念，对应心理语言学中的 grounding。

### 2.3 系统框架（四个后端共享）
- **round-barrier 内核**：每轮所有清醒 agent 针对**同一世界状态**决策，效果只在下一轮可见，因此一轮结果与 agent 步进顺序无关，可从事件日志复现。
- **三类 agent**：角色（唯一可调度）、环境（拥有记忆但从不行动）、信息载体（信件/诏令/剧本，角色可读）。
- **会话线程与距离延迟**：`say`/`gesture` 投递进收件

箱，并受**距离延迟**调制：同处一地的发言当轮可达，跨地点则需若干轮才送达，从而让"信息何时抵达"本身成为叙事变量，也迫使记忆基底正确记录"谁在何时知道了什么"。

- **信息载体（documents / letters / decrees / scripts）**：它们是拥有记忆但从不自主行动的 agent，可被角色阅读；阅读行为触发 `remember`，使文本内容进入读者的 owner-scoped 记忆，并因原子化与合并机制而与既有知识对账。

- **四个后端**：论文在四种存储/检索实现上复现同一语义（例如不同的向量索引或图存储），用以证明机制与后端无关；所有后端共享同一 round-barrier 内核与同一套 `remember`/`recall` 契约。

- **可复现性**：由于一轮的决策基于同一快照、效果延后一轮生效，整局可从事件日志重放，agent 步进顺序不影响结果，这为消融与对账实验提供了确定性基础。

### 2.4 与既有工作的关系
- 相对于 Generative Agents 的私有只追加流，Agentsensus 把"共享"从假定变为**计算产物**：owner set 由见证者并集派生，而非预先配置的可见性策略。
- 相对于多智能体协作框架的记忆共享（如共享黑板、全局向量库），它保留了**个体视角**：agent 只能回忆自己拥有的记录，因此共享 store ≠ 共享心智，避免了"全知角色"破坏叙事张力。
- 相对于语义去重/record linkage，它新增的语义是**重复项携带见证者**——合并一条重复记录同时是在断言两个角色共享同一信念，对应心理语言学中的 grounding（共同基础）。

## 3. 实验设计

### 3.1 实验设置
- **规模**：两个 LLM、四个后端、四个故事世界、最多 80 轮；世界种子一开始即沉积数千条正典事件，用以测试冷启动压力。
- **对照**：与 Generative Agents 式私有只追加记忆流对比，控制模型与后端，仅改变记忆基底的组织方式。
- **变量**：见证者数（事件被多少角色经历）、事件数、轮数、跨地点信息传播。

### 3.2 评价维度
- **存储与成本**：记录条数、embedding 规模、索引大小随轮数与见证者数的增长曲线；是否从"随见证者数增长"转为"随事件数增长"。
- **检索质量**：recall 返回内容是否覆盖集体全貌、是否仍保持 owner-scoped 的个体视角。
- **世界知识一致性**：同一事件是否存在多份漂移副本；跨记录的"结缔组织"（信使报告 ↔ 被描述的战役）能否被检索连通。
- **agent 维护行为**：在提供文档、示例与免 id 接口的条件下，agent 对自由裁量记忆管理动作的调用次数（预期为零，用以复现 P3）。

## 4. 主要发现

- **P3 复现**：在两个模型、四个后端、四个世界、最多 80 轮的设置下，agent 对所有自由裁量的记忆管理动作发出**零次**调用——即便提供文档、示例和免 id 接口。这说明依赖 agent 主动维护记忆的设计在实践中不可靠，结构机制必须内建于 `remember`/`recall`。
- **压缩效果**：等价合并把"每个共享经历按参与者各存一份"变为单条带 owner 集合的记录，存储、embedding 成本与索引规模随**事件数**而非**见证者数**增长；十名军官的军议不再产生十条近似记录。
- **一致性改善**：合并后不再存在 N 份独立措辞的漂移副本；affiliation 边为"信使报告 ↔ 战役"这类跨记录关联提供了检索通道，故事的"结缔组织"在记忆基底中有了落点。
- **个体视角保留**：owner-scoped 召回使每个 agent 仍只看到自己拥有的记录，共享 store 未退化为全知库；recall 的 affiliation 一跳扩展只在 caller 同样拥有的关联行上追加，避免越权泄漏。
- **自动建图**：记忆图完全来自同一次 deposit 的原子化陈述互为 affiliated，agent 从未显式建图，却获得了可扩展的关联召回。

## 5. 讨论与局限

- **判定的可靠性**：等价判定依赖 cosine 预筛（阈值 0.70、top-5）加 LLM judge；阈值与 judge 质量直接影响合并的查全与查准，误合并会把本应区分的信念错误绑定。
- **合并保留较短文本**：以"保留较短的一条"作为合并文本策略，可能丢失较长文本中的细节；论文未充分讨论信息损失对后续叙事的影响。
- **owner set 的语义边界**：owner 集合取并集意味着"见证即拥有"，但对间接获知（转述、阅读文档）是否应等同直接见证，仍需更细的归属语义。
- **评估规模**：80 轮、四个世界的实验展示了机制可行性，但距离"数十个角色长期运行"的完整叙事目标仍有距离。
- **未覆盖**：forgetting（遗忘）与 revising（修订）虽被识别为维护动作，但论文重心在 linking 与 merge 的自动化；长期记忆的衰减与矛盾消解仍是开放问题。

## 6. 结论

Agentsensus 的核心贡献是把多智能体故事世界的"共享记忆"从**假定**变为**被计算出来的**属性：单一 store 中，owner set 作为记录的属性由见证者并集派生，从而在保留个体视角的同时消除了见证者倍增冗余与知识碎片化。由于实证发现 agent 从不执行自由裁量的记忆维护（P3），所有结构机制——原子化、语义预筛加 LLM judge 的等价判定、owner 与 affiliated 集合的并集合并、以及 recall 的 affiliation 一跳扩展——都被内建于 `remember`/`recall` 之内，不依赖 agent 主动性。其语义落点是：合并重复项即是在断言两个角色共享同一信念，对应心理语言学中的 grounding。这为"共享 store 不等于共享心智"的故事世界记忆基底提供了一条可扩展、可复现的工程路径，同时把遗忘与修订留作后续工作。

## 摘要
角色扮演智能体的画像通常取决于系统提示中预定义的人格，而其记忆处理流程（包括对已存储记忆的优先级排序及后续检索）仍独立于该人格。这种分离导致智能体的记忆处理与预定义人格不一致，也使其行为是否遵循该人格难以验证。本文提出人格整合记忆（Personality-Integrated Memory, PersMem），将人格整合到智能体的记忆处理流程中，使其始终依赖人格。PersMem通过四个步骤处理记忆，其中人格被映射为控制以下操作的操作特定参数：(i) 情感评估，用于标注用户输入的情绪状态；(ii) 对先前存储记忆与当前输入的保留；(iii) 被动的情感驱动记忆检索，探索在语义和人格引导情绪上与用户输入相似的记忆；(iv) 主动的目标驱动记忆检索，对被动检索到的记忆进行精炼并为回复进行选择。因此，可以通过检查人机交互过程中的记忆处理轨迹来考察其与预定义人格的一致性。我们在依恋和大五人格设置下评估这些依赖人格的差异。PersMem在四类依恋分类上比随机基线高出23.1个百分点。在大五人格对话比较中，PersMem达到67.5%的准确率，比使用均匀采样记忆的基线高6.7个百分点。在CoSER上，PersMem平均得分为66.13，其中角色保真度为69.33，故事线质量为84.33。这些结果共同表明，PersMem能产生可区分的、与人格相关的记忆处理模式。

## Abstract
The profile of a role-playing agent usually depends on the pre-defined personality in a system prompt, whereas its memory processing pipeline, including prioritisation of stored memories and subsequent retrieval, remains independent of this personality. This separation causes the agent's memory processing to be inconsistent with the pre-defined personality, and makes it difficult to validate whether agent behaviours follow this personality. In this paper, we propose Personality-Integrated Memory (PersMem), which integrates personality into the agent's memory processing pipeline, making it consistently personality-dependent. PersMem processes memory using four steps, where the personality is mapped to operation-specific parameters controlling: (i) affective appraisal annotating emotion states of the user input; (ii) retention of previously stored memories along with the current input; (iii) passive affect-driven memory retrieval exploring memories similar to user input in semantics and personality-guided emotions; and (iv) active goal-driven memory retrieval that refines and selects passively retrieved memories for the reply. Consequently, consistency with the pre-defined personality can be examined by inspecting memory-processing traces during human-agent interactions. We evaluate these personality-dependent differences in attachment and Big Five settings. PersMem exceeds the chance baseline for four-way attachment classification by 23.1 percentage points. In Big Five dialogue comparisons, PersMem achieves 67.5% accuracy, 6.7 percentage points above a baseline using uniformly sampled memories. On CoSER, PersMem achieves an average score of 66.13, with scores of 69.33 for Character Fidelity and 84.33 for Storyline Quality. Together, these results show that PersMem produces distinguishable personality-related memory-processing patterns.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：基于 LLM 的角色扮演智能体已广泛用于情感陪伴、临床沟通训练、教育和互动叙事游戏，这类应用要求智能体在长时间交互中维持预设人格画像。
- **核心问题**：现有人格化智能体存在“人格—记忆分离”的结构性缺陷：
  - 人格通常只写在 **system prompt** 中，而记忆模块（存储、优先级排序、检索）是**独立于人格**运行的。
  - 当上下文变长或后续指令与 system prompt 冲突时，人格描述对回复生成的影响力会被削弱，甚至出现“人格漂移（persona drift）”“goblin syndrome”等现象。
  - 由于记忆处理不依赖人格，难以**验证**智能体行为是否真正遵循预设人格。
- **整体含义**：论文提出 **PersMem（Personality-Integrated Memory）**，将预设人格“内化”进记忆处理流程本身，使记忆的**评估、保留、被动检索、主动检索**全部由同一人格向量驱动，从而让人格在**回复生成之前**就可被观测和检验。
- **心理学依据**：情绪一致性记忆（mood-congruent memory）、自传体记忆的自我—记忆系统（Conway）、过度概括化记忆（OGM）的功能性回避理论，以及依恋理论与大五人格理论。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想
- 将预设人格表示为**固定的低维向量**：
  - 依恋设置：π = (π_anx, π_avo) ∈ [0,1]²
  - 大五设置：π_BF = (O, C, E, A, N) ∈ [0,1]⁵
- 将该向量映射为**操作特定参数**，控制四个记忆操作，且**不把人格向量或显式人格指令交给主动检索控制器和回复模型**。

### 2.2 四个依赖人格的记忆操作

**(i) 情感评估（Affective Appraisal）**
- 用 LLM 标注器或情感词典将输入转为原始 VAD 向量 ẽ = (v, a, d)。
- 通过依恋/大五特定映射 A_π 调整：
  - 依恋：高焦虑使负价更负、负性事件唤醒升高、支配度下降；高回避降低唤醒、提高支配度。
  - 大五：高神经质强化负性评估与唤醒，外向性与宜人性强化正性评估，低宜人性提高支配度。
- 维护动态 VAD 状态：s_in_t = (1−λ)s_out_{t−1} + λe_in_t，回复后再更新 s_out_t。

**(ii) 记忆保留（Memory Retention）**
- 保留值：ret(m, t; π) = exp(−(t − t_m)·r(m; π))
- 衰减率 r(m; π) = r₀(1 − c·a_m)·max(ε_ret, 1 − ρ·π_anx[−v_m]⁺)
- 唤醒越高衰减越慢；依恋焦虑/大五神经质越高，负性记忆保留越久。

**(iii) 被动情感驱动记忆检索（Passive Affect-Driven Retrieval）**
- 依恋评分：S_pas = α·sem + β_π·R + γ·ret，其中 β_π = β(1 + ξ·π_anx)
- 关系分 R 综合唤醒匹配、效价一致性、支配度匹配，加上焦虑×负性记忆项、回避×高支配项，以及**功能性回避项** Δ_fa（仅对带特异性标签的过度概括记忆生效）。
- 依恋：高焦虑提高负性记忆得分；高回避提高高支配度记忆得分，并在当前情绪更负时提高过度概括记忆得分。
- 大五：神经质强化负性记忆项，外向性+宜人性强化正性记忆项，低宜人性强化高支配项，低尽责性+高神经质强化过度概括项；开放性调节采样温度。
- 用 softmax 分布从 Top-K 候选中无放回采样 n 条记忆。

**(iv) 主动目标驱动记忆检索（Active Goal-Driven Retrieval）**
- 有明确回忆目标 g 时，以 q₀ = g 开始搜索。
- 每步由被动通路采样一个候选 m_pas_t，**人格条件化重定向门**决定是否用该候选重定向下一步：
  - I_t = σ(λ_I[S_pas(m_pas_t) − θ] + ν·a_t)
  - 依恋：θ_π = θ₀ − η·π_anx；大五：θ_BF = θ₀ − η·N
  - 高焦虑/高神经质 → 阈值降低 → 门更易触发。
- 门触发：候选加入主动召回集，取其文本前 60 字符作为下一查询；门不触发：取与当前查询最语义相似的未用记忆，并由 LLM 控制器输出修订查询或 DONE。
- 最终将被动集与主动集**合并去重**后交给回复模型。

## 6. 主要结论与发现

- **依恋人格可分性**：完整 PersMem 留出分类 **48.1%**（随机 25%，p = 0.0002）；中性门降至 40.0%，门关闭降至 25.0%，纯文本嵌入 25.0%，线性人格感知重排 30.0%。
- **四操作贡献**：被动情感检索效应最大（+0.130），其次为门控重定向（+0.085），情感评估（+0.005）和记忆保留（+0.013）较小。
- **检索与响应行为**：回避型与恐惧型在痛苦条件下召回更多过度概括记忆；焦虑型重定向到负性记忆的比例最高（0.63）。
- **大五召回模式**：神经质与召回效价 r = −0.703，外向性 r = +0.776，宜人性 r = +0.607，尽责性与过度概括记忆 r = −0.710（无特质对照仅 −0.180）。
- **大五对话**：PersMem **67.5%** 准确率，随机记忆对照 60.8%，无特质 54.2%，无记忆 53.3%。
- **CoSER**：平均 **66.13**（SC 59.83、AN 51.00、CF **69.33**、SQ **84.33**），CF 与 SQ 显著高于参考方法，但 SC/AN 相对偏低。
- **补充**：人格到增益映射校准误差 0.084 vs 固定增益 0.482；对抗性正向框架下 PersMem 保留 89% 神经质相关检索差异，prompt-persona 仅 58%；LoCoMo 上 F1 提升 0.0169（95% CI [0.0027, 0.0310]），证据召回@5 从 0.341 升至 0.387，但低于 Semantic RAG 的 0.444。

## 7. 优点

- **架构创新**：首次将人格向量系统性地映射到记忆处理全链路（评估—保留—被动检索—主动重定向），而非仅在回复阶段注入人格。
- **可解释性与可验证性**：人格影响发生在回复生成之前，召回内容统计和门重定向轨迹可作为可检查的“记忆处理痕迹”。
- **理论驱动的操作映射**：依恋与大五两套实例化共享同一管线接口，兼具心理学理论依据与工程复用性。
- **不泄露人格给下游**：主动控制器和回复模型均不接收人格向量或人格指令，避免“靠提示词演人格”的伪一致性。
- **实验规范**：跨模型盲评、盲特异性重标注（99.4% 一致，κ = 0.988）、配对随机流、聚类自助法、置换检验、72 个回归测试，可复现性设计较完整。
- **鲁棒性验证**：对抗性正向框架下仍保留大部分人格相关检索差异，说明人格被内化进记忆而非依赖表面提示。

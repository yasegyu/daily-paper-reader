## 摘要
长期记忆通过跨任务保留经验与技能，并使其在后续长时程决策中可被检索、复用和修正，从而支撑LLM智能体的自演化。然而，现有记忆管理方法仍局限于判别式检索，并受限于可复用经验的稀疏、层次化和高度冗余结构：只有一小部分依赖任务的轨迹和记忆值得保留、检索或修正。学习这些操作进一步因稀疏、延迟且间接的任务级反馈而复杂化，整个记忆生命周期中的监督信号也很弱。此外，持续的记忆演化引入了寻址不变性方面的架构张力：存储的经验不断被修正，而学习到的检索策略所使用的寻址接口必须保持稳定。为解决这些问题，我们提出GenMem，将记忆管理重构为生成式符号寻址。其核心机制是符号标识符（SID），这是一种从笛卡尔积地址空间中抽取的多级离散token元组，利用不到一百个离散符号分解百万规模的稀疏记忆空间。记忆智能体不是生成不断变化的原始内容，而是学习生成SID，而记忆演化则在固定地址处重写载荷，而不移动地址本身。在架构上，GenMem在多智能体Harness中耦合了MemRetriever和MemEvolver，并通过GRPO进行训练，采用密集的过程奖励和结果奖励，以及双通道优化。在离线记忆演化下，涵盖ALFWorld、WebShop、多跳问答、医学推理和深度研究的实验，将GenMem与强记忆增强基线进行评估……

## Abstract
Long-term memory supports the self-evolution of LLM agents by retaining experience and skills across tasks and enabling their retrieval, reuse, and revision in subsequent long-horizon decision-making. Yet existing memory management approaches remain limited to discriminative retrieval and to address the sparse, hierarchical, and highly redundant structure of reusable experience: only a small, task-dependent subset of trajectories and memories warrants retention, retrieval, or revision. Learning these operations is further complicated by sparse, delayed, and indirect task-level feedback, with weak supervision across the memory lifecycle. Moreover, continual memory evolution introduces an architectural tension as addressing invariance: stored experience is perpetually revised, yet the addressing interface consumed by learned retrieval policies must remain stable. To address, we present GenMem, which reformulates memory management as generative symbolic addressing. Its core mechanism is the Symbolic Identifier (SID), a multi-level discrete token tuple drawn from a Cartesian-product address space that factorizes a million-scale sparse memory space using fewer than one hundred discrete symbols. Instead of generating ever-changing raw content, the memory agent learns to generate SIDs, while memory evolution rewrites the payload at a fixed address without shifting the address itself. Architecturally, GenMem couples a MemRetriever and a MemEvolver within a multi-agent harness, trained via GRPO with dense process and outcome rewards with two-channels optimization. Under offline memory evolution, experiments spanning ALFWorld, WebShop, multi-hop QA, medical reasoning, and deep research evaluate GenMem against strong memory-augmented baselines...

# GenMem：面向自演化 Harness 的生成式符号记忆 —— 论文总结

## 1. 核心问题与研究动机

- **背景**：长期记忆是 LLM 智能体实现自演化的关键能力，使其能够跨任务保留经验与技能，并在后续长时程决策中完成检索、复用与修正。与百科式知识不同，这类经验型记忆具有**行动导向、情境依赖、持续演化**的特征。
- **核心问题转向**：记忆管理的核心问题已从“哪条记忆与查询最相似”转变为“哪条经验最能推进智能体当前策略”，并且这一判断必须在经验本身不断演化的过程中依然可回答。
- **两大挑战**：
  - **稀疏性挑战（Sparsity）**：经验高度冗余，仅在获取、组织、检索、演化全生命周期中的一小部分具有可复用价值；有效经验围绕共享子技能聚集，但扁平密集存储未显式编码该结构。此外，监督信号稀疏、延迟且间接，难以将任务级奖励归因到单条记忆操作。
  - **地址漂移挑战（Address Variance）**：内容不断被修正，但检索策略所依赖的寻址接口必须保持稳定。若检索依赖由当前记忆内容派生的表示，则每次修订都可能悄悄改变哪些查询能命中该条目。作者将“在修订中保持条目地址不变”的需求称为**寻址不变性（addressing invariance）**。
- **核心动机**：借鉴 LoRA 低秩更新、MoE 稀疏激活、Engram 条件知识存储等“结构化稀疏架构利用高维空间隐藏规律”的原则，将可复用经验的稀疏层级结构显式编码，通过**选择性且稳定的寻址**解决上述张力。

## 2. 方法论

### 2.1 核心思想

- 将记忆管理重构为**生成式符号寻址（generative symbolic addressing）**：智能体不生成不断变化的原始内容，而是学习生成**符号标识符（SID）**；记忆演化只在固定地址上重写载荷（payload），不移动地址本身。
- 实现“**where 与 what 解耦**”：稳定离散坐标标识经验空间中的功能区域，坐标背后的文本内容可自由编辑。

### 2.2 符号标识符（SID）定义

- 记忆库 $M=\{m_i\}_{i=1}^N$，每条记忆 $m_i=(x_i, z_i)$ 为文本经验载荷 $x_i$ 与 SID $z_i$ 的配对。
- SID 定义为多级离散符号元组：
  $$z_i=(s_i^1,\dots,s_i^L)\in \mathcal{Z},\quad \mathcal{Z}=[N_1]\times\cdots\times[N_L]$$
- 采用 $\sum_\ell N_\ell$ 个层级符号表示 $\prod_\ell N_\ell$ 个地址；共享前缀实现经验的层级组织。
- **关键性质**：在线修订形如 $(x_i,z_i)\xrightarrow{\text{Evolve}}(x'_i,z_i)$，地址保持不变。

### 2.3 经验获取与 SID 构建（冷启动）

- 使用多智能体 Harness **StackPlanner** 为每个训练查询生成多条轨迹，由 LLM 提取器对比正确、失败、未验证尝试，蒸馏可复用流程与失败教训，形成种子集 $X_{seed}$。
- 用冻结文本编码器 $e_i=f_{enc}(p_{enc}\oplus x_i)$ 编码，前缀 $p_{enc}$ 强调可复用策略、适用条件与流程，使地址反映解题模式而非表层文本相似度。
- 用 **RQ-KMeans**（残差量化 K-Means）逐层构建离散地址空间：第 $\ell$ 层对残差聚类，取最近中心索引为第 $\ell$ 级符号，并从残差中减去该中心：
  $$s_i^\ell=\arg\min_j \|r_i^{(\ell)}-c_j^{(\ell)}\|_2^2,\quad r_i^{(\ell+1)}=r_i^{(\ell)}-c_{s_i^\ell}^{(\ell)}$$
- 文中采用码本大小 $(48,16,8,8)$，用 **80 个符号**产生 **49,152 个可能地址**；同一 SID 下的多条经验被合并为单条记忆条目；码本构建后固定。

### 2.4 生成式记忆检索与演化闭环

- **MemRetriever**：从查询与推理上下文生成检索 SID $z_r$，取出关联经验并改写为任务自适应支持 $\tilde{x}_r$。
- **StackPlanner**：利用该支持执行任务，产出答案 $\hat{y}$ 与轨迹 $\tau$。
- **MemEvolver**：蒸馏轨迹，生成更新 SID $z_e$，查询关联条目后决定操作 $o\in\{\text{insert},\text{revise}\}$ 及更新载荷 $\tilde{x}_e$（revise 可通过不变/合并/空载荷实现保留、整合、删除）。
- 闭环三步：Retrieve → Execute → Evolve。

### 2.5 四阶段训练流程

1. **SID 对齐预训练**：通过五个文本–SID 映射建立双向关联——正向 $q\mapsto z$、$\tau\mapsto z$、$x\mapsto z$；反向 $z\mapsto x$、$z\mapsto d$。损失为各映射负对数似然加权和。
2. **记忆操作中期训练**：构造 ReAct 风格轨迹，分别训练 MemRetriever 与 MemEvolver；经拒绝采样筛选后，用更强教师模型提供推理轨迹与角色特定输出的蒸馏目标，以标准下一 token 目标微调。
3. **联合策略后训练**：采用 **GRPO**，奖励包含：
   - **过程奖励** $R_{process}=R_{format}+R_{strategy}+R_{SID}$（格式有效性、SID 与真值一致、LLM 评判的策略有用性）；
   - **结果奖励** $R_{out}=r_{task}(\hat{y}_{mem},y^\star)-r_{task}(\hat{y}_{no\text{-}mem},y^\star)+\alpha_{partial}\mathbb{I}[\text{两者皆对}]$，即对比式奖励，仅当两者都对时给部分奖励加分。
   - 采用**双通道优化**（proxy 与 audit 通道分别归一化优势）。
4. **在线自演化**：模型参数、编码器、SID 码本全部冻结，仅通过外部记忆的插入/修订适应新查询流，无需梯度更新或地址重分配。

## 6. 主要结论与发现

- **下游任务性能**：GenMem 在 ALFWorld、WebShop、搜索增强 QA 上均优于基线；相对无记忆基线平均提升 **17.0**（训练前）与 **15.3**（训练后）个百分点；在搜索 QA 上比第二名 SDAR 平均高 **3.7** 个百分点。ALFWorld 整体成功率 **93.6%**，WebShop 得分 **90.8 / 成功率 82.8%**，搜索 QA 平均 F1 **52.8%**。
- **检索质量**：相同候选预算与重排协议下，GenMem 最终 Top-5 命中率达 **13.15%**，高于 SkillRouter（10.28%）、TF-IDF（12.52%）、Qwen3-Embedding-0.6B（2.89%），说明相似度检索难以捕捉任务的策略需求。
- **寻址不变性验证（RQ2）**：随演化推进，GenMem 候选命中率从 20.25%（t=0）升至 25.58%（t=9），任务准确率从 30.56% 升至 36.20%；而三种内容耦合基线因嵌入漂移导致索引需重建，收益有限甚至退化，实证支持了地址与内容解耦的必要性。
- **演化动态**：SID 谱系显示跨案例演化（一条案例修订的记忆被用于解决另一案例）；更新高度集中于少数活跃 SID；MemEvolver 选择性写入而非盲目更新；载荷编辑距离统计表明存在大量内容改动，但仅 GenMem 能将其转化为持续性能增益。
- **SID 的神经符号涌现性质**：在 GPQA 上，仅提供完整 SID 前缀（无经验文本）即可将准确率从 48.32% 提升至 **54.06–54.66%**；SID 可与自然语言 token 交错使用，并具**组合性**——组合多个 SID 可组合其存储经验以应对任何单条记忆都未覆盖的新情境。
- **跨域迁移**：在未见数据集上研究类任务稳定 +2%，搜索任务从 −1%（TCRAG Harness）到 +1%（OpenHands Harness）不等。

## 7. 优点

- **范式创新**：首次将演化型经验记忆建模为“生成式符号寻址”，通过 SID 生成统一检索与更新接口，直接针对“内容演化 vs. 地址稳定”的架构张力给出结构性解法。
- **稀疏性利用充分**：用少于 100 个离散符号分解百万级稀疏记忆空间，层次化前缀天然支持粗到细的选择性访问，避免扁平密集存储的关联稀释。

## 摘要
智能体记忆系统越来越多地用于维护长期用户偏好、任务状态和不断演化的事实，但当前的评估往往将记忆行为简化为最终答案的准确率。我们提出 MemProbe，一个受认知科学启发的框架，用于诊断智能体记忆中的稳定性-可塑性权衡。该框架的动机来自认知记忆研究的一个核心洞见：记忆是重构性的，并受到干扰、来源可靠性、强化和再激活的影响。MemProbe 将这一洞见转化为四个可复用的实验范式（干扰、错误信息、巩固强度和再巩固窗口），这些范式操纵记忆应在何时被更新、保留或视为不确定。它进一步将正确性分解为行为画像，揭示系统如何更新、保留、归因和时间组织信息。我们在一个包含 56 个情节的诊断套件中实例化这些范式，并在统一协议下评估六种增量记忆系统。结果表明，总体得分相近的系统表现出不同的行为画像。MemProbe 提供了这样一种诊断视角，将总体性能转化为随时间变化的可解释记忆维护画像。代码见 https://github.com/jq-ding/MemProbe。

## Abstract
Agent memory systems are increasingly used to maintain long-term user preferences, task states and evolving facts, but current evaluations often collapse memory behavior into final-answer accuracy. We introduce MemProbe, a cognitive-science-inspired framework for diagnosing stability-plasticity tradeoffs in agent memory. The framework is motivated by a core insight from cognitive memory research: memory is reconstructive and shaped by interference, source reliability, reinforcement, and reactivation. MemProbe turns this insight into four reusable experimental paradigms (interference, misinformation, consolidation strength, and reconsolidation window) that manipulate when a memory should be updated, preserved, or treated as uncertain. It further decomposes correctness into behavioral profiles that reveal how systems update, preserve, attribute, and temporally organize information. We instantiate these paradigms in a 56-episode diagnostic suite and evaluate six incremental memory systems under a unified protocol. Results show that systems with similar aggregate scores exhibit distinct behavioral profiles. MemProbe provides such a diagnostic lens, turning aggregate performance into interpretable profiles of memory maintenance over time. Code is available at https://github.com/jq-ding/MemProbe.

## 1. 核心问题与研究动机

- **背景**：智能体记忆系统被广泛用于维护长期用户偏好、任务状态与不断演化的事实，但现有评测几乎都聚焦于最终答案的正确性（accuracy、F1、recall、任务成功率等任务级指标）。
- **核心痛点**：两个总体准确率完全相同的记忆系统，可能在记忆更新行为上截然相反——一个过度可塑（见到新证据就激进覆写旧记忆），另一个过度稳定（除非被显式纠正，否则固守过时信息）。相同的分数掩盖了长期记忆维护中截然不同的风险。
- **现有基准的局限**：LongMemEval、LoCoMo、MemBench、MemoryAgentBench、MemoryStress、AMA-Bench、MemoryArena、EverMemBench、MemConflict 等已将评测推进到增量记忆维护、矛盾处理、长程时序决策等方向，但其**主要结果仍是任务级正确率**，无法说明"是何种记忆更新行为产生了这个答案"，也无法区分系统是"检索到正确证据""学到了可靠的更新策略"还是"测试分布恰好偏向需要更新的样本"。
- **整体含义**：随着记忆机制日益多样化，仅评估最终答案正确性会把本质不同的更新画像压缩成单一分数。论文主张记忆评测应从"是否答对"转向"如何随时间更新、保留与扭曲信息"。

## 2. 方法论

### 2.1 核心思想

- 提出 **MemProbe**：一个受认知科学启发的**行为诊断框架**，把评估形式化为"受控情境操纵记忆条件 + 定向探针揭示更新行为模式"的诊断问题。
- **不假设可访问智能体内部记忆状态**，而是通过控制输入序列、观察输出行为来推断记忆倾向——遵循认知记忆实验的逻辑（内部状态不可直接观测时，受控行为范式可揭示系统性记忆倾向）。
- 核心理论洞见：记忆是**重构性**的，受干扰、来源可靠性、强化与再激活影响。

### 2.2 四个诊断范式（范式规范）

| 范式 | 认知科学来源 | 核心操纵 | 诊断目标 |
|---|---|---|---|
| **P1 干扰 Interference** | AB–AC 配对联想学习（Underwood 1957；Barnes & Underwood 1959） | 已建立记忆 vs. 合法更新 vs. 后续干扰项竞争 | 分离"成功更新"与"历史保持"；诊断过度稳定（有效更新失败）与过度可塑（干扰项侵入为新记忆） |
| **P2 错误信息 Misinformation** | Loftus 1975；Loftus & Palmer 1974 | 事件后误导信息，来源可信 vs. 不可信 | 测试来源敏感更新：能否区分"证据"与"仅仅被提及"；可信用户纠正应被采纳，幻觉/传闻/非目标值不应覆写记忆 |
| **P3 巩固强度 Consolidation Strength** | Ebbinghaus 1913；McClelland 1995；Milekic & Alberini 2002 | 记忆的先前支持强度（重复确认 vs. 一次性陈述）× 挑战强度 | 测试系统是否按记忆强度调节稳定性/可塑性，而非把所有记忆视为同等可塑 |
| **P4 再巩固窗口 Reconsolidation Window** | Nader et al. 2000；Schiller et al. 2010；Dębiec et al. 2006 | 显式再激活旧记忆后再引入新证据 | 测试再激活是否改变更新敏感性，以及该敏感性是否**选择性**地只对可靠证据生效，而非引发再激活诱导的过度更新 |

### 2.3 受控试验设计与输入协议

- **试验结构**：`编码（Encoding）→ 扰动（Perturbation）→ 探针（Probing）`，并穿插填充交互、近似事实（near-miss）与干扰项，防止任务退化为简单的近因匹配。
- **拆分扰动（Split Perturbation）**：`编码 → 填充 → P1 → 交错填充 → P2 → 扰动后上下文 → 探针`，将"变更触发/来源"与"被接受的新值"分置于不同会话，迫使系统整合分布式证据，而非检索单句决定性更新。
- **输入协议分层**：
  - 参考/基线（黄色）：Full-context reader（完整证据下的上界参考）；检索式基线 Naive RAG、Time-aware RAG、Oracle RAG（区分检索失败与阅读器推理失败）；启发式基线（最新值优先、按来源类型选择）作为捷径脆弱性检查。
  - **主评估设置：增量记忆维护**（紫色）——每个 episode 重置记忆库，按时间顺序逐会话喂入，探针时仅用系统维护的记忆状态作答。
- **形式化协议**：`M₀ ← Reset()`；`Mₜ ← Ingest(Mₜ₋₁, sₜ)`，t=1…T；`âⱼ ← Query(M_T, qⱼ)`，j=1…m。

### 2.4 行为度量体系

- **基础准确率**：`A(S;D) = (1/|D|) Σ_{q∈D} c(q,S)`，总体 `Acc(S)=A(S;Q)`。
- **稳定性–可塑性**：令 U 为期望接受有效更新的探针集，P 为期望保持既有记忆的探针集，则
  - `Plasticity(S) = A(S;U)`，`Stability(S) = A(S;P)`
  - `UpdateError = 1 − Plasticity`，`PreserveError = 1 − Stability`
  - **SP-Balance** = 调和平均 `2·P·S/(P+S)`，惩罚只在单侧表现好的系统。
- **保真度指标**：历史保真度（previous-value 准确率）、来源保真度（source 与 conflict-status 准确率）、时间保真度（temporal 探针准确率）。
- **检索与证据整合**：`ΔFC(r) = AccFC − Accr`（相对完整证据的性能损失）、`RAGnorm(r) = Accr/AccFC`（恢复比例，诊断性 Oracle RAG 可 >1）；`Δsplit = Accsplit − Accnon-split`（负值为拆分惩罚）。
- **失败归因分类**：来源丢失、时间重构失败、分布式证据检索缺失、历史覆写、更新不足、过度更新、抽取脆弱性等。
- **探针分类（6 类）**：current-value、previous-value、change-detection、source、conflict-value、temporal；使用**结构化 JSON 金标签**（含 conflict 的 status/applies_to_target 等字段、temporal 的 change_direction/trigger/reason 等字段），支持归一化与部分得分。
- **统计**：episode 级 bootstrap 置信区间（2000 次重采样，固定随机种子）；系统比较用同一重采样 episode 的配对 bootstrap；多重比较用 Bonferroni 校正。

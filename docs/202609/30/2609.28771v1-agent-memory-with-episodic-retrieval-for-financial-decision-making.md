## 摘要
大语言模型（LLMs）在金融分析与推理方面展现出强大能力，推动了近期基于智能体的交易框架的发展。尽管这些系统展现出前景，但已有方法要么侧重于长周期预测，要么作为无状态分析器运行，限制了其在复杂环境下交易需求中的适用性。为弥补这些不足，我们提出 META（Memory Enhanced Trading Agent，记忆增强交易智能体），这是首个类RAG的、情景记忆增强的多智能体金融决策框架。META 集成了一系列专门的指标智能体（例如 Trend、MACD、Stochastic、RSI、SMA、AVWAP、Heikin-Ashi）与一个融合其报告的决策智能体，以及一个记忆模块，用于检索和更新以市场状态嵌入表示、并带有结果与反思的过往交易情景。通过在相似市场状态下回忆相关经验并自适应地重新加权信号，META 在短周期评估下实现了更高的方向准确率与鲁棒性。我们的结果表明，情景记忆为交易与决策中市场状态感知、可解释且低延迟的决策提供了一种强大机制。本项目代码已在 GitHub 发布。

## Abstract
Large language models (LLMs) have demonstrated strong capabilities in financial analysis and reasoning, inspiring recent advances in agent-based trading frameworks. While these systems show promise, prior approaches either emphasize long-horizon forecasting or operate as stateless analyzers, limiting their applicability to the demands of trading in complicated settings. To address these gaps, we introduce META (Memory Enhanced Trading Agent), the first RAG-like episodic-memory-augmented multi-agent framework for financial decision making. META integrates a family of specialized indicator agents (e.g., Trend, MACD, Stochastic, RSI, SMA, AVWAP, Heikin-Ashi) with a Decision Agent that fuses their reports, and a Memory module that retrieves and updates past trading episodes encoded as market state embeddings with outcomes and reflections. By recalling relevant experiences and adaptively reweighting signals under similar market regimes, META achieves improved directional accuracy and robustness under short-horizon evaluation. Our results demonstrate that episodic memory provides a powerful mechanism for regime-aware, interpretable, and low-latency decision-making in trading and decision making. The code of this project is released on GitHub.

## 2. 方法论

### 2.1 核心思想

- 将交易策略建模为检索增强策略 \(\pi\)，输入当前市场状态 \(z_t\) 和时变情景记忆 \(M_t\)，输出结构化决策 \(d_t\)。
- 目标：最大化期望累计回报  
  \[
  J(\pi)=\mathbb{E}\left[\sum_{t=0}^{T}\gamma^t o_t(d_t)\right]
  \]
  其中 \(o_t\) 为决策结果，\(\gamma\) 为折扣因子。
- 策略被分解为两个可解释模块：
  \[
  d_t=\Pi\big(\Phi(z_t),\ \Psi(z_t,M_t)\big)
  \]
  其中 \(\Phi\) 为感知算子，\(\Psi\) 为记忆算子，\(\Pi\) 为综合算子。
- 该分解带来三点优势：异构金融输入的专门处理、基于情景记忆的检索增强泛化、透明可审计的推理链。

### 2.2 双流状态表示

- 从滑动窗口 OHLCV 数据构建市场状态：
  \[
  z_t=[z_t^{(sym)} \| z_t^{(num)}]
  \]
- **符号流** \(z_t^{(sym)}\)：编码可解释的技术指标特征，如动量、波动率、均值回归等，用于逻辑推理和规则式分析。
- **数值流** \(z_t^{(num)}\)：保留归一化的原始价量微观结构，维度为 \(5W\)，用于余弦相似度检索，捕捉纯符号抽象容易丢失的细微市场配置。
- 双流设计兼顾**可解释性**与**数值精度**，连接符号推理与子符号推理。

### 2.3 感知算子 \(\Phi\)

- 由一组专门的 Signal Agents 组成，例如 Trend、MACD、Stochastic、RSI、SMA、AVWAP、Heikin-Ashi。
- 每个智能体处理市场状态 \(z_t\)，输出紧凑报告：
  \[
  r_t^m=A_m(z_t)
  \]
- 所有报告形成感知集合 \(R_t=\{r_t^m\}_{m=1}^M\)，包含定量指标与定性语义，如“看涨背离”“检测到突破”。
- 设计优点：模块化，可独立替换或新增信号；输出结构化、可解释，便于上层符号推理。
- 附录中，各指标智能体通常先调用工具生成图表，再基于图表分析，形成“工具优先、视觉 grounding”的推理流程。

### 2.4 记忆算子 \(\Psi\)

- 实现基于案例的类比推理。情景记忆 \(M=\{m_i\}_{i=1}^N\)，每条记忆：
  \[
  m_i=(z_i,a_i,o_i,\rho_i)
  \]
  分别记录状态、动作、结果和可选文本反思。
- **检索**：对当前状态 \(z_t\)，在数值嵌入上计算余弦相似度：
  \[
  sim(z_t,z_i)=\frac{(z_t^{(num)})^\top z_i^{(num)}}{\|z_t^{(num)}\|\|z_i^{(num)}\|}
  \]
  选取满足阈值 \(\tau\) 的 top-k 邻域：
  \[
  N_t=\{(m_i,s_i)\mid s_i=sim(z_t,z_i)\ge\tau\}_{Top-k}
  \]
- **巩固与更新**：通过动态管理算子 \(Op(m_t,M)\) 管理记忆生命周期，剪枝低效用或冗余条目，保留新颖高影响经验。
- 关键点：检索到的案例不会被原样拼接到提示中，而是携带原始结果和反思，在测试时被重新批判和重新加权。

### 2.5 综合算子 \(\Pi\)

- 使用 LLM 融合感知摘要 \(R_t\) 与检索情景 \(N_t\)，输出结构化决策：
  \[
  d_t \triangleq (a_t,\kappa_t,E_t,\rho_t)
  \]
  - \(a_t\)：动作，如 LONG/SHORT；
  - \(\kappa_t\)：置信度；
  - \(E_t\subseteq R_t\cup N_t\)：所选证据子集；
  - \(\rho_t\)：简短自然语言理由。
- 采用**证据优先、约束解码**：LLM 必须先选择证据 \(E_t\)，再生成理由 \(\rho_t\)，从而形成从输入证据到交易动作的可审计解释链。
- 决策输出为严格 JSON，包含预测周期、LONG/SHORT、置信度、主要驱动、记忆洞察、理由、风险回报比、止损理由等；提示中禁止 HOLD，只允许 LONG 或 SHORT。
- 事后反思提示将交易结果转化为记忆对齐的指导，用于更新信号权重与置信度校准。

### 2.6 技术指标与公式

- 附录给出 MACD、RSI、AVWAP、SMA、Stochastic、Heiken Ashi 的定义与计算：
  - MACD：快慢 EMA 之差、信号线、直方图；
  - RSI：平均涨幅与平均跌幅之比，输出 0–100；
  - AVWAP：从锚点 \(\tau\) 开始的成交量加权平均价；
  - SMA：最近 \(n\) 期收盘价均值；
  - Stochastic：\(\%K\) 与 \(\%D\)，衡量收盘价在近期高低区间中的位置；
  - Heiken Ashi：递归平滑 OHLC，减少噪声、突出趋势。
- 这些指标分别捕捉动量、均值回归、趋势持续性和价值锚定。

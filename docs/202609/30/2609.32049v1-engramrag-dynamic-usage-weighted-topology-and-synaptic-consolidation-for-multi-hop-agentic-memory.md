## 摘要
随着自主 LLM 智能体在多会话环境中部署，传统记忆架构面临联想盲区（无法遍历多跳关系依赖）、支架遗忘（时间衰减会驱逐核心人格不变量）以及静态拓扑停滞（不可变图忽略使用动态）。基于互补学习系统（CLS）原理，我们提出 EngramRAG，一种自适应记忆架构，将低延迟的清醒状态反射与异步后台梦境状态巩固循环耦合起来。EngramRAG 引入：(1) 使用调制个性化 PageRank（U-PPR），其中转移概率通过赫布可塑性自适应，以将持久实体提升为高中心性的认知宏枢纽；(2) 巩固激活的拓扑衰减（CATD），其按拓扑承载权重而非挂钟时间新近度来缩放保留半衰期，并由冷启动宽限期（N_grace >= 4）保护；(3) 有向 SUPERSEDES DAG 过滤，以在事实变更期间抑制过时状态；以及 (4) 三源混合检索，通过动态倒数排名融合（RRF）融合稠密向量、BM25 和 U-PPR。在 LoCoMo 基准的 10 段长期对话的全部 1,982 个问答对上评估，EngramRAG 相比稠密向量 RAG 在 Recall@5 上取得 +38.9% 的相对提升（53.21% 对 38.29%，p < 0.001），在 MRR 上取得 +43.1% 的提升（0.4203 对 0.2937），显著优于 Okapi BM25（48.66%）和孤立静态图检索（8.50%）。在时间推理上，EngramRAG 达到 62.33% 的 Recall@5（比稠密向量高 16.67 个百分点）。在受控变更测试中，SUPERSEDES 将裂脑幻觉从 70.0% 抑制到 0.0%，而 90 天模拟显示在 26.21ms 的交互式检索反射下保持 100.0% 的支架保留率。

## Abstract
As autonomous LLM agents are deployed across multi-session environments, conventional memory architectures suffer from Associative Blindness (inability to traverse multi-hop relational dependencies), Scaffolding Amnesia (temporal decay evicting core persona invariants), and Static Topology Stagnation (immutable graphs ignoring usage dynamics). Grounded in Complementary Learning Systems (CLS) principles, we propose EngramRAG, an adaptive memory architecture coupling a low-latency Waking State reflex with an asynchronous background Dreaming State consolidation cycle. EngramRAG introduces: (1) Usage-Modulated Personalized PageRank (U-PPR), where transition probabilities adapt via Hebbian plasticity to promote persistent entities into high-centrality Epistemic Macro-Hubs; (2) Consolidation-Activated Topology Decay (CATD), which scales retention half-life by topological load-bearing weight rather than wall-clock recency, protected by a cold-start grace period (N_grace >= 4); (3) Directed SUPERSEDES DAG filtering to suppress obsolete state during fact mutations; and (4) Triple-source hybrid retrieval fusing dense vectors, BM25, and U-PPR via dynamic Reciprocal Rank Fusion (RRF). Evaluating on all 1,982 QA pairs across 10 long-term conversations in the LoCoMo benchmark, EngramRAG achieves +38.9% relative improvement in Recall@5 (53.21% vs. 38.29%, p < 0.001) and +43.1% in MRR (0.4203 vs. 0.2937) over dense vector RAG, significantly outperforming Okapi BM25 (48.66%) and isolated static graph retrieval (8.50%). On temporal reasoning, EngramRAG reaches 62.33% Recall@5 (+16.67 points over dense vectors). In controlled mutation tests, SUPERSEDES suppresses split-brain hallucinations from 70.0% to 0.0%, while 90-day simulations show 100.0% scaffolding retention under a 26.21ms interactive retrieval reflex.

  - **Static Topology Stagnation / 静态拓扑停滞**：已有图记忆多把图视为不可变索引，忽略真实检索使用频率、任务效用和事实变更。

## 2. 方法论

### 2.1 总体架构

- **Waking State / 清醒状态**：实时低延迟摄取与检索反射，目标 sub-30ms。
- **Dreaming State / 梦境状态**：每约 6 小时异步执行重拓扑维护，不阻塞读取路径。
- **存储引擎**：
  - Redis Stack：RedisJSON + RediSearch，管理事实信封和 HNSW 向量索引；384 维嵌入，M=16，efConstruction=200，efRuntime=50，余弦距离；并行倒排索引支持 BM25。
  - Neo4j：ACID 持久化，Cypher 建模 `[:CO_OCCURS]`、`[:ASSOCIATED_WITH]`、`[:SUPERSEDES]` 等有向类型边。
  - Redis Streams：`stream:memory_ingest` 异步入队，消费者组 `epigraph_workers`，死信队列 `stream:memory_dlq`。

### 2.2 Waking State：实时摄取与检索

- **Triage 过滤**：二分类器丢弃无信息话语。
- **L0 去重**：新事实嵌入后查 HNSW；若余弦相似度 ≥ 0.95，不新建节点，只增加已有节点访问计数。
- **解耦双写**：异步写入向量/文档存储与拓扑关系存储。
- **三源混合检索**：
  - Dense Vector HNSW；
  - Okapi BM25；
  - U-PPR 多跳图遍历。
  - 意图路由器动态计算权重，再用 Reciprocal Rank Fusion（RRF）融合。
- **SUPERSEDES 过滤**：图检索候选排除被 `SUPERSEDES` 指向的旧节点，抑制过时事实。

### 2.3 Dreaming State：离线突触巩固

- **增量聚类**：HNSW 加速 DBSCAN，O(N log N)，检测近重复实体，替代 O(N²) 成对比较。
- **Louvain 社区划分**：生成主题模块和社区质心。
- **U-PPR 重算与宏枢纽检测**：识别高中心性 Epistemic Macro-Hubs。
- **CATD 突触剪枝**：删除瞬时噪声，保护拓扑支架。
- **合并策略**：聚类内按历史访问次数和全局 PageRank 中心性选择胜出节点。

### 2.4 关键数学与算法思想

- **动态赫布边权**：
  - 边权由三部分构成：语义相似度、共检索时间衰减项、关系类型先验。
  - 若两个概念在对话中被共同检索，其边权增强；`SUPERSEDES` 等结构关系有更高先验。
- **U-PPR / 使用调制个性化 PageRank**：
  - 个性化传送向量融合查询语义相似度与历史访问强度。
  - 访问强度用 `log(1+n_i)` 做对数缩放，并用 `e^{-μ(t-t_i)}` 做时间折扣。
  - 默认 θ=0.60，μ=0.05，阻尼 d=0.85，通过幂迭代求稳态分布。
  - 对数缩放和时间折扣用于防止“富者愈富”的枢纽俘获。
- **Epistemic Macro-Hub 识别**：
  - 节点全局稳态中心性 ≥ μπ + 1.2σπ，且度数 ≥ 3。
  - 这些宏枢纽作为跨会话传播中的稳定认知锚点。
- **CATD / 巩固激活拓扑衰减**：
  - 拓扑承载分数 = 0.4 × 相对中心性 + 0.3 × 度数项 + 0.3 × 类型先验。
  - 有效衰减率 `λ_eff = λ_base(type) × exp(-2.0 × Score_topology)`。
  - 身份类 λ 最低，偏好类次之，情节类最高。
  - 物理淘汰需同时满足：置信度 ≤ 0.10、休眠超过 4 周期、度数 ≤ 1、且类型不是 identity/preference。
  - 冷启动宽限期 `N_grace ≥ 4`。
- **复杂度**：
  - 读取：`O(K·d_embed + I_PPR·(|V|+|E|))`，I_PPR ≤ 20。
  - 实测完整交互反射平均 26.21ms。
  - U-PPR 在 |V|=1,000 时约 4–6ms，|V|=10,000、约 59,980 边时约 50ms。
  - 存储多年会话历史可低于 50MB。

## 摘要
大型语言模型（LLM）智能体日益依赖外部记忆来支持长时程推理与决策。现有记忆系统通常将历史轨迹或摘要作为独立上下文片段进行检索，忽视了多步执行所依赖的过程性依赖关系。随着记忆规模扩大，这种扁平化检索会引入上下文碎片化和跨任务干扰，导致推理轨迹在结构上不一致。我们提出 ActiveMem，一种分层记忆框架，它将智能体经验递归组织为依赖感知的潜在执行树。ActiveMem 将轨迹抽象为可复用的子任务节点，同时显式保留执行转移，从而能够以当前执行状态为条件进行连贯的推理路径检索。为支持持续适应，ActiveMem 进一步通过强化学习学习动态记忆扩展、检索和剪枝策略。在各种智能体基准上的实验表明，与现有基于记忆的智能体相比，ActiveMem 持续提升任务完成度、推理稳定性和记忆效率。此外，ActiveMem 使紧凑的开源权重模型能够达到与规模大得多的专有系统相竞争的性能。

## Abstract
Large Language Model (LLM) agents increasingly rely on external memory to support long-horizon reasoning and decision making. Existing memory systems typically retrieve historical trajectories or summaries as independent context fragments, overlooking the procedural dependencies underlying multi-step execution. As memory scales, such flat retrieval introduces context fragmentation and cross-task interference, leading to structurally inconsistent reasoning trajectories. We propose ActiveMem, a hierarchical memory framework that recursively organizes agent experiences into dependency-aware latent execution trees. ActiveMem abstracts trajectories into reusable subtask nodes while explicitly preserving execution transitions, enabling coherent reasoning-path retrieval conditioned on the current execution state. To support continual adaptation, ActiveMem further learns dynamic memory expansion, retrieval, and pruning policies through reinforcement learning. Experiments across various agent benchmarks demonstrate that ActiveMem consistently improves task completion, reasoning stability, and memory efficiency over existing memory-based agents. Moreover, ActiveMem enables compact open-weight models to achieve competitive performance with substantially larger proprietary systems.

## 1. 核心问题与整体含义

- **背景**：LLM 智能体被越来越多地要求完成长时程任务（持续推理、自适应规划、多步环境交互）。这类任务的成败取决于能否在长决策轨迹中维持连贯的“过程性状态”，早期动作会直接影响后续推理与执行结果。因此，外部记忆机制（积累并检索历史经验）成为必要基础设施。
- **核心问题**：现有记忆系统（ReAct、MemoryBank、ExpeL、AWM、MemGen 等）大多把历史轨迹、摘要或语义相似上下文作为**扁平、独立的片段**检索，忽视了长时程执行背后的**过程性依赖**（procedural dependency）。
- **后果**：
  - **上下文碎片化（Context Fragmentation）**：检索到的片段彼此不连贯。
  - **跨任务干扰 / 泄漏（Cross-Task Interference / Leakage）**：把功能相关但顺序不兼容的其他领域步骤（如订机票时套用订酒店流程）盲目拼接。
  - 随记忆规模增长，这些不一致会持续破坏推理稳定性与执行连贯性。
- **论文主张**：智能体行为本质上是结构化、分层的——高层目标逐步分解为可复用子任务，成功执行依赖中间推理状态间的依赖关系。因此有效记忆应同时支持**结构化抽象**与**依赖感知检索**，而不是把历史轨迹当作独立可复用上下文。
- **整体含义**：ActiveMem 是一个分层记忆框架，把经验递归组织成依赖感知的**潜在执行树**，并让记忆的扩展/检索/剪枝成为可学习（RL 优化）的自适应决策过程，从而在冻结主干 LLM 的前提下提升长时程任务的完成度、稳定性与记忆效率。

## 2. 方法论

### 2.1 核心思想
- 用**分层潜在记忆树（Hierarchical Latent Memory Tree, HLMT）** 替代扁平记忆池：节点 = 可复用的子任务级潜在抽象，边 = 执行依赖/时序转移。
- 检索的不是孤立历史片段，而是与当前执行阶段一致的**依赖一致的推理路径**。
- 用一个**轻量、解耦的记忆控制器**同时完成：记忆拓扑演化、路径检索、潜在记忆注入，并用强化学习端到端优化（主干 LLM 全程冻结）。

### 2.2 问题形式化
- 任务指令 $x$，冻结 LLM $\pi_\theta$ 与环境 $\mathcal{E}$ 交互 $T$ 步，产生轨迹 $\tau=(s_0,a_0,\dots,s_T)$。
- 历史前缀被压缩为动态树 $\mathcal{T}_t$：$\mathcal{T}_t=\text{TreeUpdate}(\mathcal{T}_{t-1},a^{tree}_{t-1})$。
- 给定 $s_t$ 检索路径 $P_t=f_{retrieve}(s_t,\mathcal{T}_t)$；控制器 $W_\phi$ 结合 $h_t=f_{enc}(s_t;\pi_\theta)$（LLM 最后一层 token 隐状态）产生共享表示 $u_t$，再分两路：生成潜在记忆前缀 $m_t$、预测树动作 $a^{tree}_t$。
- 记忆条件策略：$\pi_{\theta,\phi}(a_t|s_t)=\pi_\theta(a_t|s_t,m_t(\phi))$；目标 $\max_\phi \mathbb{E}_{x\sim\mathcal{D},\tau\sim\pi_{\theta,\phi}}[R(\tau)]$。

### 2.3 分层潜在记忆树（HLMT）
- 节点定义 $n_i=(e_i,pa(i),ch(i))$，$e_i\in\mathbb{R}^d$ 为控制器产生的压缩潜在摘要，$pa/ch$ 为父指针与子节点集合。树结构显式建模语义层级：上层粗粒度任务语义，下层细粒度执行细节，支持**粗到细**的渐进检索。
- 初始化为虚拟根节点 $n_r$（不编码任务语义，每 episode 重置）。
- **检索算法（贪心递归遍历）**：以 $h_t$ 为查询，在深度 $k$ 选择余弦相似度最大的子节点
  $n_{k+1}=\arg\max_{n\in ch(k)}\frac{h_t\cdot e_n}{\|h_t\|\|e_n\|}$；
  当最大相似度低于阈值 $\tau_{stop}$ 时在深度 $d$ 终止；若无子节点满足，则路径仅含根节点。得到激活路径 $P_t=(n_1,\dots,n_d)$。

### 2.4 双头记忆控制器
- 路径聚合用均值池化 $\bar{p}_t=\frac{1}{|P_t|}\sum_{n_i\in P_t}e_i$（遍历深度已隐式编码路径顺序）；共享表示 $u_t=\text{MLP}_{shared}([h_t;\bar{p}_t])$。
- **潜在注入头（Latent Injection Head）**：
  - $m_t=W_{latent}u_t\in\mathbb{R}^{l_p\times d_{model}}$，作为动态软提示直接前置到当前观测的输入嵌入（附录中进一步实现为前置到选定注意力层的 KV cache：$\tilde{K}=[m_t;K],\tilde{V}=[m_t;V]$）。
  - 不逐层修改主干，开销小；LLM 参数冻结，但 RL 梯度可穿过 LLM 计算图回传到输入层以更新 $\phi$。
- **树动作头（Tree Action Head）**：$\pi_{tree}(\cdot|u_t)=\text{Softmax}(W_{tree}u_t)$，采样离散拓扑操作。
- **即时执行（高频语义更新）**：
  - `insert`：新节点 $e_{new}=W_{ins}u_t$ 作为检索叶节点 $n_d$ 的子节点挂载，保留时序层级。
  - `update`：门控 $\alpha=\sigma(W_{gate}u_t)$，$e_d\leftarrow(1-\alpha)e_d+\alpha W_{upd}u_t$。
  - 新插入/更新的嵌入均做 **L2 归一化**以防表示坍缩。
- **延迟执行（低频效用剪枝，TreeMaintenance，episode 末）**：
  - 计算节点 episodic 效用 $S(n_i)=\sum_{k=t_i}^{T}\gamma^{k-t_i}r_k$（同 episode 多次激活则取平均，避免过度归因高频循环）；
  - EMA 平滑 $S_{EMA}(n_i)\leftarrow(1-\beta)S_{EMA}(n_i)+\beta S(n_i)$；
  - 剪除 $S_{EMA}<\tau_{del}$ 的节点，其子节点直接改挂到父节点以保持连通；
  - 兄弟节点相似度 $sim(e_i,e_j)>\tau_{merge}$ 时用平均池化融合。

### 2.5 训练配方
- 采用 **GRPO**（无需 critic），并用**可验证过程监督**缓解长时程奖励稀疏：节点效用融合步骤奖励与最终回报。
- **分层优势**：$A_i=\lambda_g\frac{S(n_i)-\mu_G(S)}{\sigma_G(S)+\epsilon_0}+\lambda_l(S(n_i)-S(pa(i)))$——全局项鼓励任务级有用性，局部项保留节点相对父节点的专精性；并施加深度折扣 $\tilde{A}_i=\gamma^{d_i}A_i$。
- **联合目标**：$\mathcal{L}(\phi)=\mathcal{L}^{latent}_{GRPO}(\phi)+\lambda\mathcal{L}^{tree}_{GRPO}(\phi)$，两者均为带裁剪的重要性比形式，潜在项额外加 KL 惩罚防策略坍缩；两头共享表示、梯度联合累积，作者称未观察到训练不稳定。
- **算法流程（Algorithm 1）**：初始化虚拟根 → 每步：编码 $h_t$ → 检索路径 $P_t$ → 池化 → 共享表示 $u_t$ → 生成 $m_t$ 与树动作 $a^{tree}_t$ → LLM 依 $m_t$ 产生 $a_t$ → 环境返回 $s_{t+1},r_t$ → 即时更新树 → 回合末 TreeMaintenance → 用轨迹优化 $\phi$。
- **在线/离线解耦**（附录 8.1）：解码期间检索只在时间冻结的树快照上做；拓扑动作先缓存，回合结束后异步提交，避免并发修改导致检索不一致。
- **阈值设置**：$\tau_{stop}=0.5$，$\tau_{merge}=0.9$，$\tau_{del}$ 采用动态百分位（每回合剪除效用最低 5%）；控制器为 512 维 MLP。

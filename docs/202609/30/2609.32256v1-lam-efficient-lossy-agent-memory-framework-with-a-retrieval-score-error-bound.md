## 摘要
智能体记忆会随着智能体读取输入、进行推理和调用工具而不断增长。更长的历史会增加推理成本，并最终超出上下文窗口。基于大语言模型的摘要能够压缩该历史，但会增加延迟，且对信息损失没有显式界。我们提出 LAM，一种有损智能体记忆系统，包含三个组成部分：一条确定性去重规则，并带有对检索分数的替换界——这是对分数扰动的界，而非排序不变的保证；一个记忆管理器，它保留已缓存的前缀，并使压缩与推理重叠进行；以及一个性能模型，可在部署前估计压缩开销。在 600 条智能体轨迹上，LAM 去除了 22.47% 的观测 token，同时保留了 99.984% 的所测得 gold-patch 证据。在固定删除集下，性能模型预测：在预填充之前移除记录（而非从已预填充的上下文中删除它们）可带来 71.4 倍至 91.6 倍的端到端加速。该收益来自调度策略而非规则本身，并适用于任何保持前缀的测试。

## Abstract
Agent memory grows as agents read inputs, reason, and call tools. Longer histories increase inference cost and eventually exceed the context window. LLM-based summarization reduces this history but adds latency and provides no explicit bound on information loss. We propose LAM, a Lossy Agent Memory system with three components: a deterministic deduplication rule with a substitution bound on retrieval scores - a bound on score perturbation, not a certificate of unchanged ranking; a memory manager that preserves the cached prefix and overlaps compaction with inference; and a performance model that estimates compaction costs before deployment. On 600 agent trajectories, LAM removes 22.47% of observation tokens while retaining 99.984% of the measured gold-patch evidence. At a fixed deletion set, the performance model predicts a 71.4x-91.6x end-to-end speedup from removing records before prefill instead of deleting them from a prefilled context. That benefit comes from the schedule rather than the rule and applies to any prefix-preserving test.

# LAM：具有检索分数误差界的高效有损智能体记忆框架 —— 论文总结

## 1. 核心问题与研究动机

- **背景**：AI 智能体在执行任务时会不断读取文件、运行命令并产生输出，这些历史记录支撑任务完成，但会持续增长，推高推理成本与延迟，最终超出上下文窗口，必须进行压缩。
- **现有方法的缺陷**：
  - **LLM 摘要 / 学习式压缩器**（Gisting、ICAE、xRAG、LLMLingua-2、LightMem）依赖模型推理，增加延迟，且**不提供显式的信息损失界**。
  - **SemDeDup** 使用 k-means 对嵌入聚类，输出随初始化变化，可复现性差。
  - **观察掩蔽（observation masking）** 保留最近 k 条观测，丢弃旧内容，虽简单但不界定删除造成的检索分数损失。
  - 这些方法暴露的 token 预算、簇数或窗口大小等参数，**均不能界定删除所导致的检索分数损失**。
- **调度问题**：在长任务中压缩会反复运行，若在已预填充的上下文中删除记录，会导致后续位置的 KV 缓存失效并触发重新预填充，阻塞推理数十秒。
- **整体含义**：LAM 提出一种**确定性、可复现、带检索分数替换误差界**的有损智能体记忆框架，核心贡献在于将"压缩调度"（在预填充前删除）与"去重规则"解耦，并证明调度带来的加速远大于规则本身。

## 2. 方法论

### 2.1 核心思想
- 采用**三层有损去重**，在记录**到达时、预填充之前**进行测试，从而保留已缓存的 KV 前缀。
- 对每条被删除的记录，保留一个距离在 δ 以内的**保留代表（representative）**，从而对任意单位查询的检索分数损失给出上界。

### 2.2 关键定义与公式
- **ε-等价关系**：单位归一化嵌入 a、b 满足 ‖a−b‖₂ ≤ δ 时视为等价。
- **与余弦阈值的关系**：
  - ‖a−b‖₂² = 2 − 2cos(a,b)
  - 合并阈值 cos ≥ t ⇔ ‖a−b‖₂ ≤ δ = √(2−2t)
  - 默认 cos t = 0.95 时 δ = 0.316。
- **δ-替换（Definition 1）**：(R, π) 是 S 的 δ-替换，当 R ⊆ S、π: S→R 且对每个 x 有 ‖x−π(x)‖₂ ≤ δ。
- **定理 1（分数损失界）**：对任意单位查询 q，有 0 ≤ max_{x∈S} q·x − max_{z∈R} q·z ≤ δ，且两端均紧。
- **推论（分布无关的率失真界）**：R_P(δ) ≤ I(X; π(X)) = H(π(X)) ≤ log₂|R|。
- **移除上限（Theorem 2）**：ρ*(δ) ≤ ρ_greedy(2δ)，对应阈值 t′ = 4t−3。
- **性能模型（Equation 2）**：将每轮拆分为随上下文长度 C 缩放的部分（KV 读取、预填充）和不随其缩放的部分（权重流式加载），并用指示函数 ⊮[非前缀稳定] 决定是否支付重新预填充项。

### 2.3 三层设计
- **L0 — 字节精确哈希**：继承自 vLLM 的块哈希机制，用 xxHash3 对**行级**内容去重（行级去重率 18.14%，远高于记录级 1.61%、块级 2.61%）。
- **L1 — ε-等价候选**：用 Qε(x)=round(x/2ε) 量化后分带哈希，候选对用全精度 ℓ2 校验。
- **L2 — 误差有界字节压缩**：用 cuSZp 压缩保留的嵌入，只减少存储，不减少上下文文本。
- **层序**：先 L1 后 L0（若先 L0 会因行删除切碎块，损失 2.45 个百分点）。

### 2.4 算法流程（Algorithm 1）
1. 对到达的每个块编码一次；
2. 用分带哈希检索候选保留记录；
3. 在全精度 ℓ2 下验证距离，选择**最低索引**的合格代表；
4. 若存在则发出引用桩（stub），更新实测界 δ̂；
5. 否则加入保留集并压缩存储。

### 2.5 系统设计
- **放置**：压缩测试在**主机 CPU** 上运行，与 GPU 推理重叠。
- **局部性**：分带索引只检索候选，避免全量扫描。
- **粒度**：仅对当轮新块编码，前缀保持不变。

## 6. 主要结论与发现

- **移除与证据**：默认阈值下 LAM 移除 **22.47%** 的观测 token，保留 **99.984%** 的 gold patch 证据（6,276 行中仅丢失 1 行）；τ=0.999 时移除 22.47%，SemDeDup 为 19.60%，观察掩蔽无合格设置。
- **调度主导**：固定删除集下，预填充前移除比从已填充上下文删除**预测快 71.4×（batch 1）至 91.6×（batch 32）**；收益来自调度而非规则，任何保持前缀的测试均可获得。
- **与其他方法的对比**：在 batch 1 下，LAM 端到端比其他方法快 **9.4×–69.1×**，排序不随移除率变化，因为其他方法均非前缀稳定，需支付重新预填充。
- **跨语料泛化**：LHTB 上近重复规则移除 **33.39%** 观测 token，是 SWE-smith（13.81%）的 2.4×。
- **确定性**：在线与批处理残差在 600/600 轨迹上字节一致；跨 batch size 与跨硬件删除集相同；SemDeDup 仅 50.9% 删除块在 5 个种子间共享。
- **系统开销**：CPU 压缩与 GPU 服务重叠时，输出吞吐保持 **0.9999×** 基线，压缩器以 GPU 输出 token 速率的 4.7× 运行。
- **实测界**：δ̂ = 0.268 < δ = 0.316，所有替换均在配置界内。

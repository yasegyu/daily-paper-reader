## 摘要
基于大型语言模型的多智能体系统生成协作轨迹，记录智能体如何规划任务、验证中间结果并修复失败。重用这些过程需要保留动作的前提条件以及后续智能体所需的输出。我们的实证研究表明，将这些依赖关系分组为功能记忆单元可提高其保留率，而连接单元则能提高任务所需单元和链接的联合检索能力。即使在每种组合的内容跨格式固定时，指令与清单之间偏好的组合方式也会发生变化。根据每种组合与格式配对的执行结果更新选择，优于分别对组合和格式进行评分。这些发现促使我们提出MACE，一个通过执行反馈自适应记忆组织和智能体记忆使用的记忆-智能体协同进化框架。其MemGoG结构将功能单元表示为相关条件、动作和输出的子图，并通过支持、冲突和修复关系连接它们。MACE循环在记忆预算内选择任务相关单元和关系，并为每个智能体提供其当前操作的指令或清单。它记录选中的单元、呈现格式、智能体输出和任务结果，以更新单元评分和关系用于检索，并影响后续呈现选择。在八个基准测试中，MACE以81.11%的平均得分优于十个基线，而最强基线SAGE的得分为78.97%。

## Abstract
LLM-based multi-agent systems generate collaboration traces that record how agents plan tasks, verify intermediate results, and repair failures. Reusing these procedures requires preserving an action's prerequisites and the outputs needed by subsequent agents. Our empirical studies show that grouping these dependencies into functional memory units improves their retention, while connecting units increases retrieval of the units and links jointly required by a task. The preferred combination of units also changes between instructions and checklists, even when each combination's content is fixed across formats. Updating choices from the outcomes of each combination and format pairing outperforms scoring combinations and formats separately. These findings motivate MACE, a memory-agent co-evolution framework that adapts memory organization and agent memory use through execution feedback. Its MemGoG structure represents functional units as subgraphs of related conditions, actions, and outputs, connecting them through support, conflict, and repair relations. MACE Loop selects task-relevant units and relations within a memory budget and provides each agent with instructions or checklists for its current operation. It records the selected units, presentation formats, agent outputs, and task outcomes to update unit scores and relations for retrieval and inform subsequent presentation choices. Across eight benchmarks, MACE outperforms ten baselines with an average score of 81.11%, compared with 78.97% for the strongest baseline, SAGE.

### 2. 论文提出的方法论

论文提出 **MACE (Memory-Agent Co-Evolution)** 框架，由 **MemGoG** 结构和 **MACE Loop** 循环组成。

- **MemGoG 结构（记忆构建）**：
    - **功能记忆单元 (Functional Memory Units)**：将相关条件、动作和输出等依赖关系建模为子图，确保内部依赖的完整性。
    - **单元间关系**：通过**支持 (support)**、**冲突 (conflict)** 和**修复 (repair)** 等类型化外层关系连接不同单元，以支持跨经验的组合检索。
    - **多粒度构建**：根据智能体角色的不同需求，构建节点级或子图级记忆单元，如片段、机制、流程、角色投影、来源和冲突单元等。

- **自适应记忆合成器 (Need-aware Memory Composer)**：
    - 根据任务需求和当前状态，从候选库中筛选记忆单元。
    - 通过综合**相关性 (Relevance)**、**历史效用 (Historical Utility)**、**支持度 (Support)** 与**冲突度 (Conflict)**、**成本 (Cost)**、**风险 (Risk)** 等因素计算每个单元的得分 `St(g)`。
    - 在**记忆预算 (Budget)** 约束下，选择得分最高的单元组成工作图 `Gwork_t`，过滤掉冲突或高风险的建议。

- **自适应代理-记忆耦合器 (Adaptive Agent-Memory Coupler)**：
    - 构建“记忆单元-代理”相关性矩阵，将工作图中的单元与每个代理的当前角色、阶段和操作匹配。
    - 为每个代理生成个性化的记忆补丁 `P_t^i`，通过配置**内容 (content)**、**模式 (mode)**、**格式 (format)**（如清单或指令）、**时机 (timing)** 和**强度 (strength)** 等参数，将记忆适配到特定代理和任务。

- **反馈协同进化器 (Feedback Co-Evolver)**：
    - 记录完整的使用轨迹（选中的单元、代理输出、任务结果等）。
    - 从**局部 (local)**、**下游 (downstream)** 和**团队 (team)** 三个层级综合评估反馈，计算轨迹回报 `R_ξ`。
    - 使用更新公式 `u_t+ = u_t + ηD_ξ(R_ξ1 - u_t)` 更新记忆单元的效用评分，并强化/建立支持或冲突关系。同时记录成功轨迹和失败机制，为未来任务提供新经验。

### 6. 论文的主要结论与发现

- **核心结论**：记忆的组织方式与智能体的使用方式必须依据执行反馈进行协同进化。单纯优化记忆内容或固定呈现方式，都无法达到最优性能。
- **性能表现**：MACE在所有8个基准测试上均取得了最高分，平均得分 **81.11%**，远超最强基线 SAGE (78.97%) 和所有通用多智能体方法（如MAD平均77.78%）。
- **关键发现**：
    - 将依赖关系构建为功能单元并显式连接，可显著提升记忆的内部保留率和跨经验覆盖率。
    - 记忆组合的优劣与呈现格式（指令/清单）强相关，必须将两者作为配对进行联合优化。
    - 基于配对结果的反馈更新机制优于分别评分或固定策略。
    - MACE在骨干模型替换、网络不稳定和记忆预算缩减的情况下仍能保持较高的性能，表现出较强的鲁棒性。

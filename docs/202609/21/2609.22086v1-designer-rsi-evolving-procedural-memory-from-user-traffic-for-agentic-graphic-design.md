## 摘要
专业图形设计是一项长期智能体任务，其中结构化、可编辑的产物源于许多相互依赖的操作，但结果无法获得可靠的程序化预言。我们引入一个持续适应框架，其中冻结的前沿模型通过230多种工具操作专业设计软件，而外部程序性记忆（以自然语言技能形式）从经验中积累和优化可复用的设计程序。该记忆通过获取反复出现但未覆盖子任务的程序而扩展，并通过针对自身成功和失败执行修订现有程序而深化，同时匹配的回放门仅接受能够修复失败且不倒退已有成功的更改。在1406个真实用户简报和1869个自动评分轨迹上进行了五轮，无需权重更新且无人类标签，将技能库从76个文档衍生技能增长到139个，并将GenEval2在Claude-Sonnet-4上的执行成功率从72.7%提升到99.3%（生成质量提升11.99点），在Claude-Sonnet-4和Claude-Opus-4.6上的四个专业设计基准中，与无技能代理相比，胜率分别为61.8%和67.6%。我们进一步表明这两种机制结合是有效的：在用户流量基准中保留的200个简报上，仅扩展或仅深化的胜率分别为49.4%/48.6%（相对于无技能代理），而两者结合达到58.5%（p=0.025）。程序性记忆为在嘈杂、不可验证反馈下持续适应智能体提供了一种实际途径。

## Abstract
Professional graphic design is a long-horizon agentic task in which structured, editable artifacts emerge from many interdependent actions, yet outcomes admit no reliable programmatic oracle. We introduce a continual adaptation framework in which a frozen frontier model operates professional design software through more than 230 tools, while an external procedural memory of natural-language skills accumulates and refines reusable design procedures from experience. The memory widens by acquiring procedures for recurring uncovered subtasks and deepens by revising existing procedures against their own successful and failed executions, while a matched replay gate admits only changes that repair failures without regressing observed successes. Five rounds over 1,406 real user briefs and 1,869 automatically graded trajectories, with no weight updates and no human labels, grow the bank from 76 documentation-derived skills to 139 and raise GenEval2 execution success on Claude-Sonnet-4 from 72.7% to 99.3% (+11.99 points in generation quality), with 61.8% and 67.6% win rates against the no-skill agent across four specialized design benchmarks on Claude-Sonnet-4 and Claude-Opus-4.6. We further show the two mechanisms are effective in combination: on 200 held-out briefs from user-traffic benchmark, widening or deepening alone reaches a 49.4% / 48.6% win rate over the no-skill agent, while their combination reaches 58.5% (p = 0.025). Procedural memory offers a practical route to continual adaptation of agents under noisy, unverifiable feedback.

## 1. 核心问题与研究动机

专业图形设计是一项典型的长期智能体任务——从用户指令到最终可编辑的结构化设计产物，需要数十个相互依赖的中间操作。与代码（可用自动化测试验证）或游戏（有明确奖励信号）不同，设计任务的产出**没有可靠的程序化评估器（oracle）**，这为智能体的持续学习带来了特殊挑战：

- **长周期信用分配困难**：一个设计任务往往涉及数十乃至上百个操作序列，仅有终端反馈时难以判断哪些中间决策导致了成功或失败。
- **评估信号噪声大**：设计简报常混合客观可测试的要求（文字、颜色、排版）与主观审美标准（层次、构图、风格），自动化评估器只能部分捕捉，且 VLM 评估器的绝对分数存在跨运行漂移。
- **基础模型难以更新**：前沿模型多为外部托管或参数量巨大，直接进行权重更新不现实。

基于上述观察，作者提出一个核心假设：**将学习目标从模型权重转移到外部程序性记忆**——即围绕冻结的模型构建一个可演化的、以自然语言表示的可复用技能库。该技能库替代了代价高昂的模型训练，在保持模型固定的前提下实现持续适应。

## 2. 方法论

### 2.1 整体框架

> **核心思想**：在冻结的基础模型（frozen frontier model）外部维护一个 **Skill Bank（技能库）**，只更新其中的 `SKILL.md` 自然语言文件，不修改任何模型权重、工具或渲染器。演化循环涉及四个固定角色：

| 角色 | 功能 |
|---|---|
| **Prompter** | 从用户数据和 LLM 中生成设计简报 |
| **Solver** | 智能体本身：技能库 + 工具 → 渲染图像 |
| **Grader** | 多模态评估器，对输出打分并说明失败原因 |
| **Reflector** | 将失败信息转化为对 SKILL.md 文件的定向修改 |

技能库沿两个轴演化：**拓宽（Widening）** 与 **深化（Deepening）**，所有修改通过**回放门控（Replay Gate）** 审核后才部署。

### 2.2 拓宽（Widening）：从覆盖缺口铸造新技能

- 对每条执行轨迹，冻结的 LLM 从简报和工具调用序列中提取并规范化实际执行过的**子任务**。
- 若某个子任务未被检索到的技能覆盖（涉及失败技能对应的子任务也计为未覆盖），则将其存入**覆盖池（coverage pool）**，按规范化标签（canonical label）累积。
- 当同一标签出现次数达到阈值 **k_min = 3** 时，冻结 LLM 将这些案例蒸馏为一个候选技能。
- 候选技能通过与无技能基线的回放门控测试后才被采纳；被拒绝的候选丢弃，但其案例保留在池中等待更多证据积累。

### 2.3 深化（Deepening）：强化既有技能

- 每条轨迹记录其检索到的技能；得分低于成功阈值（**τ = 0.6**）被记为失败，计入所有检索到的技能。
- 失败计数达到阈值 **m = 2** 的技能被选出进行改写，优先处理失败最多的技能。
- Reflector 获得：简报、逐需求评分、失败原因、当前 SKILL.md，以及该技能在类似任务上成功调用的**对比性历史**（工具调用序列、中间结果、思考令牌），据此生成目标明确的定向修改。
- 若重复定向改写失败，升级为全技能重写；拒绝的改写触发可选的探索循环，在技能失败提示上测试有无技能两种分支，决定技能命运（更新/删除/保留）。

### 2.4 回放门控（Replay Gate）

这是整个框架的关键安全机制，同时解决两个混淆源：

1. **评估器漂移**：VLM 绝对分数对同一图像存在漂移，“平均分上升就接受”可能混淆改进与噪声。
2. **上游状态差异**：资源检索等上下文不同可能导致候选凭更好的输入获胜。

门控设计：
- 从触发技能/聚类的轨迹中采样**回放提示**（改写：成功/失败各采样；铸造：按触发聚类采样）。
- 每个提示生成多个**不同上下文的实例**，在同一个批次中分别用候选版本和基线版本重放执行。
- 输出以**成对方式随机换序**由评估器判断，每个上下文内部唯一差异就是技能条件。
- 一个提示只有在候选在多数上下文中获胜时才计算为胜；一个变更只有在 **∃提示获胜 ∧ ∄提示失败** 时才被接受。

该设计比最大化期望质量更保守，符合安全策略改进的指导思想——产品部署中可见回归的代价远高于错过的改进。

### 2.5 冷启动

初始技能库从产品帮助文档蒸馏获得，四阶段流水线：意图聚类 → 页面分配（无 LLM）→ 技能生成 → 验证保存，产生 76 个技能（26 Photoshop、25 Illustrator、25 InDesign 等效或跨应用）。

### 2.6 其他关键组件

- **技能表示**：Markdown 文件 + YAML 前置元数据（描述、应用模式、工具序列、前置技能、状态），正文含“何时使用/澄清/步骤/提示/错误处理”五大部分。
- **检索**：两阶段——LLM 将简报蒸馏为最大 6 个操作关键词 → token 重叠打分排序（非嵌入检索），确保作者编写与运行时检索共享同一标记器。
- **渐进式披露**：每轮向系统提示注入紧凑目录（技能名 + 一行描述），模型通过 load skill 工具按需读取完整正文。
- **个性化（Appendix I）**：通过偏好条件检索和工具范围限定，支持方法偏好、感知/精度限制、复杂手工目标三类个性化，但排除在主实验之外。

## 6. 主要结论与发现

1. **技能库持续演化显著提升性能**：五轮后技能库从 76 增至 139，GenEval2 成功率从 72.7% 升至 99.3%，DPG-Bench 从 82.7% 升至 100%。
2. **拓宽与深化互补而非替代**：单独使用仅达 49.4%/48.6% 胜率（vs 无技能基线），结合后达 58.5%（p=0.025），效果呈超加性（+3.85 完整性分数）。
3. **技能库具有跨骨干模型的泛化能力**：在三个独立模型上均获得显著收益，平均质量提升 +3.83 至 +9.67 分。
4. **演化轨迹并非单调**：R4 在低完整性阈值上短暂退步，但 R5 通过强化深化（21 次改写 vs 4 次铸造）全面恢复并超越，说明其安全性依赖有效的回放门控。
5. **铸造技能确实覆盖了种子库之外的意图**：与新技能最近邻距离（0.215）显著大于种子库内部间距（0.158），确认拓宽不是在翻新已有知识。
6. **程序记忆适用于不可验证、噪声反馈场景**：在无权重更新、无人工标签的前提下，持续适应可以发生在外部技能库中。

---

## 7. 优点

- **设计优雅的保守更新机制**：回放门控将绝对分数漂移和上游状态差异风险均考虑在内，以成对比较代替绝对分数比较，仅接受能修复失败且不倒退已有的变更——将安全策略改进思想引入自然语言技能演化。
- **冷启动方案完整**：从产品文档自动蒸馏种子技能，解决“无流量时无从学习”的冷启动问题，且仅从种子库演化，检索使用的标记器与编写时一致保证可检索性。
- **对比式深化**：Deepening 不仅看失败文本，还对比成功/失败轨迹的具体分歧，使 Reflector 能基于具体证据而非仅凭失败描述推理。
- **全面且分层的评估**：质量/成功/胜率/延迟/成本多维度评估，同时给出定性和定量证据。
- **清晰的分离设计**：把模型权重、工具、渲染器、评估器全部固定，只让技能库演化，实验控制干净，结论具有很强的可归因性。
- **渐进式披露**：目录注入 + 按需读取完整技能，避免上下文拥挤，token 利用率高。

## 8. 不足与局限

### 实验层面的不足

1. **泛化性受限**：所有用户数据来自 Adobe 流量，外部复现需要替代数据；保留评估集未公开提示文本，阻碍复现。
2. **Qwen 结果受干扰**：本地部署的超时和连接中断直接影响 27B 模型的成功率统计，作者虽承认但未完全解决。
3. **评估器偏差风险**：VLM 评估器虽然有质量，但仍有家族偏见风险（Claude 模型之间的评估关系）；作者声称通过成对比较缓解但无法彻底消除。

### 方法层面的局限

1. **回放门控是局部保守**：回放集上的无回归并不能保证全用户流量分布的单调改进——观察到的用户分布可能随时漂移。
2. **长程序保真度衰减**：指令随执行步骤累积，模型在长技能上的遵循度下降（附录 I 的瓷砖案例直观展示了这个问题）。
3. **最终可用性受模型默认策略制约**：自然语言技能的描述力有限，当模型对某操作有强默认策略时，文本指导可能不足以改变其行为。
4. **感知/验证瓶颈**：细粒度几何操作仍受模型感知能力和自动化验证能力限制（Droste 效果案例），当前仍需人类介入。
5. **技能蒸馏规模受限**：对长、多步骤的复杂手工流程，录入（标注）、蒸馏（压缩）和使用（跟随）三个环节都会损失保真度，损失不断累积。

### 应用层面的局限

- 需要企业内部部署（Asset retrieval、文档库、评估器）、数据治理框架和托管服务的企业协议，复制门槛较高；
- 对个人用户或中小团队来说，该方案的工程开销可能超过收益。

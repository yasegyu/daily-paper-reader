## 摘要
大型语言模型的记忆系统主要集中于高效检索，而关于检索到的记忆是否应被信任的决策却相对较少受到关注。当记忆库包含相互矛盾的观点时，标准的检索增强生成（RAG）会盲目地注入记忆并放大幻觉：在易受记忆注入影响的模型中，矛盾记忆下的RAG幻觉率明显高于无记忆基线的幻觉率。受前额叶皮层记忆信号机制的启发，我们提出了记忆决策层（MDL），这是一种位于检索与生成阶段之间的零参数记忆决策控制器。其核心是一个三信号互补编码器，通过基于QR的正交子空间投影和元工作记忆信号，将相关性、可靠性和任务风险融合为一种可解释的决策表示，从而量化检索记忆的可信度。基于该编码器，MDL显式地将置信度与一致性解耦，并引入了风险反转和显式弃权。在主流大型语言模型和多个开源数据集上的评估表明，MDL在一般场景下将矛盾记忆下的幻觉率降低了约56.04%，并在高风险场景下将幻觉率降至接近零。该控制器完全白盒化：它仅依赖几何运算，无需训练参数，每次决策仅增加约0.14毫秒——比其前的嵌入检索步骤快约50倍，比大型语言模型自评估调用快四到五个数量级。

## Abstract
Memory systems for large language models have focused predominantly on efficient retrieval, whereas the decision of whether retrieved memories should be trusted has received comparatively little attention. When the memory store contains conflicting positions, standard retrieval-augmented generation (RAG) blindly injects memories and amplifies hallucinations: in models susceptible to memory injection, the RAG hallucination rate under conflicting memories is markedly higher than that of a memory-free baseline. Inspired by memory signaling mechanisms in the prefrontal cortex, we propose the Memory Decision Layer (MDL), a zero-parameter memory decision controller situated between the retrieval and generation stages. Its core is a three-signal complementary encoder that fuses relevance, reliability, and task risk through QR-based orthogonal subspace projection and a meta-working-memory signal into an interpretable decision representation that quantifies the trustworthiness of retrieved memories. Building on this encoder, MDL explicitly decouples confidence from consistency and introduces risk inversion and explicit abstention. Evaluations on mainstream large language models and multiple open-source datasets show that MDL reduces the hallucination rate under conflicting memories by about 56.04% in general scenarios and approaches zero hallucination in high-risk scenarios. The controller is fully white-box: it relies purely on geometric operations, requires no trained parameters, and adds only about 0.14 ms per decision -- roughly 50x faster than the embedding-retrieval step that precedes it and four to five orders of magnitude faster than an LLM self-evaluation call.

### 2. 方法论：核心思想、关键技术细节与算法流程

**（1）总体架构：记忆决策层（MDL）**

MDL是位于检索层与生成层之间的零训练参数控制器，形式化为 π: (q, m, R, A) → a，即根据查询、候选记忆、可靠性信号与风险系数输出四级别离散动作。整体分为四个渐进阶段：
- 阶段一：信号提取与风险反转
- 阶段二：正交子空间投影
- 阶段三：元工作记忆融合与置信度-一致性解耦
- 阶段四：四级动作映射

**（2）三信号定义与编码**

- **相关性信号 M** = max_j cos(e_q, e_{m_j})，即查询与候选记忆句嵌入的最大余弦相似度（使用all-MiniLM-L6-v2）。
- **可靠性信号 R** = clip(ˉs_rel · (1 − φ)², 0, 1)，其中ˉs_rel是相关记忆间的平均成对嵌入相似度，φ是立场冲突率——由词法冲突检测器（覆盖否定、是非极性、反义词对）标记的相关记忆对比例。
- **任务风险信号 A**：由类别到风险的映射表赋值（TruthfulQA），或由健康/法律/金融等领域关键词匹配（HaluEval），取值域 {0.20, 0.50, 0.85}；高风险类别（健康、法律、金融、阴谋论等）A ≥ 0.70。关键操作是**风险反转编码** s⁻¹_A = 1 − A，将高风险转换为低激活。
- 每个标量 s ∈ [0,1] 通过高斯峰映射编码为D=16维向量 v(s) = s·1_D + Σ exp(−(s−c_i)²/2σ²)e_i（σ=0.20），得到三个通道向量 v_wm、v_r、v_a。

**（3）正交子空间投影与融合**

- 基于QR分解生成完整正交投影算子 Π_k = P_kP_k^⊤（维度分配 d1=5, d2=5, d3=6），构建子空间权重矩阵：

  W_k = s_kΠ_k + ε_c·Σ_{j≠k}Π_j

  其中 ε_c=0.10 确保主增益占主导且保持单调性。
- **二阶风险调制**：风险向量 v_a 产生有界标量增益 g_A = 0.5 + 0.5⟨v_a⟩。由于风险反转编码，风险越高，v_a 的幅值越小，g_A 随之收缩——恰好在高风险时抑制相关性驱动的置信度。
- 融合得到有界中间决策表示：**v_meta = tanh(g_A·W_wm·v_wm + W_r·v_r + W_a·v_a + b)** ∈ R¹⁶

**（4）置信度-一致性解耦（C-α解耦）**——最核心的机制

从 v_meta 并行导出两个可独立审计的标量：
- **置信度 C**（范数）：C = clip((‖v_meta‖ − n_min)/(n_max − n_min), 0, 1)
- **一致性 α**（余弦）：α = cos(v_wm, v_meta)

两者的语义区分：C 代表"确信程度"（强度），α 代表"方向正确性"（语义方向），各自承载不同信息类型且可被下游审计接口单独读取。门控调制后得最终置信度 **C_final = C · (0.3 + 0.7α)**，再映射为四级离散动作 a ∈ {Active（采纳）, Supp（抑制）, Silent（沉默）, Opt-Out（弃权）}。

**（5）参数与超参数设置**

全部为人工设定或校准集网格搜索，零训练参数。关键超参数：D=16、子空间维度(5,5,6)、σ=0.20、ε_c=0.10、主增益 s_wm/s_r/s_a = 1.0/0.7/0.5。阈值向量 θ=(θ₀,θ₁,θ₂) 在每数据集80题的独立校准集上通过网格搜索确定。归一化参数 n_min、n_max 同样取自校准集。

### 6. 主要结论与发现

- **MDL显著抑制冲突记忆下的幻觉放大**：在gemma-4-E4B-it上，MDL将总幻觉率从标准RAG的53.0%降至23.3%（p=0.014），降幅约56%，且基本消除了RAG引入的负面影响。
- **高风险场景接近零幻觉**：高风险（A=0.85）样本的幻觉率在所有模型上均达到0.0%（图3(a)、表4）；风险加权总体幻觉率降至17.0%。在HaluEval高风险场景中，幻觉率低至1.3%。
- **零参数、亚毫秒级决策**：控制器单次决策仅40.1μs（含信号聚合约0.14ms/次），较嵌入检索（~6.8ms）快约50倍，较LLM自评估（2.0–4.7s）快4–5个数量级。
- **C-α解耦具备独立审计价值**：尽管C与α相关（r=0.902），α仍在正确/错误决策间有显著区分力（t=3.70, p<0.001），说明余弦方向包含C不包含的方向性信息。
- **三信号存在协同增益**：信息论分解显示三信号联合信息量为0.057bit，非线性协同增益+0.007bit；单一信号精度退化至多数类基线（0.581），融合后可提升至约0.61–0.63。
- **M信号的安全价值不可替代**：在低相关性（M<0.4）记录中，加入M将弃权率从20.0%翻倍至40.0%，有效阻止无关噪声进入生成上下文。
- **风险反转是高风险弃权的关键**：移除风险反转编码使精度下降5.5pp，系统无法在高风险场景中自发降低范数触发弃权。

4. **风险显式化与安全冗余**：风险反转编码（s⁻¹_A = 1−A）使高风险自动触发弃权，实现领域级别的安全护栏。
5. **兼顾预防与纠正的双重路径**：在注入前阻断错误记忆（预防为主），而非生成后修复（事倍功半）。

### 8. 不足与局限

1. **边界权衡问题**：在高风险高相关性区域（A≥0.70, M≥0.70），极高的相关性可能过度抬高置信度C而削弱部分风险抑制效果——医疗领域该区域的决策精度降至55.6%。
2. **Active动作下仍有8.0%残余幻觉**：说明检索后控制无法完全替代对记忆库本身的细粒度清理，需要进一步引入片段级过滤机制。
3. **信号提取依赖启发式规则**：可靠性信号R中的词法冲突检测器覆盖有限（否定、极性、反义词对），较复杂的立场冲突（隐含矛盾、常识悖论等）可能漏检；风险系数A需人工或关键词映射，难以泛化至未预定义的领域。
4. **小样本局限**：核心实验在200题以内，置信区间较宽；3,600条信号记录中的决策精度（~61%）距离理想水平仍有明显空间。
5. **基准和基线的选择偏置**：与CRAG和Self-RAG的对比使用prompt化变体而非原始实现——CRAG的"web搜索修正"被替换为参数知识回退，Self-RAG的完整训练版并未使用；这些替换可能低估了基线方法的性能。
6. **不可控的LLM变异性**：API后端（deepseek、gemini）的底层版本和内部更新不可控，跨论文复现可能存在偏差。
7. **高计算成本的副产品**：虽然MDL本身零参数极快，但端到端评估需要大量LLM调用（例如对deepseek进行200题×3种子×2数据集），总API成本不低，某些资源的复现可能受限。
8. **诚实报告的异常结果**：移除正交子空间反而提升2.8pp精度，表明该组件的价值主要体现在可解释性和能量守恒的理论性质上，而非实际性能——这对声称"核心组成"而言略显尴尬。

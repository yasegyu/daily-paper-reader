## 摘要
优秀的辅导需要适应个体差异：它要追踪学习者的已知知识，察觉其出错的原因，并提出最能帮助下一步的问题。而大多数已部署的辅导工具只是提供固定的题库，将错误答案视为单一的信号位。我们提出了 CoLearn，一个交互式智能体辅导系统，支持迭代式辅导循环：学习者进行练习，系统则构建基于证据的学习者对内容掌握程度及其误解的记忆。随着证据的积累，该记忆被更新，并用于生成下一个个性化问题。CoLearn 包含三个组件：(i) 持久化的学习者状态记忆，采用基于软证据的贝叶斯知识追踪对每个主题的掌握程度进行更新，其中大型语言模型充当连续观测函数；(ii) 自适应问题生成，针对学习者的最薄弱主题和反复出现的误解；(iii) 证据视图，通过实时进度可视化和盲法 A/B 比较，使个性化过程可见且可测试。在盲法 A/B 评估中，基于该记忆条件化的问题在 68%–69% 的情况下被偏好于非个性化问题；而在具有隐藏真实掌握程度的角色模拟中，智能体的信念会收敛至学习者的真实掌握程度。

## Abstract
Good tutoring adapts to the individual: it tracks what a learner knows, notices why they go wrong, and asks the next question that will help most. Most deployed tutoring tools instead serve fixed item banks and treat a wrong answer as a single bit of signal. We present CoLearn, an interactive, agentic tutor that supports an iterative tutoring loop: the learner practises, and the system builds an evidence-grounded memory of the learner's mastery and misconceptions. This memory is updated as evidence accumulates and is used to generate the next personalised question. CoLearn has three components: (i) a persistent learner-state memory that updates per-topic mastery with a soft-evidence variant of Bayesian Knowledge Tracing, where a large language model acts as a continuous observation function; (ii) adaptive question generation that targets the learner's weakest topic and recurring misconceptions; and (iii) an evidence view that makes personalisation visible and testable through live progress visualisation and blind A/B comparison. In blind A/B evaluation, questions conditioned on this memory are preferred over non-personalised ones 68-69% of the time, and in persona simulations with hidden ground-truth mastery the agent's belief converges toward the learner's true mastery.

## 1. 论文的核心问题与整体含义

### 研究动机
- **基础问题**：真正优秀的教学需要适应个体差异——追踪学习者已知内容、察觉出错原因、提出最有帮助的下一步问题。但现有部署的辅导工具存在三大缺陷：
  1. **知识追踪系统**将每个回答简化为正确/错误的二进制信号，丢弃了自由文本答案中的诊断信息；
  2. **LLM 辅导系统**会话流畅但基本无记忆，无法跨会话累积对学习者的理解；
  3. **适应性不透明**——学习者无法看见或检验系统对他们的建模。
- **理论根基**：借鉴学习科学中的概念转变理论（Piaget）、误概念诊断（Tatsuoka）、最近发展区（Vygotsky）和掌握学习（Bloom）等传统，强调错误答案具有信息量，应被用于指导下一轮教学。

### 核心含义
- 该论文提出 **CoLearn**，将"理想辅导者"操作化为**人机共学习循环**：学习者答题 → 系统评分 → 挖掘误解 → 更新持久化的主题级掌握记忆 → 基于更新后的信念生成下一个更有针对性的问题。
- 核心贡献在于：将**答案级诊断**与**持久化学习者状态记忆**和**适应性练习生成**连接起来，同时使个性化过程**可见、可测试**。

## 2. 方法论

### 系统整体架构
系统包含三个核心组件，构成一个闭环：
- **持久化学习者状态记忆**（`A_t`）：存储每个主题的掌握度估计 `p`、去重后的误解列表及掌握度轨迹，按`(学习者, 学科)`维组织而非按会话存储。
- **自适应问题生成器**：针对学习者最薄弱主题和反复出现的误解生成下一道题。
- **证据视图**：通过实时进度可视化和盲法 A/B 测试界面，使人个性化可被检查。

### 关键技术：软证据贝叶斯知识追踪（Soft-Evidence BKT）
- **观测函数**：LLM 作为连续观测函数，从学生答题中输出 `mastery_evidence o ∈ [0,1]` 和 `evidence_strength w ∈ [0,1]`，不进行 0.5 二值化。
- **更新公式**：
  1. 计算贝叶斯后验（正确观测 `p₊` 和错误观测 `p₋`），基于 BKT 参数 `(p_slip, p_guess, p_transit)`；
  2. 按 `o` 混合两个后验（`o·p₊ + (1-o)·p₋`）；
  3. 按置信度 `w` 向先验收缩（`p + w·(blended - p)`）；
  4. 施加能力门控的学习转移：`p_next = p_cond + o·(1-p_cond)·p_transit`——**明确错误答案不会提高掌握度估计**，这是对标准 BKT 的变体改进。
- **误解记忆**：单选题的每个干扰项预先绑定特定误解标签，选择干扰项即产生诊断；简答题由 LLM 提取误解摘要，区分"陈述了错误内容"（positive）与"遗漏/过于模糊"（absence），并跨会话保持标签措辞一致性。

### 自适应问题生成
- 按学习者范围内主题的最弱项排序、定位最薄弱主题、选择至多两个存储误解进行探测，生成简答题或带误解绑定干扰项的单选题。
- 产生的问题附带元数据（目标主题和误解），驱动可见的"为什么这道题"标签。
- **策略层**：自然语言指南被附加到生成提示中（如"当针对存储的误解时，偏好每个误解一个干扰项的单选题"），修改文本即可改变生成行为，无需改代码。但注意：**自动策略进化仅在设计层面，尚未实现**。

## 3. 实验设计

### 评估维度与场景
1. **盲法 A/B 偏好测试**（§3.2）：18 名具备相关背景的评判者，每人完成 12 组比较（共 216 个判断），问题来源被服务端隐藏，随机排序，衡量个性化与非个性化问题的感知相关性。

3. **用户调研**（§3.4）：16 名人类评判者，13 个李克特 1-5 题项，覆盖可用性、响应速度、问题质量、反馈有用性、透明度、整体采用意愿六个维度。
4. **效率测量**：测量短答题/多选题的延迟和成本。

## 6. 主要结论与发现

- **个性化偏好显著**：回答问题由记忆条件化的问题在盲法 A/B 测试中，生物学 68%、化学 69% 的时间被偏好（p=0.008，符号检验）；混合能力学习者偏好更高（74% 生物 / 77% 化学），强学习者较低（73% / 66%）。
- **掌握度估计准确且收敛**：Adaptive 条件下的最终掌握度 MAE 最低（0.12 vs 0.16/0.20）；每个学习者的信念误差逐步走向隐藏的真实掌握度；更新幅度 |Δp| 从 0.14 降至 0.10（表明信念锁定），而两个对照组保持平缓或上移。
- **观测函数有效但有层次差异**：per-answer mastery_evidence 与真实掌握度相关性在池化水平为 r=0.68（主要由层间分离驱动），按能力层：弱层 r≈0.15、混合层 r≈0.48、强层 r≈0.41——**观测函数对最需要准确诊断的低能力学习者最不可靠**。
- **可用性良好**：用户问卷总体均分 4.0/5，75%（12/16）愿意复使用；响应速度维度最低（3.7），与实测延迟一致。

## 7. 优点

- **软证据 BKT 设计精妙**：LLM 输出的连续观测（掌握度证据 + 置信度）替代二进制的正误信号，结合置信度收缩和能力门控的学习转移，数学上是纯算术、可单元测试、可解释。
- **工程化程度高**：容器化部署、单命令启动、RBAC 认证、SSE 流式传输、完整后端测试套件，是可运行的研究原型。
- **透明化和可测试性设计领先**："为什么这道题"芯片、实时掌握度动画、分支图时间线、概念掌握雷达图，以及内置的盲法 A/B 工具，使个性化从"不可见黑箱"变为"可检验的假设"。
- **方法论上的严谨性**：明确区分"智能体的信念"与"学习者的真实知识"，不宣称学习收益，只声称记忆的收敛性；评估中使用了隐藏真实掌握度的人物模拟来验证估计准确性，而非仅依赖自我报告。
- **评价设计具隔离性**：Random-topic 和 Frozen 两种对照条件对"针对性"和"记忆写入"分别做了较好的控制。

## 8. 不足与局限

- **观测函数在低能力端失效**：对弱能力学习者的每答证据与真实掌握度相关性极低（r≈0.15），而这正是最需要准确诊断的人群；盲 A/B 还排除了弱学习者，因为"弱在所有技能上"无法区分针对性。
- **BKT 参数未个性化校准**：使用共享的默认先验参数，未按技能或学习者拟合，绝对掌握度值仅具指示性而非已校准。
- **策略自进化未实现**："self-evolve"仅存在于设计图中，策略指导文本固定，只有记忆侧适应已在系统中实现。
- **未验证实际教学效果**：A/B 衡量的是"感知相关性"而非学习收益；未独立评估问题的事实正确性、课程契合度、可回答性或干扰项质量；**未验证生成的问题确实引出其声称的误解**。
- **未评估远迁移学习**——真正的能力检验不在范围内。
- **与同类 LLM 辅导系统无直接对比**，难以确定 CoLearn 相对竞品的增量价值。
- **统计功效有限**：每个学科的评判者数仅 18 人，能力层子组分析为 6 人，未对各层单独做显著性检验。

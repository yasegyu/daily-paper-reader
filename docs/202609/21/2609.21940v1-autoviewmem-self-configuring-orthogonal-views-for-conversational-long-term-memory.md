## 摘要
长期记忆对于大型语言模型（LLM）代理在长时间交互中保持一致性和个性化至关重要。现有记忆系统通常依赖固定粒度或静态模式，但当偏好、事件、约束和时间更新等异构信息被嵌入到单一混合表示中时，这些设计会陷入困境。由此产生的语义干扰使top-K检索对噪声敏感，并常使相关证据排名不佳。我们提出AutoViewMem，这是一种数据驱动的框架，在索引之前将长期会话记忆组织为自配置、低重叠的语义视图。AutoViewMem从交互痕迹中发现候选视图，选择紧凑的互补视图集，并利用这些视图指导写入时的、基于来源的结构化记忆提取。这种以表示为先的设计将语义解缠从检索时间转移到写入时间，使得标准top-K相似性搜索能够在无需显式路由或迭代检索的情况下检索到聚焦的证据。我们进一步应用离线整合以提高记忆的紧凑性和一致性。在LoCoMo和PersonaMem基准上，在Qwen3-8B和Qwen3-14B骨干网络下的实验表明，AutoViewMem在强大的记忆基线上提高了长时程问答和个性化性能，同时保持了简单的推理流程。

## Abstract
Long-term memory is essential for large language model (LLM) agents to maintain consistency and personalization over extended interactions. Existing memory systems typically rely on fixed granularities or static schemas, but these designs struggle when heterogeneous information, such as preferences, events, constraints, and temporal updates, is embedded in a single mixed representation. The resulting semantic interference makes top-K retrieval sensitive to noise and often leaves relevant evidence poorly ranked. We present AutoViewMem, a data-driven framework that organizes long-term conversational memory into self-configuring, low-overlap semantic views before indexing. AutoViewMem discovers candidate views from interaction traces, selects a compact complementary view set, and uses these views to guide write-time structured extraction of provenance-grounded memories. This representation-first design moves semantic disentanglement from retrieval time to write time, allowing standard top-K similarity search to retrieve focused evidence without explicit routing or iterative retrieval. We further apply offline consolidation to improve memory compactness and consistency. Experiments on the LoCoMo and PersonaMem benchmarks, under both Qwen3-8B and Qwen3-14B backbones, show that AutoViewMem improves long-horizon question answering and personalization over strong memory baselines while preserving a simple inference pipeline.

- **研究背景**：基于大型语言模型（LLM）的对话代理越来越多地应用于长期陪伴、个性化助手和企业支持等场景。在这些场景中，交互跨越数周或数月，远超有限的上下文窗口。即使使用长上下文模型，直接使用完整历史记录也效果有限：话题漂移、用户状态演变以及显著事实的"长尾"分布，导致大量低相关性的上下文增加了成本和噪声，而关键细节仍埋藏在遥远的token中。

### 2. 论文提出的方法论（AutoViewMem框架）

AutoViewMem是一个两阶段记忆架构，包含**在线视图归纳与写入**以及**离线整合**两部分。

#### 2.1 核心思想
将长期记忆组织为**自配置、低重叠的语义视图**。视图与粒度是正交的：粒度控制记忆单元大小，而视图定义同一证据上的语义投影。关键设计在于——在记忆项进入向量索引之前减少语义纠缠。一旦记忆在互补视图下写入，简单的全局top-K搜索就能构建聚焦的上下文，无需显式路由或迭代检索。

#### 2.2 关键概念
- **视图（View）**：一种轻量级模式，包含名称、一组槽位和提取模板。多个视图之间在语义相似度下要求**互补且低重叠**（并非严格的线性代数意义上的正交）。
- **记忆项（Memory Item）**：携带源片段、时间戳和视图标签。

#### 2.3 在线自适应记忆学习（三段式流程）

**阶段一：视图发现（View Discovery）**
- 对话按序到达，系统并非将每个片段当作孤立写入，而是累积弱信号（重复实体、稳定偏好、重复约束）。
- 每N=50个片段，LLM从近期交互轨迹中提出10个候选视图，每个候选包含名称、槽位和提取模板。

**阶段二：视图收敛（View Convergence）**
- 候选视图含噪声且冗余，先归一化精确重复指令。
- 使用与记忆索引相同的密集编码器（e5-base-v2）编码剩余候选。
- 通过**行列式点过程（DPP）** 选择K=10个紧凑多样的视图。对于每个视图vᵢ，L-ensemble核为：Lᵢⱼ = qᵢ(zᵢᵀzⱼ)qⱼ，以样式多样性为偏好。
- 每个选定种子与其前30近邻展开，由LLM总结为规范化提取指令。

**阶段三：模式引导提取（Schema-guided Extraction）**
- 对于每个对话片段，LLM在每个活动视图下评估片段，仅在证据与该视图相关时返回结构化事实，同一证据可投影到多个互补视图。
- 提取项携带结构化字段、视图标签、时间戳和出处指针。
- 查询时，对所有记忆项执行标准top-K密集检索，在token预算内合并并去重。

#### 2.4 离线记忆整合（Offline Consolidation）
- **去重**：通过哈希规范化文本，合并元数据（视图标签、出现次数、出处）。
- **图聚类**：构建无向相似图，当cos(eᵢ, eⱼ) ≥ 0.9时建边；连通分量作为候选合并批次，超大分量通过提升阈值τ（0.90→0.999）递归分割。
- **LLM裁决**：相似度仅提出候选，不强制合并。LLM根据三种情况重写：**包含**（一项包含另一项）、**互补**（非重叠事实合并）、**独立性**（相似项表达不同事实则保持分离）。保留合并后的出处信息以供审计。

#### 2.5 推理界面
查询期保持简单——检索器搜索单一统一索引，主要组织工作在索引前完成。

### 6. 论文的主要结论与发现

1. **对LoCoMo**：AutoViewMem在两种骨干下取得最佳Judge分数，并最强F1和BLEU-1。在Qwen3-8B下超越Full History的Judge，在Qwen3-14B下仅微弱落后。词汇增益在时间推理和单跳问题上最显著。
2. **对PersonaMem-32k**：AutoViewMem在两种骨干下取得最佳整体准确率，Qwen3-14B下比最强基线高5个多点，比Full History高近14个点。优势集中在需要综合而非简单回忆的能力（泛化、偏好推荐、建议、原因回忆），且随骨干增大而扩大。
3. **消融结果**：完整模型取得最佳Judge（0.837）和最低无正例率（5.14%）。去除多视图组织时Judge最差；去除整合时无正例率最高（9.83%）；移除DPP时无正例率较完整模型更高（7.03%），说明DPP作为多样性先验并非唯一增益来源。
4. **总体**：写入时基于视图的组织方式可以在无复杂查询时控制情况下提升长时程QA和个性化质量。

### 7. 优点

- **"表示优先"的视角创新**：将语义干扰问题从检索阶段前移至写入阶段，提出了不同于粒度讨论的新维度，具有较高理论启发意义。
- **自配置机制**：无需人工设计固定模式，视图从交互数据中自动涌现，并能随用户演化调整。
- **直观且实用的架构**：保持查询期简单（标准top-K检索），不增加推理复杂性，利于实际部署。
- **证据级评估设计**：考虑多视图投影可能虚高检索指标的隐患，采用出处级去重评估，体现了严谨性。
- **消融设计全面**：将结构、选择策略、后处理三者的影响拆解清楚，可解释性强。
- **案例展示生动**：有效说明了固定提示与自适应视图投影在语义理解上的本质差异。

### 8. 不足与局限

- **依赖底层LLM能力**：视图发现、提取和整合全部依赖LLM，若LLM本身能力不足或产生幻觉，会直接影响记忆质量。
- **视图收敛非完全在线**：周期性（每50个块）从缓冲轨迹运行，在快速分布漂移下可能适应缓慢。
- **离线整合存在过度合并风险**：当细微时间变化应保持项目分离时，图聚类可能过度合并，尽管出处保留降低了这种风险。
- **基准覆盖有限**：仅评估LoCoMo和PersonaMem，未涉及多参与者、跨语言、多话题或安全关键型设置。
- **关于性能成本的分析不充分**：报告了token成本对比，但仍未提供对计算时间和API调用成本的全面前瞻性定量分析。
- **无公开代码或提示词**：论文提到接受后发布，但当前无法复现验证。
- **未讨论失败模式**：例如当用户轨迹高度多样化或信息密度极低时，视图选择是否仍然有效，缺乏系统的失败模式分析。
- **忽视与检索模型的联合优化**：视图选择与嵌入模型是分离的，是否有更好的联合优化空间尚未探索。
